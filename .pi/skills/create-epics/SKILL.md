# create-epics

Носители уже есть — второго файла не заводим:

- эпики: `docs/mvp/EPICS.md`
- тикеты: `docs/mvp/TICKETS.md` (append-only, номера `T-###` занимает только реестр)
- решения, от которых зависит тикет: `blocked-on: D-xxx` в секции тикета

## Правила

1. Тикет формулируется как наблюдаемое изменение, а не как activity: «HUD не
   перекрывает нижние ряды поля при 1920×1080», а не «разобраться с HUD».
2. У тикета обязан быть носитель проверки (тест/скрипт/кадр), иначе он
   unverifiable и в работу не берётся.
3. Если тикет ждёт `⏳`-решение — строка `blocked-on: D-xxx` обязательна:
   `scripts/gdd_gate.py` краснит тикет, ссылающийся на предварительное решение без
   пометки.
4. Эпик не создаётся, пока нет хотя бы одного тикета и одной спеки, из которой он
   следует.
