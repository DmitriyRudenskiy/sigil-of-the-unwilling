# settlement-species Specification

## Purpose

Определяет виды поселенцев, формирование каравана (не более трёх видов)
и механику специализаций, на которых строится экономика поселения.

## ADDED Requirements

### Requirement: Пять видов поселенцев
Система SHALL определять пять видов (human, beaver, lizard, harpy, fox)
со статистиками: Base Resolve, порог запросов, толерантность к голоду,
интервал перелома и ключевые черты.

#### Scenario: Создание поселенца
- **WHEN** создаётся поселенец вида lizard
- **THEN** его Base Resolve равен 5, толерантность к голоду 12, интервал
  перелома 1:40
- **AND** черта "недоверчивость" влияет на стартовый Resolve при событиях

#### Scenario: Таблица видов
- **WHEN** система инициализируется
- **THEN** все 5 видов зарегистрированы со статистиками из прототипа
- **AND** вид без статистик (bat) не доступен до DLC

### Requirement: Караван не более чем из трёх видов
Поселение SHALL формироваться из каравана, содержащего не более 3
различных видов; состав каравана определяет, какие виды живут в
поселении.

#### Scenario: Караван из трёх видов
- **WHEN** караван содержит human, beaver, harpy
- **THEN** поселение принимает всех трёх видов
- **AND** дома/жильё для каждого вида доступны по своим правилам

#### Scenario: Караван из четырёх видов
- **WHEN** караван пытается включить 4-й вид
- **THEN** 4-й вид отклоняется
- **AND** поселение остаётся с 3 видами

### Requirement: Специализации поселенцев
Поселенец SHALL иметь специализацию; работа в здании своей
специализации даёт 10% шанс двойного производства и +5 Resolve
комфорта.

#### Scenario: Работа по специализации
- **WHEN** поселенец со специализацией "лес" работает в Woodcutters' Camp
- **THEN** 10% шанс двойного улова за цикл
- **AND** +5 Resolve комфорта

#### Scenario: Работа вне специализации
- **WHEN** тот же поселенец работает в Stonecutters' Camp
- **THEN** бонусы специализации не применяются
- **AND** производство идёт в базовом темпе
