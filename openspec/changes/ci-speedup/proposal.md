# Proposal: ci-speedup

## Why

CI-2 (гейт) занимает **6м41с** на зелёном ране (фактура: ран
38443410901, 2026-10-13, success). Раскладка по шагам:

| Шаг | Время | Доля |
| --- | --- | --- |
| MCP e2e (38 тестов, 1 Godot+node-сервер на тест) | 259с | 65% |
| GdUnit4 (2474 теста, один процесс) | 69с | 17% |
| Lint (gdtoolkit: venv + gdparse + gdlint) | 26с | 6% |
| Setup (apt 10с + pip 7с + npm 9с + Godot 1с + node 4с) | ~31с | 8% |
| Остальное (checkout, checkers, docs-links, artifacts) | ~15с | 4% |

Все шаги идут **последовательно в одном job** на одном раннере.
При каждом пуше/PR исполнитель ждёт полный цикл; при красном ране
(3 MCP-ретрая — до ~13 мин) ожидание удваивается. Скорость гейта
— прямой множитель скорости всего цикла разработки (ветка → пуш →
вердикт → мерж).

## What Changes

**Гейт не ослабляется: все 4 уровня, те же exit-коды, те же ретраи,
те же артефакты. Меняется только оркестрация и параллелизм.**

1. **Параллельные job'ы гейта** (сейчас 1 job, 13 последовательных
   шагов → 4 параллельных job'а):
   - `static`: checkers + lint + DOCS-LINKS (~30с);
   - `gdunit`: GdUnit4 (~70с);
   - `mcp`: MCP e2e (~260с → ~100с после п.2);
   - `verdict` (needs: все три, `if: always()`): CI-2 Stability (D-174)
     + итоговая 4-уровневая строка (D-147).
   - Wall time: 401с → ~290с (стадия 1).
2. **Параллельные MCP-воркеры** (pytest-xdist, `dist=loadfile`, 3
   воркера на 4-ядерном раннере):
   - порт 9090 — через `MCP_PORT` (env, дефолт 9090 = backward-
     compat): конвенция уже реализована на Godot-стороне
     (домашний `tools/mcp/mcp_interaction_server.gd`); единственная
     правка — вендорный `index.ts` (spawn наследует env —
     проверено);
   - conftest: воркер `gwN` → порт `9090+N`; X-дисплей общий
     (X поддерживает несколько клиентов — текущий один Xvfb
     хватает всем воркерам);
   - `run_tests.sh`: `MCP_WORKERS` (дефолт 1 = локальное поведение
     без изменений; CI: 3) → `pytest -n $MCP_WORKERS`.
   - MCP-секция: 259с → ~100с.
3. **Кэширование setup** (actions/cache, per-job):
   - `node_modules` (key: hash package-lock.json) — −9с;
   - pip-venv (key: python + список пакетов) — −7с;
   - Godot-бинарь (key: версия) — −1с.

**Цель: wall time зелёного рана ≤ 3 мин (с 6м41с, ≥2.2×);
красный ран (3 MCP-ретрая) — ≤ ~8 мин вместо ~13.**

## Capabilities

### New Capabilities
- `ci-pipeline`: оркестрация гейта CI-2 (параллельные job'ы,
  маппинг вердикта, инвариантность гейт-семантики) и его
  производительность (параллельные MCP-воркеры, кэши setup)

## Impact

- **Workflow**: `.github/workflows/ci2.yml` (пересборка: 1 job → 4)
- **Тест-инфраструктура**: `game/run_tests.sh` (MCP_WORKERS),
  `game/tests/mcp/conftest.py` (воркер-осведомлённость: порт),
  venv-состав (+pytest-xdist)
- **Вендорный аддон** `game/addons/godot-mcp`: 1 аддитивная правка
  (`index.ts`: порт из `MCP_PORT`, дефолт 9090); прецедент локальных
  правок есть (stdin-ignore фикс, index.ts:3693); build/ gitignored
- **НЕ меняется**: тесты (38 MCP + 2474 GdUnit), exit-коды, ретраи
  CI-1(12), артефакты, check_docs_links, ci2_checkers, политика
  гейта (D-144/D-147/D-148), локальный запуск (MCP_WORKERS=1)
- **Зависимости**: GitHub-hosted runners (4 ядра, 3 job'а в
  параллель — бесплатно, без очереди); Xvfb (уже есть)
