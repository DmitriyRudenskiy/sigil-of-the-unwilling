# Design: ci-speedup

## Context

- CI-2 = единый job `gate` (13 последовательных шагов), ubuntu-latest
  (4 ядра), timeout 45 мин. Фактический зелёный ран: 6м41с
  (38443410901): MCP e2e 259с (65%), GdUnit4 69с, lint 26с,
  setup ~31с.
- MCP e2e: `conftest.py` — фикстура `mcp` function-scoped: каждый
  тест = новый node-сервер (`build/index.js`) + новый Godot
  (`-d --path`, живой, не headless) + `run_scene` + teardown.
  38 тестов × ~6.8с ≈ 259с.
- Порт 9090: на Godot-стороне **домашний** сервер
  `tools/mcp/mcp_interaction_server.gd` (измен world-controller-
  decoupling, commit adf523c0) уже читает `MCP_PORT` (цепочка: env →
  ProjectSettings `mcp/port` → 9090) + EADDRINUSE-диагностика.
  Autoload в project.godot указывает на него (НЕ на вендорный
  root-скрипт — тот мёртвый файл, не грузится). На node-стороне
  порт захардкожен: `index.ts:123` (`INTERACTION_PORT = 9090`).
  Spawn игры (`index.ts:3776`) без явного `env` → наследует
  окружение node-сервера → env доходит до Godot.
  (Найдено при реализации: первая итерация правила вендорный .gd —
  не тот файл; переделано на MCP_PORT.)
- `run_tests.sh`: один Xvfb (скан :97 → :91–:98), один pytest
  (`--timeout=900 --tb=short --durations=25`), cleanup-trap по
  PID-снимкам (масштабируется на N процессов), леджер-равенство
  (collected == executed).
- Политика гейта (нормы владельца): D-144 (main только через
  зелёный гейт), D-147 (4-уровневый отчёт), D-148 (baseline-строка),
  CI-1(12) (ретраи на раннер-окружение), D-166 (красный раннер =
  класс окружения), D-174 (stability-счётчик, мониторинг).
- Прецедент локальных правок вендорного аддона godot-mcp: stdin-ignore
  фикс (index.ts:3693, бисекция 2026-07).

## Goals / Non-Goals

**Goals:**
- Wall time зелёного рана ≤ 3 мин (с 6м41с).
- Красный ран (3 MCP-ретрая) ≤ ~8 мин (с ~13).
- Гейт-семантика инвариантна: 4 уровня, exit-коды, ретраи,
  артефакты, concurrency.
- Локальный прогон (`run_tests.sh` без env) — byte-идентичное
  поведение (1 воркер, порт 9090).

**Non-Goals:**
- Удаление/ослабление тестов, расширение quarantine.
- Шардирование GdUnit4 (стадия 3 — только если стадий 1+2 не
  хватит до цели; отдельное решение).
- Кэширование apt-пакетов (10с, низкая отдача/сложность).
- Self-hosted раннеры (инфраструктурное решение владельца, вне
  change).
- Изменение MCP-коридора (зелёный = ≤250с суммарно — норма
  владельца; параллельный прогон уменьшает и его, но порог не
  трогаем).

## Decisions

### D1. Четыре job'а, не два
`static` (checkers+lint+docs-links), `gdunit`, `mcp` — параллельно;
`verdict` — финальный (needs: все три, `if: always()`) несёт
CI-2 Stability (D-174) и 4-уровневую строку (D-147). Альтернатива
(2 job'а: fast/slow) хуже: `static` (30с) не должен ждать `gdunit`
(70с) в одном job'е; 4 job'а дают максимальный параллелизм и
максимально читаемый jobs-API (уровень = job-конклюжон).
`verdict` обязателен: stability-счётчик и итоговая строка не должны
зависеть от конкретного уровня; `if: always()` — работает и на
красном.

### D2. pytest-xdist `dist=loadfile`, 3 воркера
`loadfile` — каждый тестовый файл целиком на одном воркере: файлы
не делят состояние (у каждого теста и так свой Godot), режим
максимально предсказуемый. 3 воркера на 4 ядрах: 1 ядро — запас
под флейки (D-166-класс: конкуренция за CPU — главный риск
параллелизации). 4 воркера — отклонено: запас нулевой, флейк-риск
максимальный при выигрыше ~15с. Ретраи CI-1(12) сохраняются на
весь прогон (не на воркера) — семантика не меняется.

### D3. Порт из env `MCP_PORT`, X-дисплей общий
Порт — единственный ресурс, который реально конфликтует.
Конвенция — `MCP_PORT` (уже реализована на Godot-стороне в
домашнем `tools/mcp/mcp_interaction_server.gd`): единственная
правка — вендорный `index.ts` (`Number(process.env.MCP_PORT || 9090)`);
Godot-сторона не трогается. Spawn наследует env (проверено
index.ts:3776) → один env-канал на обе стороны. X-дисплей общий:
X-сервер по дизайну обслуживает нескольких клиентов; 3 Godot-окна
на одном Xvfb — штатно. Снимает потребность в N Xvfb и в
перестройке скана дисплеев.

### D4. MCP_WORKERS в run_tests.sh, не в workflow
Число воркеров — параметр прогона тестов, а не CI-конфигурации:
`run_tests.sh` читает `MCP_WORKERS` (дефолт 1), при >1 добавляет
`-n $MCP_WORKERS`. Workflow задаёт `MCP_WORKERS=3` env'ом на
`mcp`-job. Локально и на macOS-фолбэках (системный python3)
поведение не меняется; при отсутствии pytest-xdist в venv —
явная строка (уровень не молчит, норма MCP-секции).

### D5. Кэши: node_modules, pip-venv, Godot-бинарь
`actions/cache` с детерминированными key (hash lock-файла /
python-версия+пакеты / версия Godot). Промашка безопасна (fallback
на установку как раньше). apt не кэшируем (10с, dpkg-кэш хрупкий).

### D6. Вендорная правка — аддитивная, с дефолтом
Одна правка в `addons/godot-mcp/src/index.ts` (чтение `MCP_PORT`
с дефолтом 9090) — без env поведение byte-идентично. build/ —
gitignored (CI собирает сама). Vendor-drift фиксируется в
сообщении коммита + code-комментарии (прецедент: stdin-ignore,
index.ts:3693); docs/CHANGELOG.md — вне (его скоуп — docs/).

## Risks

| Риск | Класс | Митигация |
| --- | --- | --- |
| Флейки от CPU-конкуренции 3 Godot'ов | D-166 (окружение) | 3 воркера (запас ядро); ретраи CI-1(12); D-174-счётчик поймает серию; откат = `MCP_WORKERS=2` одной строкой |
| Порт-гонки между воркерами | код | уникальные порты 9090+i; cleanup-trap уже по PID-снимкам (масштабируется) |
| Vendor-drift godot-mcp (index.ts) | внешний | аддитивная правка с дефолтом; фиксация в коммите+комментарии |
| Промашка/битость кэша | окружение | fallback-установка; key детерминированы |
| `verdict`-job на красном ране | код | `if: always()`; test: искусственный красный ран (проверка при внедрении) |
| Леджер-равенство под xdist | код | xdist суммирует collected/executed в итоговом выводе — проверить на первом ране (строка `collected N items` + леджер-проверка run_tests.sh) |

## Measurement (приёмка)

1. Три последовательных зелёных рана main после мержа: wall time
   каждого (jobs API) — требование ≤ 3 мин (D-148: baseline-строка
   в отчёте: было 6м41с → стало X).
2. Искусственный красный (тест-ветка с падающим MCP-тестом):
   ретраи ×3 отработали, `verdict` отработал, stability-строка на
   месте, wall ≤ ~8 мин.
3. Локальный `run_tests.sh` без env: 38 тестов, порт 9090, один
   Godot на тест (diff поведения = пусто).
4. GdUnit4/MCP-счётчики тестов не изменились (2474 / 38).
