# balance-report Specification

## Purpose

Определяет отчёт баланса по матрице автоигры: сравнение метрик внутри
ролей и внутри классов, пометка аномалий и передача данных AutoBalancer.

## ADDED Requirements

### Requirement: Сравнение внутри роли
Отчёт SHALL сравнивать метрики классов внутри каждой роли: медиана
роли, отклонение каждого класса от медианы; класс, отстающий от
медианы роли больше чем на N%, помечается аномалией.

#### Scenario: Слабый класс в роли
- **WHEN** класс X отстаёт от медианы роли на >N%
- **THEN** клетка (X, роль) помечена "weak"
- **AND** в отчёте указано отклонение

#### Scenario: Сильный класс в роли
- **WHEN** класс X опережает медиану роли на >N%
- **THEN** клетка (X, роль) помечена "strong"
- **AND** в отчёте указано отклонение

### Requirement: Сравнение внутри класса
Отчёт SHALL сравнивать роли внутри каждого класса: класс, чья худшая
роль отстаёт от его лучшей роли больше чем на M%, помечается как
"однопрофильный" (специализация) — это информация, не баг.

#### Scenario: Универсал
- **WHEN** все роли класса в пределах M% от лучшей
- **THEN** класс помечен "versatile"

#### Scenario: Специалист
- **WHEN** худшая роль класса отстаёт от лучшей на >M%
- **THEN** класс помечен "specialist" с указанием лучшей/худшей роли

### Requirement: Вход для AutoBalancer
Отчёт SHALL быть машиночитаемым входом для AutoBalancer: структура
отчёта позволяет подобрать корректировки (бонусы слабым классам/ролям)
без ручного разбора.

#### Scenario: Автокорректировка
- **WHEN** AutoBalancer читает отчёт матрицы
- **THEN** для клеток "weak" предлагаются корректировки (бонусы)
- **AND** корректировки не трогают клетки "versatile" без аномалий

#### Scenario: Пороги настраиваемы
- **WHEN** порог N% (аномалия) или M% (специализация) меняется
- **THEN** отчёт пересчитывается с новыми порогами
- **AND** пороги хранятся в конфиге (не хардкод)
