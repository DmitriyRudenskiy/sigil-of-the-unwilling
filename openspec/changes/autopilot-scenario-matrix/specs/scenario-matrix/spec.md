# scenario-matrix Specification

## Purpose

Определяет драйвер матрицы автоигры 5 ролей × 11 классов:
детерминированные прогоны каждого сценария, сбор метрик и JSON-отчёт.

## ADDED Requirements

### Requirement: Матрица 5×11
Драйвер SHALL гонять все 55 сценариев (5 ролей × 11 классов) в
headless-режиме через MCP; каждый сценарий — отдельный детерминированный
прогон с фиксированным seed.

#### Scenario: Полный прогон матрицы
- **WHEN** запущен драйвер матрицы
- **THEN** гонятся все 55 сценариев
- **AND** по каждому сценарию собраны метрики роли

#### Scenario: Детерминизм
- **WHEN** один и тот же сценарий (класс, роль, seed) гонится дважды
- **THEN** метрики обоих прогонов идентичны

### Requirement: Выборочный прогон
Драйвер SHALL поддерживать прогон подмножества: по одной роли, по
одному классу или по одной клетке (класс, роль); по умолчанию в CI —
выборка (не все 55), полная матрица — по маркеру.

#### Scenario: Одна роль
- **WHEN** запущен прогон роли Собиратель
- **THEN** гонятся только 11 сценариев (Собиратель × 11 классов)
- **AND** отчёт содержит только эту роль

#### Scenario: Одна клетка
- **WHEN** запущен прогон (wizard, Торговец)
- **THEN** гонится один сценарий
- **AND** отчёт содержит одну клетку

### Requirement: JSON-отчёт
По итогам прогона драйвер SHALL писать JSON-отчёт: по каждой клетке
(класс, роль) — метрики роли, выживание, ходы, seed, время прогона;
отчёт доступен для AutoBalancer.

#### Scenario: Формат отчёта
- **WHEN** прогон завершён
- **THEN** JSON содержит массив клеток {class, role, metrics, survived,
  turns, seed}
- **AND** отчёт пишется в файл (путь в выводе)

#### Scenario: Сбой сценария
- **WHEN** сценарий упал с ошибкой (не баланс, а краш)
- **THEN** клетка помечена "error" с причиной
- **AND** остальные сценарии продолжают гоняться
