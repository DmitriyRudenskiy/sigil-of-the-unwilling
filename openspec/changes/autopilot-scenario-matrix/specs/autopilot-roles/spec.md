# autopilot-roles Specification

## Purpose

Определяет пять ролей-сценариев автоигры: цель роли, политика
автопайлота (как он играет) и метрика успеха, по которой измеряется
сбалансированность класса в этой роли.

## ADDED Requirements

### Requirement: Роль Собиратель
Сценарий Собирателя SHALL ставить целью накопить X единиц редких
ресурсов за Y дней; автопайлот добывает ресурсы, выживает и крафтит;
метрика — ресурсы/день и факт выживания.

#### Scenario: Прогон Собирателя
- **WHEN** гонится сценарий Собирателя для класса druid
- **THEN** автопайлот добывает редкие ресурсы, избегает/отбивается от
  хищников
- **AND** по итогам известен: кол-во редких ресурсов, дни, выжил ли

#### Scenario: Разные классы в роли
- **WHEN** гонятся Собиратели для всех 11 классов
- **THEN** у каждого класса своя метрика ресурсов/день
- **AND** различия метрик — данные для балансировки

### Requirement: Роль Путешественник
Сценарий Путешественника SHALL ставить целью пересечь карту из точки A
в точку B через опасные биомы; метрика — ходы до цели и потери HP.

#### Scenario: Прогон Путешественника
- **WHEN** гонится сценарий Путешественника для класса monk
- **THEN** автопайлот движется A→B, уклоняется от патрулей/встреч
- **AND** по итогам известны: ходы до цели, остаток HP, выжил ли

#### Scenario: Невозможный путь
- **WHEN** герой умирает в пути
- **THEN** метрика фиксирует "не дошёл" с ходом смерти
- **AND** сценарий завершается (не виснет)

### Requirement: Роль Городостроитель
Сценарий Городостроителя SHALL ставить целью поселение с населением X
и уровнем защиты Y; метрика — население и уровень защиты за N ходов.

#### Scenario: Прогон Городостроителя
- **WHEN** гонится сценарий Городостроителя для класса paladin
- **THEN** автопайлот развивает поселение (стройка, найм, защита)
- **AND** по итогам известны: население, уровень защиты, ходы

#### Scenario: Поселение не интегрировано с игровым миром
- **WHEN** существует автономная система settlement-system, но она не
  подключена к мировому сценарию, герою и общим ресурсам
- **THEN** основная матрица продолжает использовать City fallback
- **AND** автономная Settlement-симуляция не засчитывается как матричная
  интеграция Городостроителя
- **AND** возможное подключение выполняется отдельным адаптером/change

#### Scenario: Поселение недоступно
- **WHEN** система поселений (settlement-system) не готова к интеграции
  с миром, героем и общими ресурсами
- **THEN** роль использует город-точку (City): постройка зданий,
  уровень города
- **AND** метрики остаются сопоставимыми внутри роли

### Requirement: Роль Торговец
Сценарий Торговца SHALL ставить целью превратить стартовый капитал в X
золота через торговлю; метрика — золото к концу и маржа.

#### Scenario: Прогон Торговца
- **WHEN** гонится сценарий Торговца для класса rogue
- **THEN** автопайлот скупает/продаёт ресурсы, торгует
- **AND** по итогам известны: финальное золото, кол-во сделок, маржа

#### Scenario: Капитал утрачен
- **WHEN** золото героя падает до 0 и нет ресурсов
- **THEN** метрика фиксирует крах торговли
- **AND** сценарий завершается

### Requirement: Роль Приключенец
Сценарий Приключенца SHALL ставить целью зачистить логово босса /
выполнить квест гильдии; метрика — победа, ходы, потери.

#### Scenario: Прогон Приключенца
- **WHEN** гонится сценарий Приключенца для класса wizard
- **THEN** автопайлот идёт к логову, сражается, добивает босса
- **AND** по итогам известны: победа/поражение, ходы, остаток HP

#### Scenario: Боевой баланс
- **WHEN** гонятся Приключенцы для всех 11 классов
- **THEN** каждый класс проверяется в стандартном бою
- **AND** победы/поражения — данные для боевого баланса
