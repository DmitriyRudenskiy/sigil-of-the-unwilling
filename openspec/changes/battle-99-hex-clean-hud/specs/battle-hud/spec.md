## MODIFIED Requirements

### Requirement: Художественное поле боя

Поле боя SHALL использовать утверждённый художественный тайлсет с различимыми
гексагональными ячейками, состоянием «выбранная ячейка» и «ячейка недоступна».
Задний план поля SHALL выбираться по типу местности гекса, на котором стоит
обороняющийся (враг): тип местности читается из боевого состояния, а не задаётся
сценой статически. Местность, для которой утверждённого фона нет, обязана давать
существующий нейтральный фон без пустого кадра.

#### Scenario: Выбор ячейки

- **WHEN** игрок наводит курсор на доступную ячейку перемещения
- **THEN** ячейка подсвечена
- **AND** недоступные ячейки отличаются от доступных без опоры только на цвет

#### Scenario: Снег под ногами у врага

- **WHEN** бой начинается на местности, отображаемой снежным кадром
- **THEN** задний план — снежный кадр, гексы читаются поверх него

#### Scenario: Болото под ногами у врага

- **WHEN** бой начинается на болотной местности
- **THEN** задний план — болотный кадр, отличный от снежного

#### Scenario: Местность без утверждённого фона

- **WHEN** обороняющийся стоит на местности, для которой утверждённый фон не задан
- **THEN** показан нейтральный фон, кадр боя не пустой и не чёрный

## REMOVED Requirements

### Requirement: Таймер хода

**Reason:** лимит хода по времени (30 с на игроковый ход, D-214 §3) снят
владельцем 2026-10-27 — автопропуск хода без видимой причины читается как баг,
а виджет-кольцо, его показывавший, убран вместе с верхними значками.

**Migration:** ход игрока не ограничивается ничем; завершение хода остаётся
только явным действием игрока («Пропустить», атака, перемещение) или переходом
хода, который решает исполнитель боя. Модельные часы хода
(`turn_time_limit`/`turn_time_left`/`arm_turn_timer`/`disarm_turn_timer`/
`tick_turn_timer`) удаляются вместе с автопропуском.

### Requirement: Очередь хода

**Reason:** верхний ряд значков юнитов убран владельцем 2026-10-27 — он спорил с
полем за кадр и дублировал информацию, доступную из карточки активного юнита и
подсветки гекса.

**Migration:** очерёдность ходов остаётся правилом модели
(`tactical-combat` — «Инициатива определяет очерёдность ходов», `turn-battle-core`
— «Очередь хода по инициативе»); из интерфейса уходит только её отрисовка.
Активный юнит по-прежнему различим на поле.
