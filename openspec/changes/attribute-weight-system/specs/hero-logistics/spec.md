## MODIFIED Requirements

### Requirement: Рюкзак героя с общим лимитом
Герой SHALL иметь рюкзак для ресурсов мира с общим **весовым** лимитом
(вместо фиксированного 12 единиц). Каждый ресурс имеет вес за единицу
(см. weight-carry-system); занятый вес — сумма `количество × вес_единицы`
по всем типам. Лимит определяется выносливостью героя. Ресурсы
добавляются типами и количеством; превышение лимита по весу
ограничивает добавление.

#### Scenario: Ресурс помещается
- **WHEN** герой с незанятым рюкзаком собирает узел, чей вес добычи не
  превышает лимит
- **THEN** вся добыча кладётся в рюкзак

#### Scenario: Рюкзак переполнен по весу
- **WHEN** герой с почти полным рюкзаком по весу собирает узел
- **THEN** в рюкзак кладётся только та часть добычи, что помещается
  по весу
- **AND** игрок получает обратную связь о переполнении
- **AND** узел на карте считается собранным (не остаётся «обречённым»)

#### Scenario: Лимит виден
- **WHEN** открыт интерфейс героя
- **THEN** видны текущий занятый вес и весовой лимит рюкзака

### Requirement: Расширение провозной способности
Система SHALL позволять расширять весовой лимит рюкзака; базовое
расширение покупается в городе, имеющем рынок. Расширение добавляет
фиксированный **вес**, а не количество единиц.

#### Scenario: Телега рынка
- **WHEN** герой в городе со строительным рынком покупает расширение провоза
- **THEN** весовой лимит рюкзака увеличивается на фиксированную величину
- **AND** цена расширения видна перед покупкой

#### Scenario: Телега помогает нести тяжёлое
- **WHEN** герой с телегой и без телеги собирают одинаковые материалы
- **THEN** с телегой в рюкзак помещается больше по весу
