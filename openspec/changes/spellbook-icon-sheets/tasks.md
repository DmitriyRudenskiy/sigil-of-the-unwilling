## 5. Implement

Файлов пять, а не шесть: четыре конвейерных плюс `check.py` вместо pytest-сьютa.
Геометрия кропа — это геометрия бокса (`detect.square`), сборка листа и аудит —
вызовы в одном месте (`run.py`); отдельные `crop.py` и `sheet.py` под одну
функцию каждый не заведены.

- [x] `detect.py` — SAM → 12 боксов по ячейкам 4×3, квадрат по центру с клампом
      в границы листа, имя `<stem>_<01..12>.png`, порядок «слева направо, сверху
      вниз»; при <12 заполненных ячейках — фолбэк-сетка 4×3.
- [x] `embed.py` — та же модель и тот же API, что у `dataset_prep`
      (`get_image_features` + L2), кэш `embeddings.npz` по md5-слепку списка
      кропов. `--min_size` не передаётся: фильтр размера живёт в монолите
      `run_pipeline`, которого мы избегаем, — у инструмента своего порога нет.
- [x] `pick.py` — итерации родного отбора по 9 на остатке пула (grid search
      `k_offset −3..+3` × 5 режимов квот, выбор по LRS/DS/coverage), добор до 9
      самым далёким кандидатом, антидубль (порог `--max-intra-sim` 0.80 + запрет
      «та же книга/та же ячейка») с заменой самым далёким неиспользованным,
      `residual` при остатке < 9.
- [x] `run.py` — конвейер целиком, `report.md` / `detections.json` / `sheets.json`,
      md5 каждого листа в отчёте (вместо `INDEX.md`: карта пикселей не заведена,
      пиксели не в git, контроль — md5 в отчёте и `check.py`), флаги `--yes`
      (шлюз «сверь прототип»), `--max-intra-sim`, `--seed`, `--cell`, `--pad`,
      `--min-frac`, `--prompt`, `--limit`, `--sam-device`, `--embed-device`.
      `--dry-run` отдельным флагом не стал: его роль делает вызов без `--yes`.
- [x] Фолбэк-сетка — фиксированные 4×3; флаги `-inset`/`--split` прототипа-сетки
      не перенесены: на 22/22 листов сработала SAM-ветка, фолбэков ноль.
- [x] Самопроверки — `__main__`-блоки с `assert` в модулях (`python3
      tools/spellbook_sheets/detect.py|embed.py|pick.py`): квадрат из бокса +
      кламп, разрезы сетки, отбор даёт 9 различных, антидубль меняет ровно один
      элемент и умеет остаться без замены, запрет пары «та же ячейка», порядок
      листов. pytest не заведён: проверяемого кода меньше, чем было бы фикстур.
      Сверка готового прогона — `check.py` (секция 6).
