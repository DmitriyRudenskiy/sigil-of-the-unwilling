# Height and Elevation Specification

## ADDED Requirements

### Requirement: Дискретные уровни высоты
Поле боя SHALL использовать дискретные уровни высот (по 5-футовым инкрементам): 0 — земля, 1–2 — низкие возвышенности, 3 — второй этаж/высокие стены, 4 — башни/обрывы, 5+ — экстремальные высоты и полёт.

#### Scenario: Высота клетки
- **WHEN** клетка имеет elevation = 2
- **THEN** её высота = 10 футов
- **AND** юнит на ней получает статус "высшая точка" относительно соседей с elevation < 2

### Requirement: Преимущество высокой точки
Атака с более высокой клетки SHALL давать бонус к броску: дальнобойные атаки с разницей >= 1 уровня получают +бонус (по таблице), атака снизу вверх — штраф; ближний бой с разницей 1 уровня бонуса не даёт.

#### Scenario: Дальнобойная атака сверху
- **WHEN** стрелок на elevation 2 бьёт по цели на elevation 0
- **THEN** бросок атаки получает бонус высокой точки

#### Scenario: Атака снизу вверх
- **WHEN** юнит на elevation 0 атакует дальнобойным оружием цель на elevation 2
- **THEN** бросок атаки получает штраф

### Requirement: Линия видимости с учётом высоты
Определение линии видимости SHALL использовать алгоритм Брезенхэма с проверкой высоты: клетка-препятствие перекрывает вид, если её elevation выше прямой между атакующим и целью.

#### Scenario: Стена перекрывает вид
- **WHEN** между стрелком и целью есть клетка с elevation выше линии между ними
- **THEN** линия видимости отсутствует
- **AND** дальнобойная атака невозможна

### Requirement: Укрытие
Юнит за укрытием SHALL получать бонус к AC против атак через укрытие; полное укрытие делает юнит немишенью.

#### Scenario: Частичное укрытие
- **WHEN** юнит стоит за стеной на 1 уровень ниже линии огня
- **THEN** его AC увеличивается на величину частичного укрытия
