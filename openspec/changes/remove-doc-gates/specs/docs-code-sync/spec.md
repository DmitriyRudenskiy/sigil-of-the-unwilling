## REMOVED Requirements

### Requirement: Divergence check is a machine gate

**Reason**: Носитель `scripts/audit_docs_vs_code.py` удалён вместе с
`scripts/doc_gates.sh` — единственным его исполнителем. Ни `game/run_tests.sh`, ни
прогон CI-2 его не звали, поэтому «расхождение доков с кодом красное» было
вердиктом только в момент ручного запуска (смена `remove-doc-gates`).

**Migration**: Расхождения «доки ↔ код» становится предметом ревью диффа в треде:
правило «док обязан называть существующий носитель» остаётся в `docs-code-sync`
как договорённость, машинного замера у него больше нет. Возврат — новой сменой,
обязанной одновременно завести исполнителя (п. «Проверка без исполнителя»
capability `verification-naming`), а не только скрипт.
