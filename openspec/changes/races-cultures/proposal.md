# Proposal

## Why

GDD 02-mechanics §3.6 описывает расы и культуры: раса D&D-персонажа = культура (маппинг), одна таблица расовых коэффициентов для зданий и персонажей, race_affinity (6.5), особые выходы (6.6), гибриды (9.3), водные расы = флаг происхождения (K-A6). Реализовано частично: каталог 7★ рас в `mvp_catalog.json` (K-M5), playable slice 3 (люди/полуорки/эльфы — K-M5-правка, владелец 2026-10-04). Не реализовано: race_affinity зданий, особые выходы, гибридная культурная напряжённость, водные расы как флаг. Main specs `settlement-species` (7 видов) — pre-pivot, superseded (виды → расы, K-A6).

## What Changes

- Фиксирует: раса D&D-персонажа = культура (маппинг); одна таблица расовых коэффициентов для зданий и персонажей (02e3 модификаторы).
- Фиксирует MVP: playable slice 3 культуры (люди/полуорки/эльфы, K-M5-правка + решение владельца 2026-10-04); каталог 7★ (K-M5); каталог 54 рас — 1.0.
- Фиксирует race_affinity (6.5): бонус здания от культуры города; персонаж не меняет расу города (EC2).
- Фиксирует особые выходы (6.6): при 100% одной культуры — безусловные; при гибриде — порог 70% [ПРЕДЛОЖЕНИЕ].
- Фиксирует гибриды (9.3): культурная напряжённость — штраф за конфликтные пары, лечится сервисами (таверна/храм).
- Фиксирует: водные расы = флаг происхождения (K-A6), не отдельная экономика.

## Capabilities

### New Capabilities
- `races-cultures`: расы/культуры, affinity, особые выходы, гибриды, водные расы.

### Modified Capabilities
- None.

## Deduplication and status (v4)

- **Дубликаты (main specs):** `settlement-species` (7 видов, pre-pivot) — **superseded** K-A6 (виды → расы; «культуры» = термин-дыра, в каноне расы и группы); `settlement-reputation`/`settlement-resolve` — pre-pivot поселения, не дублируются.
- **Дубликаты (archive):** `2026-09-17-settlement-system` (виды) — pre-pivot, не дублируется.
- **Dead tasks (реализовано):** каталог 7★ рас (`mvp_catalog.json`, K-M5), playable slice 3 — помечены `[x]`.
- **Пересечения:** `pregame-flow` (конструктор: выбор расы), `party-characters` (расовые модификаторы атрибутов), `city-construction-districts` (здания и культура города).

## Impact

- Код: `mvp_catalog.json` (расы, модификаторы), `settlement_processor.gd` (race_affinity, особые выходы), `population_system.gd` (гибридная напряжённость).
- Не затрагивает: каталог 54 рас (1.0), водную экономику (K-A6: флаг, не экономика).

## Contradictions

- **C-14 (терминология, docs vs canon):** GDD использует «культуры» (MVP-scope: «1 культура (люди) аннулирована»), но K-A6: «в каноне расы и группы, не культуры» — термин-дыра. В OpenSpec-спеке: «культура» = раса D&D-персонажа (маппинг 02-mechanics §3.6); «группа» = культурная группа города (02g). Синк терминологии — docs-задача.
- **C-15 (данные, docs vs code):** playable slice 3 (люди/полуорки/эльфы) — K-M5-правка + решение владельца 2026-10-04; `mvp_catalog.json` содержит 7 рас (gnomes, halflings, tieflings, elves, humans, dwarves, half_orcs) — playable-маска не эксплицитна в данных. Маска — в `pregame-flow` (конструктор).
