# Proposal: team-romance-roleplay

## Why

У героя есть команда — последователи (Follower: раса, путь, архетип, черты, наследники), но никаких отношений между ними нет: последователь — это статичный объект для наследования. Нет пола ни у героя (поле `sex` теряется после создания персонажа), ни у последователей; нет диалогов, привязанности, романтики, конфликтов. Это упущенный пласт ролевого отыгрыша: CRPG-ядро (харизма, пути, расы) уже есть, не хватает системы межличностных отношений в команде.

## What Changes

- **Пол персонажей**: `Follower.gender` (male/female), пол героя сохраняется в `HeroStatsComponent` (сейчас `HeroBuildProfile.sex` не копируется в `apply_build`). **BREAKING**: формат сейва последователей расширяется (назад-совместимо: дефолт male).
- **Система отношений** (`RelationshipSystem`): матрица связей герой↔последователь и последователь↔последователь. Два слоя:
  - **Социальный**: дружба/неполадки, доверие (trust), конфликты, ревность
  - **Романтический**: флирт → отношения → помолвка/брак → преданность (devotion); гетеро-/гомо-/би-ориентация как скрытая черта
- **Диалоги с отыгрышем** (`TeamDialogSystem`): ветвящиеся диалоги с выбором, реплики фильтруются по полу/расе/классу(пути)/чертам/состоянию отношений; каждый выбор имеет последствия (отношения/статы/события). Контент-тиры (pg/adult) с гейтом по настройкам.
- **Пассивные эффекты**: отношения влияют на боевой дух команды, верность (предательство при низком доверии), приоритет в наследовании, моральные события (сцены-триггеры: ревность, примирение, предательство).
- **UI**: панель отношений в HeroStatusPanel (список команды, статусы связей, кнопка диалога), диалоговое окно (реплики + варианты выбора + индикатор последствий), контент-настройка в Settings.
- **Детерминизм**: все роллы — через `RandomNumberGenerator` с seed сессии; отчёты/тесты воспроизводимы.

## Capabilities

### New Capabilities
- `team-relationships`: модель отношений в команде (социальный + романтический слои, ориентация, ревность, конфликты, пассивные эффекты: боевой дух/верность/наследование)
- `team-dialogs`: диалоги с последователями (ветвления, фильтры реплик по полу/расе/пути/чертам/состоянию, последствия выборов, контент-тиры)

### Modified Capabilities
- `hero-identity`: пол героя становится частью сохранённой идентичности (сейчас `sex` из профиля создания не сохраняется в компоненте)

## Impact

- `scripts/entities/Follower.gd` — поле `gender`, сериализация
- `scripts/entities/FollowerSystem.gd` — генерация пола при рекруте (50/50, seed)
- `scripts/entities/hero/components/HeroStatsComponent.gd` — сохранение `sex` в `apply_build`
- `scripts/systems/RelationshipSystem.gd` — новая (матрица связей, тики, ревность, эффекты)
- `scripts/systems/TeamDialogSystem.gd` + `assets/data/team_dialogs/` — новая (диалоги, реплики, последствия)
- `scripts/world/SuccessionController.gd` — бонус наследования для spouse/высокого доверия
- `scripts/systems/BattleTurnExecutor.gd` или боевой бонус героя — боевой дух от отношений
- `scripts/ui/HeroStatusPanel.gd` — вкладка «Команда» с отношениями
- `scripts/ui/TeamDialogScreen.gd` — новое окно диалогов
- `scripts/constants/GameNumbers*.gd` — пороги отношений, частота событий
- `GameEventBus` — события: relationship_changed, romance_stage, betrayal, marriage
- Тесты: GdUnit4 (логика отношений/диалогов, детерминизм) + MCP e2e (рекрут → диалог → брак → эффект)
