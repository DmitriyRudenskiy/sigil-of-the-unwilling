## 6. `T-148`: декомпозиция (счёт 2026-10-21, инвентарь по `game/scenes/**/*.tscn`)

Общий счёт: **154** сценевых переопределения = `colors` 62 (`font_color` 59 +
`font_shadow_color` 3) + `fonts` 3 + `constants` 89. Первый подсрез — `font_color`
(59), он же самый большой.

Два факта, которые меняют план тикета («почти всё лечится одним `Label/font_color`»):

1. **В теме нет ни `Label/colors/font_color`, ни `Button/colors/font_color`.**
   Обычный `Label` сегодня рисуется дефолтным белым Godot, обычный `Button` —
   дефолтным серым (0.88). Отсюда и «много мёртвых» переопределений: 8 Label уже
   перекрашены в белый, то есть в то, что и так даёт дефолт.
2. **В игре две палитры.** Роли темы (`LabelSecondary`, `LabelStrong`, …) несут
   канонный hex из `docs/17-ui-style-guide.md` §1.2 (`C_TEXT #e8d5a8` =
   0.9098, 0.8353, 0.6588). Сценевые переопределения несут значения **кодовой**
   палитры `game/scripts/theme/theme_config.gd` (`C_TEXT_PRIMARY` = 0.95, 0.89,
   0.72 и т.д.). Это **не один и тот же цвет**: перенос «в роль» с совпадением по
   имени даёт визуальную дельту. Сведение палитр — решение владельца, не механика.
