# Design

> **Статус (2026-10-21, post-verdict):** C-3 (сетка в боевом экране) и Blink закрыты вердиктами владельца — **D-217** (сетки/координат нет) и **D-222** (позиционные зоны не вводят, Blink — deferred вне MVP). Значит, все места ниже, где blink/сетка/координаты/позиционные зоны описаны как активная цель MVP, — **устарели**; бой остаётся абстрактной лестницей, босс — по D-218 (мощный удар + ярость, без зон). Активный канон — в `specs/dnd-battle-ladder/spec.md` и `tasks.md`.

## Context

`campaign_battle.gd` (T-050-слой) реализует: `make_combatant`/`make_recruit`, `initiative_first` (mod DEX, тай-брейк CON, id), `_state_margin` (перевес), `_strike` (урон), `_step_down` (зона вниз), `_death_saves` (mod CON, 3/3), `resolve`, `_finalize`; `MAX_ROUNDS = 20` (D-128: ничья), `FATE_PENALTY_DIVISOR = 1.25` («Судьба следит» 02d §4.2, привязка к лестнице — Ф3, interim: margin/1,25), `DEATH_SAVES_NEEDED = 3`. `battle_rules.gd` — зоны/урон. Не реализовано: авто-режим, состояния (prone/высотный), blink, местность, бином «Фланг», AI врага (greedy + босс), карточка врага M1.

## Goals / Non-Goals

**Goals:** формализовать канон §3.4/02d/02b; авто-режим (тот же движок, детерминированный AI); состояния prone/высотный + blink (K-M7); местность 3 типа (C3) как абстрактные модификаторы; бином «Фланг» (единственный MVP); AI врага (Y3) + босс хода 21; карточка врага M1; отчёт один для обоих режимов.

**Non-Goals:** сетка/координаты (C-3 — до вердикта владельца), «преимущество/неудача» (переименовано в «сдвиг ±2», имя из отклонённого кубикового слоя), состояния frightened/stunned как каталог (K-M11: расширение каталогом — 1.0; в MVP — «frightened» только как триггер отступления авто-режима), «мораль-формула» (аннулирована навсегда, K-M11), петля мастерства (1.0).

## Decisions

- **Чистая лестница, без hex** (реализация + Q-M47): координат нет; местность = абстрактные модификаторы (±2 за тип: болото/шипы/высота, C3); бином «Фланг» = позиционный бонус «fighter+ranger против одного врага», без координат. C-3 (07-ui-ux «Бой: сетка») — флаг владельцу; боевой экран строится по лестнице (индикатор зоны + карточки), не по сетке.
- **Авто-режим = политика поверх того же движка**: AI greedy (мин. HP в радиусе, тай-брейк меньший id — детерминизм K2); отступление при «frightened»; один отчёт (REPORT) для обоих режимов. Ручной режим: «нет легального хода → Skip turn» всегда доступен (07-ui-ux).
- **AI врага (Y3)**: greedy; босс (ход 21, CR 6–8): greedy + способность при HP партии < 50% (способность — детерминированная, без RNG).
- **Состояния (K-M7)**: prone (−2/+2), высотный статус (полёт, hover; единственный носитель в MVP — волшебник), blink (заклинание из ячеек волшебника). Стек без капа (02d). «prone only» — аннулировано.
- **Удача (02d §4)**: пул ОУ = 1+modLuck; Fate Shift (1 ОУ: ступень вверх), Save (2 ОУ: критпровал → провал), «Судьба следит» (FATE_PENALTY_DIVISOR = 1.25, interim до Ф3); долг судьбы (K-R1) при исчерпании.
- **Death saves (Q-M57→(а))**: margin_N = mod(эфф. CON) + (снабжение, только N=1) − (N−1); 3 провала = смерть, 3 успеха = WOUNDED (T-116, party-characters).
- **Лимит боя (D-128)**: 20 раундов → ничья; потери фиксируются; без XP/Престижа.
- **Мораль (K-M11)**: шкалы нет; потери = −2 ступени к спасам до конца боя; принудительное отступление при 0 HD; «мораль-формула» — аннулирована навсегда.
- **Классы (K1)**: канон 11 классов (Колдуна нет; «mage» = Волшебник); MVP-маска боя = 6 (fighter/ranger/cleric/wizard/rogue/paladin); базовые 3 бойца (K-M15) — см. C-13 в party-training.

## Risks / Trade-offs

- [C-3: сетка в боевом экране — вердикт владельца] → до вердикта экран = лестница + карточки; если владелец подтвердит сетку — доп. задача в mvp-ui-flow (не трогает движок).
- [FATE_PENALTY_DIVISOR — interim (margin/1,25), Ф3] → константа с пометкой; Ф3 — привязка к лестнице (баланс).
- [Способность босса не задана в каноне] → детерминированная (без RNG), параметры — баланс-конфиг Ф4; плейсхолдеры без пометки запрещены.
- [«frightened» в MVP — только триггер отступления авто-режима] → каталог состояний (frightened/stunned) — 1.0 (K-M11).
