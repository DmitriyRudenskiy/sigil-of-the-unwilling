# dnd-battle-ladder

Боевая система post-pivot: D&D без кубиков, лестница (K-T6), Удача (7-я хар-ка), death saves (Q-M57), SM боя, лимит 20 раундов (D-128), авто-режим, AI врага (Y3) + босс хода 21, состояния prone/высотный + blink (K-M7), местность 3 типа (C3), бином «Фланг», мораль аннулирована (K-M11). Реализовано: лестница/death saves/лимит/инициатива (campaign_battle.gd). Остаток: авто-режим, AI, состояния, местность, бином, карточка врага M1. C-3: сетка в боевом экране — вердикт владельца.
