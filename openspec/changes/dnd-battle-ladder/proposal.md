# Proposal

## Why

GDD 02-mechanics §3.4 — боевая система D&D без кубиков (лестница), NОВОЕ (Q13 решено: ручная тактика + авто-опция). Реализовано частично: `campaign_battle.gd` (лестница зон, death saves, лимит 20 раундов D-128, инициатива, «Судьба следит» interim). Не реализовано: авто-режим, состояния (prone/высотный, K-M7), blink (K-M7), местность 3 типа (C3), бином «Фланг» (единственный бином MVP), AI врага (greedy + босс хода 21), карточка врага M1. Main spec `tactical-combat` описывает pre-pivot grid-бой (17×N) — supersedes.

## What Changes

- Фиксирует разрешение (K-T6): Result = mod(эфф. хар-ка) + бонус ранга + ситуативное; перевес = Result − DC; без «10 + prof».
- Фиксирует лестницу: Триумф (≥4−modLuck, мин +1) / Успех (≥0) / Частичный (≥−(3+modLuck)) / Провал / Критпровал (≤−(8+modLuck)); в бою: Триумф = урон ×2, Частичный = ½ урона, Провал = мимо, Критпровал = фамбл.
- Фиксирует Удача (7-я хар-ка): пул ОУ = 1+modLuck; Fate Shift (1 ОУ: ступень вверх); Save (2 ОУ: критпровал → провал); долг судьбы (K-R1).
- Фиксирует урон: среднее куба + mod; AC = 10 + броня + mod(DEX).
- Фиксирует death saves (Q-M57→(а)): margin_N = mod(эфф. CON) + (снабжение, только N=1) − (N−1); 3 провала = смерть, 3 успеха = WOUNDED.
- Фиксирует SM боя: SETUP→ROUND→VICTORY/DEFEAT/RETREAT→REPORT; инициатива mod(DEX), тай-брейк CON, id.
- Фиксирует лимит боя (D-128): 20 раундов → ничья, потери фиксируются, без XP/Престижа.
- Фиксирует авто-режим: тот же движок, детерминированный AI (мин. HP в радиусе), отступление при «frightened»; один отчёт для обоих режимов.
- Фиксирует AI врага (Y3): greedy (мин. HP в радиусе, тай-брейк меньший id); босс (ход 21): greedy + способность при HP партии < 50%.
- Фиксирует: статы врага видны всегда (AC/HP/удача/способности — M1); состояния prone (−2/+2) и высотный (полёт, K-M7); blink (K-M7); местность 3 типа (болото/шипы/высота, C3); бином «Фланг» (fighter+ranger, с хода 1); мораль аннулирована (K-M11); детерминизм (без RNG в разрешении, K2).

## Capabilities

### New Capabilities
- `dnd-battle-ladder`: лестничное разрешение боя, Удача, death saves, SM боя, авто-режим, AI врага, состояния, местность, бином.

### Modified Capabilities
- None.

## Deduplication and status (v4)

- **Дубликаты (main specs):** `tactical-combat` (17×N grid, dnd_profile на стеке) — **superseded** K-каноном (лестница, Q-M47: 17×11 = legacy-арена); `core-mechanics` (формула урона «10 + prof») — supersedes по боевой части (K-T6).
- **Дубликаты (archive):** `2026-09-27-dnd-battle-system`, `2026-09-28-dnd-live-battle-wiring`, `2026-09-29-dnd-battle-factory`, `2026-09-29-dnd-class-race-tactical-bonuses` — pre-pivot D&D-бой на тактической сетке; K-канон — реворк (02 §3.4 «НОВОЕ»), не дублирование.
- **Dead tasks (реализовано):** лестница/зоны, death saves (mod CON, 3/3), лимит 20 (D-128), инициатива, «Судьба следит» (FATE_PENALTY_DIVISOR) — `campaign_battle.gd`, помечены `[x]`.
- **Пересечения:** `party-characters` (WOUNDED/UNSTABLE, снабжение в бою), `region-graph-map` (ENGAGE/BATTLE/RETREAT — SM героя), `raid-pressure-system` (рейд по герою → бой, −50%), `mvp-ui-flow` (боевой экран: лестница, карточка врага M1, «Авто»).

## Impact

- Код: `campaign_battle.gd` (авто-режим, состояния, местность, бином, AI), `battle_rules.gd` (зоны, урон), `battle_ui.gd` (индикатор лестницы, карточка врага).
- Не затрагивает: формулу XP (party-characters), рейды (raid-pressure-system), карту (region-graph-map).

## Contradictions

- **C-3 (docs vs code, флаг владельцу):** 07-ui-ux «Бой: сетка (размер — 07-balance#4, D4; "8×8–12×12" — устарело), индикатор лестницы» + 02-mechanics §3.4 «размещение, местность поля (штраф/укрытие)» vs Q-M47 (2026-10-16) «K-канон-резолвер — лестница без поля (02d: индивиды; "поле 17×11" в 02d/02b/02-mechanics отсутствует)» и реализованный `campaign_battle.gd` (чистая лестница, без поля/координат). Есть ли сетка в боевом экране MVP — требует вердикта владельца. До вердикта: реализация = чистая лестница (без hex), местность = абстрактные модификаторы (±2), бином «Фланг» = позиционный бонус без координат.
- **C-6 (main spec superseded):** `tactical-combat` (openspec/specs/) — grid-бой 17×N, uстарел K-каноном; main spec не удалён (архивация — реестровый акт). Флаг: main spec требует пометки superseded или архивации.
