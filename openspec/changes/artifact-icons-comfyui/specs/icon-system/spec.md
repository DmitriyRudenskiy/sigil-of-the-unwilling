## MODIFIED Requirements

### Requirement: Генерация иконок

Иконки ресурсов, зданий, потребностей и школ магии SHALL генерироваться
процедурно скриптами-генераторами: генераторы используют базовые формы (круг,
квадрат, треугольник) и цветовую схему из ThemeConfig. Иконки артефактов
процедурно НЕ генерируются — по-слотовая форма даёт один рисунок на весь слот
(корень 23 md5-дублей), поэтому они генерируются по-id внешним генерирующим
сервисом (`artifact-icon-generation`). Процедурный генератор артефактов
сохраняется как фолбэк отображения и не является источником истины для вида иконки.

#### Scenario: Генерация иконок ресурсов

- **WHEN** запускается gen_resource_icons.gd
- **THEN** создаются PNG файлы для всех ресурсов из ResourceDef
- **AND** цвета соответствуют C_RES_* из ThemeConfig

#### Scenario: Генерация иконок зданий

- **WHEN** запускается gen_building_icons.gd
- **THEN** создаются иконки для всех типов зданий
- **AND** форма иконки отражает назначение здания

#### Scenario: Обновление иконок

- **WHEN** изменяется цветовая схема в ThemeConfig
- **THEN** повторная генерация обновляет все процедурные иконки
- **AND** стиль остаётся согласованным

#### Scenario: Иконки артефактов

- **WHEN** требуется иконка артефакта
- **THEN** она берётся из файла `assets/artifacts/<id>.png`, созданного
      по-id генерацией, а не из процедурной отрисовки слота
- **AND** повторный запуск процедурного генератора не считается выполнением
      требования уникальности
