# Design: social-systems-delta

## Context

- ТЗ: "низкий интеллект, обман в городе, харизма, население, отряд
  и прогрессия оружия" (4 стата: INT/WIS/CHA/LUK).
- **Уже реализовано** (`social-stats-weapon-tech`, архивирована):
  - `DeceptionCheck` — формула `base + (10−INT)×4 − comp×2`,
    clamp 5–85, comp = max(WIS,CHA,LUK−10); DC 10/13/14/16/18/20;
    4 степени (10–30% / качество / долг-штраф / кража-ловушка);
    wis-замечание, luk-спасение, cha-скидка.
  - `LeadershipCheck` — иммиграция −50..+50% (таблица), кап стеков
    1–7, recruit_quality 0.8–1.25, d20-наём (DC 8/10/12/14/18/20),
    исходы success/rumor/refused/critical, отток при cha ≤5.
  - `WeaponTechService`/`WeaponCatalog` — 5 тиров
    (1 Дерево/камень, 2 Железо, 3 Сталь, 4 Редкое, 5 Легенда),
    вес/прочность/урон, ковка (int-качество, wis-подделка,
    luk-удача, cha-скидка), tech-лестница города
    (кузница+железо+уголь→2, +золото→3, +кварц→4, +киноварь→5).
- ГdUnit4-тесты: `test_weapon_tech.gd`, `test_deception_check.gd`,
  `test_leadership_check.gd`, `test_capacity.gd`.

## Goals / Non-Goals

**Goals:**
- Разделение дерева (1) и камня (2): перенумерация тиров 1–5.
- Каталог ~30 изделий (6/этап) с типами и назначениями.
- Требования переходов этапов (верстак/печь/закалка/кузнец).
- Негативные события cha 1–7 (бунты, дезертирство, стимулы).
- Модификаторы найма (оплата/еда/спасение/жестокость/условия).

**Non-Goals:**
- DeceptionCheck и формулы харизмы (уже 1:1 по ТЗ).
- Магия артефактов (только "редкое" как материал).
- Проверка силы для тяжёлого оружия.
- Новые здания (верстак/закалка — уровни существующих).

## Decisions

### D1: Перенумерация тиров — breaking, один раз

Новая лестница: 1 Дерево, 2 Камень, 3 Железо, 4 Сталь, 5
Редкое/магия (легенда слита в 5).

- **Почему:** ТЗ явно разделяет дерево и камень ("этап 1: нельзя
  создавать каменное оружие"). Текущая 5-тир-лестница уже
  существует — сдвигаем, а не добавляем 6-й тир (6 тиров ≠ 5
  этапов ТЗ).
- **Последствия:** stone_axe tier 1→2; tech-лестница
  WeaponTechService: железо 2→3, золото 3→4, кварц 4→5,
  киноварь (легенда) — убирается, 5 = редкое (кварц+киноварь);
  `weapon_tier_for_city` fallback +1; тесты weapon_tech/capacity —
  обновить.
- **Альтернатива:** 6 тиров (дерево/камень/железо/сталь/редкое/
  легенда) — отклонено: ТЗ = 5 этапов, легенда — частный случай
  редкого.

### D2: Каталог — расширить ITEMS, MATERIALS не трогаем

`MATERIALS` (вес/прочность/урон по тиру) остаётся; `ITEMS`
расширяется до ~30 записей `{tier, display_name, type, purpose,
two_handed, gold}`. Тип — строка (bludgeoning/piercing/slashing/
throwing/ranged/defense).

- **Почему:** единый источник параметров уже есть (MATERIALS);
  каталог — только список изделий. `best_item(tier)` и
  item_weight/damage/durability работают без изменений.

### D3: Требования переходов — проверка в WeaponTechService

`stage_requirements_met(city, target_tier)` — статическая
функция: этап 2 — здание "верстак" (или уровень кузницы 0 +
ресурсы камень/смола), этап 3 — smithy ≥1 + coal + bog_iron +
кузнец, этап 4 — smithy ≥2 (закалка). Кузнец — найм через
LeadershipCheck (уже есть: "smith" DC 14).

- **Почему:** tech-лестница уже в WeaponTechService; добавляем
  требования, не двигая логику.

### D4: События низкой харизмы — CharismaEvents (новый статик)

`CharismaEvents.on_day_passed(city, rng)` — по cha лидера:
6–7 — флаг "нужны стимулы" (набор требует оплаты/еды); 4–5 —
отток (есть SOCIAL_ATTRITION_CHA) + мораль −1; 1–3 — d20-проверка
бунта/дезертирства (шанс по таблице), исходы: побег жителей,
дезертир бойца, отказ приказа.

- **Почему:** паттерн статических систем; отток уже есть —
  расширяем, не дублируем.
- **Альтернатива:** в crisis_event_system (SOCIAL_UNREST) —
  отклонено: crisis — кризисы мира, не персональная харизма.

### D5: Модификаторы найма — расширение recruit_check

`recruit_check(rng, cha, rep, offers, difficulty, mods: Array
[String])` — mods: "pay" +2, "food" +2, "rescue" +4, "bad_terms"
−3, "cruelty" −5 (rep-бонус уже есть ±3).

- **Почему:** сигнатура расширяется опциональным параметром —
  существующие вызовы не ломаются.

## Risks / Trade-offs

- **Breaking перенумерация** (D1): все tier-ссылки (тесты,
  tech-лестница, fallback) — митигация: один diff, grep "tier",
  регрессия GdUnit4.
- **Каталог 30 изделий**: контент-набор, не логика — митигация:
  const-таблица, без кода.
- **События хаоса**: новые d20-броски — детерминизм через
  управляемый rng (паттерн DeceptionCheck).

## Migration Plan

1. Фаза 1: перенумерация тиров (MATERIALS/ITEMS/лестница/fallback)
   + обновление тестов.
2. Фаза 2: каталог ~30 изделий + типы.
3. Фаза 3: требования переходов этапов.
4. Фаза 4: CharismaEvents (бунты/дезертирство/стимулы).
5. Фаза 5: модификаторы найма.
6. Фаза 6: регрессия (GdUnit4 + MCP + 60-ходовая проба).

## Open Questions

- "Верстак" — отдельное здание или уровень кузницы 0 (дефолт:
  ресурсы + здание "workbench" из tech tree, если есть).
- Кузнец как перманентный NPC или флаг найма (дефолт: флаг).
- Шанс бунта при cha 1–3 (дефолт: d20 vs 15, 1 раз в 10 ходов).
