# Proposal

## Why

GDD 02-mechanics §3.7 + 02c — 8 знаков, Престиж как единое число (ledger), ранги. Реализовано частично: `signs.json` (8 знаков, этика-векторы, T-002/T-124/T-129), выбор из 8 (SignChoiceUI), Престиж-ledger (K-M16, CampaignComposition), ранги (prestige.json, D-133). Не реализовано: SM знака (DORMANT/ACTIVE/SLEEPING), фракционные действия (≤12, штраф стиля), косметические ранги в UI (титул/рамка), счётчик «N осталось». Main specs pre-pivot (reputation-system и др.) — не дублируются.

## What Changes

- Фиксирует: 8 знаков (искра/время/баланс/первозданный/тень/гармония/цикл/основа), выбор из 8 на всю игру (Q18, D12 — автор 2026-10-02; «из 3» — устарело); все 8 играбельны в MVP (Q-M32).
- Фиксирует Престиж: единое число, ledger (K-M16, K-D5: без счёта): универсальные начисления/штрафы + фракционные действия знака (≤12 за кампанию); штраф стиля — только за повтор; потеря не штрафуется; тактическое отступление не штрафуется.
- Фиксирует ранги: пороги 0/200/500/1000/2000 (5 рангов; титулы «Безымянный»/«Известный»/«Почётный»/«Славный»/«Легендарный»); 6-ранговая шкала 0/500/1500/3500/7000/12000 аннулирована (K-D5/K-M16); падение ниже порога = понижение.
- Фиксирует якорь кампании: ход 21 = «Почётный» (500–999), верх — касание «Славного» (1000).
- Фиксирует: Престиж чисто косметический (S2): притока населения нет; награда ранга = титул/косметика.
- Фиксирует SM знака: DORMANT→ACTIVE (выбор); ACTIVE→SLEEPING (Престиж ≤ 0); SLEEPING→ACTIVE (Престиж > 0); TRIAL — Post-MVP (1.0: 8 испытаний, +250).
- Фиксирует FS: один знак на носителя (инвариант); потеря знака только смертью (MVP: передача знака нет; смерть носителя не кончает кампанию — «утрата» −2 к спасам, K-M11).
- Фиксирует EC: 13-е фракционное действие → без начисления (UI-счётчик «N осталось»); Престиж 0 → SLEEPING (не game over).
