## Why

Проект вырос: в `game/assets/` ~800 файлов (юниты 384, артефакты 108, курсоры 64, иконки, аудио, тайлы, raw), но нет надёжного способа понять, какие из них используются в игре, а какие — мёртвый груз. Асеты не вычищаются, потому что ручная проверка «ссылается ли где-то файл» ошибкоопасна: часть путей строится динамически (`"res://assets/units/%s.png" % key`), и такой ассет легко пропустить. Нужен автоматический детектор неиспользуемых ассетов с перемещением в архив.

## What Changes

- Новый standalone-анализатор ассетов (без запуска Godot), который по дереву `game/assets/` вычисляет «используемые» пути и отчётливо показывает «неиспользуемые».
- Детектор учитывает статические `res://assets/...`-литералы в `.gd`/`.tscn`/`.tres`/`.json` **и** динамические пути, построенные через `%s` из ключей игровых данных (юниты `%s`/`%s_s`, иконки статов по `art.id`). Это критично: без учёта ключей данных он ложно пометит мёртвыми почти все юниты и артефакты.
- Режим **dry-run** (отчёт без перемещений) по умолчанию; перемещение в `_archive` — отдельным явным шагом.
- Перемещение неиспользуемых ассетов в `_archive` с обязательным manifest-файлом (JSON): что, откуда, куда, почему (причина/ключ детектора). Это единственный механизм отката.
- Обязательная верификация после архивации: прогон через уже существующий runner `game/tools/shell/run_operability.sh` (сцены/сценарии/тесты/console-clean) — должен остаться `CLEAN`.
- Документация процесса в `docs/`.

## Capabilities

### New Capabilities
- `asset-archiver`: детектор «неиспользуемых» ассетов (dry-run отчёт), архиватор с manifest-откатом, верификация операбильности после перемещения.

### Modified Capabilities
- (нет — спецификабельное поведение не меняет существующие specs `audio` / `documentation`.)

## Impact

- **Системы**: `game/assets/` (удаление/перемещение файлов), `game/scripts/entities/UnitSprites.gd`, `game/scripts/ui/ArtifactInventoryScreen.gd`, `game/tools/artifact_icon_generator.gd` — только чтение (источники референсов), правке не подлежат.
- **Зависимости**: Python 3 (есть на macOS по умолчанию); никаких новых пакетов.
- **Риски**: ложное помечание «мёртвым» ассета сломает игру (битые текстуры/звук). Митигация: data-aware детекция, dry-run по умолчанию, только высокая уверенность, обязательная верификация `run_operability.sh`, откат через manifest + git.
- **Инфраструктура**: новый `_archive/` (или `game/assets/_archive/`) — см. design.
