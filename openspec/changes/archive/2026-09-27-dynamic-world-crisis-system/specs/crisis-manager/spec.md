# Crisis Manager Specification

## ADDED Requirements

### Requirement: Кризис блокирует ход
Кризис SHALL блокировать игровой цикл до принятия игроком решения: при старте кризиса day-таймер останавливается, ввод в остальные UI блокируется, доступен только диалог кризиса.

#### Scenario: Старт кризиса
- **WHEN** срабатывает trigger_crisis(event)
- **THEN** is_crisis_active = true
- **AND** цикл дней останавливается (игрок не может пройти день)
- **AND** emit'ится сигнал crisis_started

#### Scenario: Разрешение кризиса
- **WHEN** игрок выбрал вариант и кризис разрешён
- **THEN** is_crisis_active = false
- **AND** игровой цикл возобновляется
- **AND** emit'ится сигнал crisis_resolved(event, choice_index)

### Requirement: Условия запуска кризиса
Новый кризис SHALL запускаться только если: нет активного кризиса, прошёл cooldown, выполнены условия события (население/сезон/день).

#### Scenario: Кризис во время кризиса
- **WHEN** сработал триггер нового кризиса, а текущий ещё активен
- **THEN** новый кризис не запускается (ставится в очередь или отбрасывается)

### Requirement: Типы кризисов
Система SHALL поддерживать кризисы типов: ресурсный (нехватка еды/ресурсов), моральный (требования жителей), природный (буря, засуха), внешняя угроза (мародёры) — каждый с 2–4 вариантами решений и последствиями.

#### Scenario: Ресурсный кризис
- **WHEN** запасы еды ниже порога
- **THEN** запускается ресурсный кризис с вариантами: урезать пайки / отправить охотников / использовать резервы
- **AND** каждый вариант имеет измеримые эффекты (happiness, food, population)

### Requirement: Эскалация при бездействии
Если игрок не принял решение за отведённое время, кризис SHALL эскалировать (повышаться серьёзность или применяться наихудший эффект).

#### Scenario: Таймер истёк
- **WHEN** время на решение кризиса истекло
- **THEN** применяется эффект бездействия
- **AND** серьёзность кризиса увеличивается
