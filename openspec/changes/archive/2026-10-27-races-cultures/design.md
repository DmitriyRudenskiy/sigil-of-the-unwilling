# Design

## Context

`mvp_catalog.json` реализует: 11 классов (K1), 7 рас (K-M5: gnomes, halflings, tieflings, elves, humans, dwarves, half_orcs), `archetype_rules`, `group_relations`, `groups`. K-M5-правка + решение владельца 2026-10-04: playable slice 3 (люди/полуорки/эльфы). Не реализовано: race_affinity зданий (6.5), особые выходы (6.6), гибридная культурная напряжённость (9.3), водные расы как флаг (K-A6). Main spec `settlement-species` (7 видов) — pre-pivot, superseded (K-A6: виды → расы).

## Goals / Non-Goals

**Goals:** формализовать канон §3.6; race_affinity (6.5) как требование; особые выходы (6.6) с порогом 70% [ПРЕДЛОЖЕНИЕ]; гибриды (9.3); водные расы = флаг (K-A6); playable slice 3 в конструкторе.

**Non-Goals:** каталог 54 рас (1.0), водная экономика (K-A6: флаг, не экономика), «культуры» как отдельная сущность (C-14: термин-дыра, в каноне расы и группы).

## Decisions

- **Терминология (C-14)**: «культура» = раса D&D-персонажа (маппинг §3.6); «группа» = культурная группа города (02g). Одна таблица коэффициентов (02e3) для зданий и персонажей. GDD-строка «1 культура (люди) аннулирована» — термин-дыра; K-A6: в каноне расы и группы.
- **Playable slice 3** (K-M5-правка, владелец 2026-10-04): люди/полуорки/эльфы — в конструкторе (pregame-flow); каталог 7★ остаётся в `mvp_catalog.json` (1.0: 54 расы).
- **Race affinity (6.5)**: бонус здания от доминирующей культуры города; персонаж не меняет расу города (EC2). Реализация — в `settlement_processor.gd` (зависимость: city-construction-districts).
- **Особые выходы (6.6)**: 100% одной культуры → безусловные; гибрид → порог 70% [ПРЕДЛОЖЕНИЕ, ждёт автора].
- **Гибриды (9.3)**: культурная напряжённость — штраф за конфликтные пары; лечится сервисами (таверна/храм). Конфликтные пары — `group_relations` (уже в каталоге).
- **Водные расы (K-A6)**: флаг происхождения, не отдельная экономика. В MVP — не играбельные (playable slice 3 = люди/полуорки/эльфы); флаг — для 1.0.

## Risks / Trade-offs

- [C-14: термин-дыра «культуры»] → в спеке явно: культура = раса персонажа, группа = группа города; синк GDD-терминологии — docs-задача.
- [C-15: playable-маска не эксплицитна в данных] → маска в конструкторе (pregame-flow); `mvp_catalog.json` — полный каталог 7★.
- [Порог 70% — предложение] → не канон; конфиг с пометкой [ПРЕДЛОЖЕНИЕ], вердикт автора.
- [Конфликтные пары не заданы числом] → `group_relations` (каталог) + баланс-конфиг Ф4.
