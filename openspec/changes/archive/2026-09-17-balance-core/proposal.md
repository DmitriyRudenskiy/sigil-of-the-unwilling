# Proposal: balance-core

## Why

Ранняя игра (early-game-foundation) реализована, но числа в ней ещё не калиброваны под реального игрока. Раньше калибровка предполагалась «после ручной прогонки» — сейчас она делается **прогоном через MCP**: автоматический сценарий играет раннюю игру по каноническому пути и измеряет, где игрок застревает. Это даёт воспроизводимые данные вместо ощущений и позволяет повторять калибровку после каждого изменения баланса.

Известные подозрения (подтвердить/опровергнуть прогонкой):

1. **Поток ресурсов → строительство**: рюкзак 12 ед., узлы дают мало, телега 20 индустрии — цикл «собрал → выгрузил → построил» может занимать десятки ходов без видимого прогресса.
2. **Стоимость казарм/стрельбища** относительно доходности города раннего уровня.
3. **Стойкость соло-героя**: личный боец (hp = combat_hp) против 1-го кольца — есть ли вообще шанс без рекрутов.
4. **Сезон Буря** (×0.4 производство, ×1.25 стаи) — не превращается ли в «стоп-кран» на 20 ходов.

## What Changes

- Новый **MCP-сценарий прогонки** (`test_balance_probe.py` + GDScript-сценарий): новая игра → N ходов канонической стратегии (сбор, выгрузка, стройка, рекрутка, бои) с автоматическим автоигроком; на каждом шаге логирует состояние (ресурсы, уровень города, армия, ходы до цели).
- **Исследовательские метрики** (не геймплей): время до первого здания, время до первой рекрутки, время до первой победы, доля проигранных боёв, «затыки» (ходы без прогресса).
- **Калибровка констант** `GameNumbers*` (GameNumbersHero/GameNumbersCity/GameNumbersBattle) под метрики из прогонки: цели — первое здание ≤ 5 ходов, первая рекрутка ≤ 10 ходов, первая победа ≤ 3 ходов после появления, Буря не даёт >50% падения темпа.
- **Отчёт** о до/после (таблица метрик) как артефакт прогонки в `tools/mcp/`.

## Capabilities

- `balance-probe` — MCP-автопрогонка ранней игры с метриками (новое)

## Impact

- `tests/mcp/` — новый прогон-тест (не блокирующий: провал метрики = warning с отчётом, не fail)
- `game/scripts/constants/GameNumbers*.gd` — правки чисел (без изменения механик)
- `game/tools/mcp/` — сценарий автоигрока + логгер метрик
- Не трогается: структура боя (BATTLE_BOARD_W=17 — parity trap), кольца, сезоны, техдерево (механики), сейвы.
