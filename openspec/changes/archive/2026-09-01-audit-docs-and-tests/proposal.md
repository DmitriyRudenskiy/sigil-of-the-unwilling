# Аудит документации и тестов

## Why

После миграции `restructure-game-folders` документация и тесты — две поверхности,
где расхождение с кодом затухает незаметно: доки ссылаются на пути/имена, которые
больше не существуют; тесты покрывают не то, что покрывали (или тихо не попадают
в прогон). Систематической картины покрытия, битых ссылок и «тёмных» систем нет —
есть только разовые grep-свипы. Нужен однократный аудит с отчётом и приоритизованными
рекомендациями, чтобы следующие изменения опирались на верную базу.

## What Changes

**Аудит документации** (41 `.md` в `docs/` + `AGENT.md`, `README.md`, `game/README.md`):
- битые ссылки: md-ссылки, `res://`-пути, пути к файлам/скриптам/сценам, имена
  autoload и class'ов — сверка с реальным деревом и кодом
- индекс `docs/README.md`: все файлы проиндексированы, нет сирот и дублей
- покрытие системами: каждая система из `AGENT.md`/`game/scripts/` — есть ли у неё
  документ, есть ли у документа свежее содержание (спот-чек по ключевым системам:
  turn pipeline, battle, city/economy, magic, world)
- противоречия и дубли между документами

**Аудит тестов** (80 `.gd` в `game/tests/`):
- матрица покрытия: система/ability → тесты (какие системы не покрыты вовсе)
- «осиротевшие» тесты: файлы, которые раннер `run_tests.gd` не подбирает
  (именование, явный skip-список, папка `fakes/`)
- качество: слабые/пустые ассерты, flaky-асинхронные тесты (тайм-ауты, race),
  дубли покрытия между тестами
- согласованность с CI: всё, что в `game/tests/`, реально прогоняется в CI;
  все ли CI-шаги (compile_all, check_scene_refs, spell_validation, check_tileset,
  unit_tests) покрывают свои заявленные инварианты

**Отчёт:** findings + рекомендации с приоритетами (P0/P1/P2) в `docs/` + запись
в индексе `docs/README.md`.

**Явно не в scope:** исправление найденных проблем (следующий change по отчёту),
дописание недостающих тестов, переписывание доков.

## Impact

- **Новое:** отчёт аудита в `docs/` (область по решению design) + запись в
  `docs/README.md`
- **Читается (без изменения):** `docs/`, `game/tests/`, `game/tools/shell/`,
  `game/scripts/`, `game/project.godot`, `AGENT.md`, `README.md`, `openspec/specs/`
- **Не затрагивается:** игровой код, CI, сами тесты, main-спеки
- **Согласованность с dirty-деревом:** 418 unstaged-удалений (старые docs, raw-
  ассеты) — WIP пользователя; аудит идёт по рабочему дереву, удалённые файлы
  не помечаются как «потерянные», индексы сверяются по наличию файлов на диске
