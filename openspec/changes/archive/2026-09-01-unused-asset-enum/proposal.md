## Why

Ассеты-курсоры `game/assets/cursors/cursor_01.png … cursor_32.png` (32 картинки 128×128,
вырезанные с фона `game/tools/extract_cursors.py`) **не используются** ни в каком коде и
имеют только порядковый номер. Ссылки на них — строки вида `cursor_05.png`, что нетипизировано
и нечитаемо. Нет реестра/enum для обращения к пронумерованным асетам.

## What Changes

- **Поиск неиспользуемых асетов**: статический анализ референсов (static ∪ data-driven),
  выявляющий неиспользуемые асеты и их категории (cursors / textures / ui / raw / …).
- **Enum для пронумерованных асетов**: для асетов, идентифицируемых порядковым номером
  (курсоры), ввести типизированный enum (`CursorSprite`) с семантическими значениями
  (BOOT/HAND/WARRIORS) для определённых и числовыми (CURSOR_NN) для остальных, и резолвер
  enum → `res://`-путь (`%02d`, числовой fallback).

## Scope

- **Поиск**: все неиспользуемые асеты (cursors / textures / ui / raw / audio / other).

## Capabilities

### New Capabilities
- `unused-asset-enum`: поиск неиспользуемых асетов; enum для пронумерованных асетов
  (курсоры) с резолвером пути.

## Impact

- `game/tools/` — анализатор референсов асетов (поиск).
- `game/scripts/data/` — `CursorSprite` enum + резолвер пути (для пронумерованных асетов).
- `game/assets/cursors/` — асеты-курсоры (без перемещения; только именование в коде).
- `game/tools/shell/run_operability.sh` — вердикт CLEAN; автотесты enum/резолвера.
