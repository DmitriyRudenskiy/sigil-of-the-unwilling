# Proposal: ui-icons-cursors-improvement

## Why

В игре отсутствует полноценная графическая проработка интерфейса: курсоры не имеют уникальных изображений для разных режимов взаимодействия, иконки для многих элементов UI отсутствуют или представлены текстовыми заглушками (эмодзи), недостающая графика для кнопок, панелей и декоративных элементов снижает визуальную целостность и погружение. Это приводит к:
- Низкому визуальному качеству интерфейса по сравнению с графикой артефактов и юнитов
- Отсутствию визуальной обратной связи при взаимодействии (курсор не отражает контекст действия)
- Использованию эмодзи вместо полноценных иконок для ресурсов, зданий, потребностей героя
- Несогласованному стилю графических элементов
- Слабой читаемости UI в игровых ситуациях

## What Changes

- **Система курсоров**: добавление полноценных спрайтов курсоров для всех режимов (DEFAULT, WALK, COLLECT, ATTACK, CAST_SPELL, TALK); настройка горячих точек (hotspot) для точного позиционирования
- **Библиотека иконок**: создание набора иконок 32x32 и 64x64 для ресурсов (дерево, камень, ртуть, руда, сера, кристаллы, самоцветы, золото), зданий (ферма, шахта, кузница, таверна, рынок), потребностей героя (отдых, общение, вдохновение), школ магии (воздух, огонь, вода, земля)
- **UI графика**: кнопки состояний (normal, hover, pressed, disabled), рамки для панелей, слайдеры, чекбоксы, радио-кнопки, прогресс-бары, декоративные разделители, фоновые текстуры для панелей
- **Интеграция с ThemeConfig**: обновление темы Godot для использования новых ассетов вместо StyleBoxFlat заглушек
- **Генерация иконок**: скрипты для процедурной генерации иконок в едином стиле (по аналогии с gen_artifact_icons.gd)

## Capabilities

### New Capabilities
- `cursor-sprites`: полноценные спрайты курсоров с горячей точкой для каждого режима взаимодействия
- `icon-library`: библиотека иконок для всех категорий игровых элементов (ресурсы, здания, потребности, магия)
- `ui-widgets`: графические виджеты для кнопок, панелей, слайдеров, прогресс-баров
- `icon-generator`: инструменты для генерации иконок в едином стиле

### Modified Capabilities
- `CursorController`: использование спрайтов вместо пустых путей в MODE_ASSETS
- `ThemeConfig`: замена цветовых констант на текстуры для панелей, кнопок, рамок
- `ResourceRegistry`, `ArtifactRegistry`: использование иконок из библиотеки вместо эмодзи

## Impact

- **Новые файлы**: 
  - `openspec/specs/icon-system/spec.md`, `openspec/specs/cursor-system/spec.md`, `openspec/specs/ui-graphics/spec.md`
  - `game/assets/cursors/cursor_default.png`, `cursor_walk.png`, `cursor_collect.png`, `cursor_attack.png`, `cursor_spell.png`, `cursor_talk.png`
  - `game/assets/ui/icons/resources/`, `buildings/`, `needs/`, `schools/` подпапки с иконками
  - `game/assets/ui/widgets/` для кнопок, панелей, слайдеров
  - `game/scripts/build/gen_resource_icons.gd`, `gen_building_icons.gd`, `gen_need_icons.gd`
- **Изменённые файлы**: 
  - `game/scripts/autoload/CursorController.gd` (заполнение MODE_ASSETS путями к спрайтам)
  - `game/assets/theme/game_theme.tres` (обновление стилей с новыми текстурами)
  - `game/scripts/theme/ThemeConfig.gd` (добавление путей к иконкам)
  - UI сцены (`*.tscn`) для использования новых иконок и виджетов
- **Тесты**: unit-тесты загрузки курсоров, отображения иконок, интеграционные тесты UI

## Non-goals

- Полная перерисовка всех существующих артефактов и юнитов (это отдельные задачи)
- Создание анимированных курсоров и иконок (только статичные изображения в первой итерации)
- Поддержка нескольких тем оформления (светлая/тёмная) — только одна стиль-тема
- Интеграция с системой локализации иконок (иконки универсальны)
