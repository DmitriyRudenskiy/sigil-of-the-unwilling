# docs-code-sync

Сверка документации с кодом игры: двусторонний гейт `scripts/audit_docs_vs_code.py`
(ссылка дока обязана разрешаться в код; автозагрузки/действия input map/сцены/ключи
сейва обязаны быть названы в docs/; классы — ratchet-allowlist), карта систем
`docs/18-system-map.md` и реверс-секции (управление, автозагрузки, пайплайн сцен,
формат сейва, слой событий) с указанием источника-скрипта. Базлайн аудита
2026-10-26: 5/15 автозагрузок, 5/5 действий ввода, 20/51 сцены, 246/405 классов не
названы в доках. Код игры не меняется: поведение, описанное в доках и отсутствующее
в коде, регистрируется тикетом, а не дописывается.
