# Core D&D Mechanics Specification

## ADDED Requirements

### Requirement: Шесть характеристик и модификаторы
Каждый персонаж SHALL иметь шесть характеристик (STR, DEX, CON, INT, WIS, CHA); модификатор рассчитывается как floor((score − 10) / 2).

#### Scenario: Модификатор 14
- **WHEN** характеристика = 14
- **THEN** модификатор = +2

#### Scenario: Модификатор 8
- **WHEN** характеристика = 8
- **THEN** модификатор = −1

### Requirement: Бонус владения по уровню
Бонус владения SHALL расти с уровнем: 1–4: +2, 5–8: +3, 9–12: +4, 13–16: +5, 17–20: +6. Бонус применяется к атакам во владеем оружии, заклинаниям и броскам спасения в владеемой характеристике.

#### Scenario: Боец 5-го уровня
- **WHEN** уровень персонажа = 5
- **THEN** бонус владения = +3
- **AND** он добавляется к атаке владеемым оружием

### Requirement: Расчёт класса доспеха (AC)
AC SHALL рассчитываться по типу доспеха: без доспеха 10 + DEX; лёгкий base + DEX; средний base + min(DEX, 2); тяжёлый base; щит +2 при владении.

#### Scenario: Средний доспех с высоким DEX
- **WHEN** персонаж в среднем доспехе (base 14) с DEX mod +3
- **THEN** AC = 14 + 2 = 16 (модификатор ограничен +2)

#### Scenario: Тяжёлый доспех
- **WHEN** персонаж в тяжёлом доспехе (base 18) с DEX mod +4
- **THEN** AC = 18 (DEX не добавляется)

### Requirement: Бросок атаки
Бросок атаки SHALL рассчитываться как d20 + модификатор характеристики + бонус владения (если оружие владеемое) + ситуационные модификаторы; попадание при total >= AC цели.

#### Scenario: Попадание
- **WHEN** d20 = 15, STR mod +3, бонус владения +2, AC цели 18
- **THEN** total = 20 >= 18, атака попала

#### Scenario: Критический успех
- **WHEN** d20 = 20
- **THEN** бросок считается критическим (двойной урон по правилам системы)

### Requirement: Расчёт урона
Урон SHALL рассчитываться по кубикам оружия (WEAPON_DAMAGE: "XdY") + модификатор характеристики; тип урона (DamageType) определяется оружием.

#### Scenario: Урон мечом
- **WHEN** оружие "longsword" (1d8), d8 = 6, STR mod +3
- **THEN** урон = 9, тип SLASHING

#### Scenario: Урон без характеристики
- **WHEN** модификатор характеристики отрицательный
- **THEN** модификатор урона не опускается урон ниже 1 (по выбору реализации — floor 0 для damage)
