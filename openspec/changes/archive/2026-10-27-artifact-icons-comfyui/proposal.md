## Why

Из 54 файлов `game/assets/artifacts/*.png` только 31 уникальный рисунок: процедурный
`gen_artifact_icons.gd` рисует форму по **слоту**, поэтому все артефакты одного слота
получают одну картинку (12 групп дублей → **23** id без собственного вида). Хуже —
**6 id реестра не имеют файла вообще**: `club`, `stone_axe`, `iron_sword`,
`steel_longsword`, `runic_blade`, `rune_sword` достижимы кузнечным
`WeaponTechService.forge()`, а инвентарь резолвит `artifacts/%s.png`
(`artifact_inventory_screen.gd:417`) → **пустая текстура в живой игре уже сегодня**.

Гейт владельца по данным пройден (`docs/15` §5): obtainability подтверждена,
`rune_sword`/`runic_blade` — не дубль, rarity проставлен явно у всех 60 id. Сет
**29** согласован, спек готов (`docs/15` §2–3). Генерация упиралась только в
инструмент: в локальной сессии нет image-модели. Источник — **ComfyUI API**,
который предоставляет владелец.

## What Changes

- Конвейер генерации 29 иконок через **ComfyUI HTTP API**: префикс-промпт
  [[13-art-bible]] + субъект и акцентный цвет каждого id из `docs/15` §2.
- Постобработка до бюджета арта: канвас 64×64, грид 8, отступ 8 px, PNG-32 с
  альфой, **≤ 6 КБ**; окантовка по тиру (MINOR/MAJOR/RELIC) — **уровень ячейки,
  не пиксели иконки** (смена rarity в данных не требует перегенерации).
- **Контакт-лист всего сета** (~60 id: 31 живая + 29 новых) на тайле `#281c0f`
  с рамками тиров — артефакт ревью, один взгляд закрывает и контраст-режим §4.5,
  и визуальную оценку плотности RELIC.
- Автогейт перед выкладкой: канвас/формат/вес/наличие альфы/уникальность md5 —
  падает на любом несоответствии, а не на «глазом посмотрели».
- Интеграция — **отдельным PR** после приёмки контакт-листа: 29 файлов в
  `game/assets/artifacts/`, маппинг не меняется (загрузчик резолвит по id).
- `gen_artifact_icons.gd` для артефактов **не удаляется**, но перестаёт быть
  источником истины: остаётся фолбэком «нет ComfyUI / нужен плейсхолдер» и
    помечен как таковой.

## Capabilities

### New Capabilities
- `artifact-icon-generation`: генерация иконок артефактов по ComfyUI из спека
  `docs/15` — промпт-конвейер, постобработка к бюджету, автогейт, контакт-лист
  ревью, порядок интеграции.

### Modified Capabilities
- `icon-system`: требование «Генерация иконок» было «процедурно скриптами по
  аналогии с `gen_artifact_icons.gd`» — для артефактов заменяется на по-id
  генерацию через ComfyUI (процедурный генератор = фолбэк), потому что
  по-слотовая форма и есть корень 23 дублей.

## Impact

- `game/assets/artifacts/` — 29 новых файлов + 23 замены плейсхолдеров;
  переимпорты `.import` (генерирует `--import`).
- `game/scripts/build/gen_artifact_icons.gd` — демотия «фолбэк», логика не трогается.
- Код игры — **ноль правок**: загрузчик уже резолвит `artifacts/%s.png` по id,
  новые файлы подхватываются автоматически.
- `docs/12-asset-audit.md` — остаётся snapshot; перегенерация реестра аудита
  после интеграции (md5-дубли должны уйти в ноль).
- Внешняя зависимость: **ComfyUI-эндпоинт от владельца** (URL + модель/воркфлоу).
  Ключ — только из окружения, в репозиторий и логи не попадает.
- Тесты: смок `artifact_inventory_screen` + GdUnit-сета артефактов; новых
  id-без-файла покрывается гейтом «обе вселенные» (id ↔ файл).
