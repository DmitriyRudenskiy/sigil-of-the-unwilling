## Why

Канон UI существует (арт-библия rev2 + `docs/17-ui-style-guide.md`), но не
закреплён машинными проверками: адаптивность layout (1280×720 → 4K/ultrawide)
проверяется только глазом, таблица контраста §1.2 гайда требует «числа
пересчитывать после любой правки палитры» — а скрипта или теста для этого нет,
приём UI-ассетов (ASSET-1/ASSET-2) не имеет гардов по альфе/9-slice. Внешний
пакет `godot-ui-taskpack` содержит рабочие проверки этого класса (задачи 3.5,
5.2, 2.3–2.7) — три из них адаптируются под гейт проекта.

## What Changes

- Новый GdUnit4 functional-тест: адаптивный прогон ключевых UI-сцен на 5
  разрешениях (1280×720, 1920×1080, 2560×1440, 3440×1440, 3840×2160) — rect
  каждого Control внутри вьюпорта (допуск 2 px), без непреднамеренных
  перекрытий sibling-элементов >20% площади (осознанные оверлеи — исключения).
- Новый GdUnit4 unit-тест: WCAG-контраст-гард — пересчёт контраст-пар из живых
  `ThemeConfig.C_*` и сверка со значениями таблицы `docs/17-ui-style-guide.md`
  §1.2 (дрейф-гард) + ассерты правила: текст ≥4.5:1, нетекстовое
  состояние/граница ≥3:1.
- Новый скрипт `scripts/check_ui_assets.py` (Pillow, exit ≠ 0 при нарушениях,
  конвенция `check_docs_links.py`): прозрачность углов у кнопок/слотов/иконок,
  однородность центрального тайла 9-slice-панелей (порог stddev), тёмные ореолы
  на полупрозрачных краях.

## Capabilities

### New Capabilities

- `ui-verification-gates`: headless-верификация UI — адаптивный layout на 5
  разрешениях, контраст-канон из `ThemeConfig`, качество UI-ассетов (альфа,
  9-slice, ореолы).

### Modified Capabilities

(нет — `ui-graphics` устарел до арт-библии rev2, его сверка — отдельное дело,
в этот срез не входит)

## Impact

- Код: `game/tests/functional/ui/` (+1 тест-файл), `game/tests/unit/ui/` (+1
  тест-файл), `scripts/check_ui_assets.py` (новый). Игровой код не меняется.
- Гейт: `game/run_tests.sh` не трогается — GdUnit4 подхватывает новые тесты
  автоматически (лестница тестов: +N); python-скрипт вызывается отдельно, как
  `check_docs_links.py` (зависимость: системный python3 + Pillow, проверено
  Pillow 12.2.0).
- При первом прогоне ожидаются НАХОДКИ (нарушения в живых сценах/ассетах) —
  они фиксируются в отчёте; чинить находки доверием «отключить тест» нельзя:
  либо чиним layout/ассет, либо явное решение владельца с фиксацией в
  `TICKETS.md`.
