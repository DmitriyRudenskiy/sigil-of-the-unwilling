## Context

Текущее состояние городов и навигации:

- **Старт**: `WorldBootstrap._create_cities` регистрирует **один** город — столицу
  «Перворечье» (центр (10,10), `special_sites` со святилищем). Второй город отсутствует.
- **Villages**: `MapSpawner.place_villages()` кладёт `village_count` (по умолч. 8) villages
  на проходимые клетки; при входе героя village_клетка → `_on_village` → `capture_village_at`
  → добавляется в список «Деревни» в `InfoPanel`.
- **CityPanel** (`game/scripts/ui/CityPanel.gd`, `class_name`): пассивная панель
  (население/районы/здания), с кнопкой «Закрыть» (`close()` → `closed.emit()`). **Не
  подключена** к `WorldUIManager` — из мира не открывается.
- **MarkerLayer**: рисует reach-маркеры (зелёный/жёлтый/красный) по клику по карте;
  `show_markers(hero_cell, mp, dist_map)`, `hide_markers()`.
- **City**: `display_name`, `center` (Vector2i), `uid`, `is_capital`, `special_sites`.
- **WorldShortcuts**: I (инвентарь), F5/F9 (сейв/лоад), Esc.

Недостаёт: второго города, навигации (значки), рабочего «выхода из города».

## Goals

- Два города при старте.
- Навигационные значки городов рядом с героем.
- Открытие города у героя + рабочая кнопка выхода.

## Decisions

### D1: Два города при старте
Во `_create_cities` регистрируется второй город (второй не столица) с уникальным
`display_name` = «Город 2», `center` — **рядом со столицей** (~15 гексов, через
`_nearest_walkable`). Столица «Перворечье» = «Город 1», остаётся `is_capital`.
`register_city(second, false)`.

### D2: Навигационные значки городов
`MarkerLayer` рисует 2 значка городов с именами **«Город 1»/«Город 2»**. Значки
показываются **сразу по клику в меню навигации** (без порога расстояния). Клик по
значку → прокладка пути к `city.center` (соседней проходимой клетке). Реализация —
через существующий `_draw()`/Label-спрайты, без нового рендер-стека.

### D3: Открытие города у героя
Два триггера (оба варианта):
- **Авто-открытие** при подходе героя вблизи `city.center` → открыть `CityPanel`
  через `WorldUIManager`.
- **Открытие по клику** по значку города (см. D2).
Герой при входе **ставится на клетку, с которой вошли** (вход — с соседней
проходимой клетки).

### D4: Кнопка выхода из города
В CityPanel кнопка **«Выход из города»** → `close()` → `closed.emit()` →
`WorldUIManager` скрывает панель.

## Risks

- **Города «виртуальны»**: города — RefCounted-модель, их `center` не всегда совпадает
  с проходимой клеткой на карте. Митигация: D1 — `center` через `_nearest_walkable`;
  при открытии/навигации брать проходимую клетку у центра.
- **Конфликт reach-маркеров**: MarkerLayer уже рисует пути по клику; значки городов
  могут пересекаться. Митигация: отдельный слой/зона или `_draw`-разделение по слою.
- **Открытие по умолчанию**: каждый раз у города открывать панель — может мешать.
  Митигация: открывать по клику/наведению или с флагом «авто-открытие».

## Migration

1. D1: второй город в `WorldBootstrap._create_cities`.
2. D2: значки городов в `MarkerLayer`.
3. D3: подключение CityPanel к `WorldUIManager` + открытие у героя.
4. D4: кнопка выхода в CityPanel.
5. `run_operability.sh` (CLEAN) + автотесты старта/навигации/выхода.
