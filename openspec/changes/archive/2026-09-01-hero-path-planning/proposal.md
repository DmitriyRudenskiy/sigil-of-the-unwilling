## Why

Герой сейчас перемещается только «клик — посмотреть путь → клик — идти» к одной клетке за раз, без сохранённого маршрута и автохода: игроку нужно заново задавать направление каждый ход, а недоступные с текущим бюджетом ходов клетки не подсвечены.

## What Changes

- **Планирование траектории.** Клик-1 показывает путь к клетке; 2-й клик фиксирует маршрут автохода (`planned_path`), если он ещё не зафиксирован. Зафиксированный маршрут сохраняется между ходами. Если маршрут уже зафиксирован — 2-й клик запускает немедленное движение вперёд.
- **Автоход в начале хода.** В начале каждого хода герой автоматически проходит по маршруту шагами, расходуя дневной бюджет ходов; останавливается на целевой клетке, а если ходов не хватило — останавливается midway и сохраняет остаток пути на следующий ход.
- **Подсветка доступности.** Клетки, до которых не хватает ходов, подсвечиваются красным; достижимые — зелёным/жёлтым, чтобы игрок видел, проходим ли маршрут.

## Capabilities

### New Capabilities
- `hero-path-planning`: планирование и фиксация траектории героя, автоход в начале хода, подсветка клеток по доступности (ход vs не хватает ходов).

### Modified Capabilities
- (нет — новой способности соответствует новая спецификация; существующие поведения движения не переписываются.)

## Impact

- `HeroMovementController` — поле `planned_path`, метод автохода в начале хода, сигнал о фиксации/отмене маршрута, входные данные для подсветки достижимости.
- `HeroController` — вызов автохода из хука старта хода (`_reset_time_and_movement`), pass-through для маршрута.
- `MarkerLayer` — красный цвет для клеток с нехваткой ходов (красный фронталь → зона недостаточности ходов).
- `WorldEventRouter` / старт хода — триггер автохода после сброса `move_points`.
- UI — действие фиксации/отмены маршрута.
