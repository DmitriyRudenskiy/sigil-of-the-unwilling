## Context

См. `proposal.md` — «Why». Здесь — только состояние кода, которое определяет
подход.

**Поле.** `GameNumbersBattle.BATTLE_BOARD_W/H` (17/11) читаются из
`GameNumbers` и далее только через `BattleState.BW/BH`: `battle_state_builder.gd`
(линии размещения: атакующий у колонки 0, обороняющийся у `BW - 1`),
`battle_ai.gd` (BFS, радиусы), `battle_view.gd:59` (обводка поля `±RING`),
`battle_state.gd:590` (кэш дистанций). Геометрия в одном месте — правка
двухстрочная.

**Верх HUD.** `scripts/ui/battle_ui.gd`: `@onready` на `$hero_cards`,
`$initiative_bar`, `$initiative_bar/init_col/init_box`; `update_initiative()`
(строка 258) пишет ленту; `hud_bands()` (строка 572, D-279) резервирует камере
полосы `hero_cards` + `initiative_bar`. Кольцо — отдельный виджет `turn_ring`.

**Таймер хода.** Живёт в модели (`BattleState.turn_time_limit/turn_time_left/
arm_turn_timer/disarm_turn_timer/tick_turn_timer`, D-214 §3), его крутит
`battle_turn_executor.gd` в состоянии `WAITING_INPUT`, взводит
`battle_controller.gd`. Кольцо показывало **число инициативы**, а не остаток
времени — то есть в интерфейсе не было видно ни таймера, ни лимита ходов.

**Местность в бою.** `BattleState.battle_terrain` заполняет
`set_battle_terrain()`, у которого **нет вызывающих** — в живом бою
`get_terrain_at()` всегда возвращает `plain`. Источник настоящей местности —
клетка врага в мире: `world_battle_coordinator._launch_battle(enemy_cell)` →
`BattleHandoff` → `BattleFlow.start_battle(...)`. Фонов как узлов в
`battle_view.tscn` нет: есть `Terrain` (TileMapLayer), `Highlight`, `Cursor`,
`Camera` и `set_default_clear_color()` в `setup()`.

**Референсы.** Два кадра владельца: снежный лес и болото (1679×937, гексы
pointy-top вписаны в декоративную рамку). Пиксели `reference/*` в git не идут,
кроме `INDEX.md` (D-185); игровые текстуры в `game/assets/` — идут.

## Goals / Non-Goals

**Goals:**

- 11×9 = 99 гексов как единственная мера поля боя, старых следов (17×11) в
  доках не остаётся.
- Верх кадра пуст; очередь хода и инициатива остаются правилами модели.
- Ход игрока ничем не ограничен по времени.
- Задний план — один из утверждённых кадров, выбранных по местности врага;
  неопознанная местность даёт существующий нейтральный фон.

**Non-Goals:**

- Генерация боевой местности (пруды, холмы, бонусы `BattleTerrain` по клеткам) —
  только фон; боевые модификаторы местности не включаются.
- Число раундов/ходов как правило боя — не вводится.
- Новый арт для остальных местностей — не рисуется, ждёт комплект от владельца.
- MCP-тесты и GdUnit-покрытые новые проверки — не пишутся (директива владельца
  2026-10-27; см. «Decisions» про верификацию).

## Decisions

**1. Размер поля — константой, не сценой.** `BATTLE_BOARD_W := 11`,
`BATTLE_BOARD_H := 9`. Альтернатива (размер как поле сцены/параметр боя) —
создаёт второй источник истины рядом с `BW/BH`, отклонено.

**2. Виджеты удаляются, а не скрываются.** `initiative_bar` (+ `init_col`,
`init_box`), `turn_ring` и `update_initiative()` вырезаются из сцены и скрипта;
`hero_cards` остаётся как есть (по умолчанию скрыт, «значков» игрок не видит).
`hud_bands()` оставляет резерв по нижней панели и обязана работать с `null`
полосами — она это делает (`if band == null: continue`), правка нужна только в
списке полос. Скрыть вместо удаления — значит оставить мёртвый код, пишущий в
невидимое (урок «немых ключей», D-197).

**3. Таймер хода снимается с модели целиком.** Поля и методы
`turn_time_*`/`arm_turn_timer`/`disarm_turn_timer`/`tick_turn_timer`, тик в
исполнителе, взвод в контроллере, пауза при открытой книге заклинаний и
автопропуск по истечении удаляются; `test_turn_timer.gd` удаляется вместе с
поведением. Альтернатива «выключить по умолчанию» оставляет мёртвый путь,
который никто не включит, и тест, который его охраняет.

**4. Ключ фона — мировая местность клетки врага, а не тип `BattleTerrain`.**
Референсы — «снег» и «болото»; это биомы мира, которых в боевом перечне
(`plain/forest/hill/water/fort`) нет. Путь данных:
`_launch_battle(enemy_cell)` уже знает клетку врага → `BattleHandoff` добавляет
`background_terrain` (имя мировой местности) → необязательный параметр
`BattleFlow.start_battle()` → `battle_controller.start_battle()` →
`BattleState.background_terrain` (значение по умолчанию — `plain`, старые
вызывающие не ломаются) → `BattleView` берёт текстуру из таблицы
`TERRAIN_BACKGROUND: Dictionary` (имя местности → путь к png), нет ключа —
текущее поведение (clear color + трава). Альтернатива «читать
`get_terrain_at()` обороняющегося» отклонена: `battle_terrain` пуст, фон всегда
был бы лугом. Альтернатива «BattleView сам спрашивает мир» отклонена: связывает
бой с миром в обход handoff.

**5. Фон — `Sprite2D` под `Terrain`, а не `ColorRect`/шейдер.** Кадр-референс
сам содержит рамку и декор; спрайт позиционируется по границам поля
(`field_bounds`/`fit_camera`), масштаб — по ширине, aspect сохраняется.
Текстуры — `game/assets/ui/backgrounds/battle_{snow,swamp}.png` (в git),
строки в `reference/INDEX.md` — по D-185.

**6. Верификация — кадр, не тест.** Приёмку ведёт съёмка сцены
(канал `CAPTURE_SCENE`/`CAPTURE_SETUP` по [[CAPTURE-HELPER]], отдельный
короткий запуск Godot с GUI) и её
поэлементный разбор зрением по скиллу `.pi/skills/ui-grid-review`; вердикт и
расхождения — в треде. Это прямое указание владельца («не используй тесты,
работай со сценой отдельно»), отступающее от правила AGENTS.md «тесты —
единственный способ верификации логики»; отступление фиксируется записью в
`docs/DECISIONS.md` рядом с решением о снятии таймера, чтобы следующий агент не
«дописывал» тесты молча.

## Risks / Trade-offs

- **[99 гексов тесно для максимального состава]** → `battle_state_builder` уже
  переносит заблокированные клетки (`_resolve_blocked_placement`); кадр с
  максимальным составом снимается отдельным шагом и, при вылезании за поле,
  становится отдельным тикетом, а не молчаливым допуском.
- **[Снятый таймер → ход может висеть]** → осознанный выбор владельца;
  завершение хода остаётся явным. Авто-пропуск по таймауту в бою больше не
  существует нигде.
- **[D-279 `reserve_hud_bands` теряет верхние полосы]** → `hud_bands()`
  упрощается до нижней панели; кадрирование поля проверяется кадром до/после,
  иначе D-279 тихо регрессирует.
- **[Удаление тестов уменьшает леджер]** → ожидается и оформляется по формату
  (`+0 / −N / quarantine 0`), причина — удалённое поведение.
- **[Док-следы 17×11 и таймера останутся]** → grep-задача отдельным пунктом
  (`17×11`, `turn_time`, `initiative`, `turn_ring`) по `docs/` и `openspec/`.

## Migration Plan

1. Модель: константы поля → снятие таймера → `background_terrain` в состоянии.
2. Интерфейс: удаление верхних виджетов, деградация `hud_bands()`, фон в
   `battle_view`.
3. Арт: два кадра в `game/assets/ui/backgrounds/` + строки `reference/INDEX.md`.
4. Документация: замена старых правил (07-balance §4, 14-ux-battle-hud,
   DECISIONS, GAP-LIST, TICKETS T-050), запись D-###.
5. Приёмка: кадры (снег/болото/фолбэк, максимальный состав) → ux-review зрением
   → только потом push в `main` (по «мержи» владельца).

Откат — revert коммита смены: правки не трогают сейвы и формат данных, кроме
удалённых полей таймера (они не сериализуются — проверить на шаге 1).

## Open Questions

- Остальные местности (луг, песок, камни, вода) — ждём арт или временно один
  нейтральный фон? По умолчанию: нейтральный, пока нет кадра.
- Судьба скрытых `hero_cards` (удалить вместе с лентой или оставить под
  будущий HUD) — решается на шаге 2 по кадру.
