## MODIFIED Requirements

### Requirement: Сверка с макетом
Приёмка визуального изменения SHALL включать сравнение снимка с макетом и список
обнаруженных расхождений; расхождение либо устраняется, либо фиксируется как
зарегистрированное решение владельца. Кадр и макет SHALL размечаться одной адресной
сеткой (`scripts/ui_grid.py`, одинаковые `--cols/--rows`), а отчёт сверки SHALL
перечислять расхождения адресами ячеек; для экрана, имеющего поэлементную карту,
отчёт SHALL печатать покрытие кадра (`COVERAGE: n/m`) и отдельно — список элементов,
скрытых по значению.

#### Scenario: Расхождение найдено
- **WHEN** при сверке обнаружено расхождение с макетом
- **THEN** расхождение записано в отчёт приёмки адресом ячейки сетки
- **AND** для него указан вердикт: устранено, отложено с задачей либо принято владельцем

#### Scenario: Расхождение с производным правилом стиля
- **WHEN** снимок по макету оказывается несовместим с производным правилом канона (палитрная полоса `C′`, приёмка по ΔE, формула D-184 там, где кадр распадается на раму и поле)
- **THEN** конфликт зафиксирован как вопрос владельцу (Q-M89), а не разрешён сменой макета или правила ради зелёной сверки
- **AND** решение не принимается молча в коде

#### Scenario: Покрытие кадра
- **WHEN** экран с картой элементов снимается для приёмки
- **THEN** отчёт содержит `COVERAGE: n/m` по этой карте
- **AND** элемент, отсутствующий в кадре без строки «скрыт по значению», — падение
  приёмки, а не пропуск

## ADDED Requirements

### Requirement: Разбор кадра зрением до публикации
Живой кадр SHALL разбираться машинным зрением агента до публикации смены: кадр
открывается вместе с макетом-источником, расхождения перечисляются поэлементно,
вердикт публикуется в треде. Кадр без вердикта и вердикт без кадра приёмку не
составляют; «глазом не смотрел» не является основанием для вывода «нельзя
проверить».

#### Scenario: Смена готова к публикации
- **WHEN** визуальная смена прошла автоматические проверки
- **THEN** в треде есть кадр и поэлементный вердикт против макета
- **AND** публикация состоялась после этого разбора, а не до него

#### Scenario: Пиксели не едут в git
- **WHEN** кадр нужен как доказательство вердикта
- **THEN** сам кадр живёт в снимаемом каталоге (`game/tmp/shots/`), а в репозитории
  остаются карта, размеры и развёрнутая свёрка (D-185) либо кадр в
  `docs/img/` как часть документации
