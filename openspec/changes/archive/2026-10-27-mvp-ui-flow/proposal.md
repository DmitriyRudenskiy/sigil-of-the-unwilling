# Proposal

## Why

GDD 07-ui-ux — 8 экранов MVP (K-M8: предыгра, меню, карта, город, бой, партия, хроника, настройки + туториал-оверлей) + SM навигации + панель целей 3 первых дней (M3) + инварианты UI. Реализовано частично: меню (main_menu), город (city_screen/campaign_city_board), бой (battle_ui), хроника (chronicle_screen), настройки (settings_screen), предыгра (character_creation_ui/sign_choice_ui — не связаны). Не реализовано: SM навигации (7-экранная петля), туториал-оверлей, панель целей 3 дней (M3), экран партии (отдельный), «карта» = регион-граф (region-graph-map). «Отчёт» как экран аннулирован (K-M8).

## What Changes

- Фиксирует 8 экранов MVP (K-M8): предыгра, меню, карта, город, бой, партия, хроника, настройки + туториал-оверлей (первые ходы, не сцена). «Отчёт» аннулирован (результаты боя — финал боевого экрана; события хода — хроника).
- Фиксирует SM навигации: PREGAME→MENU→MAP→(CITY/BATTLE/PARTY/CHRONICLE/SETTINGS)→...; BATTLE→MAP (финал «Продолжить», K-M8); MAP→ХРОНИКА anytime; *→TUTORIAL (первый вход в экран, 1 раз).
- Фиксирует панель целей 3 первых дней (M3): день 1 — построй ферму и барраки; день 2 — тренируй воина (K-M15; тренировка, не наём — Q18); день 3 — сходи в руины. Панель видна, пока не выполнены все цели; TTFD покрывает первое действие.
- Фиксирует инварианты: любой модификатор достижим за ≤2 клика до причины (столп 1); в бою все правила D&D, влияющие на ход, видны без подсказок (справка — по клавише).
- Фиксирует: низкое разрешение (1280×720 миним.) → сетка масштабируется, на основных экранах нет скролла; поле боя при 720p — масштаб ×0.8 (C-10: размер поля — 07-balance#4, «8×8–12×12» устарело).
- Фиксирует: ПАРТИЯ: очередь тренировки пуста и партия полна → «что освободит слот» (ссылка на бой/смерть), не пустоту.
- Фиксирует: БОЙ (финал): единственный выход — «Продолжить» (нет «закрыть в никуда»).

- **Дубликаты (active changes):** `ui-mockup-parity` (визуальная паритетность с мокапами) — **зависимость**, не дублирование (здесь — навигация/SM, там — пиксели).

- **Dead tasks (реализовано):** меню (main_menu), город (city_screen/campaign_city_board), бой (battle_ui), хроника (chronicle_screen), настройки (settings_screen) — помечены `[x]`.
