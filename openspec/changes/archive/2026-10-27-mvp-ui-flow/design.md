# Design

## Context

Реализовано: `main_menu.gd` (меню), `city_screen.gd`/`campaign_city_board.gd` (город), `battle_ui.gd` (бой), `chronicle_screen.gd` (хроника), `settings_screen.gd` (настройки), `character_creation_ui.gd`/`sign_choice_ui.gd` (предыгра, не связаны). Не реализовано: SM навигации (7-экранная петля), туториал-оверлей, панель целей 3 дней (M3), экран партии (отдельный), «карта» = регион-граф (region-graph-map). `adventure_ui.gd` — legacy hex-мир (не campaign-карта).

## Goals / Non-Goals

**Goals:** формализовать канон 07-ui-ux; SM навигации (7 экранов + предыгра); туториал-оверлей (первые ходы, не сцена); панель целей 3 дней (M3); инварианты (≤2 клика до причины, правила D&D видны); экран партии («что освободит слот»).

**Non-Goals:** визуальная паритетность (ui-mockup-parity), графика (ui-graphics), сетка в боевом экране (C-3 — до вердикта владельца), «отчёт» как экран (аннулирован, K-M8).

## Decisions

- **8 экранов (K-M8)**: предыгра, меню, карта, город, бой, партия, хроника, настройки + туториал-оверлей. «Отчёт» аннулирован (результаты боя — финал боевого экрана; события хода — хроника; двойной учёт = расползание UI).
- **SM навигации**: PREGAME→MENU→MAP→(CITY/BATTLE/PARTY/CHRONICLE/SETTINGS); BATTLE→MAP («Продолжить», K-M8); MAP→ХРОНИКА anytime; *→TUTORIAL (первый вход, 1 раз). Реализация — `world_ui_manager.gd` (существует, но legacy hex) или новый `campaign_ui_manager.gd`.
- **Панель целей 3 дней (M3)**: день 1 — ферма + барраки; день 2 — тренировка воина (K-M15, Q18: тренировка, не наём); день 3 — руины. Панель видна, пока не выполнены все цели; TTFD покрывает первое действие. Реализация — `main.gd` (сейчас минимальный, без tutorial/3-day goals).
- **Инварианты**: ≤2 клика до причины (столп 1); в бою все правила D&D видны без подсказок (справка — по клавише).
- **Низкое разрешение (1280×720 миним.)**: сетка масштабируется, на основных экранах нет скролла; поле боя при 720p — масштаб ×0.8 (C-10: размер поля — 07-balance#4, «8×8–12×12» устарело; C-3: сетка — до вердикта).
- **Экран партии**: очередь тренировки пуста и партия полна → «что освободит слот» (ссылка на бой/смерть), не пустота. Реализация — новый `party_screen.gd` (сейчас нет отдельного экрана).

## Risks / Trade-offs

- [C-3: сетка в боевом экране — вердикт владельца] → до вердикта боевой экран = лестница + карточки; если владелец подтвердит сетку — доп. задача (не трогает движок).
- [C-10: 07-balance#4 устарело] → размер поля — до вердикта C-3; синк docs.
- [Туториал-оверлей — не сцена] → оверлей поверх экранов (не отдельная сцена); реализация — `tutorial_overlay.gd`.
- [Экран партии — новый] → `party_screen.gd` (сейчас нет); данные — `party_system.gd`.
