# Spec Delta: tactical-combat (ADDED — D&D-персонажный бой)

> Дельта к main-spec `openspec/specs/tactical-combat/spec.md`. Добавляет режим
> персонного D&D-боя поверх существующей stack-модели (backward compatible).

## ADDED Requirements

### Requirement: D&D-персонажный бой
Боевой цикл SHALL поддерживать персонную D&D-модель: юнит, несущий `DnDCombatantProfile`, сражается как персонаж с реальным пулом HP, классом доспеха (AC) и d20-бросками атаки. Когда обе стороны пары атаки — D&D-персонажи, атака резолвится через `DnDBattleBridge` (d20 + модификатор + бонус владения vs AC цели; попадание при total ≥ AC; крит при натуральном 20; урон по кубикам оружия). Урон применяется к пулу HP цели; персонаж умирает при HP ≤ 0. Чистые stack-юниты (без профиля) не меняются.

#### Scenario: D&D-атака попадает
- **WHEN** D&D-персонаж атакует D&D-персонажа и d20-бросок + модификаторы ≥ AC цели
- **THEN** цель получает урон по кубикам оружия (с модификатором характеристики)
- **AND** урон вычитается из пула HP цели

#### Scenario: D&D-атака промахивается
- **WHEN** d20-бросок + модификаторы < AC цели
- **THEN** цель не получает урона

#### Scenario: Критический удар
- **WHEN** натуральный бросок = 20
- **THEN** атака является критической (двойные кубики урона)

#### Scenario: Смерть персонажа
- **WHEN** пул HP D&D-персонажа опускается до 0 или ниже
- **THEN** персонаж считается погибшим (не участвует в очереди ходов)

#### Scenario: Инициатива по DEX
- **WHEN** два D&D-персонажа вступают в бой
- **THEN** очерёдность ходов определяется инициативой 10 + DEX-модификатор

#### Scenario: Backward-compatibility
- **WHEN** в бою только stack-юниты (без DnDCombatantProfile)
- **THEN** бой резолвится в классической stack-модели (count × per-unit hp), без изменений
