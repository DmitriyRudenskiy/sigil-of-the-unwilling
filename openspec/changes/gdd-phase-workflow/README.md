# gdd-phase-workflow

Четырёхфазный контур проработки GDD (аудит → углубление → гриль-петли → фиксация),
закреплённый в репозитории: состояния секций в frontmatter и в док-гейте, реестровые
поля, дайджест для ре-грундинга вместо перечитывания 2,6 МБ, тонкие навыки поверх уже
существующих носителей, теги фаз и правило «вопрос владельцу не останавливает работу».

Артефакты: `proposal.md` (замеры расхождения), `design.md` (шесть решений с
отвергнутыми альтернативами), `specs/gdd-phase-workflow/spec.md` (7 требований),
`tasks.md` (6 групп, 25 задач).
