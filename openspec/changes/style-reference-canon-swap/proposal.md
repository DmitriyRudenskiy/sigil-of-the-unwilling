# Proposal: style-reference-canon-swap

## Why

Владелец передал новый комплект референсов (`/Users/user/Downloads/Новая папка с объектами 40`,
8 файлов) и объявил его **единственным каноном стиля**: старый архив `reference/`
(55 пикселей + карта на 57 строк, D-184) из проекта удаляется. Документация стиля
(`docs/13-art-bible.md` rev2, `docs/17-ui-style-guide.md`) сейчас описывает
несуществующий архив: §10 «Карта 57 референсов», §4.6 «измеренные полосы 57 файлов»,
§10.2 «файлы 14/15 остаются в reference как доказательство отрицательного решения» —
после удаления эти строки становятся ложью в документе, который объявлен единым
источником истины по стилю.

Новый комплект меняет не только список файлов: он другой по светлоте и насыщенности
(яркая живописная «долина» вместо «хроники при свече»), вводит золотую
титульную антикву как носитель бренда и иконочный шрифт (Font Awesome 6) как
носитель интерфейсных глифов. Канон, не переписанный под него, будет расходиться
с тем, на что смотрят художник и UI-фаза 5.

## What Changes

- **Архив референсов заменяется целиком.** 8 файлов из папки владельца → `reference/`
  под каноническими именами `01…08` (без перекодирования пикселей); **55 старых
  пикселей удаляются** из `reference/`. Политика git не меняется: пиксели в
  `.gitignore`, в git — только карта `reference/INDEX.md`.
- **`reference/INDEX.md` переписывается** под 8 записей: имя ↔ файл-источник ↔
  размер ↔ категория ↔ «для чего» ↔ провенанс/лицензия. Старая нумерация 01–57
  объявлена исторической (аудит `docs/12-asset-audit*` — замороженный снимок, не правится).
- **`docs/13-art-bible.md` → rev3:** §10 карта референсов (8 файлов), §4.6 полосы
  пересчитаны на новом комплекте, §1.1/§1.2 — сверка формулы D-184 с новым
  комплектом (что подтвердилось, что переписано), §5 типографика (титульная золотая
  антиква + роль иконочного шрифта), §7/§9 формулы иконок, мира, «Знака» — по новым
  носителям, §11 анти-паттерны (записи про удалённые файлы → текстовые решения),
  §12 провенанс (провенанс-свип: эталонная сторона удалена, зафиксировать потолок).
- **`docs/17-ui-style-guide.md`:** §2 типографика (роли шрифтов), §6 иконки
  (глифы FA как отдельная роль — служебные иконки против живописных игровых),
  §9 таблица расхождений с живой темой — новые строки (шрифт-оверрайды, радиусы).
- **Реестры:** D-185 (замена архива референсов, объём вытеснения D-184), D-186
  (типографика: титульная антиква + иконочный шрифт, PT Serif остаётся body),
  запись в `docs/CHANGELOG.md`, новые вопросы в `docs/QUESTIONS.md`, билет
  ASSET-2 (лицензия и приобретение шрифтов) в `docs/mvp/TICKETS.md`.
- **Гарант согласованности:** `scripts/check_reference_index.py` — каждая строка
  карты описывает существующий файл, каждый файл в `reference/` описан в карте,
  словарь статусов легален. Падает на дрейфе 8↔8.
- **Вне объёма (deferred):** тема `game_theme.tres`, UI-сцены, `game/assets/fonts/`
  — носители шрифта подключаются отдельным билетом после решения по лицензии
  (тот же порядок, что D-184: документ → приёмка → фаза 5).
- **Вне объёма (другое намерение):** продакшн-пайплайн генерации концептов
  (comfyui, seed/workflow, жизненный цикл draft → review → approved/rejected,
  реестр концептов, аудит canon/drift/remake) — отдельное change, заводимое после
  решения владельца по UI-канону и политике git; ComfyUI на машине отсутствует
  (замеры — в `design.md`, решение 9).

## Impact

- **Файлы:** `reference/` (8 новых пикселей локально, 55 удалено), `reference/INDEX.md`,
  `docs/13-art-bible.md`, `docs/17-ui-style-guide.md`, `docs/DECISIONS.md`,
  `docs/CHANGELOG.md`, `docs/QUESTIONS.md`, `docs/mvp/TICKETS.md`,
  новый `scripts/check_reference_index.py`.
- **Не трогается:** `game/` (тема, сцены, ассеты, шрифты), `.gitignore`
  (политика `reference/*` + `!reference/INDEX.md` сохраняется),
  замороженные снимки `docs/12-asset-audit.md` / `12-asset-audit-registry.csv`
  (строятся на нумерации 01–57 — помечаются историческими, не переписываются).
- **Верификация:** `python3 scripts/check_docs_links.py` + новый гарант +
  `game/run_tests.sh` (регрессия не ожидается — код игры не тронут).
- **Открытые вопросы (флаг владельцу, не блокер документов):** (1) оба `.woff2` —
  **Font Awesome 6 Pro** (Solid/Light, 6.7.2, 68 глифов, лицензионной записи внутри
  файла нет) — права на Pro не зафиксированы; (2) «шрифт» в комплекте — это
  **образец леттеринга (PNG)**, а не файл шрифта: титульная антиква должна быть
  приобретена/опознана, и у неё должна быть кириллица (UI по-русски).
- **Проверено на машине (2026-10-14):** Godot 4.7.2 импортирует `.woff2` как
  `FontFile` (`importer="font_data_dynamic"`) — конвертация не нужна; размеры и
  подписи 8 файлов сняты `sips`/fontTools.
