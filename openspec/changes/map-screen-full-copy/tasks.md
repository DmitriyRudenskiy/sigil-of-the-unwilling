## 3. Перестановка блоков HUD по макету

- [ ] 3.1 Тесты места: нижняя полоса (силуэт панели отряда из двух блоков,
      медальон, табличка, каркас способностей, кнопка повозки) лежит в нижней
      полосе кадра и в порядке макета; узел хода — в правом нижнем углу; правые
      верхние кнопки — круглые книга и шестерня. Падает на текущем кадре.
- [ ] 3.2 Нижняя полоса: `PartyPanel` переезжает из левого угла в полосу, слоты
      делятся на два блока (2×2 + 1 = пять, ёмкость `DEFAULT_CAPACITY = 5` не
      меняется, три ячейки второго блока не рисуются), пустые слоты остаются
      пустыми.
- [ ] 3.3 Медальон: новый лёгкий контрол `RingProgress` = доля прошедших дней
      месяца (`CampaignCalendar.days_per_month()` = 28), бейдж = цели с
      `done == false` (`CampaignGoalTracker`), клик открывает журнал целей
      (носитель D-241). Табличка: имя поселения из носителя поселения; печенье и
      склянка — заглушка с меткой (провизии и зелий в носителях нет: `HeroInventory`
      хранит артефакты), тикет «провизия и зелья как данные».
- [ ] 3.4 Каркас способностей: восемь пустых ячеек + оверлей-метка «задача»,
      иконки птицы и лотоса не рисуются, клик — no-op, один тикет на блок и его
      иконки. Круглая кнопка повозки ведёт в городской экран существующим путём
      (`city_screen.gd:125` → `buy_cart_pressed`), доступность = доступность
      городского экрана.
- [ ] 3.5 Узел хода: большая круглая кнопка + две малые (мечи, глобус). Кнопка
      хода сохраняет семантику «единственный драйвер хода» (существующие тесты
      `Кнопка хода` обязаны остаться зелёными); малые кнопки — заглушки с меткой,
      не кликаются, один тикет «вспомогательные кнопки узла хода».
- [ ] 3.6 Правый верхний угол: книга и шестерня как круглые кнопки с носителями
      экранов; город/партия/хроника/меню переезжают в блоки макета, второй
      носитель экрана не заводится.
- [ ] 3.7 Левая нижняя колонка: плашка даты с шестерней (строка через
      `GameText.campaign_date`, литерала в коде экрана нет), новый лёгкий узел
      миникарты кампейна на `MapScreenModel` + `RegionMap` + `FogOfWar`
      (боевой `MinimapPanel` не трогается), вертикальная полоса из четырёх
      тайлов: четвёртый (круг) сбрасывает выбор региона и неактивен без выбора,
      тайлы 1–3 сохраняют свои носители. Дата следует за ходом (существующий тест
      остаётся зелёным), миникарта читает тот же носитель, что и поле (тест).
- [ ] 3.8 Верхняя полоса счётчиков: носитель-рамка макета (латунные ячейки,
      разделитель, орнамент конца) вместо текущего ряда; `CampaignCounters` остаётся
      единственным источником строк, заполняются только счётчики с носителем
      (правило T-158 → вариант (а) сохраняется: пустая ячейка не рисуется),
      не предъявленные попадают в реестр скрытых, а не исчезают молча.
- [ ] 3.9 `python3 -m gdtoolkit.linter` и `godot --headless --path game --import`
      чистые; леджер тестов (`+/−/quarantine`, было X → стало Y) в треде.
