## 3. Перестановка блоков HUD по макету

- [ ] 3.1 Тесты места: нижняя полоса (два блока по 4 слота, медальон, табличка,
      блок заклинаний, кнопка повозки) лежит в нижней полосе кадра и в порядке
      макета; узел хода — в правом нижнем углу; правые верхние кнопки — круглые
      книга и шестерня. Падает на текущем кадре.
- [ ] 3.2 Нижняя полоса: `PartyPanel` переезжает из левого угла в полосу, слоты
      делятся на два блока по 4 (вместо 5 в ряд), пустые слоты остаются пустыми;
      медальон и табличка поселения получают носители значений либо задачу;
      бирюзовое кольцо прогресса вокруг медальона не рисуется, пока не отвечен
      вопрос о его мере (design.md, Open Questions).
- [ ] 3.3 Блок заклинаний/способностей (8 слотов) и круглая кнопка повозки:
      носитель-заглушка с явной отметкой задачи, значения не выдумываются;
      строки реестра ссылаются на заведённые T-.
- [ ] 3.4 Узел хода: большая круглая кнопка + две малые (мечи, глобус). Кнопка
      хода сохраняет семантику «единственный драйвер хода» (существующие тесты
      `Кнопка хода` обязаны остаться зелёными), малые кнопки без экрана-носителя
      выключены.
- [ ] 3.5 Правый верхний угол: книга и шестерня как круглые кнопки с носителями
      экранов; город/партия/хроника/меню переезжают в блоки макета, второй
      носитель экрана не заводится.
- [ ] 3.6 Левая нижняя колонка: плашка даты с розеткой, панель миникарты,
      вертикальная полоса тайлов; дата следует за ходом (существующий тест
      остаётся зелёным), миникарта читает тот же носитель, что и поле (тест).
- [ ] 3.7 Верхняя полоса счётчиков: носитель-рамка макета (латунные ячейки,
      разделитель, орнамент конца) вместо текущего ряда; `CampaignCounters` остаётся
      единственным источником строк, заполняются только счётчики с носителем
      (правило T-158 → вариант (а) сохраняется: пустая ячейка не рисуется),
      не предъявленные попадают в реестр скрытых, а не исчезают молча.
- [ ] 3.8 `python3 -m gdtoolkit.linter` и `godot --headless --path game --import`
      чистые; леджер тестов (`+/−/quarantine`, было X → стало Y) в треде.
