## ADDED Requirements

### Requirement: Поле графа регионов — узел игрового пути
Кампанейское поле карты SHALL существовать в игровом пути как узел сцены
кампании, а не только как модель данных. Видимые игроку объекты поле SHALL
читать из канонического носителя (`FogOfWar` + `RegionMap` через
`MapScreenModel`); параллельный список «известного» заводить нельзя (D-200).

#### Scenario: Поле видно в игре
- **WHEN** игрок открывает кампанию
- **THEN** на экране есть поле карты с биомом, туманом войны и объектами узлов
- **AND** кадр не показывает пустой фон там, где должно быть поле

#### Scenario: Визит узла меняет поле и миникарту
- **WHEN** герой посещает узел графа и туман войны открывается
- **THEN** поле и миникарта показывают открывшийся объект
- **AND** проверка идёт от сигнала интерфейса, а не от прямого вызова метода
  модели

#### Scenario: Модель без прод-вызывающего — дефект
- **WHEN** проверка игрового пути не находит вызова модели экрана карты из
  прод-кода
- **THEN** это считается дефектом экрана, а не допустимым состоянием «модель
  готова, узла ещё нет»
