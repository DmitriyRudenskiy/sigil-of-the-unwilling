## ADDED Requirements

### Requirement: Поле графа регионов — узел игрового пути
Кампанейское поле карты SHALL существовать в игровом пути как узел сцены
кампании, а не только как модель данных, и SHALL принимать клик по региону.
Видимые игроку объекты поле SHALL читать из канонического носителя (`FogOfWar` +
`RegionMap` через `MapScreenModel`); параллельный список «известного» заводить
нельзя (D-200).

#### Scenario: Поле видно в игре
- **WHEN** игрок открывает кампанию
- **THEN** на экране есть поле карты с биомом, туманом войны и объектами узлов
- **AND** кадр не показывает пустой фон там, где должно быть поле

#### Scenario: Визит узла меняет поле и миникарту
- **WHEN** герой посещает узел графа и туман войны открывается
- **THEN** поле и миникарта показывают открывшийся объект
- **AND** проверка идёт от сигнала интерфейса, а не от прямого вызова метода
  модели

#### Scenario: Модель без прод-вызывающего — дефект
- **WHEN** проверка игрового пути не находит вызова модели экрана карты из
  прод-кода
- **THEN** это считается дефектом экрана, а не допустимым состоянием «модель
  готова, узла ещё нет»

#### Scenario: Клик по региону выбирает регион
- **WHEN** игрок кликает по открытому региону поля
- **THEN** регион выбран, отклик идёт через существующий `MapScreenModel`
  (карточка региона, причины недоступности), нового входного пути и новой модели
  не заведено
- **AND** состояние выбора живёт в узле поля, `RegionMap` от клика не мутирует

#### Scenario: Маркер отряда — существующий носитель
- **WHEN** поле показывает положение отряда
- **THEN** маркер рисуется по `RegionMap.hero_region`, отдельного спрайта или
  отдельного списка «кто на карте» нет

#### Scenario: Поле не перехватывает ввод интерфейса
- **WHEN** клик приходится на область HUD (полоса счётчиков, нижняя полоса, узел
  хода)
- **THEN** нажатие получает элемент HUD, а не поле; проверка — тестом клика по
  кнопке, лежащей поверх поля
