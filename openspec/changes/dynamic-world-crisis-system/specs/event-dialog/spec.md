# Event Dialog UI Specification

## ADDED Requirements

### Requirement: Панель события с выбором
Диалог события SHALL отображать иконку, заголовок, описание и кнопки вариантов; для кризисов дополнительно показывается бейдж серьёзности. Остальной интерфейс блокируется, пока диалог открыт.

#### Scenario: Открытие диалога события
- **WHEN** событие срабатывает
- **THEN** открывается центральная панель с тёмной подложкой
- **AND** ввод в остальные UI элементы заблокирован

#### Scenario: Бейдж кризиса
- **WHEN** открыт диалог кризиса (тип CRISIS)
- **THEN** виден бейдж серьёзности (индикатор 1–5)
- **AND** кнопка закрытия без выбора недоступна

### Requirement: Отображение требований и последствий выбора
Каждая кнопка выбора SHALL показывать текст варианта, невыполненные требования (красным) и превью эффектов (иконка + значение).

#### Scenario: Невыполненное требование
- **WHEN** выбор требует здание, которого нет у игрока
- **THEN** требование отображается красным
- **AND** кнопка неактивна

### Requirement: Анимация и звук
Диалог SHALL открываться с анимацией (fade-in + scale) и звуковым эффектом; выбор варианта подтверждается звуком.

#### Scenario: Анимация открытия
- **WHEN** диалог открывается
- **THEN** подложка и панель появляются с fade-in
- **AND** воспроизводится звуковой эффект
