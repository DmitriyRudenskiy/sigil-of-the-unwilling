## MODIFIED Requirements

### Requirement: Панели и рамки
Панели SHALL иметь фоновую текстуру, рамку по периметру, закруглённые углы (radius 4px). Размеры рамок: 2px для обычных панелей, 4px для модальных окон. Носителем фоновой текстуры SHALL быть ассет-изображение, произведённый генерационным контуром; панель экрана, у которой фон задан только кодом (`StyleBoxFlat`) или заглушкой, приёмку не проходит. Цвет носителя проверяется по действующему правилу ΔE против палитрной полосы; конфликт макета и палитры фиксируется как вопрос владельцу (Q-M89), а не решается сменой макета.

#### Scenario: Стандартная панель
- **WHEN** открывается панель (InfoPanel, ArmyPanel)
- **THEN** фон использует C_PANEL_BG с текстурой
- **AND** рамка имеет цвет C_PANEL_BORDER

#### Scenario: Модальное окно
- **WHEN** открывается диалог (ArtifactChestDialog)
- **THEN** рамка утолщается до 4px
- **AND** тень становится глубже (shadow_size 12)

#### Scenario: Экран героя
- **WHEN** открывается экран героя
- **THEN** его пергаментные секции используют носители макета 12 (пергаментная панель
  с рваным краем, латунная рамка портрета, латунные разделители)
- **AND** цвет носителя проверен по ΔE против палитрной полосы

#### Scenario: Затемнение фона
- **WHEN** открыто модальное окно
- **THEN** фон затемняется C_OVERLAY_DIM (75% прозрачности)
- **AND** клик вне окна закрывает его

## ADDED Requirements

### Requirement: Носители элементов экрана героя
Элементы канонического макета экрана героя SHALL иметь носители-ассеты,
произведённые генерационным контуром (`image-clone/`, ComfyUI-очередь) с якорями из
кропов самого макета и с кадровым промптом по стилю: пергаментная панель (9-slice,
рваный край), латунная рамка портрета, латунный разделитель, плитка кнопки-камня
(состояния: покой, фокус, нажата, недоступна), слот-рамка экипировки, карточка
участника с профилем-рамкой, полосы уровня и количества, иконки характеристик.
Каждый носитель SHALL регистрироваться с провенансом и проходить гейт ассетов
(`scripts/check_ui_assets.py`: целые углы альфы, 9-slice-совместимость, ореолы).

#### Scenario: Носитель произведён
- **WHEN** для элемента макета заведён ассет
- **THEN** он получен кадровым прогоном генерационного контура с указанием
  использованных якорей
- **AND** гейт ассетов зелёный, провенанс записан

#### Scenario: Контур недоступен
- **WHEN** генерационный контур (очередь ComfyUI) недоступен
- **THEN** элемент регистрируется в карте элементов с номером задачи
- **AND** экран не публикуется с молча отсутствующим носителем и не подменяется
  процедурной имитацией

### Requirement: Заглушка не является носителем
Экран SHALL ссылаться на носитель, прошедший гейт ассетов: изображение-заглушка
(однотонный квадрат, кадр меньший минимального размера элемента, файл без
альфа-канала там, где он нужен) не удовлетворяет требованию носителя, а ссылающийся
на него экран не проходит приёмку визуальной смены.

#### Scenario: Ссылка на заглушку
- **WHEN** приёмка находит в экране ссылку на 154-байтную заглушку или иной кадр,
  не проходящий гейт ассетов
- **THEN** приёмка падает с именем ассета и ссылкой на задачу производства
- **AND** смена не публикуется
