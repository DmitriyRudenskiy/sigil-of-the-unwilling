# Design

## Context

Реализовано: `signs.json` (8 знаков: искра/время/баланс/первозданный/тень/гармония/цикл/основа; этика-векторы, T-002/T-124/T-129), `SignChoiceUI` (выбор из 8), Престиж-ledger (K-M16, `CampaignComposition`), `prestige.json` (ранги, D-133), `EthicsSystem`. Не реализовано: SM знака (DORMANT/ACTIVE/SLEEPING), фракционные действия (≤12, штраф стиля), косметические ранги в UI (титул/рамка), счётчик «N осталось».

## Goals / Non-Goals

**Goals:** формализовать канон §3.7/02c; SM знака; фракционные действия (≤12 за кампанию, штраф стиля только за повтор); косметика (S2); якорь кампании (ход 21 = «Почитаемый»).

**Non-Goals:** испытания (Post-MVP, 1.0: 8 испытаний +250), PvP (нет мультиплеера, S3), приток населения (S2: косметика), передача знака (MVP: нет).

## Decisions

- **8 знаков, выбор на всю игру** (Q18, D12 — автор 2026-10-02; «из 3» — устарело). Все 8 играбельны в MVP (Q-M32; C-16: строка MVP-scope «подмножество — TBD» устарела).
- **Престиж = единое число, ledger** (K-M16, K-D5: без счёта): универсальные начисления/штрафы + фракционные действия знака (≤12 за кампанию). Штраф стиля — только за повтор (повторяющееся фракционное действие). Потеря не штрафуется; тактическое отступление не штрафуется.
- **Ранги** (финальная редакция 2026-09-30): пороги 0/200/500/1000/2000 (5 рангов, титулы «Безымянный»/«Знаемый»/«Почитаемый»/«Славный»/«Легендарный» — канонизация титулов владельцем 2026-10-04, D-133); 6-ранговая шкала 0/500/1500/3500/7000/12000 аннулирована (K-D5/K-M16). Падение ниже порога = понижение.
- **Якорь кампании**: ход 21 = «Почитаемый» (500–999), верх — касание «Славного» (1000). Баланс — в `prestige.json` (D-133).
- **Косметика (S2)**: притока населения нет; награда ранга = титул/косметика. «Район создан» — не источник Престижа (K-M16, C-11).
- **SM знака**: DORMANT→ACTIVE (выбор); ACTIVE→SLEEPING (Престиж ≤ 0); SLEEPING→ACTIVE (Престиж > 0). SLEEPING ≠ game over. TRIAL — Post-MVP.
- **Один знак на носителя** (инвариант). Потеря — только смерть; MVP: передача нет; смерть носителя — «утрата» (−2 к спасам, K-M11), кампания продолжается (R1).

## Risks / Trade-offs

- [C-16: MVP-scope «подмножество — TBD» vs Q-M32 (все 8)] → Q-M32 новее — канон; синк docs.
- [Фракционные действия ≤12 — счётчик в сейве] → поле `faction_actions_used` в ledger; миграция fail-fast.
- [Штраф стиля «за повтор» — определение повтора] → повтор = то же фракционное действие знака (id); параметры — баланс-конфиг.
- [Косметика рангов — UI] → титул/рамка в mvp-ui-flow; здесь только требование. Титул закрыт плитой `SignPlaque` (2.3, 2026-10-25); рамка осталась — T-198 (градация пяти рамок не описана ни в каноне, ни в макете).
