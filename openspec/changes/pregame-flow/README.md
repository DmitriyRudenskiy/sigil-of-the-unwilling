# pregame-flow

Предыгровой поток (Q18, автор 2026-10-02): 6 шагов до хода 1 — конструктор → знак (из 8 на всю игру) → земной шар (граф регионов, K-T7) → города (штраф оккупации после второго, кривая TBD) → партия (5 попутчиков) → тренировка (база, не наём). Реализовано: конструктор (character_creation_ui.gd), знак (sign_choice_ui.gd, T-002). Остаток: земной шар (region-graph-map), выбор городов, стартовая партия, playable slice 3 (C-15).
