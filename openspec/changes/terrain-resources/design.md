## Context

Текущее состояние карты и ресурсов:

- **Террейн**: `MapModel.terrain_grid[cell]` → `HexUtils.Terrain {WATER=0,SWAMP=1,SAND=2,
  GRASS=3,FOREST=4,MOUNTAIN=5,SNOW=6}`. Горы непроходимы (`is_walkable` исключает MOUNTAIN),
  леса проходимы. Генерация по шумам высоты/температуры (`MapModel.generate_noise`).
- **Ресурсы на карте**: `MapSpawner.place_resources()` кладёт `map.resource_cells`
  (cell → int 0–6) на проходимые клетки, **исключая WATER/MOUNTAIN**; `WorldSpawner` рисует
  спрайты-эмодзи. На контакте (`HeroMovementController._move_next_step` → `request_resource_pickup`)
  и `WorldEventRouter._on_hero_moved` ресурс подбирается и клетка стирается.
- **Скрытые жилы**: `ResourceNodeManager.generate_nodes_for_map` — 8% шанс по биому
  (oak/silver/coal/…), система discovery/extraction-ключей.
- **ResourceDef**: `wood` (Дерево, биомы grass/forest, иконка 🌲, extraction_unit=worker) и
  `stone` (Камень, биом mountain, иконка 🪨, extraction_unit=worker) — уже есть,
  `is_hidden_resource=false` (базовые). `HeroResources.pickup_resource(int)` начисляет по
  индексу в `["wood","mercury","ore","sulfur","crystal","gems","gold"]`.

Недостаёт: горы не дают камень (на них ресурсы не кладутся), леса не дают конкретно
дерево. Хотят: лес и горы как точки добычи.

## Goals

- Сделать лес и горой точками добычи (лес → дерево, гора → камень).
- Разместить точки во время генерации карты.
- Добыча по контакту с клеткой, с истощением и персистентностью.
- Визуально маркировать точки добычи и выработанные клетки.
- Сохранить существующую систему `resource_cells` и вердикт `run_operability.sh` = CLEAN.

## Decisions

### D1: Движок «террейн → ресурс» в одном месте
Отображение `terrain_grid → resource_id` вынесено в один модуль (напр. `TerrainResourceMap`
в `game/scripts/data/` или константа в `MapModel`): `FOREST→wood`, `MOUNTAIN→stone`.
Расширяемо на другие биомы (см. Open Question), но по умолчанию — только лес и горы.

### D2: Точки добычи — отдельное поле модели
В `MapModel` новое поле `terrain_resource_cells: Dictionary = {}` (cell → resource_id).
Популируется `MapSpawner.place_terrain_resources()` после генерации террейна, до/после
`place_resources`. Отдельно от `resource_cells`, чтобы не ломать старую систему.

### D3: Добыча по контакту
`WorldEventRouter._on_hero_moved(cell)`: после текущей логики проверить `terrain_grid[cell]`
по `TerrainResourceMap`; если клетка есть в `terrain_resource_cells` и не истощена —
начислить ресурс герою (`hero.resources`), пометить истощённой, эмитить сигнал, записать
в `world_delta`. Повторный вход ресурс не даёт.

### D4: Истощение + персистентность
Истощённые клетки хранятся (напр. `terrain_resource_cells` убираем, а состояние в
`world_delta.add_removed_terrain_resource(cell)` / отдельный сет). Настройки истощения:
по умолчанию точки исчерпаны навсегда; выработанная клетка не восстанавливается в этом
прогоне.

### D5: Визуальная маркировка
Точки добычи визуально标记руются (спрайт/иконка 🌲/🪨 над клеткой или подсказка);
выработанные — меняют вид (убираем иконку/замещаем). Реализация — через существующий
`MapRenderer`/`WorldSpawner`-слои, без нового рендер-стека.

## Risks

- **Конфликт с `place_resources`**: старые ресурсы кладутся на проходимые клетки, включая
  леса; могут совпасть с лесной точкой. Митигация: D2 (раздельные поля) + проверка
  пересечений при размещении.
- **Горы непроходимы, но их можно «обрабатывать»**: если герой не может встать на гору,
  добыча по контакту недостижима. Митигация: добыча по **соседней** клетке (контакт),
  либо горы сделать добычивыми из соседней клетки — **открытый вопрос**.
- **Плотность**: если каждой лесной/горной клеткой — карта завалит дерево/камень.
  Митигация: D6 (конфигурируемая плотность).
- **Персистентность истощения**: надо синхронизировать с `world_delta`/состоянием карты.
  Митигация: D4, отдельное поле + сериализация.

## Migration

1. `TerrainResourceMap` (D1): FOREST→wood, MOUNTAIN→stone.
2. `MapModel.terrain_resource_cells` (D2).
3. `MapSpawner.place_terrain_resources()` в генерации (`MapGenerator`).
4. Добыча по контакту в `WorldEventRouter._on_hero_moved` (D3).
5. Истощение + `world_delta` (D4); маркировка (D5).
6. `run_operability.sh` (CLEAN) + автотесты генерации/добычи.

## Open Questions

1. **Добыча из соседней клетки**: горы непроходимы — добывать камень, стоя на соседней
   клетке, или горы сделать проходимыми для добычи? (по умолчанию — контакт из соседней)
2. **Истощение**: навсегда / возобновляемо по ходу / по лимиту ходов?
3. **Плотность**: все клетки лесов/гор, или выборочно (напр. каждый N-ный)?
4. **Требование**: нужен юнит «worker»/навык для добычи (у `wood/stone` extraction_unit=worker),
   или базовая добыча всегда доступна?
5. **Охват**: только лес/гора (wood/stone), или расширить на снег→руда, болото→железо?
6. **Визуал**: формат маркировки (спрайт/эмодзи/подсказка) и размер.
