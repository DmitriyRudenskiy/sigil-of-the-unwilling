# Spec Delta: crafting (NEW capability)

## ADDED Requirements

### Requirement: Система SHALL предоставлять данные-рецепты
Рецепты крафта определяются в `game/data/config/crafting_recipes.json` и загружаются с валидацией: каждый ресурс, технология и результат существуют в реестрах игры.

#### Scenario: Валидный набор
- **WHEN** игра стартует с корректным JSON
- **THEN** все рецепты зарегистрированы, ≥8 штук, покрывают каждый стратегический ресурс

#### Scenario: Некорректный рецепт
- **WHEN** рецепт ссылается на неизвестный ресурс
- **THEN** загрузка падает с явной ошибкой валидации, рецепт не активен

### Requirement: Крафт SHALL требовать ресурсы, технологию и мастерскую
`can_craft(recipe)` возвращает true только если у героя есть все ресурсы, технология изучена и в городе построена мастерская.

#### Scenario: Успешный крафт
- **WHEN** все требования выполнены и вызван `craft(recipe)`
- **THEN** ресурсы списаны, предмет добавлен в инвентарь с весом, событие `item_crafted` отправлено

#### Scenario: Отказ по ресурсам
- **WHEN** одного ресурса меньше стоимости
- **THEN** `can_craft` = false, состояние мира не изменилось

### Requirement: Результаты SHALL уважать логистику и артефактный контур
Обычные предметы проходят через weight-carry-систему героя; результаты класса «артефакт» регистрируются в ArtifactRegistry.

#### Scenario: Перегруз
- **WHEN** предмет не помещается по весу
- **THEN** крафт отклонён до списания ресурсов

### Requirement: Прогресс крафта SHALL сохраняться
Открытые рецепты и история крафта сериализуются в world-state; load восстанавливает их без дублирования событий.

#### Scenario: Roundtrip
- **WHEN** state сохранён и загружен
- **THEN** набор открытых рецептов идентичен исходному
