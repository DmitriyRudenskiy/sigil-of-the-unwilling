# Design

## Context

K-T7 (2026-10-02) заменил hex-мир кампании на граф регионов: «карта — это граф; узлы — атрибуты регионов; движение — по рёбрам». В campaign-слое (`game/scripts/campaign/`) карты нет: `TurnDriver` знает только ход/фазу, `ThreatSystem` — только город. `AdventureUI` + `WorldPersistence` — legacy hex-мир pre-pivot (arena/1.0). Это главный провал MVP: без похода нет «увидел → двинул → решил», нет one-time XP узлов (R4), нет «герой в городе → бой» (R5/R6), не проверяется инвариант доходимости якорей (K-M4).

## Goals / Non-Goals

**Goals:** данные графа (MAP-1 + MVP-маска), узлы с one-time loot, туман (радиус 1), движение по переходам (K-M4, R7), SM героя с авто-режимом и безопасным отступлением (Y10), инвариант доходимости якорей 7/14/21.

**Non-Goals:** дороги/NPC-поселения/5+8 узлов/туман-механики (Post-MVP), hex-слой (legacy-арена, 1.0), «слухи» (Post-MVP), кривая штрафа оккупации (pregame-flow).

## Decisions

- **Граф = JSON-данные, не процедурная генерация.** MAP-1 (40–48 регионов) — фиксированный файл `game/data/campaign/region_graph.json`; MVP-маска (5–8 регионов) — отдельный файл `mvp_mask.json` (K-R4: единый источник данных). Генерация узлов — по `terrain_preference` (жёсткая привязка в MVP, K-M2/P-3).
- **Переход = рёберный шаг, не hex-шаг** (D-191: «переход» — единица логистики). Скорость `биом + ЛОВ − вес` (K-M4) — баланс-конфиг, создаётся в Ф4 (2 регулярных биома + заготовки). Еда тратится в днях переходов, а не каждый календарный день (Q-M75→(б)).
- **Туман = множество открытых регионов** (радиус 1, Q-M54→(а)); свой город всегда видим (EC 07-ui-ux). Состояние — в сейве (секция карты через `MvpSaveSchema`, миграция fail-fast).
- **SM героя** — в `region_map.gd` (не в `party_system.gd`): позиция, туман, visited-узлы, авто-режим (2 дня без выбора). Боевые состояния (BATTLE/VICTORY/DEFEAT) — шов в `campaign_battle.gd` (dnd-battle-ladder).
- **Инвариант доходимости** — авто-балансировщик на данных (не на скорости игрока): если якорь 7/14/21 недосягаем за бюджет переходов — смещается расстановка узлов, а не формула K-M4.
- **Отступление (Y10)** — авто-возврат в город за 1 день, новых боёв по пути нет; это состояние RETREAT SM, не «полёт».

## Risks / Trade-offs

- [Расстановка узлов — дизайн-задача (T03 в 09-risks)] → генератор с `terrain_preference` + детерминированный seed; баланс — в Ф4.
- [К-M4 ратифицирован, но числа (биом/вес) — «создаётся в Ф4»] → баланс-конфиг с плейсхолдерами запрещён: файл создаётся с явными TBD-пометками и не читается до Ф4 (аналог инертных ключей raids.json — не повторять эту ошибку).
- [C-3: есть ли сетка в боевом экране (07-ui-ux «Бой: сетка» vs Q-M47 «лестница без поля»)] → карта не зависит от ответа: граф регионов — без hex. Боевое поле — вопрос `dnd-battle-ladder`; до вердикта владельца боевой экран не строится по «сетке».
- [Legacy hex-мир остаётся в репо] → не трогаем (`AdventureUI`, `WorldPersistence`); campaign-слой не импортирует их.
