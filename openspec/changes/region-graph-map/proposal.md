# Proposal

## Why

GDD 02-mechanics §3.1 (K-T7, 2026-10-02) канонизирует карту кампании как **граф регионов** (MAP-1: 40–48 регионов, MVP-маска 5–8), но в кампании карты нет вовсе: герой не имеет позиции, нет узлов, тумана, переходов. `AdventureUI` — legacy hex-мир pre-pivot, не campaign-слой. Это самая крупная нереализованная механика MVP: без неё не работают «поход», «узел = one-time XP/лоот», «отступление», «герой в городе → бой», инвариант доходимости якорей 7/14/21 (K-M4).

## What Changes

- Вводит граф регионов как данные кампании: фиксированный граф MAP-1 (40–48 регионов) + MVP-маска (связное подмножество 5–8 регионов, K-R4).
- Вводит узлы (K-T7 Ф5а: узел = атрибут региона): 5 узлов MVP (2 руины, 1 руда, 2 лагеря CR 1/2) + 1 город игрока + 2–3 нейтральных поселения (post-MVP); loot one-time (Y4).
- Вводит туман: неизведанные регионы не видны; радиус в MVP = константа 1 (Q-M54→(а)).
- Вводит движение (K-M4, ратифицирован): скорость = биом + ЛОВ − вес; переход = единица логистики (D-191); еда тратится за переход (R7, Q-M75→(б)); инвариант доходимости якорей 7/14/21 (авто-балансировщик).
- Вводит SM героя: EXPLORE/ENGAGE/BATTLE/VICTORY/DEFEAT/RETREAT; авто-режим; отступление = авто-возврат в город за 1 день без боёв по пути (Y10).

## Capabilities

### New Capabilities
- `region-graph-map`: граф регионов, узлы, туман, движение, SM героя, инвариант доходимости.

### Modified Capabilities
- None.

## Deduplication and status (v4)

- **Дубликаты (main specs):** нет — `terrain`, `rivers`, `roads`, `verticality` описывают pre-pivot hex-мир (legacy-арена), не campaign-граф; supersedes-отношение, не дублирование.
- **Дубликаты (archive):** `2026-09-17-city-hex-layout-prototype` и др. — hex-слой, не graph; не дублируются.
- **Dead tasks:** нет — механика не реализована в campaign-слое (проверено: нет `region_graph`/`RegionGraph`/`region_map` в `game/scripts/campaign/`).
- **Пересечения:** `dnd-battle-ladder` (ENGAGE/BATTLE/RETREAT — боевая часть SM), `party-characters` (снабжение партии в переходах, R7), `mvp-ui-flow` (экран «Карта»: туман, узлы, оверлей-режимы 15.1).

## Impact

- Новые данные: `game/data/campaign/region_graph.json` (MAP-1), `mvp_mask.json` (5–8 регионов).
- Новый скрипт: `game/scripts/campaign/region_map.gd` (граф, туман, SM героя) + шов в `TurnDriver` (player-фаза: переходы) и `ThreatSystem` (рейд по клетке героя → бой).
- Сейв: секция карты (позиция героя, туман, visited-узлы) — через `MvpSaveSchema` (миграция fail-fast, save-migration).
- Не затрагивает: legacy hex-мир (`AdventureUI`, `WorldPersistence`) — остаётся для arena/1.0.

## Contradictions

- **C-3 (docs vs code, флаг владельцу):** 07-ui-ux «Бой: сетка (размер — 07-balance#4, D4)» + 02-mechanics §3.4 «размещение, местность поля» vs Q-M47 «K-канон-резолвер — лестница без поля» и реализованный `campaign_battle.gd` (чистая лестница, без поля). Есть ли сетка в боевом экране MVP — требует вердикта владельца; здесь карта — это граф регионов (без hex), поле боя — вопрос `dnd-battle-ladder`.
- **TBD (без ссылки на реестр):** радиус тумана в MVP — GDD пишет «радиус TBD, Ф3», но Q-M54→(а) уже ратифицировал константу 1; строка GDD устарела. Кривая штрафа оккупации (pregame, 00-overview) — «TBD, баланс» — реестрируется в `pregame-flow`.
