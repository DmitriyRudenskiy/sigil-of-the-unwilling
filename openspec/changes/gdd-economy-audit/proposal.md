# Proposal: gdd-economy-audit

## Why

Задача 5.3 контура фаз (`gdd-phase-workflow`) — «ревью-часть по экономике» — по
форме не сборка инструмента, а первый прогон готового контура на живой секции.
Держать её в change, который описывает метод, значит смешивать «носитель есть» и
«носитель применили»: первое закрыто 26 задачами и гейтом, второе требует цитат по
конкретной таблице и, возможно, вопросов владельцу. Перенесено отдельным change по
решению владельца от 2026-10-27.

## What changes

- `docs/06-economy.md` проходит фазу «аудит → верификация» по контракту
  `docs/19-gdd-workflow.md`: каждая строка таблицы источников/стоков и каждая
  строка якорей получает подтверждение **носителем** (файл:строка в `game/` или
  запись реестра) либо вопрос `Q-M##`.
- Секция меняет состояние только по решению с номером: `deepened → verified`
  требует `D-###`, промежуточный `verified` с незакрытым `⏳` недопустим.
- Найденные противоречия идут в `docs/QUESTIONS.md` (по одному на дыру) и/или
  `docs/09-risks.md` (`R-##`), а не правятся молча.

## Metrics

| Факт | Число |
| --- | --- |
| `docs/06-economy.md` | 101 строка, `status: deepened`, `date: 2026-10-16` |
| Таблица «Источники/стоки» (§20) | 5 строк данных (Еда, Дерево, Камень, Железо, Оружие) |
| Таблица «Якоря баланса кампании» (§68) | 5 строк данных |
| Секций в файле (`##`) | 7 (включая легаси-секцию «Легаси city-economy (не канон)») |
| Балансировочных рычагов, перенесённых из GDD.md | 17 (§94) |
| Строк с цитатой-носителем (`game/...:число` или `D-###`) в двух таблицах | 0 |

Прежняя формулировка 5.3 говорила «14 табличных строк» — по замеру их 10 (5 + 5)
плюс две строки заголовков; расхождение — признак того, что задача писалась без
замера, и это же причина, по которой она перенесена.

## Out of scope

- Правка чисел баланса: числа живут в `game/data/config/balance/*.json` и
  `docs/07-balance.md` §10; смена меняет документ и задаёт вопросы, код не трогает.
- Остальные 42 секции GDD: прогон по одной секции за смену — правило `loop-me`
  (лимит три прохода, остановка по условию).
- Новые фичи экономики: документ никогда не тянет код за собой (D-224).
