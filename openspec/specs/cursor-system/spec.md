# cursor-system Specification

## Purpose

Определяет систему курсоров для игрового интерфейса: набор спрайтов курсоров для разных режимов взаимодействия, горячие точки (hotspot), переключение режимов, интеграцию с CursorController.

## Requirements

### Requirement: Режимы курсора
Система SHALL поддерживать 6 режимов курсора: DEFAULT (стандартная стрелка), WALK (перемещение героя), COLLECT (сбор ресурсов), ATTACK (атака врага), CAST_SPELL (применение заклинания), TALK (диалог с NPC). Каждый режим имеет уникальный спрайт.

#### Scenario: Курсор по умолчанию
- **WHEN** игра запущена и нет активных действий
- **THEN** отображается курсор DEFAULT
- **AND** hotspot находится в верхнем левом углу стрелки

#### Scenario: Курсор перемещения
- **WHEN** герой начал движение по карте
- **THEN** курсор меняется на WALK
- **AND** hotspot указывает точную точку назначения

#### Scenario: Курсор сбора
- **WHEN** игрок наводит курсор на ресурс для сбора
- **THEN** курсор меняется на COLLECT
- **AND** визуально отражает действие "взять"

#### Scenario: Курсор атаки
- **WHEN** игрок выбирает режим атаки или наводит на врага
- **THEN** курсор меняется на ATTACK
- **AND** hotspot указывает точку удара

#### Scenario: Курсор заклинания
- **WHEN** игрок выбирает заклинание для применения
- **THEN** курсор меняется на CAST_SPELL
- **AND** может отображать школу магии цветом

#### Scenario: Курсор диалога
- **WHEN** игрок наводит на NPC для разговора
- **THEN** курсор меняется на TALK
- **AND** визуально предлагает взаимодействие

### Requirement: Спрайты курсоров
Каждый режим курсора SHALL иметь PNG файл размером 32x32 или 64x64 пикселя с прозрачностью. Hotspot (точка привязки) должна быть указана в конфигурации для каждого курсора.

#### Scenario: Загрузка спрайта курсора
- **WHEN** игра запускается
- **THEN** все спрайты курсоров загружаются в память
- **AND** кэшируются для быстрого доступа

#### Scenario: Настройка hotspot
- **WHEN** курсор применяется
- **THEN** hotspot указывает точную позицию клика
- **AND** визуальное смещение корректно

#### Scenario: Прозрачность курсора
- **WHEN** курсор накладывается на игровой элемент
- **THEN** прозрачные области не перекрывают обзор
- **AND** форма курсора чётко видна

### Requirement: Переключение режимов
CursorController SHALL автоматически переключать режимы курсора на основе событий игры (hero_moving_changed, resource_extracted, battle_started, etc.). Ручное переключение также возможно через set_mode().

#### Scenario: Автоматическое переключение при движении
- **WHEN** герой начинает движение
- **THEN** вызывается _on_hero_moving_changed(true)
- **AND** курсор меняется на WALK

#### Scenario: Автоматическое переключение при сборе
- **WHEN** ресурс собран
- **THEN** вызывается _on_resource_extracted()
- **AND** курсор меняется на COLLECT на 0.6 секунды

#### Scenario: Ручное переключение режима
- **WHEN** вызывается set_mode(Mode.ATTACK)
- **THEN** курсор немедленно меняется на ATTACK
- **AND** режим сохраняется до следующего события

#### Scenario: Возврат к режиму по умолчанию
- **WHEN** действие завершено (движение остановлено, бой окончен)
- **THEN** курсор возвращается на DEFAULT
- **AND** состояние сбрасывается

### Requirement: Конфигурация MODE_ASSETS
MODE_ASSETS в CursorController SHALL содержать полные пути к файлам спрайтов, размеры и hotspot для каждого режима. Пустые пути недопустимы.

#### Scenario: Конфигурация режима WALK
- **WHEN** определяется MODE_ASSETS[Mode.WALK]
- **THEN** путь указывает на `res://assets/cursors/cursor_walk.png`
- **AND** hotspot = Vector2i(16, 32) для указания точкой вниз

#### Scenario: Конфигурация режима COLLECT
- **WHEN** определяется MODE_ASSETS[Mode.COLLECT]
- **THEN** путь указывает на `res://assets/cursors/cursor_collect.png`
- **AND** hotspot = Vector2i(32, 16) для захвата сверху

#### Scenario: Конфигурация режима ATTACK
- **WHEN** определяется MODE_ASSETS[Mode.ATTACK]
- **THEN** путь указывает на `res://assets/cursors/cursor_attack.png`
- **AND** hotspot = Vector2i(28, 28) для точности удара

### Requirement: Fallback курсор
Если спрайт курсора не загружен или путь пустой, система SHALL использовать стандартный курсор Godot (CURSOR_ARROW). Ошибка загрузки должна логироваться.

#### Scenario: Отсутствие файла спрайта
- **WHEN** файл курсора не найден по пути
- **THEN** используется Input.CURSOR_ARROW
- **AND** в лог пишется предупреждение

#### Scenario: Повреждённый файл
- **WHEN** PNG файл не может быть загружен
- **THEN** fallback на стандартный курсор
- **AND** ошибка фиксируется в логе

#### Scenario: Пустой путь в конфигурации
- **WHEN** MODE_ASSETS содержит пустой путь
- **THEN** применяется CURSOR_ARROW
- **AND** требуется исправление конфигурации
