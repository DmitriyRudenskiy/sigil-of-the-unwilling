# save-migration Specification

## Purpose

Определяет контракт персистентности игрового мира: полное покрытие сериализации (матрица + roundtrip-тесты), версионирование формата сейва с миграциями, запрет скрытого статического состояния и переживание активного кризиса save/load.

## Requirements

### Requirement: Каждая stateful-подсистема SHALL иметь roundtrip-покрытие
Для каждой подсистемы игрового состояния существует запись в матрице покрытия (`doc/SAVE_MATRIX.md`) и functional-тест `save → load → deep-equal` (`game/tests/functional/save_roundtrip_*.gd`).

#### Scenario: Gap не мержится
- **WHEN** новая подсистема с состоянием добавлена без roundtrip-теста
- **THEN** тест-набор проваливается (матрица требует строку)

### Requirement: Формат сейва SHALL быть версионирован
Сейв содержит `save_version` (`SaveData.CURRENT_VERSION`); загрузка файла без версии трактуется как v1; между версиями существуют функции миграции (`_migrate_vN_to_vN+1`).

#### Scenario: Миграция v1→v2
- **WHEN** загружается сейв версии 1 при текущей 2
- **THEN** применена `migrate_v1_to_v2`, состояние корректно

### Requirement: Скрытое статическое состояние SHALL запрещено
`static var`, хранящие игровое состояние, запрещены; сезонный счётчик (`WorldSeasons._turns_in_season`) хранится в сериализуемом состоянии (`WorldStateDelta.season_turns`) и перезаписывается при load.

#### Scenario: Load сбрасывает hidden state
- **WHEN** load выполнен
- **THEN** состояние мира полностью определено файлом сейва, артефактов прошлого прогона нет

### Requirement: Активный кризис SHALL переживать save/load
Фаза кризиса, таймеры и уже выбранные варианты восстановления сохраняются (`CrisisEventSystem.serialize_state`) и восстанавливаются (`deserialize_state`) без повторной отработки эффектов.

#### Scenario: Середина кризиса
- **WHEN** save/load во время активного crisis-события
- **THEN** фаза/таймеры идентичны, эффекты не применились повторно
