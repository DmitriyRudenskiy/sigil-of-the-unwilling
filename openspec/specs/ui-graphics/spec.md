# ui-graphics Specification

## Purpose

Определяет систему графических элементов UI: кнопки, панели, рамки, слайдеры, прогресс-бары, декоративные элементы; интеграцию с темой Godot; замену StyleBoxFlat заглушек на текстуры.

## Requirements

### Requirement: Кнопки состояний
Система SHALL предоставлять графику для 4 состояний кнопок: normal (обычное), hover (наведение), pressed (нажатие), disabled (отключено). Каждая кнопка состоит из фона, рамки и текста.

#### Scenario: Кнопка в обычном состоянии
- **WHEN** кнопка отображается без взаимодействия
- **THEN** используется стиль normal с цветом C_BTN_NORMAL
- **AND** рамка имеет цвет C_BTN_BORDER

#### Scenario: Кнопка при наведении
- **WHEN** курсор наведён на кнопку
- **THEN** фон меняется на C_BTN_HOVER
- **AND** может быть лёгкая анимация подсветки

#### Scenario: Кнопка при нажатии
- **WHEN** игрок кликает на кнопку
- **THEN** фон меняется на C_BTN_PRESSED
- **AND** текст может сместиться на 1 пиксель

#### Scenario: Отключенная кнопка
- **WHEN** кнопка недоступна (disabled = true)
- **THEN** используется серый цвет (C_GRAY_DIM_40)
- **AND** курсор не меняется на hover

### Requirement: Панели и рамки
Панели SHALL иметь фоновую текстуру, рамку по периметру, закруглённые углы (radius 4px). Размеры рамок: 2px для обычных панелей, 4px для модальных окон.

#### Scenario: Стандартная панель
- **WHEN** открывается панель (InfoPanel, ArmyPanel)
- **THEN** фон использует C_PANEL_BG с текстурой
- **AND** рамка имеет цвет C_PANEL_BORDER

#### Scenario: Модальное окно
- **WHEN** открывается диалог (ArtifactChestDialog)
- **THEN** рамка утолщается до 4px
- **AND** тень становится глубже (shadow_size 12)

#### Scenario: Затемнение фона
- **WHEN** открыто модальное окно
- **THEN** фон затемняется C_OVERLAY_DIM (75% прозрачности)
- **AND** клик вне окна закрывает его

### Requirement: Прогресс-бары
Прогресс-бары SHALL отображать заполнение от 0% до 100% с использованием цвета заполнения и фона. Типы: здоровье, мана, опыт, время выполнения действия.

#### Scenario: Прогресс здоровья
- **WHEN** отображается здоровье юнита
- **THEN** заполнение зелёным (C_ORB_HIGH)
- **AND** фон тёмно-серый (C_RARITY_TRACK)

#### Scenario: Прогресс маны
- **WHEN** отображается мана героя
- **THEN** заполнение синим (C_SCHOOL_WATER)
- **AND** стиль согласован с темой

#### Scenario: Прогресс опыта
- **WHEN** показывается опыт до следующего уровня
- **THEN** заполнение золотым (C_TEXT_GOLD)
- **AND** плавная анимация изменения

### Requirement: Слайдеры и переключатели
Слайдеры SHALL иметь дорожку (track), ползунок (thumb), области min/max. Чекбоксы и радио-кнопки должны иметь состояния checked/unchecked.

#### Scenario: Слайдер громкости
- **WHEN** игрок регулирует громкость
- **THEN** ползунок перемещается по дорожке
- **AND** значение обновляется в реальном времени

#### Scenario: Чекбокс настроек
- **WHEN** игрок включает опцию
- **THEN** чекбокс показывает галочку
- **AND** настройка применяется немедленно

#### Scenario: Радио-кнопки сложности
- **WHEN** выбран один вариант сложности
- **THEN** только одна радио-кнопка активна
- **AND** остальные деактивированы

### Requirement: Декоративные элементы
Система SHALL включать декоративные разделители, уголки для панелей, фоновые узоры, иконки категорий для улучшения визуального восприятия.

#### Scenario: Разделитель секций
- **WHEN** панель содержит несколько секций
- **THEN** между секциями горизонтальная линия
- **AND** цвет линии C_GRID_LINE

#### Scenario: Уголки панели
- **WHEN** панель имеет декоративные уголки
- **THEN** уголки расположены по 4 углам
- **AND** цвет соответствует рамке

#### Scenario: Фоновый узор
- **WHEN** панель имеет фоновый узор
- **THEN** узор не отвлекает от контента
- **AND** прозрачность 10-20%

### Requirement: Интеграция с ThemeConfig
ThemeConfig SHALL предоставлять пути ко всем графическим элементам UI. game_theme.tres должен использовать текстуры вместо纯色 StyleBoxFlat.

#### Scenario: Загрузка темы
- **WHEN** игра запускается
- **THEN** загружается game_theme.tres
- **AND** все стили применяют текстуры

#### Scenario: Обновление темы
- **WHEN** ThemeConfig изменён
- **THEN** тема перезагружается
- **AND** UI обновляется dynamically

#### Scenario: Fallback на цвет
- **WHEN** текстура не найдена
- **THEN** используется сплошной цвет
- **AND** ошибка логируется
