# UX-спека: боевой HUD (UI-2)

Экран: `scenes/battle.tscn`; HUD: `BattleUI` (CanvasLayer 10) +
`BattleSpellbookPanel` + `SettingsScreen`; постоянные панели: `ResourceBar`,
`ArmyPanel`. Канон экрана: [[07-ui-ux]] (K-M8, M1), правила боя: [[02-mechanics]] §3,
визуал: [[13-art-bible]]. Спецификация включает **дрейф** — текущий код уже растерял
часть канона (см. §3).

## 1. Контракт экрана

| Термин | Значение |
|---|---|
| Вопрос | «Что мне сделать этим ходом, чтобы стол склонился?» |
| Вход | Сталкивание армий на карте кампании → `BattleController.start_battle` |
| Выход | Только финал боя → «Продолжить» → карта кампании (K-M8: отдельного отчёта нет) |
| Видимое состояние | Чей ход; чьи фигуры; чьи HP; лестница исходов; что стоит сделать |
| Первый аффорданс | Кнопка действия активного юнита (Attack/Move), под курсором по умолчанию |
| Вход | Мышь (клик по клетке/кнопке) + клавиши (§5) + геймпад-навигация (фокус, UI-5) |
| Responsive | Фикс-раскладка 1920×1080, stretch canvas_items; минимум читаемости 1280×720 |
| Accessibility | Все состояния — форма+цвет; фокус-рамка; клавиатурная альтернатива каждой кнопки; текст ≥16 px @720p |

Инварианты канона: все влияющие на ход правила видны без подсказок (справка — по
клавише); нет допустимого хода → «Пропустить» доступен всегда; карточка врага всегда
показывает AC/HP/УДЧ/способности (M1).

## 2. Макет (зоны)

```
┌────────────────────────────────────────────────────────────┐
│ A: инициатива (очередь, активный выделен)      [13-art §5] │
├──────────────────────────────┬─────────────────────────────┤
│                              │ B: карточка цели (M1):      │
│    Клеточное поле боя        │ AC/HP/УДЧ/способности       │
│    (hex/square, юниты,       │ + C: лестница исходов       │
│     подсветки ходов)         │ (Триумф…Критпровал, порог)  │
├──────────────────────────────┴─────────────────────────────┤
│ D: нижняя панель: [⚙][Отступление][Ждать][Атака]           │
│    | лог строка ▲▼ [История] | [Оборона][Пропустить][Книга]│
└────────────────────────────────────────────────────────────┘
```

`ResourceBar`/`ArmyPanel` — постоянные панели кампании (не боевые): остаются на
городском/карточном экране; в бою скрыты (`battle.tscn` их не включает — проверено grep; живут в `adventure_ui.tscn`).

## 3. Дрейф: код против канона (чинится в UI-3, фиксируется здесь)

| Канон (07-ui-ux) | Код сейчас | Вердикт |
|---|---|---|
| Инициатива сверху | `initiative_panel` удалён из сцены, `update_initiative` — no-op (`battle_ui.gd:88`) | вернуть зону A |
| Счётчик хода в turn_line | не обновляется (no-op комментарий там же) | вернуть в зону A |
| Attack preview / active unit info | `top_panel` удалён, `set_attack_preview`/`update_active_unit` — no-op (`battle_ui.gd:79-84`) | зоны B/C |
| Лестница исходов (индикатор) | отсутствует полностью | новая зона C |

## 4. Элементы

### A. Инициатива (верхняя полоса)
- Горизонтальная очередь портретов 48×48 (юнит-портрет, [[13-art-bible]] §8.2),
  активный — золотая рамка 2 px + подъём +2 px; мёртвые — десатурация 60%.
- Скролл колесом при >12 юнитов; тултип — имя+HP (не обязателен для решения).
- Счётчик хода — моно-шрифт 24 px справа полосы.

### B. Карточка цели (M1)
- Появляется при наведении/выборе любой вражеской фигуры, не исчезает пока цель
  валидна. Поля: имя (32 px), AC, HP текущ/макс, УДЧ (атака), способности (иконки 32).
- Числа — моно (прыгущая ширина HP убивает чтение).
- Недоступная цель — красная кромка `#e05a4a` + иконка ✗ (не только цвет, §4.3 библии).

### C. Лестница исходов
- Вертикальная шкала из 5 зон: Триумф/Успех/Частичный/Провал/Критпровал; текущий
  перевес — маркер; пороги подписаны числами (моно 16 px); сдвиг от Удачи —
  стрелкой-дельтой. Пересчёт — на каждое изменение состава.
- Зоны: успех — `#7aa85a`→`#c9a227`→нейтральный→`#e05a4a`→`#7a100c`; подписи
  текстом пергаментом (контраст-таблица библии §4.2).

### D. Нижняя панель (живая, правки минимальны)
- Состав (слева направо): ⚙, Отступление, Ждать, Атака | лог-строка + ▲▼ + История |
  Оборона, Пропустить, Книга. Порядок канона; подписи — кириллица (UI-6).
- Атака disabled, пока нет допустимой цели (`set_attack_enabled`); Ждать vs Пропустить
  разведены по ролям: Ждать = ход с ожиданием, Пропустить = нет допустимого хода —
  всегда активен.
- «Авто» — справа от Пропустить (новая кнопка, сигнал `auto_requested`).
- Лог: последняя строка + ▲▼ листают историю (живой механизм, 50 записей);
  панель «История» — ItemList, закрытие Esc.
- Стиль панелей — тема `game_theme.tres`; скругления привести к ≤2 px в UI-3
  (`army_panel.gd` ставит 4/3 — дрейф против библии §6).

### E. Книга заклинаний (живая)
- Слоты школ; недоступные — десатурация + причина в тултипе (не «серо и молча»).
- Выбор → `spell_chosen` → режим цели на поле; Esc закрывает.

### F. Финал боя (новый)
- Оверлей поверх поля: итог (та же лестница, итоговая зона), потери сторон
  (моно-таблица), единственная кнопка «Продолжить». Никаких «закрыть в никуда».

## 5. Ввод

| Действие | Мышь | Клавиша |
|---|---|---|
| Атака / ход | клик по цели/клетке | `A` / `Space` подтвердить |
| Оборона / Ждать / Пропустить | кнопки D | `D` / `W` / `S` |
| Книга | кнопка | `K`, Esc закрыть |
| История | кнопка/▲▼ | `H`, `↑`/`↓` |
| Авто | кнопка | `Q` |
| Настройки | ⚙ | `Esc` (приоритет: открытая панель → закрыть, иначе настройки) |

## 6. Acceptance criteria (для UI-3)

1. Зона A показывает очередь; активный отличим формой (рамка+подъём), не только цветом.
2. Карточка цели (B) содержит AC/HP/УДЧ/способности без подсказок (M1); числа моно.
3. Лестница (C) обновляется до боя и в бою; зоны подписаны; colorblind-тест: различима без цвета.
4. `skip` не отключается никогда, кроме чужого хода; тест на `set_controls_enabled(false)` → skip активен.
5. Финал: один выход «Продолжить»; тест перехода на карту.
6. Все кнопки D доступны с клавиатуры (§5); фокус-рамка видима (библия §6).
7. Тексты — ≥16 px @720p; контраст пар — из библии §4.2 (тест палитры в CI не обязателен, проверено расчётом).

## 7. Вне скоупа UI-2

Ребаланс лестницы (07-balance), AI-автобой (02-mechanics §3.4 реализация), локализация
строк (UI-6), геймпад-навигация целиком (UI-5), бой на нетипичных разрешениях (<1280×720).
