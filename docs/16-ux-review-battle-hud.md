# 16 — UX-ревью боевого HUD

Ревью по [[14-ux-battle-hud]] §6 (7 AC) с опорой на [[13-art-bible]] §4.2/§6.
Канал: harness `game/tools/ux_shots.gd` (живой рендер 1280×720, кадры в
`/tmp/ux-shots/` после `Godot --path game -s tools/ux_shots.gd`); «до» —
worktree на `23ccf030^1` (до шага 2). Диффов шага 2 по цвету в коде нет:
`Color()` в `battle_ui.gd` = 0, палитра — только тема.

## Список расхождений (приоритет)

- **M1-1. Текстура кнопок — синий `#2659BF`** (`assets/ui/widgets/buttons/button_normal.png`,
  центр = RGB 38,89,191). Все кнопки HUD (панель, финал, «Продолжить») — синий
  вне палитры §4.1. Тема ни при чём — ресурс. Фикс: перегенерация четырёх
  текстур button_* в палитру (image-очередь, [[13-art-bible]] §4.1).
- **M1-2. AC7: шрифты <16 px** — `battle_ui.tscn`: `turn_line` 12, `log_line` 13,
  `history_up/down` 10, `history_btn` 14. Фикс: поднять до 16 (пять правок).
- **M2-1. Подписи зон отсутствуют** (A «Очередь», B «Цель», C — вне скоупа шага).
  AC3 требует подписи.
- **M2-2. Хоткеи §5 не реализованы**: только `ui_accept` на финале
  (`battle_ui.gd:71–75`). H/↑/↓/Q/Esc — нет ни в UI, ни в контроллере.
- **M2-3. Карточка без строки способностей** (спека: иконки 32, M1).
- **M2-4. Финал «Остаток: %d / %d»** — числа в одном Label с подписью, шрифт
  serif, не моно (`battle_ui.gd:185–188`).
- **M3-1. Мёртвая ячейка очереди отличается тоном** (десат), без формы —
  colorblind-риск (AC3 оговорка).
- **M3-2. HP-строка карточки при 1 200 000 / 1 200 000 упирается в рамку**
  (кадр 03) — нет отступа/переноса.
- **M3-3. Переход «Продолжить → карта» без теста** (AC5 вторая половина).
