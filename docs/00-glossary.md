# Глоссарий — единая терминология

Единый словарь проекта. Правило: в рабочих документах (`gdd/*`) термин пишется только в **канонической записи**. Запрещённые синонимы — не для лора и нарратива (хроника 04-narrative пишет «живым языком»), а для правил, формул, UI-текстов и тикетов.

Формат: **термин** — определение. *Не писать:* — близкие или запрещённые варианты. Источник — секция, где термин определён.

## Частые перепутывания (шпаргалка)

| Пара | Разница |
|---|---|
| **ход vs раунд** | Ход = день кампании (21 всего). Раунд = единица внутри боя (TIMEOUT 20) |
| **фаза vs фаза кампании** | Фаза — этап хода (SETTLEMENT/PLAYER/THREATS). Фаза кампании — период 1–7 / 8–14 / 15–21 |
| **партия vs отряд** | Партия — персонажи игрока (≤5, ходят на карте). Отряд — юниты города (военная сеть) |
| **юнит vs персонаж** | Юнит — боевая единица города (пул, барраки). Персонаж — член партии (класс, XP, смерть перманентна) |
| **Престиж vs Слава vs репутация** | Престиж — число системы Знака (косметика, S2). Слава — метрика 02g (заказы, уровни города). Репутация — пре-пивот (AtS), в каноне не используется |
| **снабжение vs провизия** | Снабжение — еда на партию (R7). Провизия — колода зданий 02g |
| **соседство vs аура** | Соседство — правило «рядом с B → +X%». Аура — влияние на радиус (02e 7.1) |
| **город vs поселение** | Город — сетка зданий игрока. Поселение — узел карты (не город) |
| **знак vs ЛXXIII** | Знак — артефакт (8, MVP-подмножество TBD). LXXIII — модификатор уровней 5–11 в 02g |
