## 1. Топология

- **44 региона** (в пределах канона 40–48): **внешнее кольцо — 36** + **сердце — 8**.
- **Планетарное замыкание:** кольцо замкнуто (R36 ↔ R01) — восток/запад сходятся; «север» = к сердцу, «юг» = к периферии.
- **Водное кольцо** между кольцом и сердцем — **не регионы**: представлено **бродами** (именованные рёбра кольцо→сердце, cost/CR).
- **Город: 1 на регион**, но **8 городов v1** — по одному в стартовом регионе каждого сектора. Дикари-регионы (без города) несут узлы. NPC-поселения — 1.0 (02-mechanics §3.1).
- **Сектора:** 8 (по знаку), 4–6 регионов каждый. Сектор = единица CR-якорей и MVP-маски.

## 2. Движение

- **Стоимость входа в регион (дни, config) — черновые якоря до Ф3-проработки** (формула канона — D4: бином + Ловкость + вес, 02-mechanics §3.1): равнины 2, лес 3, горы 4, болото 4, река 3, руины 3, священная роща 3, выжженная 3; **брод** 2–3 (по ребру) + CR.
- **Шаги внутри региона:** лимит шагов/день — TBD (P-5).
- **Дороги (1.0):** снижение cost рёбра на 1.
- **Инвариант (аналог D4 для отменённой сетки 24×24):** диаметр кольца (18 регионов) ≈ 45–54 дня ≥ 31 ход — кампания (21 ход) не покрывает карту целиком. Обход кольца ≈ 90–110 дней. Босс ход 21 (R5) — **приходит в город финальным рейдом** (composition = босс, 04-narrative; H5 — лагерь-источник, не цель похода).

## 9. MVP-маска (K-R4)

- **Сектор S1 (R01–R05), поле `mvp: true`** — эталонная MVP-маска: 5 регионов, связное подмножество.
- **Узлы MVP (5):** 2 лагеря (R02 C1, R05 C2), 2 руины (R03, R05), 1 руда (R04, железо +20 one-time) — по MVP-scope.
- **Внешние границы = отсутствующие рёбра:** R01–R36 и R05–H1 (брод F1) в MVP не существуют.
- Каждый стартовый сектор — потенциальная MVP-маска (своя связка 4–6 регионов со своим набором узлов); выбор старта выбирает маску. Данные — единый источник: поле `mvp` + поле сектора.
- Фракции = подмножество-конфиги (K-R4); совет/дипломатия — вне MVP.
