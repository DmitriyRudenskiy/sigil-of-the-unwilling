# Art Bible — Sigil of the Unwilling

Черновик UI-1. Палитра **консолидирована из живых ассетов** (`assets/theme/game_theme.tres`,
`widgets/panels/panel_bg.png`, `ui/main_menu_bg.png`), не выдумана. Входы: [[00-overview]]
(столпы 1.2, питч, референсы), [[07-ui-ux]], [[12-asset-audit]] (DoD: формат-политика,
бюджеты, стиль иконок, AI-пост-обработка). Секции — по шаблону art-bible (9); плотность —
списки ограничений. До утверждения владельцем — `status: draft`; после — `deepened`.

## 1. Visual Identity Statement

**Визуальное правило (одна строка):** *Хроника державы, нарисованная при свече: тёмное тёплое
дерево, золотая линия, единственный алый акцент — всё, что важно, читается на карте без текста.*

Тест неопределённости: новый ассет спорный → если он холоднее, светлее или пёстнее «свечи» —
он неправ; если его смысл не читается силуэтом/линией без подписи — он неправ.

Принципы (каждый служит столпу 00-overview §1.2):
1. **Поселение — боевая сила** → здания и тайлы рисуются как *объекты на карте*, а не иконки
   в меню: вес, тень на клетку, читаемый статус (построено/осада/разорено) без тултипа.
2. **Честный стол** → UI нейтрален и «бумажный»: никаких скруглённых аркадных панелей;
   прямые углы, золотая окантовка, тёмное дерево — стол, хроника, протокол.
3. **Нежелающий** → протагонист/знак визуально не героический центр: знак — тусклое клеймо
   на тёмном, а не сияющий артефакт; слава в этой игре — не блёстки.

## 2. Mood & Atmosphere

| Состояние | Эмоция | Свет/контраст | Несущий элемент | Энергия |
|---|---|---|---|---|
| Карта/стройка | делитая забота, «ведомство» | ровный тёплый, низкий контраст | золото линий районов | размеренная |
| Бой | сжатие перед ударом | холоднее на 1 ступень, выше контраст | красная линия фронта | напряжённая |
| Событие/решение | бумага при свече | виньетка, тёплый точечный | рамка решения на затемнении | пауза-выдох |
| Провал рейда/кризис | утрата | в холод и сажу, десатурация | пепельные тайлы | тихая |
| Меню/титул | порог порога | почти чёрный холодный `#090b0e` | силуэт трона | безмолвная |

## 3. Shape Language

- Гексы и прямые углы UI (мир — шестиугольник, документ — прямоугольник); скругления ≤2 px.
- Иерархия силуэтов: знак > юнит/здание > декор; декор не имеет замкнутых силуэтов.
- Юнит читается с 48 px (силуэт + 1 акцентный цвет фракции); здание — с одной клетки карты.
- UI-грамматика мира не повторяет: мир — рука хрониста, UI — его переплёт (дерево/золото/пергамент).

## 4. Color System

Живая палитра темы (извлечено из `game_theme.tres`/`panel_bg.png`, не инвентарь желаний):

| Роль | HEX | Значение в мире |
|---|---|---|
| База панелей | `#281c0f` | дерево стола |
| Панель/поля | `#4a3423`, `#3a2415` | дерево, переплёт |
| Золото окантовки | `#8a6a3a` / `#9e7738` | Престиж, знак, акцент хрониста |
| Границы/тени | `#16100a`, `#201006` | сажа, тиснение |
| Алый акцент | `#7a100c` | рейд, долг, кровь — **только угроза и знак** |
| Фон титула | `#090b0e` | порог (меню) |

Семантика: золото = Престиж/знак/подтверждение; алый = угроза/расход; зелёный `#4a7a3a`-семейка =
лес/сытость/положительный бином; синий = мана/магические события (не для экономики).
Биомы карты: поле — тёплый охра, болото — холодная зелень ×0.5 штрафа (02b B.2), шипы — серый с
алым. **Colorblind:** красное/зелёное никогда не единственный сигнал — дублируется формой
(треугольник угрозы, штриховка) и иконкой; статус района — иконкой, не только цветом.

## 5. Character Design Direction

Персонажей-артов в MVP нет; носитель — **знак на панели**, не портрет. Юнит-партии:
портрет 128×128 (canvas, см. §8), один акцент фракции, фон — база панелей (не белый).
Различение союз/враг — рамка (золото/сажа), не поза. LOD: детализация до 48 px, дальше — силуэт.

## 6. Environment Design Language

Здания: рисованный стилизованный «гравюрный» вид (живые `building_*.webp` — AI-гравюра, принять
как направление), canvas 640×640, фон прозрачный, тень на клетку печатается кодом. Текстура —
плоская с линией (не PBR-фото). Плотность пропа: 1 декор на 3–4 клетки. Storytelling: сожжённое —
то же здание в пепельной палитре + трещина, не отдельный ассет.

## 7. UI/HUD Visual Direction

Экраны — по [[07-ui-ux]] (8 узлов графа). Типографика: один шрифт с засечкой-полукругом
(хроника), веса: заголовок/тело/подпись; минимальный кегль читаемого — 16 px @1080p.
Иконки: контурная гравюра 1.5 px линия, сетка 8, canvas 64 (см. §8). Панели: `#281c0f` +
окантовка `#8a6a3a` (живая тема — не перекрашивать без причины). Анимации: 120–180 мс,
ease-out; никаких отскоков (протокол, не аркада). Доступность: контраст текст/панель ≥ 7:1
(AAA для мелкого текста), цель — WCAG AA целиком.

## 8. Asset Standards (закрывает DoD аудита)

**Формат-политика (мешанина PNG/JPG/WEBP из аудита):**
- UI, иконки, тайлы, юнит-портреты: **PNG** (прозрачность, crisp-линия).
- Фото-арт/здания/AI-генерация: **WEBP** (q 80–85).
- **JPG запрещён для новых ассетов**; миграция: при правке ассета — пересбор в канонический
  формат, мёртвые jpg-двойники удаляются PR-чисткой (UI-0c).

**Бюджеты (снимает NOT ASSESSED):**

| Класс | Canvas | Формат | Бюджет веса |
|---|---|---|---|
| Иконки (ресурсы/здания/ниды/школы) | 64×64, грид 8 | PNG-32 | ≤ 6 КБ |
| Юнит-портрет | 128×128 | PNG-32 | ≤ 16 КБ |
| Здание | 640×640 | WEBP q82 | ≤ 60 КБ |
| Портрет-иллюстрация (1.0) | 512×512 | WEBP q82 | ≤ 120 КБ |
| Фон/тайл-шит | 1920×1080 / кратно 32 | WEBP q85 / PNG | ≤ 350 КБ |
| Иконка артефакта | 64×64 | PNG-32 | ≤ 6 КБ |

**Вердикт по 40 вне-гридовым (аудит):** AI-портреты/здания **принять как растровое содержимое
на канвасе** (грид требуется канвасу и тайлам, не «дышащему» краю иллюстрации); перекропать
при перегенерации под канвасы таблицы; hex-шиты и `world_tiles` — пересобрать кратно 32 при
следующей правке (не блокер).

**Стиль иконок артефактов (вход UI-4, +23 к 31 живой):** тёмный фон `#281c0f`, предмет —
гравюрный силуэт по центру (отступ 8 px), редкость — цвет окантовки (минор `#8a6a3a`,
мажор `#c9a227`, реликвия `#7a100c` + золотая искра). Никаких рамок «багет».

**Правило AI-генерации (иначе «вне грида» плодятся):** каждый сгенерированный ассет проходит
пост-процессинг до коммита: (1) кроп/ресайз на канвас таблицы, (2) унификация палитры
(квантование к палитре §4, допуск ±12 по L), (3) экспорт в канонический формат, (4) имя
`[category]_[name]_[variant].webp|png` нижним регистром, (5) проверка бюджета веса.
Ассет, не прошедший конвейер, в репо не кладётся.
