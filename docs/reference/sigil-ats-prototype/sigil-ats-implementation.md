# Статус реализации

> Часть [базы знаний](sigil-ats-notes.md). Аудит того, что реализовано корректно в текущем билде Sigil of the Unwilling (Godot 4.7). Связано: [механики](sigil-ats-mechanics.md), [расы](sigil-ats-races.md), [здания](sigil-ats-buildings.md).

## ✅ Реализовано корректно

### 1. Базовая структура игры
- **Гексагональная карта** с 3 кольцами и ядром из 4 гексов (Очаг, склад, убежище, свободная поляна) — правильно.
- **Сезонный цикл**: Морось (×1.2) → Ясный сезон (×1.0) → Буря (×0.4) — работает как задумано.
- **Цель игры**: 14 очков репутации — соответствует оригиналу.

### 2. Ресурсная система
- 4 категории ресурсов: сырьё, материалы, провизия, сложная еда.
- Лимит хранения: базовый 60 + склады — реализован.
- Визуализация дельты (приход/расход) — корректна.

### 3. Расы (5 из 7)

| Раса | Реализовано |
|------|-------------|
| 👨 Люди | ✓ Базовый настрой 15, комфорт «Пивоварение», мастерство «Земледелие» |
| 🦫 Бобры | ✓ Базовый настрой 10, комфорт «Инженерия», мастерство «Деревообработка» |
| 🦎 Ящеры | ✓ Базовый настрой 5, высокая стойкость, комфорт «Тепло», мастерство «Мясопроизводство» |
| 🦅 Гарпии | ✓ Базовый настрой 5, комфорт «Портняжное дело», мастерство «Алхимия» |
| 🦊 Лисы | ✓ Базовый настрой 5, комфорт «Кооперация» (3+ лис = +5 к настрою), мастерство «Лес» |
| 🐸 Жабы | ✗ Не реализованы |
| 🦇 Нетопыри | ✗ Не реализованы |

### 4. Настроение
- База по расе ✓
- Жильё: +3 за любое, ещё +3 за расовый дом ✓
- Комфортная специализация: +5 при работе в профильном здании ✓
- Мастерство: **+15% к выработке** (в коде `eff *= 1 + 0.15 * Math.min(prof, 2)`) ✓
- Голод: −25 при `hungryT > 0` ✓
- Без жилья: −2 ✓
- Службы и любимая еда добавляют **половину** значения из `needs` ✓

⚠️ Две расхождения с документацией:
1. Здесь мастерство = «+15% к выработке», в [разделе специализаций](sigil-ats-races.md#специализации) — «+10% шанс удвоить добычу». Канон ATTs — **10% шанс двойного выхода** (см. [референс](../against-the-storm/ats-canon.md)); код отклоняется от канона. ❓ Определить целевое поведение Sigil of the Unwilling.
2. «Половина значения из `needs`» против целых +4…+10 в [таблице потребностей](sigil-ats-races.md#система-потребностей); в анализе документа значения — полный бонус на жителя (см. [референс](../against-the-storm/ats-canon.md)). ❓

### 5. Враждебность леса
- Растёт на +5 за разведку и +8 за новый год ✓
- Во время Бури снижает настроение ✓
- **Лисы** не боятся Бури (`m += 0`) ✓
- **Ящеры** стойкие: делят штраф на 24 вместо 12 ✓

### 6. Гниль
- Кисты появляются в дальних кольцах ✓
- Во время Бури: −2 к настрою всем за каждую кисту ✓
- Пост гнили выжигает кисту за 3 тика, даёт +1 репутации ✓

### 7. Поручения и чертежи
- Пул заказов с масштабированием по годам ✓
- Чертежи предлагаются раз в год, выбор из 3 вариантов ✓
- Здания с `bp:1` требуют чертёж ✓

## ❌ Не реализовано

- Жабы (раса, уровень 9) — включая каменные дома с бассейнами и бонус хранителя очага.
- Нетопыри (раса, уровень 11) — включая «Преданность», «Гордость», готический стиль построек.
