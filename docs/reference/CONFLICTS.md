# Реестр расхождений: вольта ↔ канон

Сверка импортированного референса ([[README]]) с канон-доками репо. Формат строки:
**утверждение вольты | канон репо | основание | вердикт**.

Вердикты: **нельзя** — в канон не переносится; **ждёт владельца** — перенос возможен
только решением владельца; **идея** — полезна как идея, числа/состав не переносятся;
**справка** — описание чужой системы, конфликтов с каноном нет, но и заимствования нет.

Ссылки вида `файл:строка` — по файлам этой зоны (строки уже с учётом provenance-шапки)
и по канон-докам репо.

## 4. Что можно брать как есть

Из всей вольты без решения владельца пригодны только **не-числовые** вещи:

- формулировки-категории (комфорт vs мастерство, сырьевая vs сложная еда) — как язык описания;
- промпты генерации (Allods, HoMM III) — как материал для ASSET-зоны и [[13-art-bible]];
- сам факт, что механика существует у других игр, — как аргумент в пользу того, что она реализуема.

Всё остальное — через владельца.
