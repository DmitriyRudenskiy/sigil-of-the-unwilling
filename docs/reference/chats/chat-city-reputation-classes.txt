## 🏛️ 1. Система Репутации и Миграции
Вместо абстрактного «счастья» город имеет **Репутацию (от -100 до +100)**. Она определяет, будут ли люди стекаться в ваш город или бежать из него.

*   **Рост населения (Иммиграция):** Если Репутация > 0, каждый ход в город прибывают «караваны переселенцев». Чем выше репутация, тем больше людей и тем выше шанс прибытия редких классов (Ученых).
*   **Убыль населения (Эмиграция и Бунты):** Если Репутация < 0, жители начинают покидать город (сначала Ученые, потом Работники). При критически низкой репутации начинаются бунты, а Ополченцы могут дезертировать или поднять мятеж.
*   **Факторы Репутации:**
    *   *(+)* Избыток еды, победы армии, построенные Чудеса, низкие налоги.
    *   *(-)* Голод, высокие налоги, вражеские набеги на 2-е и 3-е кольца, эпидемии, нехватка Жилья (перенаселение).

---

## 👥 2. Классы населения и Жилье (Housing)
Население делится на три класса. Каждому классу нужен свой тип **Жилья** (которое строится в 1-м кольце или центре). Если людей больше, чем мест в Жилье, возникает **Перенаселение** (штраф к Репутации и болезням).

### 🌾 1. Работник (Worker / Peasant)
*   **Роль:** Основа экономики. Добывает ресурсы, работает на полях и в мастерских.
*   **Жилье:** *Хижины / Трущобы* (дешевые, вмещают много людей, но требуют еды).
*   **Особенность:** Составляют большинство населения. Легко привлекаются базовой едой и отсутствием войн.

### ⚔️ 2. Ополченец (Militia / Citizen-Soldier)
*   **Роль:** Защита города, гарнизон, основа для набора полевой армии.
*   **Жилье:** *Казармы / Общежития* (требуют оружия и золота на содержание).
*   **Особенность:** Если вы забираете Ополченцев в **Полевую Армию** (уводите войска с карты города), город остается без защиты! Сторожевые башни и Стены теряют бонусы, пока войска не вернутся.

### 📜 3. Ученый (Scholar / Mage / Cleric)
*   **Роль:** Исследования, магия, религия, управление сложной инфраструктурой.
*   **Жилье:** *Усадьбы / Терема* (дорогие, требуют Роскоши и высокой Репутации).
*   **Особенность:** Самые капризные. Первыми покидают город при падении Репутации. Привлекаются наличием Библиотек, Храмов и Чудес.

## ⚙️ 3. Механика Назначения (Worker Assignment)
Здания **не работают автоматически**. Они дают потенциал, но для его реализации туда нужно назначить население соответствующего класса.

*   **Пример 1 (Экономика):** *Железная Шахта* требует **4 Работников**. Если вы назначите только 2, она будет работать на 50% (давать половину руды). Если назначите 0 — шахта простаивает.
*   **Пример 2 (Оборона):** *Сторожевая Башня* во 2-м кольце требует **2 Ополченцев**. Они несут вахту, давая обзор и защиту от грабежей.
*   **Пример 3 (Наука):** *Библиотека* в центре требует **3 Ученых** для генерации очков исследования.

### 🧩 Стратегическая дилемма (Gameplay Loop)
У вас ограниченный пул населения. Вам постоянно придется выбирать:
*   *Снять ли 5 Работников с Полей, чтобы отправить их на Стройку Чуда Света?* (Риск: город начнет голодать, упадет Репутация).
*   *Забрать ли Ополченцев со Сторожевых Башен, чтобы сформировать ударный отряд против врага?* (Риск: враг может разграбить ваши Шахты, пока армия в пути).
*   *Перевести ли Ученых из Университета в Храм, чтобы успокоить религиозный бунт?* (Риск: остановятся исследования).

## 🏗️ Обновленный Реестр Зданий (с учетом классов)

### 🏘️ Жилые Зоны (1-е Кольцо / Городская черта)
*   **Трущобы (Slums):** Вмещают 10 Работников. Дешевые, но генерируют преступность (требуют Ополченцев для патрулирования).
*   **Казармы (Barracks):** Вмещают 5 Ополченцев. Позволяют лечить войска и нанимать элиту.
*   **Усадьбы (Estates):** Вмещают 2 Ученых. Требуют Роскошь (Вино/Шелк), но сильно повышают Репутацию города.

### 🏭 Производство и Добыча (2-е и 3-е Кольца)
*   **Ферма:** Требует 2 Работников. Производит Еду.
*   **Лесопилка / Шахта:** Требует 3-4 Работников. Производит дерево/руду.
*   **Склад:** Требует 1 Работника. Увеличивает лимит хранения.
*   **Торговый Пост (3-е кольцо):** Требует 1 Работника и 1 Ученого (для ведения бухгалтерии). Позволяет продавать ресурсы по повышенной цене.

### 🏰 Инфраструктура и Защита (Центр и Кольца)
*   **Стены:** Требуют **Ополченцев** для гарнизона. Чем больше Ополченцев назначено в гарнизон, тем выше бонус к защите при осаде.
*   **Сторожевая Башня:** Требует 2 Ополченцев. Защищает соседние гексы от грабежей.
*   **Храм:** Требует 2 Ученых (Жрецов). Генерирует Веру, лечит население, повышает Репутацию.
*   **Магическая Башня:** Требует 3 Ученых (Магов). Позволяет кастовать заклинания на карту.

## 🔄 Пример игрового цикла (Как это играет)

**Ситуация:** Ваш город на 5-м уровне. Репутация +20.
1.  **Прибытие:** В город прибывает караван. Из-за хорошей Репутации и свободных Усадеб вы получаете **+2 Ученых** и **+5 Работников**.
2.  **Назначение:** Вы сразу назначаете Ученых в только что построенный *Университет* (исследования ускоряются). Работников вы отправляете на новую *Золотую Шахту* в 3-м кольце.
3.  **Кризис:** Разведчики доносят, что армия противника движется к вашему городу.
4.  **Мобилизация:** Вы заходите в панель города и нажимаете **«Призвать Ополченцев»**. Все Ополченцы из Казарм и Сторожевых Башен превращаются в отряды на карте. 
5.  **Последствия:** Ваши Сторожевые башни «слепнут» (враги могут обойти их и сжечь Фермы). Стены города теряют бонус гарнизона. Но зато у вас есть полевая армия, чтобы встретить врага в поле!
6.  **Восстановление:** После победы вы возвращаете войска в город. Репутация взлетает до +50 (Триумф!), что привлекает в город элитных Ученых и купцов.

## 🎯 Итог: Почему это делает игру шедевром

1.  **Эмоциональная привязанность:** Вы больше не смотрите на цифру «Население: 1450». Вы видите: *«У меня 800 Работников пашут поля, 200 Ополченцев мерзнут на стенах, а 50 Ученых спорят в Библиотеке»*. Вы начинаете заботиться о них.
2.  **Глубокий микроменеджмент без рутины:** Назначение населения происходит в одном удобном окне города. Это не клик-ад, а **головоломка распределения ресурсов**.
3.  **Синергия с кольцами:** 
    *   *1-е кольцо* становится зоной элитного жилья (Усадьбы) и инфраструктуры счастья.
    *   *2-е кольцо* — это гигантская фабрика, куда каждое утро «едут на работу» толпы Работников.
    *   *3-е кольцо* — опасный фронтир, где Ополченцы несут вахту, защищая богатства города.
4.  **Живой мир:** Эпидемия может выкосить Работников, и ваши Шахты встанут. Война может забрать Ополченцев, и бандиты начнут грабить караваны. Город уязвим, и его нужно защищать не только стенами, но и грамотной социальной политикой.

# Механика городов: Гибридная система «Цитадель и Кольца»

## 1. Архитектура карты и Зонирование
Город занимает 1 центральный гекс и 3 кольца вокруг него. Чтобы решить проблему нехватки слотов, вводится система **функционального зонирования**. Каждое кольцо имеет свою специализацию.

*   **Центральный гекс (Цитадель):** «Мозг» города. Здесь находится Ратуша и **2 свободных слота** под Ключевые Районы (Военный, Гражданский или Магический). Районы не добывают ресурсы, они дают глобальные бонусы и открывают ветки юнитов/технологий.
*   **Первое кольцо (6 гексов) — Городская черта:** Жилые кварталы, инфраструктура счастья (Таверны, Храмы) и базовая торговля. Это «улицы» города.
*   **Второе кольцо (12 гексов) — Промышленность и Агро:** Фермы, Шахты, Лесопилки, Мельницы, Кузницы. Производственный хребет.
*   **Третье кольцо (18 гексов) — Фронтир, Роскошь и Чудеса:** Виноградники, Торговые посты, Гильдии и Чудеса Света. Зона экспансии и сверхприбылей.

---

## 2. Ключевые системные формулы (Закрытие дыр)

1. **Математика населения:** Население измеряется в людях. 
   * **Еда** определяет *скорость* прироста.
   * **Жилые кварталы** определяют *лимит* (потолок). 
   * **Благоустройство** (Таверны, Храмы, Роскошь) определяет *эффективность*. Если Благоустройство ниже нуля — город бунтует, производство падает.
2. **Проблема рельефа (Софт-лок):** Если вокруг нет камня или леса, игрок может построить Рынок (в 1 кольце) и **покупать** ресурсы за золото. Альтернатива: поставить добывающее здание на равнине, но с эффективностью 50% (штраф за логистику).
3. **Стены:** Не занимают слоты. Это **кольцевой апгрейд**, который покупается за ресурсы и опоясывает Первое кольцо.

## 4. Реестр Зданий и Механик

### 🏰 Центральная Цитадель (3 слота)
1. **Ратуша (Авто):** Дает лимит хранения, базовую защиту и открывает строительство Стен.
2. **Военный Район (Слот 1):** Казармы, Кузница (апгрейд), Плац. Позволяет нанимать войска и улучшать их экипировку.
3. **Гражданский/Магический Район (Слот 2):** Библиотека, Храм или Гильдия Магов. Дает очки науки/веры и ускоряет исследования.

### 🏘️ Первое кольцо: Городская черта (6 гексов)
Здания здесь требуют **Благоустройства** и не привязаны к рельефу.
*   **Жилой квартал:** Дает базовый Лимит Населения (500 на Тир 1). 
    * *Бонус смежности:* Если рядом Храм или Таверна — +15% к скорости роста.
*   **Рынок:** Генерирует золото. Позволяет покупать отсутствующие ресурсы (решение проблемы рельефа).
*   **Таверна / Пивоварня:** Потребляет Еду, генерирует **Благоустройство**. Критически важна для остановки бунтов.
*   **Храм:** Генерирует Веру, защищает город от вражеской магии и шпионов.

### 🏭 Второе кольцо: Промышленность и Агро (12 гексов)
*   **Добывающие (зависят от рельефа):** Лесопилка (лес), Каменоломня (горы), Шахта (руда). 
    * *Дыра закрыта:* Можно построить на равнине с штрафом -50% к добыче.
*   **Перерабатывающие (смежность):** 
    * **Мельница:** Ставится рядом с 2+ Полями. Увеличивает выработку еды на 50%.
    * **Кузница:** Ставится рядом с Шахтой. Дает +1 производство и +1 золото за ход.
*   **Склад:** Увеличивает лимит хранения ресурсов (важно для подготовки к осаде или зиме).

### 🏕️ Третье кольцо: Фронтир (18 гексов)
*   **Роскошь:** Виноградники, Фруктовые сады, Пасеки. Дают мало еды, но много Золота и Благоустройства.
*   **Чудо Света:** Занимает **3 смежных гекса**. Требует колоссальных ресурсов, но дает уникальный бонус (например, «Оракул: +50% к науке»).
*   **Гильдии:** Занимают 1 гекс. 
    * *Гильдия Воров:* Позволяет саботировать экономику врага.
    * *Гильдия Наемников:* Позволяет нанимать юниты без лимита населения.

## 5. Боевая система и Осады

### Стены и Периметр
*   Стены строятся по периметру 1-го кольца. 
*   **Уровни:** Частокол (дерево) -> Каменная стена (камень) -> Бастионы (железо + золото).
*   Стены дают гарнизону бонус к защите +50% и заставляют врага тратить ходы на их разрушение.

### Грабеж Фронтира
Внешние здания (Кольца 2 и 3) **не защищены стенами**. 
*   Вражеские отряды могут атаковать и грабить Шахты/Фермы, лишая город ресурсов.
*   **Контрмера:** Игрок может строить **Сторожевые башни** во 2/3 кольце. Они дают обзор и замедляют врагов.
*   *Стратегический выбор:* Прятать важные Шахты и Чудеса ближе к центру (в 1 кольцо), а уязвимые Поля выносить на периферию под защиту башен.

## 🎯 Итог: Почему это работает?

1. **Нет софт-лока:** Игрок всегда может купить ресурсы на Рынке или использовать штрафные лесопилки на равнине.
2. **Нет дефицита слотов:** Городские здания (Таверны, Рынки, Жилье) вынесены в 1-е кольцо. В центре только управление.
3. **Математика сходится:** Население 11 уровня достигается за счет апгрейда Жилых Кварталов и бонусов Гражданского района, а не спама домами.
4. **Пространственный пазл:** Бонусы смежности (Мельница у Полей, Кузница у Шахты) заставляют игрока планировать застройку, как в *Endless Legend*.
5. **Разнообразие городов:** Из-за ограниченного места (36 гексов) игрок не сможет сделать город "всё в одном". Придется специализироваться: **Крепость**, **Торговый Хаб** или **Магическая Академия**. Это создает глубокую экономику между городами.
   
   Отличный концепт! Идея объединения камерного менеджмента *Lords of Magic* (где каждый город чувствуется как уникальный организм) и территориального расширения из *Endless Legend* (районы на карте, бонусы соседства) имеет огромный потенциал.

## 🕵️‍♂️ 1. Аудит: Конфликты и Дыры (Что было сломано)

1. **Конфликт «Бутылочного горлышка» (3 слота в центре):**
   * *Проблема:* В центре всего 3 слота (1 занимает Ратуша). Остается **2 слота**. Но в списке городских зданий их больше 10 (Казармы, Храм, Рынок, Кузница и т.д.). Игрок физически не сможет построить всё это.
   * *Решение:* Разделить здания на **«Районы Цитадели»** (центральные слоты, задающие профиль города) и **«Внешнюю инфраструктуру»** (гексы колец).
2. **Дыра «Стены в вакууме»:**
   * *Проблема:* Стены занимают драгоценный центральный слот. Логически стены окружают город, а не стоят внутри него.
   * *Решение:* Стены — это **глобальное улучшение** города (апгрейд Ратуши), не занимающее слот.
3. **Угроза софт-лока (Генерация карты):**
   * *Проблема:* Что если в 1-м кольце (6 гексов) нет леса или камня? Игрок не сможет построить Лесопилку/Каменоломню и застрянет на 2-3 уровне.
   * *Решение:* Ввести механику **Форпостов** и базовую добычу от самой Ратуши.
4. **Математическая дыра «Спам жильем»:**
   * *Проблема:* Если внешний жилой дом дает +5 населения, а 3-е кольцо содержит 18 гексов, игрок застроит всё домами, игнорируя еду и счастье.
   * *Решение:* Переход от «плоского» населения к системе **Лимита Жилья (Capacity)** и **Потребления Еды**. Население растет само, если есть Еда и Свободное Жилье.
5. **Микроменеджмент на 11 уровне:**
   * *Проблема:* Требование «улучшить все здания до 3 уровня» на 36 гексах — это рутинный ад для игрока в поздней игре.
   * *Решение:* Заменить на требование по **Общему процветанию / Очкам Развития**.

## 🛠️ 2. Проработанные Механики (Фундамент)

### Концепция Центрального Гекса (Цитадель)
Центральный гекс — это **«Сердце города»**. Он имеет **3 слота для Районов**.
* **Слот 1:** Ратуша (Авто, улучшает лимиты, открывает стены).
* **Слот 2:** Военный / Административный район (Казармы, Рынок, Монетный двор).
* **Слот 3:** Культурный / Магический район (Храм, Библиотека, Университет).
* *Правило:* Здания в Цитадели не добывают ресурсы, они дают **глобальные модификаторы, слоты для героев и лимиты**.

### Концепция Внешних Гексов (Кольца)
Внешние гексы делятся на три типа:
1. **Добывающие (Ноды):** Строятся *только* на соответствующем рельефе (Лес, Руда, Плодородная земля).
2. **Перерабатывающие:** Можно строить на *любом* гексе, но они требуют **Соседства** с добывающими для бонусов.
3. **Жилые / Специальные:** Усадьбы, Чудеса света, Форпосты.

### Новая механика: Матрица Соседства (Adjacency)
Чтобы избежать хаотичной застройки, вводится правило синергии (как в *Endless Legend*):
* **Мельница** рядом с **Полем пшеницы** = +50% к муке.
* **Кузница** рядом с **Шахтой** = -20% времени на производство оружия.
* **Таверна** рядом с **Пивоварней** и **Жилым районом** = +2 к Счастью.
* **Храм** рядом с **Кладбищем/Руинами** = + к Вере, но снижает Счастье.

### Новая механика: Инфраструктура и Логистика
Город не может бесконечно расширяться без **Дорог и Акведуков**.
* Каждое кольцо требует базовой Инфраструктуры (строится в Ратуше). Без нее внешние здания во 2-м и 3-м кольцах работают с штрафом -50% к эффективности (симуляция логистических потерь).

## 🏛️ 3. Обновленный Реестр Зданий

### 🏰 Районы Цитадели (3 слота)
1. **Ратуша (Слот 1 - Авто):** Хранилище, лимит населения, глобальная защита. Улучшение Ратуши возводит **Стены** (деревянные -> каменные -> магические).
2. **Военно-Торговый Тракт (Слот 2):**
   * *Казармы:* Найм войск, лечение.
   * *Рынок:* Торговые караваны, конвертация ресурсов.
   * *Монетный двор:* Чеканка золота из слитков.
3. **Духовно-Научный Тракт (Слот 3):**
   * *Храм:* Вера, защита от порчи, инквизиция.
   * *Библиотека/Университет:* Очки исследований, найм магов.
   * *Гильдия Теней:* Шпионаж, саботаж, наем убийц (альтернатива Храму).

### 🌲 Внешние Здания (Гексы колец)
**Добывающие (требуют рельеф):**
* *Лесопилка / Каменоломня / Шахта / Золотая жила.*
* *Поле / Пастбище / Виноградник.*

**Перерабатывающие (ставятся на пустую землю, требуют соседства):**
* *Мельница* (усиливает Поля).
* *Пекарня* (усиливает Мельницы).
* *Пивоварня* (требует Пшеницу/Воду).
* *Кузница* (требует Шахту/Лесопилку).
* *Порт / Торговый пост* (требует выхода к воде или краю карты).

**Жилые и Специальные:**
* *Усадьба (Внешний дом):* Дает **+Лимит Жилья** и немного Золота (налоги). Не дает еду.
* *Колодец / Акведук:* Обязателен для роста. 1 Колодец обслуживает 3 соседних Жилых гекса.
* *Чудо Света:* Занимает 1 гекс, требует огромных ресурсов, дает уникальный эффект на всю империю.

## 🛡️ 5. Закрытие дыр и новые механики (Depth & Polish)

### 1. Решение проблемы «Нет ресурсов рядом» (Форпосты)
Если в 1-м кольце нет камня, а он нужен для 2-го уровня, игрок может построить **Форпост** (стоит дешевле, но работает только на добычу 1 ресурса). Форпост можно поставить в радиусе 5 гексов от города, но его нужно соединить **Дорогой**, иначе ресурсы будут «теряться» по пути.

### 2. Система Счастья и Бунтов (The Happiness Engine)
Население не просто растет. Оно имеет параметр **Мораль (от -100 до +100)**.
* **Потребности:** Еда, Вода, Жилье. (Если не хватает — Мораль падает).
* **Роскошь:** Пиво, Вино, Мёд, Фрукты. (Дают +Мораль).
* **Последствия:**
  * *Мораль < 0:* Бунты (остановка производства, дезертирство войск).
  * *Мораль > 80:* Бэби-бум (ускоренный рост), +15% к производству.
* *Дыра закрыта:* Игрок не может просто застроить всё полями и домами. Ему *придется* тратить гексы на Пивоварни, Виноградники и Таверны, чтобы удерживать Мораль.

### 3. Содержание (Maintenance) и Лимит Рабочих
Каждое внешнее здание требует **Рабочих (Pop-points)**.
* Шахта = -3 рабочих.
* Поле = -2 рабочих.
* Усадьба = +5 рабочих (генерирует население).
* *Дыра закрыта:* Игрок не может построить 36 добывающих зданий на 3-м кольце. У него просто не хватит населения для их обслуживания. Это заставляет балансировать между Жилыми Усадьбами и Производством.

### 4. Уязвимость колец (Тактический аспект)
Внешние здания **не защищены стенами Цитадели**.
* Если враг нападает на город, он может грабить внешние гексы (сжигать поля, рушить шахты).
* *Контрмера:* Игрок может строить **Сторожевые башни** (занимают внешний гекс, не дают ресурсов, но защищают соседние 3 гекса от грабежей и дают бонус к обзору).
* Это создает интересную тактику: прятать важные Шахты и Чудеса ближе к центру (в 1-м кольце), а поля и лесопилки выносить на периферию.

### 5. Экология и Истощение (Опционально для хардкора)
* **Вырубка лесов:** Лесопилка со временем (или после постройки 3-4 штук) истощает гекс, превращая лес в Пустошь. На пустоши можно строить здания, но там нельзя сажать еду.
* **Загрязнение:** Кузницы и Шахты снижают привлекательность соседних гексов для Усадеб (штраф к Счастью). Игрок должен зонировать город: Промзона (подальше от центра) и Жилые кварталы (рядом с Тавернами и Храмами).

## 💡 Итог: Как это играет (Gameplay Loop)

1. **Ранняя игра (1-3 ур.):** Игрок борется за выживание. Ищет баланс между Едой, Водой и Жильем. Строит первые Усадьбы. Вынужден адаптироваться под terrain (нет леса? Придется покупать дерево на Рынке, как только появится Слот 2).
2. **Средняя игра (4-7 ур.):** Открывается 2-е кольцо. Игрок начинает выстраивать **цепочки соседства** (Шахта -> Кузница -> Казармы). Появляется потребность в Роскоши (Вино, Пиво) для контроля Счастья растущего населения.
3. **Поздняя игра (8-11 ур.):** Борьба за место на карте. 3-е кольцо заставляет принимать тяжелые решения: построить Чудо Света или три Усадьбы для поддержания населения? Защищать периферию Сторожевыми башнями или стянуть все войска в Цитадель?

Эта система избавляет от микроменеджмента "ради галочки", добавляет пространственное мышление (пазл соседства) и делает каждый город на карте уникальным в зависимости от рельефа и выбранной стратегии игрока.
Это потрясающая идея! В 4X-стратегиях и градостроях прибрежные города часто страдают от «синдрома урезанной карты» (когда вода съедает 30–50% гексов для расширения). Введение механики **Сдвига Цитадели (Relocation)** не просто закрывает эту дыру, но и создает масштабный поздний эндгейм-проект, напоминающий исторический перенос столиц или разрастание мегаполисов (как Санкт-Петербург или древний Рим).

Ниже представлена полная проработка этой механики и ее интеграция в нашу систему.

---

## 🌊 1. Контекст: Водные гексы и «Прибрежный штраф»
Прежде чем переносить центр, нужно определить, как работает вода. Вода не должна быть просто «стеной». 
*   **Водные гексы в кольцах** позволяют строить **Морскую инфраструктуру** (Порт, Верфь, Рыбный рынок, Маяк). 
*   Они дают огромное количество **Золота** и **Еды**, а также открывают морские торговые пути.
*   **Проблема:** Водные гексы не подходят для Жилых кварталов, Ферм и Шахт. Прибрежный город быстро упирается в потолок нехватки *сухопутных* гексов во 2-м и 3-м кольцах, что блокирует достижение 11 уровня.

---

## 🏛️ 2. Механика: «Сдвиг Цитадели» (Urban Relocation)

Когда прибрежный (или зажатый горами) город достигает своего физического предела, игрок может инициировать **Сдвиг Цитадели** — монументальный проект по переносу административного сердца города на новый, более просторный гекс внутри текущих границ.

### 📜 Условия запуска (Unlock Conditions)
1.  **Уровень города:** Не ниже **7-го** (когда открывается 3-е кольцо, и нехватка места становится критической).
2.  **Технология:** Изучена ветка *«Градостроительство и Логистика»*.
3.  **Ресурсы:** Колоссальные запасы Камня, Золота и Дерева.
4.  **Население:** Требует временного назначения **50% всех Работников** города на «Великую Стройку» (это парализует экономику на время переноса).
5.  **Целевой гекс:** Игрок должен выбрать **сухопутный гекс** внутри текущего 2-го или 3-го кольца, на котором еще нет построек (или снести там существующую).

### ⚙️ Процесс переноса
*   **Этап подготовки (3-5 ходов):** На целевом гексе возводится фундамент **Новой Ратуши**. В это время город находится в состоянии *«Чрезвычайного положения»*: производство падает на 50%, Репутация временно снижается (из-за шума и разрухи), а Ополченцы не могут покидать город.
*   **Этап Переезда (1 ход):** Административный центр переносится. Кольца **пересчитываются** вокруг нового гекса!
*   **Уязвимость:** Если в этот момент на город нападут, стройка будет разрушена, а город получит огромный штраф к Репутации и бунт.

---

## 🗺️ 3. Пространственный Пазл: Что происходит с картой?

Это самая интересная часть. Когда центр смещается, **вся сетка колец сдвигается вслед за ним**.

1.  **Новый Центр (Ring 0):** Выбранный гекс становится новой Цитаделью. Он получает 3 слота под Районы.
2.  **Старый Центр (Бывший Ring 0):** Превращается в уникальную зону — **«Исторический Центр»** или **«Старый Порт»** (если был у воды). 
    *   *Что это дает:* Он больше не занимает слоты, а становится **пассивным Мега-зданием**, которое дает огромные бонусы к Золоту, Торговле и Репутации (как туристическая/историческая достопримечательность). Все старые постройки в нем сохраняются, но апгрейдить их больше нельзя.
3.  **Пересчет Колец (The Shift):**
    *   Гексы, которые были на окраине старого 3-го кольца, теперь могут оказаться во 2-м кольце новой Цитадели!
    *   **Главное:** Сдвигая центр вглубь суши, игрок **«захватывает» новые сухопутные гексы**, которые раньше были за пределами карты города. Открывается пространство для новых Ферм, Шахт и Чудес Света, что позволяет городу продолжить рост до 11 уровня.

---

## 👥 4. Влияние на Население и Классы

Перенос центра — это стресс для жителей. Механика глубоко интегрирована с классами населения:
*   **Работники:** Тратят свои силы на снос старых дорог и прокладку новых. Во время стройки возникает дефицит рабочих на Фермах (риск голода).
*   **Ученые:** Должны разработать *План застройки* (тратятся очки исследований). Если Ученых не хватает, время стройки увеличивается, а новые кольца получат штраф к эффективности на первые 10 ходов.
*   **Ополченцы:** Должны патрулировать улицы во время хаоса переезда, чтобы предотвратить мародерство (штраф к Репутации, если Ополченцев не хватает).
*   **Репутация:** После успешного завершения Репутация получает **+30 (Триумф Архитектуры)**, что вызывает массовый приток Ученых и богатых переселенцев в новые Жилые кварталы.

## 🔄 Пример игровой ситуации (Gameplay Loop)

**Ситуация:** Вы основали стартовый город на берегу моря. К 7-му уровню у вас мощный Порт, флот и много Золота, но с суши город зажат лесами и горами. Вам негде строить Жилые кварталы для Ученых и Университеты. Лимит населения достигнут.
1.  **Решение:** Вы издаете *Эдикт о Сдвиге Цитадели*. Вы выбираете гекс в 3-м кольце, глубоко в лесу, который вы предварительно расчистили.
2.  **Жертва:** Вы снимаете 40 Работников с Верфей и Ферм. Производство золота и еды падает. Вы вынуждены закупать еду у соседних городов своей империи, чтобы избежать голода.
3.  **Сдвиг:** Спустя 5 ходов центр переносится вглубь континента. Старый Порт становится «Исторической Гаванью» (+50% к доходу от морской торговли).

## 💡 Итог: Почему это гениально?

1.  **Спасение неудачного старта:** Игрок больше не обязан перезагружать игру, если стартовый город заспавнился у воды или в тупике гор. Пространственный пазл решается эволюционным путем.
2.  **Исторический нарратив:** Город ощущается живым. Он начинается как скромный форт или торговый порт на побережье, а к концу игры превращается в расползающуюся во все стороны континентальную Метрополию, где старый центр становится музеем под открытым небом.
3.  **Глубокий стратегический выбор:** Сдвигать центр или нет? Это стоит огромных ресурсов и временной паралича экономики. Игрок должен точно рассчитать, окупятся ли новые гексы во «вновь открывшихся» кольцах, или проще основать совершенно новый город в другом регионе. 
4.  **Синергия с классами:** Использование Работников, Ученых и Ополченцев как "топлива" для этого мега-проекта делает управление населением невероятно осязаемым.
   ## Механика городов (вдохновлено Lords of Magic и Endless Legend)

### Общая концепция
Город основывается на одной клетке гексагональной карты — **центральном гексе**. Внутри этого гекса доступно **3 слота** под городские постройки (здания инфраструктуры, управления, военные и т.п.). Один слот сразу занимает **Ратуша** (центр города), два остаются свободными.

Вокруг города располагаются **три кольца** гексов:
- **Первое кольцо** — 6 соседних гексов;
- **Второе кольцо** — 12 гексов (через один от центра);
- **Третье кольцо** — 18 гексов (через два от центра).

На каждом внешнем гексе можно построить **одно внешнее здание** (добывающее, производственное, жилое и т.д.). Внешние здания занимают весь гекс и дают ресурсы или бонусы.

**Развитие города** (уровень 1–11) открывает доступ к новым кольцам, новым типам зданий и улучшениям. Уровень повышается при выполнении определённых условий (рост населения, постройка ключевых зданий).

### Система уровней города (1–11)

| Уровень | Требования для достижения | Что открывается |
|---------|---------------------------|-----------------|
| **1**   | Город основан (стартовый) | Доступно первое кольцо. Городские здания: Ратуша (авто), Жилой дом (городской), Казармы. Внешние здания: Колодец, Поле пшеницы, Жилой дом (внешний). |
| **2**   | Население ≥ 20, построены 1 Колодец и 1 Поле пшеницы | Новые городские здания: Пивоварня, Таверна. Внешние: Ферма (улучшение поля). |
| **3**   | Население ≥ 50, построены Пивоварня и Таверна | Новые городские здания: Рынок, Склад. Внешние: Лесопилка (если есть лес на гексе), Каменоломня (если есть камень). |
| **4**   | Население ≥ 100, построен Рынок | **Открывается второе кольцо**. Новые городские здания: Кузница, Стены. Внешние: Шахта (если есть руда), Пастбище. |
| **5**   | Население ≥ 150, построена Кузница | Новые городские здания: Храм, Библиотека. Внешние: Мельница, Пекарня. |
| **6**   | Население ≥ 250, построен Храм | Улучшение городских зданий до 2 уровня (Ратуша, Рынок, Казармы). Новые внешние: Виноградник, Пасека. |
| **7**   | Население ≥ 400, построена Библиотека | **Открывается третье кольцо**. Новые городские здания: Университет, Больница. Внешние: Золотая шахта, Каменоломня (улучшенная). |
| **8**   | Население ≥ 600, построен Университет | Новые городские здания: Обсерватория, Монетный двор. Возможность строить **Чудо света** (одно на город, занимает 1 внешний гекс). |
| **9**   | Население ≥ 900, построено Чудо света | Новые городские здания: Гильдия воров, Гильдия магов, Гильдия воинов. Улучшение внешних зданий до 2 уровня. |
| **10**  | Население ≥ 1300, построена любая Гильдия | Улучшение всех зданий до максимального (3) уровня. Новые внешние: Фруктовый сад, Торговый пост. |
| **11**  | Население ≥ 1800, все ключевые здания улучшены до 3 уровня | Максимальный уровень. Город получает статус **Столицы**: +25% ко всем ресурсам, открыты все возможные постройки и улучшения. |

> **Примечание:** Требования по населению и зданиям — примерные, могут настраиваться под баланс. Важно, что каждое новое кольцо открывается на уровнях 4 и 7, а ключевые здания (пивоварня, таверна, рынок, кузница и т.д.) поэтапно расширяют функционал.

### Базовый набор зданий

#### Городские здания (строятся в центральной клетке, всего 3 слота)

1. **Ратуша**  
   *Автоматически занимает 1 слот при основании.*  
   Центр управления. Определяет уровень города, даёт базовое хранение ресурсов и +1 к лимиту населения. Может улучшаться (до 3 уровня) с ростом города.

2. **Казармы**  
   Позволяют нанимать военные юниты (мечники, лучники и т.д.). Чем выше уровень казарм, тем более продвинутых юнитов можно нанимать. Занимают 1 слот.

3. **Жилой дом (городской)**  
   Даёт +10 к населению. Можно строить несколько, если есть свободные слоты (но центральных слотов всего 3). Улучшение увеличивает прирост населения.

4. **Пивоварня**  
   Производит пиво из пшеницы (требуется поле пшеницы). Пиво используется в таверне, для торговли или повышения боевого духа армии.

5. **Таверна**  
   Потребляет пиво и еду, даёт бонус к счастью (морали) города, увеличивает приток новых жителей. Также может служить местом найма героев.

6. **Рынок**  
   Увеличивает доход золота, позволяет торговать ресурсами с другими городами. Открывает доступ к улучшенным торговым маршрутам.

7. **Кузница**  
   Производит оружие и броню для юнитов, улучшает качество войск. Требует железо (с шахты).

8. **Храм**  
   Даёт бонус к культуре и вере, снижает недовольство. Открывает доступ к религиозным юнитам и заклинаниям.

9. **Библиотека**  
   Ускоряет исследование технологий или магических знаний. Позволяет нанимать магов.

10. **Стены**  
    Увеличивают защиту города при осаде. Могут улучшаться.

#### Внешние здания (строятся на гексах колец, одно здание на гекс)

1. **Колодец**  
   Обеспечивает город водой. Без колодца рост населения замедляется, возможны болезни. Можно строить несколько для больших городов.

2. **Поле пшеницы**  
   Производит продовольствие (зерно). Основа пищевой цепочки. Может быть улучшено до **Фермы** (больше еды).

3. **Жилой дом (внешний)**  
   Отдельный дом на окраине, даёт +5 к населению. Не занимает слот в центре, но требует гекс.

4. **Лесопилка**  
   Добывает древесину (строительный ресурс). Требует гекс с лесом.

5. **Каменоломня**  
   Добывает камень. Требует гекс с каменистой почвой.

6. **Шахта**  
   Добывает железо или другие металлы (медь, серебро, золото). Требует гекс с рудой.

7. **Мельница**  
   Перерабатывает зерно в муку, увеличивает эффективность полей. Может быть улучшением для поля (ставится рядом или на тот же гекс).

8. **Пекарня**  
   Производит хлеб из муки, даёт больше продовольствия и бонус к счастью.

9. **Пастбище**  
   Даёт мясо и шерсть, увеличивает продовольствие. Может быть улучшено до **Скотного двора**.

10. **Виноградник** / **Пасека** / **Фруктовый сад**  
    Производят вино, мёд, фрукты — ресурсы для торговли и улучшения морали.

### Взаимодействие зданий и ресурсов
- **Цепочка еды:** Поле пшеницы → Мельница → Пекарня → Таверна (потребляет хлеб и пиво) → счастливое население.
- **Военная цепочка:** Шахта (железо) → Кузница → Казармы (найм экипированных юнитов).
- **Торговля:** Излишки ресурсов (зерно, пиво, вино, металлы) продаются на рынке, принося золото.

### Развитие колец
- **Первое кольцо** доступно с 1 уровня, но количество одновременно строящихся зданий может быть ограничено (например, не более 3 до 2 уровня).
- **Второе кольцо** открывается на 4 уровне, позволяет размещать более специализированные постройки (шахты, пастбища, кузницу как внешнее здание, если нужно).
- **Третье кольцо** открывается на 7 уровне, здесь можно строить уникальные и высокоуровневые объекты (чудеса света, золотые шахты, гильдии).

Таким образом, развитие города от 1 до 11 уровня происходит через накопление населения, постройку ключевых зданий и поэтапное расширение на окружающие гексы. Баланс между городскими слотами и внешними гексами заставляет игрока стратегически планировать застройку, как в Lords of Magic и Endless Legend.

### Основные концепты (кратко)

- **Город** — центральный гекс с **3 слотами** под городские здания (ратуша, казармы, рынок и т.п.).
- **Кольца застройки** — вокруг города три кольца внешних гексов:
  - **1-е кольцо** (6 гексов) — доступно сразу;
  - **2-е кольцо** (12 гексов) — открывается на 4 уровне;
  - **3-е кольцо** (18 гексов) — открывается на 7 уровне.
- **Уровни города (1–11)** — открывают новые здания, кольца и улучшения. Рост зависит от населения и постройки ключевых зданий.
- **Внешние здания** — по одному на гекс кольца, дают ресурсы (еда, камень, железо, золото, жильё).
- **Цепочки ресурсов** — например: поле пшеницы → мельница → пекарня → таверна (счастье) или шахта → кузница → казармы (войска).

### Механика типов клеток (террейна)

Каждый внешний гекс имеет тип местности. Внешние здания можно строить только на подходящих типах клеток. Это заставляет планировать застройку с учётом ландшафта.

| Тип клетки           | Можно строить (примеры)                                                   | Нельзя строить                                |
| -------------------- | ------------------------------------------------------------------------- | --------------------------------------------- |
| **Равнина**          | Поле пшеницы, ферма, пастбище, жилой дом, колодец, мельница, пекарня      | Каменоломня, шахта, лесопилка                 |
| **Лес**              | Лесопилка, пасека, фруктовый сад, охотничий домик                         | Каменоломня, поле пшеницы, пастбище           |
| **Холмы / Скалы**    | Каменоломня, шахта (если есть руда), наблюдательная башня                 | Поле пшеницы, жилой дом, колодец (нужна вода) |
| **Болото**           | Тростниковая ферма, солеварня, жилой дом (с бонусом к защите от болезней) | Каменоломня, шахта, поле пшеницы, пастбище    |
| **Пустыня**          | Колодец (жизненно необходим), караван-сарай, золотая шахта                | Лесопилка, поле пшеницы, пасека               |
| **Вода / Побережье** | Рыбацкая пристань, торговый порт, солеварня                               | Любые сухопутные здания                       |
| **Горы (высокие)**   | Шахта (редкие металлы), крепость                                          | Практически всё остальное                     |

**Правила:**
- Для строительства **каменоломни** нужен гекс с холмами или скалами.
- Для **жилого дома** нужна ровная, пригодная для жизни земля (равнина, лесная опушка, но не скалы или болото без осушения).
- **Колодец** можно строить только там, где есть водоносный слой — равнина, лес, но не на скалах или в пустыне без специального улучшения.
- Некоторые здания могут иметь альтернативные варианты для разных террейнов (например, «ферма на болоте» → рисовая плантация, даёт меньше еды, но устойчива к наводнениям).

Это добавляет элемент территориального планирования и делает каждую карту уникальной: город в горах будет добывать камень и металлы, но испытывать нехватку еды, а город на равнине — наоборот.

# 2. Каноническая структура города

## 2.1. Городская территория

Город состоит из:

1. **Центральный гекс (Цитадель)**  
   - 3 слота:
     - 1 автоматический: **Ратуша**
     - 2 выбираемых: **Районы**

2. **Кольца вокруг центра**
   - **1-е кольцо** — 6 гексов  
   - **2-е кольцо** — 12 гексов  
   - **3-е кольцо** — 18 гексов  

Итого: **36 внешних гексов**.

## 2.2. Функциональная специализация колец

### Центр — управление
Здесь находятся только **Районы**. Они не добывают ресурсы напрямую, но:
- открывают ветки зданий;
- дают глобальные бонусы;
- увеличивают лимиты классов;
- позволяют строить продвинутые внешние постройки.

### 1-е кольцо — городская черта
Здесь размещаются:
- жильё;
- рынки;
- таверны;
- храмы;
- склады;
- базовая защита;
- городская инфраструктура.

Это «тело» города.

### 2-е кольцо — производство и агро
Здесь размещаются:
- фермы;
- шахты;
- лесопилки;
- каменоломни;
- пастбища;
- мельницы;
- кузницы;
- сельские жилые выселки.

Это экономический хребет.

### 3-е кольцо — фронтир, роскошь и экспансия
Здесь размещаются:
- виноградники;
- пасеки;
- сады;
- торговые посты;
- гильдии;
- сторожевые башни;
- форты;
- чудеса света.

Это зона риска и высокой доходности.

---

# 3. Население: единая математика

## 3.1. Базовые единицы

### Население
Измеряется в **жителях**.

Диапазон роста города:
- **Уровень 1:** 0
- **Уровень 11:** 10 000 жителей  
- Возможны бонусы свыше 10 000 от чудес, столицы, переноса центра, уникальных черт.

### Рабочая ячейка
Чтобы не считать тысячи людей поштучно, вводится **командная ячейка**:

> **1 рабочая ячейка = 100 жителей**

Все трудовые, военные и научные назначения считаются в ячейках.

Пример:
- Население 3 500 → 35 рабочих ячеек.
- Ферма требует 2 рабочих ячейки.
- Сторожевая башня требует 1 ополченскую ячейку.

---

## 3.2. Классы населения

Классы — это не просто счётчики, а **назначаемые социальные роли**.

### 1. Работники
- Основная масса населения.
- Работают на полях, шахтах, складах, стройках, рынках.
- Самый гибкий класс.

### 2. Ополченцы
- Военнообязанные жители.
- Используются для:
  - гарнизона;
  - сторожевых башен;
  - стен;
  - полевой армии.
- Требуют оружия и содержания.

### 3. Учёные
- Жрецы, маги, писари, инженеры, лекари, администраторы.
- Используются для:
  - науки;
  - магии;
  - веры;
  - управления сложными зданиями;
  - части торговли и гильдий.
- Требуют роскоши, стабильности и инфраструктуры.

---

## 3.3. Классовые лимиты

Нельзя просто «назначить всех в учёные». Нужны:
1. **свободные ячейки класса**;
2. **соответствующее жильё или инфраструктура**;
3. **ресурсы на содержание**.

### Что дают классовые лимиты
- **Городской квартал** даёт лимит рабочих ячеек.
- **Казармы** дают лимит ополченцев.
- **Усадьбы, библиотеки, храмы, академии** дают лимит учёных.

Это решает проблему:
- «в городе 10 000 жителей, но нет 3 учёных»;
- «игрок хочет 50 ополченцев без казарм»;
- «все стали магами без инфраструктуры».

---

## 3.4. Формула доступных ячеек

Пусть:

- `P` — население города;
- `W_total = ceil(P / 100)` — всего рабочих ячеек.

Каждая ячейка может быть:
- работником;
- ополченцем;
- учёным;
- безработной.

Условия:
```text
Workers + Militia + Scholars <= W_total
```

Но каждый класс дополнительно ограничен:
```text
Workers <= WorkerClassCap
Militia <= MilitiaClassCap
Scholars <= ScholarClassCap
```

Если население выросло, а классовых мест нет:
- появляется **избыточное население**;
- растёт недовольство;
- снижается репутация;
- возможны бунты.

---

# 4. Репутация: единый показатель довольства и привлекательности

## 4.1. Почему не нужны отдельные «счастье», «мораль» и «благоустройство»

Раньше в тексте были:
- Счастье;
- Мораль;
- Репутация;
- Благоустройство.

Это создавало путаницу.

Финальное решение:

> **Репутация** — единый показатель от **-100 до +100**, который одновременно отражает:
> - внутреннее довольство жителей;
> - внешнюю привлекательность города;
> - устойчивость к бунтам;
> - приток/отток мигрантов.

---

## 4.2. Факторы Репутации

### Положительные
| Фактор | Эффект |
|---|---:|
| Избыток еды | +5…+20 |
| Положительная репутация от построек | +5…+15 |
| Таверны, храмы, роскошь | +5…+20 |
| Победы армии | +10 |
| Построенное Чудо | +15 |
| Завершённый перенос центра | +30 |
| Низкие налоги | +5 |
| Хорошая вода и санитария | +5…+10 |

### Отрицательные
| Фактор | Эффект |
|---|---:|
| Голод | -10…-30 |
| Нехватка воды | -10…-25 |
| Перенаселение без жилья | -10…-20 |
| Высокие налоги | -5…-20 |
| Вражеские грабежи колец | -5…-15 |
| Эпидемия | -20 |
| Безработица > 25% | -10 |
| Поражение армии | -10 |
| Пожары/разрушения | -5…-15 |

Итоговое значение:
```text
Reputation = clamp(-100, +100)
```

---

## 4.3. Эффекты Репутации

| Диапазон | Состояние | Эффекты |
|---:|---|---|
| +80…+100 | Золотой век | +15% производство, +50% приток элиты, ускорение роста |
| +30…+79 | Процветание | стабильная иммиграция, бонус к найму специалистов |
| +1…+29 | Норма | небольшой приток населения |
| -1…-30 | Недовольство | эмиграция, -10% эффективность |
| -31…-70 | Кризис | забастовки, дезертирство, -25% эффективность |
| -71…-100 | Бунт | часть зданий отключается, ополчение может восстать, возможен мятеж |

---

# 5. Миграция и рост населения

## 5.1. Базовые условия роста

Население растёт только если выполнены условия:

1. **Еда в плюсе**
2. **Есть свободное жильё**
3. **Есть вода**
4. **Репутация не отрицательная**
5. **Есть рабочие/классовые места**

Если хотя бы один критический ресурс отсутствует, рост останавливается или начинается отток.

---

## 5.2. Формула прироста

Базовая формула:

```text
NetPopulationChange =
    FoodSurplus * 8
  + Reputation * 1.5
  - FoodDeficit * 12
  - WaterShortagePenalty
  - OvercrowdingPenalty
  - UnemploymentPenalty
```

Ограничения:
- максимум **+150 жителей за ход** при нормальном развитии;
- максимум **-300 жителей за ход** при катастрофе;
- прирост не может превысить свободную ёмкость жилья.

Дополнительно:
- если нет воды: `-30` к формуле;
- если безработица выше 25%: прирост делится пополам;
- если репутация ниже -70: начинается принудительная эмиграция.

---

## 5.3. Кто приезжает

Мигранты распределяются по вакансиям.

### Приоритет появления:
1. **Работники** — всегда, если есть жильё и еда.
2. **Ополченцы** — если есть свободные места в казармах и репутация ≥ +10.
3. **Учёные** — если есть усадьбы/библиотеки/храмы и репутация ≥ +25.

### Веса распределения
```text
WorkerWeight  = freeWorkerSlots * 10
MilitiaWeight = freeMilitiaSlots * 6
ScholarWeight = freeScholarSlots * 4
```

Если репутация высокая:
- `ScholarWeight += 3`
- `MilitiaWeight += 2`

Если репутация отрицательная:
- первыми уезжают **Учёные**;
- затем **Ополченцы**;
- последними — **Работники**.

Это делает элиту хрупкой и ценной.

---

# 6. Классовое жильё и лимиты

## 6.1. Принцип

Каждое жильё даёт:
1. **ёмкость населения**;
2. **классовые ячейки**;
3. **потребность в обслуживании**.

Больше нельзя просто «поставить 18 домов». Теперь важно:
- какой это тип жилья;
- в каком кольце стоит;
- есть ли вода, еда, дорога;
- есть ли рабочие места.

---

## 6.2. Типы жилья

| Здание | Кольцо | Ёмкость населения (Т1/Т2/Т3) | Классовые ячейки | Требования | Особенности |
|---|---|---:|---|---|---|
| **Городской квартал** | 1 | 350 / 700 / 1200 | 4 / 8 / 14 Работников | вода, дорога | основной городской дом |
| **Казармы** | 1 | 200 / 400 / 600 | 1 / 2 / 4 Ополченца | Военный район, оружие | лечит войска, даёт гарнизон |
| **Усадьба** | 1–2 | 150 / 300 / 500 | 1 / 2 / 4 Учёных | роскошь, высокая репутация | сильная привлекательность для элиты |
| **Сельский выселок** | 2–3 | 250 / 500 / 800 | 3 / 6 / 10 Работников | дорога/колодец | дешёвый, но уязвимый |

---

## 6.3. Почему это работает

### Ранняя игра
- игрок ставит 1–2 городских квартала;
- строит поле и колодец;
- получает первых работников.

### Средняя игра
- нужно решать:
  - строить ли казармы под ополчение;
  - или усадьбы под учёных;
  - или сельские выселки ради дешёвой рабочей силы.

### Поздняя игра
- жильё становится плотным;
- каждый гекс на счету;
- нужно балансировать:
  - жильё;
  - еду;
  - защиту;
  - роскошь;
  - науку;
  - торговлю.

---

# 7. Механика назначений

## 7.1. Главный принцип

> Здание не работает автоматически.  
> Оно даёт потенциал, но для работы в него нужно назначить ячейки населения нужного класса.

Пример:
- Шахта требует 4 Работника.
- Назначено 4 → работает на 100%.
- Назначено 2 → работает на 50%.
- Назначено 0 → простаивает.

---

## 7.2. Формула эффективности здания

```text
Efficiency = AssignedCells / RequiredCells
```

Если `Efficiency < 1`, здание выдаёт меньше результата.

Дополнительно:
- если эффективность ниже 50%, здание может получать штраф к износу;
- если здание требует Учёных, а их нет — оно не работает вовсе;
- если здание требует Ополчение, а его сняли — защита падает.

---

## 7.3. Итоговый выпуск здания

```text
Output = BaseOutput
       * Efficiency
       * TerrainModifier
       * AdjacencyBonus
       * LogisticsModifier
       * ReputationModifier
```

---

## 7.4. Приоритеты авто-назначения

Чтобы не было микро-ада, вводятся режимы:

1. **Выживание**
   - еда;
   - вода;
   - медицина/храмы.

2. **Оборона**
   - стены;
   - башни;
   - гарнизоны.

3. **Экономика**
   - добыча;
   - производство;
   - торговля.

4. **Развитие**
   - наука;
   - магия;
   - вера.

Игрок может:
- включить авто-режим;
- вручную переопределить приоритеты;
- закрепить конкретных специалистов за зданием.

---

# 8. Ресурсы и базовые формулы

## 8.1. Основные ресурсы

| Ресурс | Назначение |
|---|---|
| **Еда** | рост, содержание, предотвращение голода |
| **Дерево** | строительство, стены, дороги |
| **Камень** | стены, здания, чудеса |
| **Железо** | оружие, казармы, продвинутые постройки |
| **Золото** | содержание, торговля, наём |
| **Роскошь** | усадьбы, учёные, репутация |
| **Наука** | технологии |
| **Вера / Магия** | спецэффекты, чудеса, уникальные проекты |

---

## 8.2. Еда

### Потребление
```text
FoodNeed = ceil(Population / 100)
```

То есть 1 ячейка населения = 1 еда в ход.

### Производство
Базовые значения:

| Здание | Т1 | Т2 | Т3 |
|---|---:|---:|---:|
| Ферма | 6 | 10 | 16 |
| Пастбище | 4 | 7 | 10 |
| Рыбацкая пристань | 6 | 10 | 14 |

Это делает еду понятной и масштабируемой.

---

## 8.3. Вода

Вода — не ресурс в складе, а **инфраструктурное покрытие**.

### Источники:
- Колодец
- Акведук
- Река/озеро рядом
- Порт/пристань в прибрежном городе

### Правила:
- жильё без воды снижает рост;
- при дефиците воды растёт риск эпидемий;
- акведук повышает лимит населения и репутацию.

---

## 8.4. Логистика

Здания во 2-м и 3-м кольцах должны быть соединены дорогой с центром.

Если дороги нет:
- 2-е кольцо: **-25% эффективности**
- 3-е кольцо: **-50% эффективности**

Это закрывает дыру «бесконечного расширения без инфраструктуры».

---

# 9. Бонусы смежности

Это одна из ключевых механик, которая делает город пространственным пазлом.

## 9.1. Основные примеры

| Связь | Эффект |
|---|---|
| Мельница рядом с 2+ фермами | +2 еды за каждую соседнюю ферму, макс +6 |
| Пекарня рядом с фермой/мельницей | +4 еды, +1 репутации |
| Кузница рядом с шахтой | +2 производства, +2 золота |
| Таверна рядом с жильём | +2 репутации |
| Храм рядом с жильём | +2 репутации |
| Усадьба рядом с храмом/библиотекой | +1 к науке/вере |
| Усадьба рядом с шахтой/кузницей | -2 репутации из-за загрязнения |
| Сторожевая башня рядом с дорогой | +1 обзор |
| Торговый пост рядом с дорогой/портом | +2 золота |

---

## 9.2. Зачем это нужно

Игрок вынужден думать не только «что построить», но и **где построить**.

Это даёт:
- уникальные планировки городов;
- специализацию по рельефу;
- осмысленное зонирование;
- разницу между «просто застройкой» и «хорошо спроектированным городом».

---

# 10. Финальная структура центральных районов

## 10.1. Центр города: 3 слота

### Слот 1 — Ратуша
Автоматически строится при основании.

**Функции:**
- уровень города;
- хранение ресурсов;
- открытие стен;
- дороги;
- инфраструктура;
- проекты переноса центра.

**Уровни:**
1. Поселение
2. Город
3. Столичный центр

---

### Слот 2 — Военный / Торговый / Ремесленный район
Открывается на **уровне 3**.

Игрок выбирает один из трёх:

#### 1. Военный двор
- +2 / +4 / +6 к лимиту ополчения;
- открывает казармы и фортификацию;
- лечение войск;
- снижает потерю защиты при мобилизации.

#### 2. Торговый двор
- +5 / +10 / +20 золота;
- +1 / +2 / +3 каравана;
- усиливает рынки и торговые посты;
- позволяет покупать отсутствующие ресурсы.

#### 3. Ремесленный двор
- +10% / +20% / +30% к производству и строительству;
- удешевляет здания;
- усиливает кузницы, пекарни, мастерские.

---

### Слот 3 — Храмовый / Академический / Магический район
Открывается на **уровне 5**.

Игрок выбирает один из трёх:

#### 1. Храмовый округ
- +вера;
- +репутация;
- снижение риска бунтов;
- лечение и защита от порчи.

#### 2. Академический округ
- +наука;
- +2 / +4 / +6 к лимиту учёных;
- открывает библиотеки и университеты.

#### 3. Магический шпиль
- +магия;
- защита от вражеских заклинаний;
- открывает магические башни и зачарование стен.

---

## 10.2. Почему это лучше старых 10 зданий в центре

Раньше в центре пытались уместить:
- казармы;
- рынок;
- храм;
- библиотеку;
- кузницу;
- стены;
- жильё.

Это было невозможно.

Теперь центр даёт **стратегический профиль города**, а всё остальное вынесено на гексы.

---

# 11. Реестр внешних зданий

Ниже — финальный, сбалансированный реестр.

Обозначения:
- **Р** — рабочие ячейки;
- **О** — ополченцы;
- **У** — учёные.

---

## 11.1. Жильё

| Здание | Кольцо | Требует | Выдаёт |
|---|---|---|---|
| Городской квартал | 1 | вода | жильё и рабочие ячейки |
| Казармы | 1 | Военный район | жильё и ополчение |
| Усадьба | 1–2 | роскошь | жильё и учёных |
| Сельский выселок | 2–3 | дорога/вода | дешёвое рабочее жильё |

---

## 11.2. Еда

| Здание | Кольцо | Террейн | Персонал | Выход |
|---|---|---|---:|---|
| Ферма | 2–3 | плодородная земля | 2 Р | еда |
| Пастбище | 2–3 | равнина/лес | 2 Р | еда + роскошь на Т3 |
| Рыбацкая пристань | вода | побережье | 2 Р | еда + золото |
| Мельница | 2 | рядом с фермами | 1 Р | бонус к еде |
| Пекарня | 1–2 | рядом с фермой/мельницей | 2 Р | еда + репутация |

---

## 11.3. Добыча

| Здание | Кольцо | Террейн | Персонал | Выход |
|---|---|---|---:|---|
| Лесопилка | 2–3 | лес | 3 Р | дерево |
| Каменоломня | 2–3 | холмы/скалы | 3 Р | камень |
| Железная шахта | 2–3 | руда/горы | 4 Р | железо |
| Золотая шахта | 3 | золото/горы | 4 Р | золото |
| Форпост-добыча | вне колец | ресурсный гекс | 2 Р | базовая добыча |

---

# 12. Таблица уровней города (финальный баланс)

Это единая таблица, заменяющая все старые варианты.

## 12.1. Принципы
- Население считается в жителях.
- Уровень не повышается «сам по себе от зданий», если нет инфраструктуры.
- Поздние уровни требуют не только население, но и **Процветание**.

## 12.2. Что такое Процветание

**Процветание** — агрегированный показатель развития города.

Формула:
```text
Prosperity =
    Population / 100
  + 10 * сумма уровней всех зданий
  + 25 * уровень районов
  + 100 за Чудо
  + 20 за положительную репутацию
  + бонусы от исторического центра
```

Это закрывает проблему «улучшить все 36 зданий до 3 уровня».

# 13. Закрытие дыр и софт-локов

## 13.1. Дыра: «Нет камня/леса рядом»

### Финальное решение
1. **Рынок**
   - позволяет покупать ресурсы за золото;
   - особенно важен в Торговом районе.

2. **Форпосты**
   - можно строить вне колец на ресурсных гексах;
   - требуют дорогу;
   - работают только на добычу;
   - лимит: 2–3 форпоста на город.

3. **Караваны**
   - если есть торговый двор или торговый пост, можно импортировать ресурс.

### Что убрано
- больше нет «шахты на равнине со штрафом 50%» как универсального костыля.

Террейн остаётся важным, но софт-лок закрыт.

---

## 13.2. Дыра: «Слишком мало слотов в центре»

### Финальное решение
- центр = районы;
- всё массовое строительство вынесено в кольца;
- районы дают не здания, а **доступ к зданиям**.

---

## 13.3. Дыра: «Стены занимают слот»

### Финальное решение
Стены — апгрейд Ратуши.

Уровни:
1. Частокол
2. Каменная стена
3. Бастионы
4. Магический барьер

Стены не занимают гекс, но требуют:
- ресурсы на постройку;
- гарнизон ополчения для полной эффективности.

---

## 13.4. Дыра: «Спам жильём»

### Финальное решение
Жильё даёт рост только при выполнении условий:
- вода;
- еда;
- дорога;
- репутация;
- рабочие места.

Если построить только жильё:
- город вырастет до предела;
- затем начнутся безработица, голод, бунты.

---

## 13.5. Дыра: «Микроменеджмент в поздней игре»

### Финальное решение
- ячейки вместо отдельных жителей;
- авто-назначение;
- приоритеты;
- агрегированные здания;
- процветание вместо требования «улучшить всё».

---

# 15. Перенос центра города

Это очень сильная механика, поэтому она должна быть ограничена.

## 15.1. Зачем нужен перенос центра

Он решает проблемы:
- прибрежный город упёрся в море;
- город зажат горами;
- старый центр стал тесным;
- нужно развернуть город к плодородным землям или новой торговой оси.

---

## 15.2. Условия запуска

Разрешается при:
1. **Уровень города ≥ 7**
2. Изучена технология **Градостроительство / Логистика**
3. Репутация ≥ 0
4. Есть целевой сухопутный гекс внутри текущей зоны города
5. На целевом гексе нет Чуда / Исторического центра / воды

---

## 15.3. Стоимость

Базовая цена:
- **1200 камня**
- **1000 золота**
- **800 дерева**
- **200 еды**

Каждый повторный перенос:
- **+50% к стоимости**
- **-10 репутации при старте проекта**

---

## 15.4. Длительность

Базовая длительность: **5 ходов**

Можно сократить:
- назначить больше рабочих;
- использовать Ремесленный район;
- иметь высокие процветание и дороги.

Минимальная длительность: **3 хода**  
Максимальная при дефиците рабочих: **8 ходов**

---

## 15.5. Эффекты во время переноса

Пока идёт проект:
- -30% производство;
- -10 репутации;
- нельзя завершать часть столичных проектов;
- город становится уязвим к рейдам.

Если враг атакует и прорывает оборону:
- проект может быть разрушен;
- часть ресурсов сгорает;
- город получает бунт или сильную панику.

---

## 15.6. Эффекты после завершения

### Новый центр
- выбранный гекс становится новой Цитаделью;
- Ратуша и районы переносятся/перестраиваются;
- кольца пересчитываются относительно нового центра.

### Старый центр
Превращается в **Исторический центр**:
- уникальный пассивный бонус;
- +10 золота;
- +5 репутации;
- +10% хранение;
- не может быть снесён;
- занимает гекс навсегда.

Это главный антиэксплойт: каждый перенос **уменьшает доступную застройку на один гекс**.

---

## 15.7. Ограничения

Максимум:
- **2 переноса центра на город**

Кулдаун:
- **15 ходов между переносами**

Дополнительно:
- нельзя перенести центр так, чтобы потерять Ратушу без исторического якоря;
- нельзя переносить центр в водный гекс;
- нельзя переносить центр в гекс с Чудом.

---

# 16. Боевая система, милиция и осады

## 16.1. Главный принцип

Ополчение — это не просто «войска из города». Это **ресурс безопасности**.

Если вы снимаете ополчение с защиты:
- башни слепнут;
- стены слабеют;
- фронтир становится уязвим.

---

## 16.2. Назначение ополчения

Ополченцы могут быть назначены в:
1. **Гарнизон стен**
2. **Сторожевые башни**
3. **Форты**
4. **Полевую армию**
5. **Резерв города**

Если ополчение назначено в полевую армию, оно больше не защищает здания.

---

## 16.3. Стены

Уровни:
1. Частокол
2. Каменная стена
3. Бастионы
4. Магический барьер

Стены защищают:
- центр;
- 1-е кольцо.

Не защищают:
- 2-е кольцо;
- 3-е кольцо.

Бонус стены работает полностью только при назначенном гарнизоне.

---

## 16.4. Грабёж фронтира

Враг может:
- атаковать фермы;
- сжигать лесопилки;
- разграбить шахты;
- разрушить торговые посты.

Последствия:
- здание временно отключается;
- город теряет ресурсы;
- падает репутация;
- растёт паника.

Контрмеры:
- сторожевые башни;
- форты;
- полевая армия;
- стены и магический барьер.

---

# 17. Городская специализация

Чтобы города не были одинаковыми, добавляются **черты города**.

## 17.1. Когда выбираются
- на **уровне 9** или **11**;
- зависят от построенных районов, рельефа и стиля игры.

---

## 17.2. Примеры черт

### Крепость
- +25% к защите стен;
- +2 ячейки ополчения;
- -10% золотого дохода.

### Торговый узел
- +2 каравана;
- рынок эффективнее на 50%;
- +репутация при избытке роскоши.

### Кузница империи
- +20% производство;
- экипировка дешевле;
- выше содержание рабочих.

### Академия
- +25% наука;
- учёные требуют меньше роскоши;
- слабее военная защита.

### Священный город
- +вера;
- +10 репутации;
- устойчивость к бунтам.

### Порт
- водные здания эффективнее на 25%;
- перенос центра дешевле;
- уязвимость к морским набегам.

# 20. Игровой цикл: как это играет

## 20.1. Ранняя игра
Игрок:
- ставит колодец;
- строит поле;
- строит первый квартал;
- балансирует еду и жильё;
- пытается выйти в плюс по репутации.

Главная задача: **выжить и закрепиться**.

---

## 20.2. Средняя игра
Игрок:
- выбирает первый район;
- открывает 2-е кольцо;
- строит добычу;
- решает, куда вкладывать рабочих:
  - в шахты;
  - в фермы;
  - в рынок;
  - в казармы.

Главная задача: **выбрать специализацию города**.

---

## 20.3. Поздняя игра
Игрок:
- открывает 3-е кольцо;
- строит усадьбы и гильдии;
- управляет репутацией;
- решает, строить ли Чудо;
- защищается от грабежей;
- думает о переносе центра, если рельеф исчерпан.

Главная задача: **удержать сложный организм города от кризиса**.

# 21. Итоговый список: что теперь является каноном

## 21.1. Население
- измеряется в жителях;
- 1 ячейка = 100 жителей;
- классы: Работники, Ополченцы, Учёные;
- классы требуют жилья и инфраструктуры.

## 21.2. Рост
- зависит от еды, воды, жилья, репутации, рабочих мест;
- нет бесконтрольного спама домами.

## 21.3. Центр
- Ратуша + 2 района;
- районы дают профиль города;
- стены — апгрейд Ратуши.

## 21.4. Кольца
- 1-е кольцо — городская ткань;
- 2-е кольцо — производство и агро;
- 3-е кольцо — фронтир, роскошь, чудеса.

## 21.5. Экономика
- здания работают только при назначении ячеек;
- есть смежность, логистика, террейн;
- рынок и форпосты закрывают софт-локи.

## 21.6. Репутация
- единый показатель довольства и привлекательности;
- влияет на миграцию, производство, бунты, отток элиты.

## 21.7. Война
- ополчение — ограниченный ресурс;
- полевая армия ослабляет город;
- 2-е и 3-е кольца уязвимы.

## 21.8. Перенос центра
- мощный, но дорогой;
- ограничен;
- создаёт исторический центр;
- спасает прибрежные и зажатые города, но не является бесконечным эксплойтом.

- **тело** — гексы и кольца;

# 2. Симуляция прогрессии города на 50 ходов

## 2.1. Допущения симуляции

- Сложность: **нормальная**
- Внешних войн и осад нет
- Есть небольшие грабежи, но они успешно сдерживаются
- Террейн благоприятный: рядом есть фермы, лес, холмы, руда
- Город стартует с **200 жителей** и базовым убежищем на 200 ёмкости
- Уровень 1 не повышается автоматически только по населению: нужны инфраструктурные условия
- Цель симуляции — показать **реалистичный темп роста**, а не speedrun

## 2.4. Выводы из симуляции

### Что видно
- Город достигает **уровня 9 за 50 ходов** при устойчивом развитии.
- **Уровень 10** реалистично достигается к **55–60 ходу**.
- **Уровень 11** без агрессивной оптимизации, чудес и торговли обычно уходит на **70–80 ходов**.
- Узкие места по порядку:
  1. жильё;
  2. еда;
  3. вода;
  4. классовые лимиты;
  5. репутация;
  6. логистика 3-го кольца.

### Почему темп нормальный
- Ранний рост быстрый, потому что мало населения и легко закрыть еду/жильё.
- Средний рост замедляется, потому что нужны районы, дороги, склады, рынок.
- Поздний рост требует роскоши, науки, обороны фронтира и больших строек.

function AutoAssignPopulation(city):
    availableWorkers  = city.totalWorkers
    availableMilitia  = city.totalMilitia
    availableScholars = city.totalScholars

    jobs = GetAllJobs(city)
    SortJobsByPriority(jobs)

    for job in jobs:
        if job.class == WORKER:
            assign = min(job.required, availableWorkers)
            job.assigned = assign
            availableWorkers -= assign

        if job.class == MILITIA:
            assign = min(job.required, availableMilitia)
            job.assigned = assign
            availableMilitia -= assign

        if job.class == SCHOLAR:
            assign = min(job.required, availableScholars)
            job.assigned = assign
            availableScholars -= assign

    city.unemployed =
        availableWorkers + availableMilitia + availableScholars

# 1. Исправленная базовая модель населения

| Группа | Описание |
|---|---|

| **Работники** | Обученная рабочая сила. Эффективно работают на добыче, полях, складах, стройках. |
| **Ополченцы** | Обученные бойцы. Нужны для гарнизона, башен, стен, патрулей. |
| **Учёные** | Обученные специалисты: писари, жрецы, лекари, маги, инженеры. |

Формула населения:

| Параметр | Значение |

1. **Строить здания**

2. **Выполнять базовый труд**

3. **Обучаться**

Свободные **не могут** полноценно занимать:

- военные посты;

# 3. Миграция, отток, смерть

## 3.1. Миграция

Мигранты приходят, если:

- есть свободное жильё;
- есть еда;
- репутация не отрицательная.

Формула:

```text
MigrationPoints =
      FreeHousing * 3
    + max(0, Reputation) * 0.5
    + FoodSurplus * 2
```

Порог появления 1 жителя:

```text
25 MigrationPoints = +1 свободный житель
```

Если `FreeHousing <= 0`, миграция не идёт.

---

## 3.2. Эмиграция

Жители уходят, если:

- репутация отрицательная;
- не хватает еды;
- нет жилья;
- идут бунты, пожары, эпидемии.

Формула:

```text
LeavePoints =
      abs(min(0, Reputation)) * 1
    + max(0, FoodDeficit) * 2
    + max(0, -FreeHousing) * 3
```

Порог ухода 1 жителя:

```text
25 LeavePoints = -1 житель
```

Сначала уходят свободные, затем учёные, затем ополченцы, затем работники.

---

## 3.3. Еда

Потребление:

```text
FoodNeed = Population
```

То есть 1 житель = 1 еда в ход.

Если еды не хватает:

```text
FoodDeficit = FoodNeed - FoodStock
```

Последствия:

- падает репутация;
- растут болезни;
- начинается эмиграция;
- накапливаются очки голодной смерти.

---

## 3.4. Старость

Вводится накопитель старости:

```text
AgingPoints += Population * 0.02 * AgingModifier
```

```text
100 AgingPoints = 1 смерть от старости
```

| Фактор | Эффект |
|---|---:|
| Нет лазарета | +25% |
| Есть лазарет | -20% |
| Есть храм | -10% |
| Есть бани | -10% |
| Голод | +50% |
| Перенаселение | +25% |

# 6. Полный дата-дизайн-документ по зданиям

## 6.1. Формат записи

Для каждого здания используются поля:

```yaml
id: уникальный идентификатор
name: название
class: класс здания
tags: теги
unlock: требования открытия
placement: размещение
cost: стоимость
work: чел-ходы
staff: персонал
effects: эффекты
```

### Важно про `work`

`work` — это **человеко-ходы**.

Если назначен 1 человек:

```text
BuildTime = work
```

Если назначено 3 человека:

```text
BuildTime = ceil(work / 3)
```

# 10. Итоговая логика города

## 10.1. Порядок хода

```text
1. Рассчитать жильё и свободные места.
2. Рассчитать воду и болезни.
3. Назначить свободных/работников на здания.
4. Рассчитать строительство.
5. Рассчитать еду.
6. Рассчитать обучение.
7. Рассчитать миграцию.
8. Рассчитать эмиграцию.
9. Рассчитать старость, болезни, голод.
10. Применить события.
11. Проверить уровень города.
```

---

## 10.2. Главное отличие новой версии

Теперь город начинается с **одного человека**, а не с готовой толпы.

Игровой цикл такой:

1. Построить жильё.
2. Привлечь людей репутацией и едой.
3. Обучить свободных.
4. Назначить обученных на здания.
5. Снизить болезни и смерть.
6. Только затем расширяться.

Это делает раннюю игру более хрупкой, но логичной:  
**город — не готовый механизм, а маленькое поселение, которое нужно вырастить и защитить.**

# 2. Баланс под стартовые карты

Ниже — баланс для четырёх стартовых типов карты:

- **Лес**
- **Равнина**
- **Побережье**
- **Холмы**

Общее правило:

> За 50 ходов город должен доходить максимум до **3 уровня**.  
> Нормальный результат к 50 ходу: **34–38 жителей**, обученные работники, базовая еда, вода, жильё и 1–2 специалиста.

| Ход | Ориентир |
|---:|---|

| 16–25 | Уровень 2, дом, трудовой двор |

# 3. Карта: Лес

## 3.1. Характер карты

Лес — карта с хорошим деревом и охотой, но более сложной едой и повышенным риском пожаров.

### Сильные стороны
- много дерева;
- охота и собирательство работают хорошо;
- лесопилка быстро становится эффективной.

### Слабые стороны
- меньше открытых плодородных участков;
- выше риск пожаров;
- меньше камня, если нет холмов.

# 9. Итоговая рекомендация по балансу

Если нужно сохранить единый уровень сложности для всех карт:

- **Равнина** должна быть самой лёгкой по еде, но самой опасной по набегам.
- **Лес** — универсальный средний старт с риском пожаров.
- **Побережье** — сильное по еде и торговле, но ограниченное по земле.
- **Холмы** — самый сложный ранний старт, но самый сильный в добыче камня и обороне.

При текущей модели:
- все четыре карты должны приходить к **уровню 3 примерно к 46–50 ходу**;
- если карта выходит на уровень 3 раньше 45 хода, можно слегка уменьшить миграцию или увеличить стоимость жилья;
- если карта не достигает уровня 3 к 50 ходу, нужно усилить раннюю еду или снизить шанс эпидемий.

### USER
Спроектируй википедию какие там будут страницы

### ASSISTANT
Проектирование внутриигровой энциклопедии (Вики / Кодекса) — это критически важный этап. В сложных стратегиях и градостроях (вроде *RimWorld*, *Dwarf Fortress*, *Endless Legend* или *Crusader Kings*) Вики становится не просто справочником, а **главным инструментом выживания и планирования**.

Ниже представлена архитектура Википедии для нашей игры. Она разделена на логические порталы, чтобы и новичок, и опытный теориикрафтер могли быстро найти нужное.

# 📖 1. Портал: Руководство и Основы
*Здесь собраны статьи для новичков и общие концепции.*

*   **Первые 50 ходов (Гайд по выживанию)** — Пошаговая стратегия: как не умереть от голода и болезней, начав с 1 основателя. Почему 3-й уровень — это потолок ранней игры.
*   **Интерфейс города** — Как читать панель Репутации, назначать рабочих и использовать очередь строительства.
*   **Цикл хода** — В каком порядке игра считает еду, миграцию, болезни и обучение.
*   **Словарь терминов** — Глоссарий (Человеко-ходы, Очки обучения, Лимит жилья, Фронтир).

---

# 👥 2. Портал: Население и Общество
*Всё о людях, которые живут в вашем городе.*

*   **Население (Обзор)** — Концепция 4 состояний: Свободные, Работники, Ополченцы, Учёные.
*   **Миграция и Репутация** — Как работает шкала от -100 до +100. Что привлекает мигрантов, а что вызывает исход элиты.
*   **Обучение и Тренировка** — Как превратить Свободного жителя в Специалиста. Накопление Очков Обучения (100 очков = 1 специалист).
*   **Смертность, Старость и Болезни** — Формулы накопления очков старости и эпидемий. Как Лазареты, Бани и Кладбища спасают город от вымирания.
*   **Голод и Истощение** — Что происходит, когда Еда падает ниже нуля. Механика голодной смерти и дезертирства.

---

# 🏗️ 3. Портал: Градостроительство и Зонирование
*Пространственный пазл и архитектура.*

*   **Архитектура города** — Концепция Цитадели (3 слота) и Трёх Колец.
*   **Цитадель и Районы** — Подробный разбор слотов: Военный, Торговый, Ремесленный, Храмовый, Академический. Как выбор района меняет профиль города.
*   **Бонусы смежности (Пазл застройки)** — *Самая популярная страница у минмаксеров.* Таблицы синергий (например, Мельница + Поля, Кузница + Шахта, Усадьба + Храм).
*   **Стены и Оборона периметра** — Как работают Частокол, Каменные стены и Магический барьер. Почему стены бесполезны без гарнизона Ополченцев.
*   **Логистика и Дороги** — Штрафы за отсутствие дорог во 2-м и 3-м кольцах.
*   **Перенос центра (Сдвиг Цитадели)** — Эндгейм-механика. Как спасти город, зажатый горами или морем. Стоимость, кулдауны и создание Исторического центра.

---

# 🌾 4. Портал: Экономика и Ресурсы
*Кровеносная система вашего поселения.*

*   **Базовые ресурсы** — Еда, Дерево, Камень, Железо, Золото. Где добываются и как тратятся.
*   **Роскошь и Благоустройство** — Вино, Мёд, Фрукты. Зачем они нужны Учёным и Усадьбам.
*   **Пищевые цепочки** — Как сырое зерно превращается в хлеб через Мельницы и Пекарни для бонусов к Репутации.
*   **Торговля и Караваны** — Как Рынок и Торговые посты позволяют покупать недостающие ресурсы, если на карте нет нужного террейна.
*   **Хранение и Порча** — Как работают Амбары и Склады. Что происходит с едой, если лимит хранения превышен.

# 📜 5. Портал: Реестр Зданий (База данных)
*Интерактивный каталог с фильтрами по тегам, классам и стоимости.*
*(На странице есть боковая панель с чекбоксами: `[x] Только жильё`, `[x] Требует воды`, `[x] Обучает учёных`)*

*   **Жилые здания** — Укрытие, Дом, Общинный дом, Усадьба. (Лимиты жилья и классовые слоты).
*   **Добыча и Производство** — Собирательство, Лесопилки, Шахты, Кузницы. (Требования к террейну и риски аварий).
*   **Сельское хозяйство** — Поля, Пастбища, Виноградники.
*   **Обучающие здания** — Трудовой двор, Тренировочная площадка, Школа, Писарская изба.
*   **Медицина и Санитария** — Очаг, Колодец, Акведук, Лазарет, Бани, Кладбище.
*   **Военная инфраструктура** — Казармы, Сторожевые башни, Форты.
*   **Чудеса Света** — Уникальные мега-структуры, занимающие 3 гекса. Требования и глобальные эффекты.

# 🌍 6. Портал: Мир, Биомы и События
*Внешние условия и случайности.*

*   **Стартовые Биомы** — Подробный разбор 4 карт:
    *   🌲 **Лес** (Много дерева, риск пожаров).
    *   🌾 **Равнина** (Идеальная еда, риск набегов и засух).
    *   🌊 **Побережье** (Рыбалка, торговля, нехватка суши).
    *   ⛰️ **Холмы** (Камень, железо, оборона, риск оползней).
*   **Рельеф и Террейн** — Таблица совместимости зданий и типов почвы.
*   **События и Кризисы** — Энциклопедия случайных событий:
    *   *Эпидемия* (Условия вспышки и способы карантина).
    *   *Пожар* (Как тушить и какие здания горят быстрее).
    *   *Набег фронтира* (Как Сторожевые башни спасают экономику).
    *   *Суровая зима / Засуха* (Сезонные модификаторы).
*   **Враги и Угрозы** — Типы рейдеров, бандитов и вражеских армий. Как работает механика грабежа колец.

# ⚙️ 7. Портал: Под капотом (Для теориикрафтеров)
*Точные цифры для тех, кто любит просчитывать всё на 100 ходов вперёд.*

*   **Математика Репутации** — Точные формулы начисления и штрафов.
*   **Формулы Миграции** — Как рассчитывается вес прибытия Работников vs Учёных.
*   **Таблицы Человеко-часов** — Сколько свободных жителей нужно назначить на стройку, чтобы сократить время возведения в 2 или 3 раза.
*   **Таблица Процветания** — Как рассчитывается скрытый параметр `Prosperity`, необходимый для перехода на уровни 4–11.
*   **Скрытые теги зданий** — Список всех тегов (`fire_risk`, `luxury`, `wall`, `death`) и как они взаимодействуют с событиями.

# 🛠️ Фичи интерфейса Вики (Как это выглядит в игре)

1. **Перекрёстные ссылки (Hyperlinks):**
   Если в статье *«Эпидемия»* встречается слово *«Лазарет»*, оно выделено синим. Клик по нему открывает всплывающую карточку здания с его стоимостью и эффектом снижения болезней.
2. **Калькулятор смежности:**
   На странице *«Бонусы смежности»* есть мини-инструмент: игрок выбирает здание (например, *Кузница*), и Вики показывает визуальную сетку гексов, подсвечивая, какие здания дадут ей бонус, а какие (например, *Жильё*) получат штраф к Репутации из-за шума.
3. **Динамические предупреждения:**
   Если игрок открывает статью *«Поле»* на карте *«Холмы»*, Вики выдаст красную плашку: *«Внимание: На вашем текущем биоме мало плодородных земель. Рекомендуется изучить Торговлю или Охоту»*.
4. **Закладки и Цели:**
   Игрок может добавить статью *«Перенос центра»* в закладки. Когда город достигнет 7 уровня, игра сама пришлет уведомление: *«Вы изучили механизм Сдвига Цитадели. Обратитесь к закладкам в Кодексе»*.
5. **Спойлер-теги:**
   Эндгейм-механики (Чудеса Света, Магические башни, Столичный статус) скрыты под спойлер-тегами `[Раскрыть]`, чтобы не перегружать новичка информацией в первые часы игры.

### 💡 Итог: Зачем такая структура?
Эта Википедия решает главную проблему сложных стратегий — **когнитивную перегрузку**.
* **Новичок** заходит в *«Первые 50 ходов»* и просто следует чек-листу, чтобы не умереть от голода.
* **Мидгеймер** открывает *«Бонусы смежности»* и *«Обучение»*, чтобы оптимизировать экономику.
* **Хардкорщик** сидит в *«Формулах»* и *«Таблицах тегов»*, просчитывая идеальный перенос центра на 45-м ходу.

Такой Кодекс становится не просто текстом, а **полноценным игровым инструментом**, встроенным в UI.

# ТЕХНИЧЕСКАЯ СПЕЦИФИКАЦИЯ ВИКИ / КОДЕКСА

## 1. Назначение системы

Вики/Кодекс — это внутриигровая база знаний, которая:

- объясняет механики выживания и развития;
- хранит справочники по зданиям, ресурсам, биомов, событиям;
- помогает новичку пройти первые 50 ходов;
- даёт продвинутому игроку формулы, теги и таблицы;
- поддерживает динамические подсказки в зависимости от состояния города.

---

## 2. Архитектура данных

Вики должна быть **дата-драйвен**. Контент хранится отдельно от кода, желательно в формате:

```text
/wiki
  /pages
    00_home.json
    01_survival_first_50.json
    02_population_overview.json
    ...
  /categories
  /components
  /localization
```

Каждая страница — это объект с метаданными и блоками контента.

---

## 3. Схема страницы

Базовая структура страницы:

```json
{
  "id": "wiki_home",
  "slug": "/wiki/home",
  "type": "portal",
  "category": "core",
  "priority": 1,
  "title": "Кодекс Градостроителя",
  "subtitle": "От одного основателя до живого города",
  "access": {
    "always_visible": true,
    "required_level": null,
    "required_turn": null
  },
  "tags": ["wiki", "home", "navigation"],
  "related_pages": [],
  "blocks": []
}
```

---

## 4. Типы страниц

| Тип | Назначение |
|---|---|
| `portal` | Главная страница, навигационный хаб |
| `guide` | Пошаговые руководства |
| `mechanic` | Описание игровой механики |
| `entity_list` | Список зданий, ресурсов, событий |
| `entity_page` | Страница конкретного здания/события/биома |
| `formula` | Формулы и расчёты |
| `reference` | Таблицы, глоссарий, теги |

---

## 5. Типы контентных блоков

Для сборки страниц используются блоки:

```json
{ "type": "heading", "level": 2, "text_key": "wiki.section.title" }
```

Поддерживаемые блоки:

| Блок | Назначение |
|---|---|
| `paragraph` | Обычный текст |
| `callout` | Важное предупреждение / совет |
| `list` | Список |
| `table` | Таблица |
| `formula_block` | Формула расчёта |
| `building_card` | Карточка здания |
| `biome_card` | Карточка биома |
| `event_card` | Карточка события |
| `resource_card` | Карточка ресурса |
| `tag_filter` | Фильтр по тегам |
| `search_box` | Поиск по вики |
| `progress_tracker` | Чек-лист прогресса |
| `spoiler` | Скрытый контент |
| `related_pages` | Ссылки на похожие страницы |

---

## 7. Система доступности и спойлеров

Контент может открываться по условиям:

```json
"access": {
  "always_visible": false,
  "required_level": 3,
  "required_turn": 50,
  "required_building": "core_townhall",
  "required_event_seen": "epidemic"
}
```

Правила:

1. Базовые страницы доступны всегда.
2. Поздние механики скрыты до первого релевантного события.
3. Если страница заблокирована, показывается заглушка:

```text
Этот раздел станет доступен позже.
```

---

## 8. Динамические подсказки

Вики должна уметь показывать контекстные подсказки на основе состояния города.

Примеры:

| Условие | Подсказка |
|---|---|
| Еда < 0 | Показать страницу «Голод и выживание» |
| Нет воды | Показать страницу «Колодцы и вода» |
| Болезни выше 0.08 | Показать страницу «Эпидемии и санитария» |
| Свободные жители без обучения | Показать страницу «Обучение населения» |
| Репутация < 0 | Показать страницу «Эмиграция и недовольство» |

---

## 9. Интеграция с игровыми данными

Вики должна ссылаться на основные справочники:

```text
buildings.json
resources.json
biomes.json
events.json
population_classes.json
city_levels.json
training_system.json
disease_system.json
```

Пример ссылки на здание:

```json
{
  "type": "building_card",
  "building_id": "housing_shelter"
}
```

Пример ссылки на биом:

```json
{
  "type": "biome_card",
  "biome_id": "forest"
}
```

---

## 10. Локализация

Все тексты должны быть вынесены в локализационные ключи.

Пример:

```json
{
  "text_key": "wiki.home.intro"
}
```

Локализационный файл:

```json
{
  "wiki.home.title": "Кодекс Градостроителя",
  "wiki.home.intro": "Город начинается с одного человека..."
}
```

Не хранить «сырой» текст внутри логики компонентов.

# 5. Путь новичка

Блок должен отображаться как чек-лист:

```text
Путь основателя:
1. Построй Укрытие.
2. Обеспечь еду.
3. Найди воду.
4. Построй жильё для мигрантов.
5. Обучи первых работников.
```

Технически чек-лист должен отслеживаться по игровым флагам:

| Шаг | Условие выполнения |
|---|---|
| Построй Укрытие | `housing_shelter` построен |
| Обеспечь еду | `food_stock > 0` и `food_surplus >= 0` |
| Найди воду | построен `water_well` или есть природная вода |
| Построй жильё | суммарный `housing_capacity > 1` |
| Обучи первых работников | обучен хотя бы 1 `worker` |

---

## 5.1. Визуальное состояние чек-листа

Каждый пункт может быть:

```text
locked    — ещё не начинался
active    — текущая цель
done      — выполнено
warning   — цель под угрозой
failed    — цель провалена
```

Пример:

```text
✔ Построй Укрытие
✔ Обеспечь еду
! Найди воду
○ Построй жильё для мигрантов
○ Обучи первых работников
```

# 6. Контекстные подсказки

Главная страница должна показывать динамические блоки в зависимости от состояния города.

## 6.1. Список условий

| Условие | Заголовок подсказки | Текст | Целевая страница |
|---|---|---|---|
| `food <= 5` | Голод близко | Запасы еды заканчиваются. Построй источник пищи. | Еда и выживание |
| `water_coverage < 100%` | Нет воды | Жители страдают без воды. Построй колодец. | Вода и санитария |
| `disease_rate > 0.08` | Болезни распространяются | Улучши санитария, построй очаг или лазарет. | Болезни и эпидемии |
| `free_housing <= 0` | Нет места | Мигранты не могут заселиться. Построй жильё. | Жилые здания |
| `free_population > 5` | Свободные без дела | Обучи свободных жителей в Трудовом дворе. | Обучение и тренировка |
| `reputation < 0` | Люди уходят | Репутация города падает. Улучши условия жизни. | Миграция и репутация |

---

## 6.2. Приоритет подсказок

Если активных подсказок несколько, показывать в порядке приоритета:

```text
1. Голод
2. Вода
3. Болезни
4. Нехватка жилья
5. Репутация
6. Обучение
```

Максимум одновременно: 3 подсказки.

## 9.3. Логика контекстных подсказок

Псевдокод:

```javascript
function getMainPageHints(city) {
  const hints = [];

  if (city.food_stock <= 5) {
    hints.push("food_warning");
  }

  if (city.water_coverage < 1.0) {
    hints.push("water_warning");
  }

  if (city.disease_rate > 0.08) {
    hints.push("disease_warning");
  }

  if (city.free_housing <= 0) {
    hints.push("housing_warning");
  }

  if (city.reputation < 0) {
    hints.push("reputation_warning");
  }

  if (city.free_population > 5) {
    hints.push("training_warning");
  }

  return hints
    .sort(byHintPriority)
    .slice(0, 3);
}
```

---

## 9.4. Логика чек-листа новичка

Псевдокод:

```javascript
function getBeginnerChecklist(city) {
  return [
    {
      id: "build_shelter",
      done: city.hasBuilding("housing_shelter"),
      warning: city.turn > 8 && !city.hasBuilding("housing_shelter")
    },
    {
      id: "secure_food",
      done: city.food_stock > 0 && city.food_surplus >= 0,
      warning: city.food_stock <= 5
    },
    {
      id: "find_water",
      done: city.hasBuilding("water_well") || city.hasNaturalWater,
      warning: city.water_coverage < 1.0
    },
    {
      id: "build_housing",
      done: city.housing_capacity > 1,
      warning: city.free_housing <= 0
    },
    {
      id: "train_workers",
      done: city.workers >= 1,
      warning: city.free_population > 5 && city.workers === 0
    }
  ];
}
```

## 9.5. Ошибки и крайние случаи

| Случай | Поведение |
|---|---|
| Нет данных города | Показывать статичную версию без подсказок |
| Подсказка ведёт на заблокированную страницу | Показывать заглушку или ближайшую доступную страницу |
| Чек-лист не может быть рассчитан | Показывать только текстовые шаги |
| Игрок уже прошёл первые 50 ходов | Скрыть «Путь основателя» или показать его в свёрнутом виде |

```text

6. Корректно ссылается на основные разделы.
7. Все тексты вынесены в локализацию.
8. Нет дублирования контента.
9. Страница адаптируется под состояние города.

```
