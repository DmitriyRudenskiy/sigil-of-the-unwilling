# Skills System — PoE2: Deadfire

16 навыков в двух категориях. Уровень навыка = число, определяющее успешность задач и открывающее опции в диалогах.

## 🟢 Active Skills (7) — влияют на механики

| Навык | Что делает |
|-------|------------|
| **Alchemy** | Зелья: качество, доступные рецепты |
| **Arcana** | Свитки и магические предметы |
| **Athletics** | Физические действия: прыжки, перелезания, силовые проверки |
| **Explosives** | Бомбы: урон и эффективность |
| **Mechanics** | Ловушки и механизмы: обезвреживание, вскрытие |
| **Sleight of Hand** | Взлом замков, карманные кражи |
| **Stealth** | Скрытность: радиус обнаружения, sneak-подходы |

## 🔵 Passive Skills (9) — диалоги и interactions

| Навык | Что делает |
|-------|------------|
| **Bluff** | Ложь и обман |
| **Diplomacy** | Переговоры, мирные исходы |
| **History** | Знание истории Эоры |
| **Insight** | Чтение мотивов, «считать» собеседника |
| **Intimidate** | Угрозы и давление |
| **Metaphysics** | Души, адра, устройство мира |
| **Religion** | Боги и культы |
| **Streetwise** | Подворотни, контрабанда, городские связи |
| **Survival** | Дикая местность, следы, выживание |

> [!info] Active тоже работают в проверках
> Active-навыки участвуют в диалогах наравне с Passive, но дополнительно усиливают игровые механики.

## 🎲 Очки навыков

### При создании
| Источник | Single class | Multiclass |
|----------|--------------|------------|
| Класс | **2 очка × 5 навыков** | усреднение: (2+0)/2 = **1** |
| Предыстория | **1 очко × 3 навыка** (редко 2+1 или 2 в один) | **не усредняется** |

### При левелинге
Каждый уровень: **+1 очко в Active** и **+1 очко в Passive** — независимо от single/multiclass.

---

## 🤝 Assisted checks

Часть проверок — «с помощью партии»: значение навыка ГГ получает бонус от proficiency остальных компаньонов.
Другие проверки — строго личный навык выбранного персонажа.

## 💡 Рекомендации по ролям

| Роль | Навыки |
|------|--------|
| Танк/фронт | Athletics, Intimidate, Mechanics |
| Кастер | Arcana, Metaphysics, Religion, History |
| Скаут/рога | Stealth, Sleight of Hand, Mechanics, Explosives |
| Лицо партии | Diplomacy, Bluff, Insight, Streetwise |
| Следопыт | Survival, Athletics, Perception-зависимые проверки |

> [!tip] Совет
> Держи хотя бы 1–2 очка в **Mechanics** или бери компаньона-взломщика: замки и ловушки встречаются постоянно.
