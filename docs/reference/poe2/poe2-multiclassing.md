# Multiclassing Guide — PoE2: Deadfire

> [!warning] Главное правило
> Два класса выбираются **один раз при создании персонажа**.
> Изменить, добавить или убрать класс **нельзя никогда**.

## ⚙️ Как это работает

- Персонаж прокачивает оба класса **одновременно** одним уровнем
- Способности обоих деревьев доступны по мере роста **Power Level**
- Базовые значения (Health, защиты, навыки) — **среднее** двух классов

## 📊 Числа: single vs multi

| Параметр | Single class | Multiclass |
|----------|--------------|------------|
| Power Level | каждые **2** уровня | каждые **3** уровня |
| Тир способностей 8–9 | ✅ доступен | ❌ недоступен |
| Очки Power Source на 7 ур. | 6 | 5 + 5 = 10 |
| Health/защиты/навыки | полные | усреднённые (round down) |
| +3 к защитам за уровень | да | да (без изменений) |

### Пример усреднения: Barbarian + Wizard
| Параметр | Barb | Wiz | Multi |
|----------|------|-----|-------|
| Base Health | 46 | 38 | 42 |
| Health/ур | +16 | +8 | +12 |

### Навыки
(2 в классе A + 0 в классе B) / 2 = **1**.
Бонусы культуры/расы/фона добавляются **после** — не режутся.

---

## ⚖️ Плюсы и минусы

### ✅ Плюсы
- Широкое дерево способностей, интересные синергии
- Больше очков Power Source → больше способностей за бой
- Гибкость роли в бою
- Даже «неоптимальный» билд остаётся играбельным

### ❌ Минусы
- Медленный доступ к высоким тирам способностей
- **Потолок: тир 7** — топ-способности обоих классов мимо
- Усреднённое здоровье и навыки
- Сложнее в ранней игре, пока нет снаряжения

## 🧪 Проверенные комбинации

| Комбо | Идея |
|-------|------|
| Fighter + Wizard (Battlemage) | Мил + заклинания усиления |
| Rogue + Ranger | Скрытность + питомец/стрельба |
| Paladin + Priest | Ауры + лечение, «святой рыцарь» |
| Barbarian + Druid | Ярость + spiritshift, фронтовой зверь |
| Cipher + Chanter | Контроль + поддержка, комбо-кастер |
| Monk + Priest | Раны + лечение, самообеспеченный мили |

> [!tip] Принцип синергии
> Ищи пересечение по атрибутам (оба класса хотят один стат) и компенсацию слабостей (кастер + живучесть, мили + контроль).

---

## 🚦 Кому что брать

### Бери multiclass, если:
- Уже прошёл игру single class
- Хочешь уникальные билды и синергии
- Играешь на нормальной сложности

### Бери single class, если:
- Первое прохождение
- Высокая сложность (нужны топ-способности)
- Хочешь простую и сильную прогрессию

## ✅ Чек-лист перед подтверждением

- [ ] Оба класса хотят одни и те же 2–3 атрибута
- [ ] Понимаю, что теряю тиры 8–9
- [ ] Стартовые способности выбраны в **обоих** деревьях
- [ ] Роли классов не дублируются бессмысленно (два чистых мили без синергии)
