# Сравнение: PoE2 vs D&D 5e

Две системы cRPG/TTRPG с общей основой (классы, расы, атрибуты), но разной философией дизайна.

## 📊 Сводная таблица

| Параметр | PoE2: Deadfire | D&D 5e (2024) |
|----------|----------------|---------------|
| **Видов/рас** | 6 + 17 подрас | 10 базовых + 70+ расширенных |
| **Классов** | 11 | 12 (13 с подклассами-гибридами) |
| **Атрибутов** | 6: MIG/CON/DEX/PER/INT/RES | 6: STR/DEX/CON/INT/WIS/CHA |
| **Бонусы расы** | Фиксированы по виду | Свободные +2/+1 или +1/+1/+1 |
| **Мультикласс** | Выбрать 2 класса при создании; навсегда | Добавлять уровни разных классов при левел-апе |
| **Магия** | Power Source (восст. вне боя) + лимит тиров за встречу | Spell Slots (восст. на long/short rest) |
| **Макс. уровень** | 20 | 20 |
| **Подклассы** | Выбираются сразу (кроме Fighter/Monk) | Выбираются на 3 уровне |
| **Изменение атрибутов** | ❌ Невозможно после создания | ⚠️ ASI на 4/8/12/16/19 уровнях |
| **Навыки** | 16 (7 Active + 9 Passive) | 18 skills + tool proficiencies |
| **Философия** | Сбалансированность, «любой билд играбельный» | Гибкость, но много «ловушек» для новичков |

---

## 🎯 Ключевые механические различия

### 1. Мультиклассирование

| Аспект | PoE2 | D&D 5e |
|--------|------|--------|
| Когда выбирается | При создании (один раз) | В любой момент при левел-апе |
| Прогрессия способностей | Общая (Power Level каждые 3 ур.) | Независимая у каждого класса |
| Потолок | Тир 7 | Полный доступ ко всем тирам |
| Гибкость | Нулевая после старта | Высокая, можно менять стратегию |

> [!tip] Философия
> **PoE2:** «Реши раз и играй без страха сломать билд».
> **D&D:** «Экспериментируй, но читай гайды — легко сделать слабого персонажа».

### 2. Атрибуты

| Аспект | PoE2 | D&D 5e |
|--------|------|--------|
| Изменение | Заморожены навсегда | ASI 5 раз за карьеру |
| Роль в бою | % урона/скорости/защит | Модификатор к d20 |
| Важнейший стат | Perception (Accuracy) | Разные для каждого класса |
| Границы при создании | 3…18 | 8…15 (point buy) |

### 3. Магия

| Аспект | PoE2 | D&D 5e |
|--------|------|--------|
| Ресурс | Power Source Points (един для класса) | Spell Slots (разные уровни) |
| Восстановление | Вне боя (авто) | Long Rest (8ч) или Short Rest (1ч) |
| Empower | Усилить 1 способность за бой | Нет аналога |
| Свитки/предметы | Arcana skill | Spell Scroll — proficiency |

### 4. Навыки vs Skills

| Аспект | PoE2 | D&D 5e |
|--------|------|--------|
| Количество | 16 | 18 |
| Деление | Active/Passive | Все одинаково-пассивные |
| Прокачка | 1 Active + 1 Passive за уровень | Выбор skill при создании + Background |
| В бою | Active влияют (Alchemy, Explosives) | Навыки почти только вне боя |

## 🧭 Когда какую систему брать

### Выбирай PoE2, если:

- ✅ Хочешь **cRPG с тактическими боями в реальном времени с паузой**
- ✅ Любишь **богатый лор Эоры**
- ✅ Ценишь **сбалансированность** — «плохих» билдов почти нет
- ✅ Предпочитаешь **фиксированные выборы** (не любишь переделывать)
- ✅ Нужна **уникальная магия** (Cipher, Chanter, Monk Wounds — нигде больше нет)
- ✅ Играешь **в одиночку** за компьютером

### Выбирай D&D 5e, если:

- ✅ Хочешь **настольную RPG с друзьями** за столом
- ✅ Любишь **огромный выбор** рас и подклассов
- ✅ Ценишь **гибкость билдов** и эксперименты
- ✅ Нужна **совместимость** с десятками модулей (Forgotten Realms, Eberron, Ravenloft…)
- ✅ Хочешь **сообщество** (стримы, подкасты, форумы)
- ✅ Играешь в **кооперативе** — партии, DM

## 💡 Что можно портировать из D&D 5e в наш Godot-проект

| Механика | Применимость |
|----------|--------------|
| **Inspiration** (advantage на d20) | ✅ Отлично ложится как «heroic resource» |
| **Proficiency Bonus** (растущий) | ✅ Вместо PoE2-шного Accuracy — проще масштабировать |
| **Background = +2/+1 атр. + skill + tool** | ✅ Уже почти есть в PoE2 (background даёт skills) |
| **Feats вместо ASI** | ⚠️ Опционально; PoE2-шная система способностей уже шире |
| **Spell Slots с short rest** | ❌ Конфликтует с PoE2 Power Source; лучше оставить как есть |
| **Concentration** (удержание 1 баффа) | ✅ Хорошо для баланса магов |
