# Character Creation Flow — PoE2: Deadfire

> [!info] О документе
> Пошаговый порядок экрана создания персонажа *Pillars of Eternity II: Deadfire*.
> Детальные страницы: [[poe2-races]], [[poe2-classes]], [[poe2-attributes]], [[poe2-skills]], [[poe2-multiclassing]].

---

## Шаг 0 — Импорт или новый персонаж

При входе в создание игра предлагает:
1. **Импортировать персонажа** из сейва (PoE1 или раннего сейва Deadfire)
2. **Создать нового**

> [!tip]
> При импорте сохраняются раса/класс/атрибуты; внешность и имя можно поменять.

---

## Шаг 1 — Пол

- Варианты: **Male / Female**
- Влияет на: внешность, портреты, голос, часть реплик в диалогах
- **НЕ влияет на**: атрибуты, навыки, боевые возможности

> [!info] Лор
> В разных нациях Эоры роли полов различаются, но исключения есть везде. Статистически пол не даёт ничего.

---

## Шаг 2 — Раса и подраса

### 2.1 Раса (6 вариантов)

| Раса | Бонусы атрибутов |
|------|------------------|
| Human | +1 MIG, +1 RES |
| Elf | +1 DEX, +1 PER |
| Dwarf | +2 MIG, +1 CON, −1 DEX |
| Aumaua | +2 MIG |
| Orlan | +2 PER, +1 RES, −1 MIG |
| Godlike | +1 DEX, +1 INT |

### 2.2 Подраса (17 вариантов)

- **Не влияет** на атрибуты
- Даёт **пассивную способность**
- Слегка влияет на реакцию NPC
- Люди: все подрасы делят одну способность — *Fighting Spirit*
- Godlike дополнительно выбирают тип тела (чистая косметика)

> [!warning] Ограничение Godlike
> Godlike **не могут носить шлемы и головные уборы** — не подходит ни один.

Детали: [[poe2-races]]

## Шаг 3 — Класс, подкласс, мультикласс

### 3.1 Single class или multiclass

- **Single class** — один класс, полная прогрессия (Power Level каждые 2 уровня)
- **Multiclass** — два класса сразу; Power Level каждые 3 уровня; **нет доступа** к способностям 8–9 уровней

> [!warning] Необратимое решение
> Мультикласс выбирается **один раз при создании** и не меняется никогда.
> Новичкам не рекомендуется. Детали: [[poe2-multiclassing]]

### 3.2 Классы (11)

Barbarian • Chanter • Cipher • Druid • Fighter • Monk • Paladin • Priest • Ranger • Rogue • Wizard

### 3.3 Подкласс

У каждого класса свой список подклассов (ордена паладина, божества жреца, школы волшебника…).

### 3.4 Стартовые способности при создании

| Класс | Что выбираешь |
|-------|---------------|
| Barbarian | 1 ability |
| Chanter | 1 invocation + 1 фраза чанта |
| Cipher | 1 power |
| Druid | 1 spell + форма spiritshift |
| Fighter | 1 ability |
| Monk | 1 ability |
| Paladin | 1 ability |
| Priest | 1 spell |
| Ranger | 1 ability + animal companion |
| Rogue | 1 ability |
| Wizard | 1 spell |

Детали: [[poe2-classes]]

## Шаг 4 — Атрибуты (point-buy)

### Правила

- Все атрибуты стартуют с **10** (расовые бонусы УЖЕ видны в числах)
- Игрок распределяет **15 очков** по курсу 1:1
- Границы: **3…18** (до расовых/культурных бонусов)
- Итоговая сумма: **78 очков**

> [!warning] Необратимо
> Атрибуты **нельзя изменить после создания**. В игре — только временные бафы (предметы, еда, заклинания).

### Шесть атрибутов

| Атрибут | Боевой эффект (за очко от 10) |
|---------|-------------------------------|
| Might (MIG) | ±3% урон и лечение, ±2 Fortitude |
| Constitution (CON) | ±5% Endurance/Health, ±2 Fortitude |
| Dexterity (DEX) | ±3% скорость атаки, ±2 Reflex |
| Perception (PER) | ±1 Accuracy, ±2 Reflex |
| Intellect (INT) | ±10% AoE, ±5% длительность, ±2 Will |
| Resolve (RES) | −3% длительность вражеских эффектов, ±1 Deflection, ±2 Will |

> [!tip] Мета
> **Perception** — важнейший стат для любого билда (Accuracy = шанс попадания/крита).
> Типичные dump stats: Resolve, Constitution.

### Подсказки в креаторе

- ⭐ золотая звезда — атрибут настоятельно рекомендован классу
- серебряная звезда — рекомендован

Детали: [[poe2-attributes]]

## Шаг 5 — Культура и предыстория

### 5.1 Культура

Даёт **+1 к атрибуту**, стартовое снаряжение и список доступных предысторий.

| Культура | Бонус |
|----------|-------|
| Aedyr | +1 RES |
| Deadfire Archipelago | +1 DEX |
| Ixamitl Plains | +1 RES |
| Old Vailia | +1 INT |
| Rauatai | +1 CON |
| The Living Lands | +1 MIG |
| The White that Wends | +1 PER |
| The Dyrwood | +1 RES |
| Naasitaq | +1 PER |
| Eir Glanfath | +1 CON |

### 5.2 Предыстория (Background)

- Даёт очки навыков (обычно по 1 в три навыка)
- Часть предысторий доступна только определённым культурам

> [!info] Мультикласс не режет
> Бонусы культуры и предыстории **не усредняются** при мультиклассе — применяются полностью.

---

## Шаг 6 — Владение оружием

- Выбираешь стартовое владение оружием и/или щитом
- Открывает **модальные способности** (Overdraw, Binding Block и т.д.)
- **Нет штрафа** за оружие без владения — просто недоступны модальные способности

> [!warning] Двуручник + щит
> Взял двуручное оружие и щит? В стартовом тайнике не будет одноручника под щит (найдётся вскоре в игре).

---

## Шаг 7 — Внешность, голос, поза

- **Портрет**: 103 стандартных (не ограничены расой/полом) + кастомные (импорт готовится заранее)
- **Цвета**: одежда (primary/secondary), кожа, волосы, глаза
- **Голова**: причёска, стиль лица, растительность (только мужские)
- **Голос**: 8 сетов (только соответствующие полу) или без голоса
- **Поза**: 8 вариантов осанки/энергетики

---

## Шаг 8 — Имя

- Любое имя
- Лорные имена — по справочнику Personal Names

---

## После создания — стартовое снаряжение

- Оружие под выбранные владения находится сразу после создания
- Состав стартового набора зависит от культуры

---

## ✅ Чек-лист перед подтверждением

- [ ] Раса/подраса подобраны под билд
- [ ] Класс/мультикласс — финальное решение (не меняется!)
- [ ] Все 15 очков атрибутов потрачены (иначе игра спросит подтверждение)
- [ ] PER не сброшен без причины
- [ ] Культура и предыстория дополняют навыки класса
- [ ] Владение оружием совпадает с планируемым оружием
