# Attributes System — PoE2: Deadfire

Атрибуты — **врождённые** качества персонажа (в отличие от навыков — **выученных**).
Определяются при создании и **не меняются навсегда**.

## 📏 Шкала значений

| Диапазон | Значение |
|----------|----------|
| < 10 | Низкий (вплоть до crippling-штрафов) |
| 10 | Средний (базлайн, без бонусов) |
| 11–15 | Высокий |
| 16+ | Исключительный — многие проверки в диалогах требуют 16+ |

---

## ⚡ Шесть атрибутов и боевые эффекты

За каждое очко **выше/ниже 10**:

| Атрибут | Боевой эффект | Диалоги |
|---------|---------------|---------|
| **Might (MIG)** | ±3% урон и лечение, ±2 Fortitude | Запугивание, грубая сила |
| **Constitution (CON)** | ±5% Endurance и Health, ±2 Fortitude | Терпеть боль, выносить нагрузки |
| **Dexterity (DEX)** | ±3% скорость атаки, ±2 Reflex | Ловкость рук, быстрые реакции |
| **Perception (PER)** | ±1 Accuracy, ±2 Reflex | Заметить ложь, детали, фон |
| **Intellect (INT)** | ±10% радиус AoE, ±5% длительность, ±2 Will | Дедукция, озарения, решение задач |
| **Resolve (RES)** | ∓3% длительность вражеских эффектов, ±1 Deflection, ±2 Will | Ментальное давление, лидерство, убеждение |

> [!tip] Мета
> **Perception** — важнейший стат для всех: Accuracy = шанс Graze/Hit/Crit.
> Типичные dump stats: Resolve, Constitution, иногда Dexterity.

## 💰 Point-Buy

### Правила
- Старт: **10** в каждом атрибуте (расовые бонусы УЖЕ в числах)
- Распределить: **15 очков** (1:1)
- Границы: **3…18** (до расовых/культурных модификаторов)

### Бухгалтерия очков
| Источник | Очки |
|----------|------|
| База 6×10 | 60 |
| Распределение игрока | +15 |
| Расовый бонус (нетто) | +2 |
| Культурный бонус | +1 |
| **Итого** | **78** |

### Пример границ
Aumaua из культуры The Living Lands: Might от **6** до **21** (18 + 2 раса + 1 культура).

> [!warning] Необратимо
> После создания атрибуты не растут. Только временные бафы: предметы, еда, заклинания, отдых.

### Стакинг бафов (PoE2)
- **Пассивные** источники (экипировка, пассивки) — **стакаются**
- **Активные** (еда, consumables, модалки, способности) — **не стакаются**: последний применённый заменяет предыдущий
- Временными бафами можно превысить 30

## 🗣 Атрибуты в диалогах

- Открывают дополнительные реплики и исходы квестов (избежать боя, репутация)
- Часто требуют **15–16+**
- Проверяются атрибуты **только главного героя** (в диалогах); в scripted interactions можно выбрать члена партии

## 🎯 Приоритеты по классам (community practice)

| Класс | Приоритет |
|-------|-----------|
| Barbarian | MIG → CON → DEX |
| Chanter | INT → PER → RES |
| Cipher | INT → PER → DEX |
| Druid | INT → PER → CON |
| Fighter | MIG → CON → PER |
| Monk | MIG → DEX → PER |
| Paladin | MIG → RES → CON |
| Priest | INT → RES → PER |
| Ranger | PER → DEX → MIG |
| Rogue | DEX → PER → MIG |
| Wizard | INT → PER → DEX |

> [!info] Во всех строках подразумевается: PER не дампишь — он важен всегда.
