# 12. Военная система (канон-детали)

## 12.1. Сеть и роли узлов [КАНОН]

Военная мощь — не отдельное здание, а сеть:

| Роль | Здание | Что делает |
|---|---|---|
| Рекруты | Казарма | создаёт основу армии |
| Обучение | Плац | повышает качество/скорость |
| Снаряжение | Кузница | оружие/снаряжение |
| Снабжение | Склад | продовольствие/логистика |
| Командование | Командный шатёр | лимит и координация |
| Разведка | Башня | раннее предупреждение |
| Оборона | Палисад, башни | защита путей |

Формула:
```
army_strength =
    (recruit_nodes + training_nodes + equipment_nodes + supply_nodes + command_nodes)
  × connectivity_score
  × morale_score
  × district_bonus
  × event_modifier
```

## 12.2. Производство [КАНОН]

Производство юнитов — **мягкая деградация**, а не жёсткий стоп: при нехватке роли скорость падает, а не обнуляется.

```
production_speed =
    base_speed
  × min(1, node_factor)
  × min(1, supply_factor)
  × min(1, road_factor)
  × morale_factor
  × district_factor
```

node_factor, supply_factor, road_factor — доля выполненных требований (0–1); при 0 — 25% базовой скорости.

## 12.4. Юниты будущего [КАНОН]

Конница (плац + конюшня + дорога + командование), осадные (кузница + склад + казарма + мощёная дорога), элитные расовые (орочий берсерк, эльфийский стрелок, человек-капитан).

## 12.5. Армия, лимит, снабжение [КАНОН]

Лимит армии = базовый 10 + командование×3 + районы×2 (MVP). Снабжение: каждый юнит потребляет 1 еду/день; армия >50% лимита — +5% настроение (02g); <25% — −5% настроение (02g).

# 13. Бой и угрозы (канон-детали)

## 13.2. Функция давления (K-T5, 2026-10-02) [КАНОН]

Цели рейдов: еда, железо, оружие, население, здания, дороги, районы. Последствия:
- еда −20–40%; железо/оружие −10–30%; разрушение зданий; дороги −50% на 3 дня; потери рабочих; настроение (02g) −10–20%.

Противодействие: палисады, башни, гарнизоны, разведка, ремонт, запасы.

> **Аннулировано (K-T5/K-R3, 2026-10-02):** фиксированный календарь рейдов (дни 7/10/14/17/21) — архив в git-истории. Календаря рейдов нет: рейд = пересечение порога накопителя давления.

```
pressure(city, t) = Base(city) × Wealth(city) × Anomalies(city) × Region_History(city) × Global_Phase(t)
```

> **Размещение лагерей (D-130, 2026-10-03):** лагеря-источники — **динамические** сущности функции давления, не статические данные карты (статическое размещение воссоздало бы календарную проблему — аннулировано K-T5). Порождение: при пересечении порога тира аккумулятором города-цели. Размещение — детерминированный выбор: сухие узлы в радиусе `k_p = 2` (взвешенные рёбра графа соседства), свободные от города/данжа/аномалии/лагеря; при равенстве расстояний — лексикографический порядок ID (I1-совместимо). Тир лагеря = тир волны. Уничтожение — мини-данж (§4 GDD). После уничтожения — cooldown региона («лагеря помнят», K-T5). Валидация — контракт системы давления: «каждая волна имеет source_camp; лагерь уничтожим; после — cooldown» (не валидация карты). Босс E4 «Разлом» — статический спецконтент, не лагерь; в MVP лагеря только динамические.

| Фактор | Смысл | Источник |
|---|---|---|
| Base(city) | базовое давление региона | config региона |
| Wealth(city) | видимое богатство (запасы) | 06-economy (запасы) |
| Anomalies(city) | активные аномалии/события | 02f-a-core |
| Region_History(city) | история рейдов региона (после рейда — кулдаун, затем рост) | накопитель города |
| Global_Phase(t) | фаза кампании (config, не календарь) | config кампании |

- **Аккумулятор:** каждый ход pressure начисляется в накопитель города; пересечение порога тира (1–3) → генерация волны.
- **Волна:** генерируется с лагеря-источника (регион); состав и сила по тиру (1–3: лёгкий/средний/крупный, power 15/30/60 — R6, balance config); движется к городу (прибытие через N ходов); **без кубиков** (детерминизм, сид = config кампании).
- **Кулдаун:** после рейда накопитель сбрасывается в 0.
- **Директивы темпа (K-R3, не календарь):** floor — первый рейд ≈ ход 7 (tutorial-тир, гарантирован); ceiling — рейдов нет в первые N ходов; window — финальный тир гарантирован к ходу 21 (MVP-кампания); composition — цель = слабейший запас.
- **Оборона:** гарнизон (статус Fighter, K-A5) + барраки (defense 0.2, R6); `loss = power × (1 − defense)`.
- **SM рейда:** IDLE → CHARGING → INBOUND → STRIKE → RESOLVED → COOLDOWN → IDLE (02-mechanics §3.8).
- **MVP:** 1 город → один накопитель. Несколько городов (1.0) — независимый накопитель на город, волны распределяются по графу.

(Разрешение рейдов — [[02-mechanics#3.8 Давление среды и рейды (AtS, V5) — НОВОЕ|02 §3.8]].)
