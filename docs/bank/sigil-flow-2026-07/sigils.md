# Знаки (Sigils) — ядро механики

Ядро системы Знаков: ресурсная модель Носителя, идентичность по классу, каст «только свой цвет»,
Резонанс. Термины — в `CONTEXT.md`. Реализация — в `HeroMagic`, `SchoolType`, `BattleSpellBridge`.
Числа — стартовые, под баланс (как в `doc/races-economy.md`).

## 1. Scope

**В ядре:** 5 пулов Знака у Носителя; математика регенерации; основной Знак по классу;
каст «только свой цвет»; Резонанс (−1 касту своего цвета); миграция старых сейвов.
Слои: **только микробои** (заклинания героя). Городская экономика НЕ трогается.

**Отложено (Phase 2):** престиж/ранги Знаков; резонанс/диссонанс сверх −1; дипломатия и
постройки по Знакам; расширение до 8 Знаков; рост уровня школы; пассивки на каждый цвет
(вариант B); полный 5-индикаторный UI.

## 2. Пять Знаков

Ровно 5 базовых Знаков = 5 базовых цветов `SpellColor`:

| Знак | SpellColor | Стихии-источники (мост) | Статус в ядре |
|---|---|---|---|
| Искра | `FIRE` | Fire | активен |
| Время | `TIME` | Air | активен |
| Равновесие | `JUSTICE` | — | спит (нет заклинаний) |
| Первозданность | `PRIMAL` | Water, Earth | активен |
| Тень | `SHADOW` | — | спит (нет заклинаний) |

`COLORLESS` и `MULTIFACTION` — служебные (не-базовые), пулов не имеют.
`JUSTICE`/`SHADOW` — «спящие» пулы: существуют, регенерируют, но в ядре нет заклинаний
этих цветов (контент — Phase 2). Никакой класс не маппится в JUSTICE/SHADOW, поэтому
«пустой основной» не возникает.

## 3. Пулы

У Носителя 5 пулов (по одному на базовый цвет). Константы в `GameNumbersHero`:

- `SIGIL_POOL_BASE = 10` — max обычного пула.
- `SIGIL_POOL_PRIMARY_BONUS = 6` — основной пул = 10 + 6 = **16**.
- `SIGIL_REGEN_BASE = 1` — реген обычного пула за ход.
- Реген основного пула = `SIGIL_REGEN_BASE + knowledge` (1 + знание).
- `SIGIL_RESONANCE_DISCOUNT = 1` — скидка Резонанса.
- **Старт боя: все пулы полные** (основной 16, остальные 10).

## 4. Основной Знак

Определяется **классом** через мост Школа→Цвет (`_CLASS_STARTER_SPELLS` + `SchoolType.to_color`):

| Класс | Школа | Основной Знак |
|---|---|---|
| wizard | Fire | Искра (FIRE) |
| druid | Earth | Первозданность (PRIMAL) |
| priest | Water | Первозданность (PRIMAL) |
| chanter | Water | Первозданность (PRIMAL) |
| ranger | Air | Время (TIME) |
| barbarian, fighter, monk, paladin, rogue, cipher | — | **нейтральный** (5 равных пулов по 10, реген 1, без Резонанса) |

Нейтральный Носитель: `primary_sigil = -1` (нет основного). Пулы есть (готовы к Phase 2),
но каст ограничен отсутствием уровней школ.

## 5. Мост Школа→Цвет (Single Source of Truth)

`SchoolType.to_color(school_id: int) -> SpellColor` — **единственное** место маппинга:

- `AIR → TIME`
- `FIRE → FIRE`
- `WATER → PRIMAL`
- `EARTH → PRIMAL`
- иначе → `COLORLESS`

`BattleSpellBridge.to_spell` (цвет для отображения) и `HeroMagic` (цвет для каста)
используют только его. Локальный `SCHOOL_TO_COLOR` в бридже и дублирующий enum
`SpellRegistry.School` удаляются (объединяются в `SchoolType`).

## 6. Каст

Цвет заклинания: `C = SchoolType.to_color(spell.school_int)`. Каст возможен, если:

1. **Ворота школы:** `school_level(spell.school_int) >= spell.level`.
2. **Топливо (строго свой цвет):** `sigils[C] >= cost`.

**Стоимость** (порядок важен):
```
cost = spell.base_mana
if "anti_magic" in spell.tags: cost += 2          # старое правило, сохраняется
if C == primary_sigil:       cost = max(1, cost - SIGIL_RESONANCE_DISCOUNT)   # Резонанс
```
Потрачено: `sigils[C] -= cost`. При провале каста после траты — возврат той же суммы.

## 7. Регенерация

Каждый ход боя (`end_turn`):
- обычный пул: `+SIGIL_REGEN_BASE` (1), до своего max.
- основной пул: `+(SIGIL_REGEN_BASE + knowledge)`, до max 16.

## 8. Миграция сейвов

`HeroMagic.serialize()` хранит `sigils: Dictionary` (5 ключей-цветов) + `primary_sigil`
вместо `mana_current`/`mana_max`. `deserialize()`:

- в данных **нет** ключа `sigils` (старый сейв) → инициализировать все 5 пулов полными
  (основной 16, остальные 10); старое `mana_current`/`mana_max` **игнорируется**.
- при первом сохранении старого сейва ключи `mana_current`/`mana_max` **удаляются**.

## 9. Временный UI

Пока 5 индикаторов не готовы: один индикатор = **основной пул** (число, как «мана»).
Остальные 4 — скрыты / в меню. Код exposes `get_sigil(color)`, `get_total_sigil()`,
`get_primary_sigil()` для полного UI в Phase 2.

## 10. Отложено (Phase 2)

- Рост уровня школы (прогрессия магии).
- Пассивки на каждый цвет (вариант B: FIRE→+sp, TIME→+spd, PRIMAL→+heal, ...).
- Полный 5-индикаторный UI.
