## 2. Vertical slice (один проход, старт → финиш)

```
NEW GAME → [1. ПРЕДЫГРА] (класс → раса (9) → внешность → знак (1/8) → 1 город → партия ≤5) → сейв v1
→ [2. МЕНЮ] → [3. КАРТА] ход 1 (бит «Знак») + ТУТОРИАЛ-ОВЕРЛЕЙ (д.1 ферма+барраки, д.2 ополченец, д.3 руины)
ЦИКЛ ХОДА N (1..21):
  SETTLEMENT (авто): производство, население R3, upkeep районов, SM дефицита, тики ×4
  PLAYER: [КАРТА] движение (биом+ЛОВ−вес) / узлы one-time / отступление (1 день)
          [4. ГОРОД] 02g hex: постройка (5→7+ к ходу 14), районы (7 групп → Престиж +500), наём
          [6. ПАРТИЯ] ростер ≤5, уровни 1–5, экипировка (вес)
  THREATS (авто): функция давления → рейд? герой в городе → [5. БОЙ] (CR 1/2/6) | в походе → авто-рейд (R5)
  → [7. ХРОНИКА] (1 строка, ≤5/день) → ход N+1
БИТЫ (K-M9): 1 знак · 3 слух (Post-MVP-строка) · 7 рейд (floor) · 14 район · 17 сильный рейд · 21 финал
ХОД 21: босс CR 6–8 (герой в городе) ИЛИ авто-рейд → ПОБЕДА (запас > 0) / ПОРАЖЕНИЕ (wipe ИЛИ запасы ≤ 0) → [2. МЕНЮ]
[5. БОЙ]: SETUP → ROUND → VICTORY / DEFEAT / RETREAT (лимит боя: 20 раундов → ничья, Q-M20; не состояние SM)
```
