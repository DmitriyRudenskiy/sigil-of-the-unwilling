# Кадр и разбор T-315 — пластина отключённой команды в командном ряду

**Экран/канал:** `game/scenes/battle.tscn`, живой Godot через godot-mcp
(`run_project` + фикстура кода состояния), канонный кадр 1920×1080. Фикстура —
`game/tools/capture/battle_hud_full.gd` (тот же носитель, что у T-241/T-310),
своя `Xvfb` 1920×1080, `MCP_PORT=9095`.

**Что проверялось.** Не состав ряда (он собран 4+4 и принят D-293/D-294), а
критерий закрытия T-315: **кадр ряда не содержит медальона, светлее соседних
×1.5** (кроме активного hover). Курсор того же стиля в проверку не входил — он
арт-предмет (см. диспозицию).

**Сверка с макетом.** Макет-источника нет: `design/single_window_layout/all_screens_ui.png`
в репозитории и на машине отсутствует (**T-312**), поэтому вердикт вынесен по
правилу D-293 («медальоны читаются своими пластинами») и по числовому критерию
самого билета, а не «как на макете».

## Геометрия (замер `game_eval`'ом по живому ряду)

Все восемь медальонов — 100×100 при y = 943, трансформация единичная (канвас-пиксель
равен пикселю снимка), то есть прямоугольник замера = прямоугольник пластины:

| Медальон | x | y | w×h |
| --- | --- | --- | --- |
| attack / defend / retreat / auto | 20 / 140 / 260 / 380 | 943 | 100×100 |
| spellbook / cancel / wait / skip | 1430 / 1550 / 1670 / 1790 | 943 | 100×100 |

Проверяемая пластина — `retreat_btn`: в этом состоянии `disabled = true`, до правки
`self_modulate = (1, 1, 1, 1)`, после — `(0.45, 0.42, 0.38, 2.9)`
(`ThemeConfig.C_BATTLE_MEDALLION_DIM`).

## Разбор кадра A/B

`row_ab.png` (оба ряда ×2, подписаны «до»/«после»), тот же раскрой, что у
`row_before_2x.png` / `row_after_2x.png`:

- **до:** третья пластина — полупрозрачный призрак, снежное поле читается сквозь
  знак, это самый яркий элемент ряда; силуэт «бегущего» различим, но сливается с
  фоном и не отличается от включённых соседей ни яркостью, ни формой;
- **после:** тёмная непрозрачная пластина, знак читается, пластина чуть темнее
  включённых соседей — состояние «недоступно» видно без наведения мыши;
- ряд целиком (8 пластин, подписи хоткеев) расхождений по составу и местам не даёт.

## Расхождения и диспозиция

| Расхождение | Диспозиция |
| --- | --- |
| Заглушённая «Отступить» светлее ряда в 4.38 раза | **устранено** кодом (`_set_medallion_enabled`), кадр после — 0.84× |
| Диагностика билета «сырой альфа-канал пикса, нужна правка уровня темы» | **устранена**: у `Button` нет `icon_disabled_modulate` (замер → `(0,0,0,1)`, ключи принадлежат `TextureButton`), гасит иконку движок; в билете исправлено |
| Прежний замер билкадром по `bottom_bar` давал «α 1.0 и α 2.9 сошлись» | **устранено**: замер по прямоугольникам пластин (`scripts/measure_medallion_row.py`) |
| Курсор того же стиля, что медальоны (D-293) | **отложено**: арт-прогон, в листе 7.4 девятой ячейкой лёг знак «Отмены»; билет из-за этого не закрыт |
| Медальон книги заклинаний не гаснет вместе с рядом, выбор заклинания молча отклоняется | **заведено отдельно: T-319** (нужна директива а/б) |

## Критерии билета

| AC | Вердикт |
| --- | --- |
| Кадр ряда не содержит медальона, светлее соседних ×1.5 (кроме hover) | **PASS** (0.84×, кадр после) |
| Тест зоны D держит пластину у всех восьми | **PASS** (`test_zone_d_disabled_medallion_paints_dim`, 6/6 в файле; батарея `game/tools/mut_battle_medallion_dim.sh` — 5/5 мутантов красные) |
| Курсор есть в том же стиле | **FAIL** (арт-прогон, D-293; кодом не закрывается) |

**Вывод.** Предмет «полупрозрачная пластина неактивной команды» закрыт кодом,
кадром и тестом; билет T-315 остаётся открытым до арт-прогона курсора.
