# UX-review экрана героя: кадр, адресная сетка, COVERAGE по карте элементов

Смена: `openspec/changes/hero-screen-full-copy`, задачи **5.1**, **5.2**, **5.5**
и проверка группы 5. Дата: 2026-11-02. Разбор — `.pi/skills/ui-grid-review`.

## Кадр

`game/tmp/shots/hero-copy-1080.png`, 1920×1080, канал разработки
(`godot --path game -s tools/shot_scene.gd -- --scene=res://scenes/ui/artifact_inventory_screen.tscn`).
Замер тёмных полей по краям: **L0 R0 T0 B0**, содержимое занимает все
1920×1080 — предупреждение про клампинг окна (~1836×1025) на этом канале
здесь не сработало, кадр канонического размера. Сетка-разметка —
`scripts/ui_grid.py` 10×10.

Кадр снят **без игрового состояния**: сцена поднимается напрямую, поэтому
значения (имя, мана, содержимое сумки, карточки отряда) пустые. Это граница
кадра, а не дефект: заполненные состояния уже сняты и разобраны отдельными
фикстурами в тикетных ревью — `ux-hero-grid-t255.md`, `ux-hero-bands-t257.md`,
`ux-hero-doll-t258.md`, `ux-hero-unit-cards-t306.md`, `ux-artifact-tip-t256.md`.
Здесь объект проверки другой — **геометрия и состав блоков по карте элементов**.

| адрес | что | вердикт |
| --- | --- | --- |
| A1..C4 | портрет в латунной раме | на месте, арт не заглушка (T-249 закрыт) |
| A5 | плашка имени | есть; без состояния — подстановка «Герой» (скрыто по значению) |
| A6..C7 | «Амуниция»: четыре характеристики парами 2×2 с иконками | состав совпал с картой; значения — из носителя, в пустом состоянии не заполнены |
| A8..C10 | список надетого | **узлы есть** (`EquipRow_%d`, писатель `artifact_inventory_screen.gd:428`), в пустом состоянии список пуст — «скрыт по значению», не «нет носителя» (T-254 закрыт) |
| D1..D3 | мана + «Книжечка» | блок из зоны переноса (вне макета), лежит в своей зоне, на блоки макета не лезет |
| E1..G6 | бумажная кукла: фигура + 16 рамок слотов | рамки на адресах карты; фигура занимает блок (T-258 закрыт); при поднятой руке силуэт переходит верхнюю границу окна — см. расхождение 2 |
| D6..J10 | сетка сумки 10×5 = 50 | ровно 10 колонок и 5 рядов, шаг общий (T-255 закрыт), подписи «10 колонок / 5 рядов» на месте |
| H1..H4 + I2 | «Навыки» и четыре слота | на адресах карты |
| I4..J10 | колонка карточек отряда | четыре карточки; значения Lv/HP/MP **сняты с приёмника** по Q-M121 (уровень и опыт живут на экране «Отряд», T-306 закрыт); прокрутки при >4 участниках нет — **T-317** (выбор за владельцем) |
| J1 | плитка «×» (закрыть) | есть; плитки «?» в правом нижнем углу нет — **T-252** (журнал квестов, носителя нет) |

Расхождения:

1. **Пиксельного макета нет на машине.** `reference/12_inventory_parchment_sheet.jpeg`
   в git не входит (D-185), на машине агента 2026-11-02 отсутствует — проверено
   обращением к файлу. Значит `scripts/ui_diff.py` «кадр против макета» сегодня
   вынести нечем, а сверка идёт по **карте элементов** (`docs/20-ux-hero-screen.md`)
   и по CSV-инвентарю носителей. Факт записан в строку 12 `reference/INDEX.md`,
   чтобы следующая сессия не искала отсутствующий файл. Это же объясняет, почему
   T-253 (тон носителей) и T-260 (бейдж стака) остаются открытыми: их мерило —
   пиксель макета.
2. **E1/G1 — силуэт фигуры переходит верхнюю границу окна** при поднятой руке
   (кадр без состояния, фигура в позе с поднятым мечом). Рамка куклы — на своём
   адресе, выходит за окно именно рисунок. Диспозиция: **принято как есть**
   (фигура рисуется поверх и обрезается окном, это визуальная норма кадра) —
   при признаках, что обрезано что-то читаемое (лицо, подпись), будет тикет.

## COVERAGE

Носитель меры — `game/scenes/ui/artifact_inventory_screen.carriers.csv`:

```
# COVERAGE artifact_inventory_screen: covered 13 / outside-mockup 7 / missing 1
# Инвариант: covered + missing == 14
```

Единственная строка-тип макета без носителя — `# TYPE 04 строка уровня = missing`:
уровня героя нет ни в одной модели (T-306 закрыт со снятием значений с приёмника
и оговоркой **Q-M121**). Покрытие кадра не ниже вердикта пункта 5.4: прежний
вердикт считался по кадру, где сетка жила своим шагом, теперь шаг общий
(T-255), врезка и фигура на месте (T-258), полосы выровнены (T-257).

Сверка таблицы геометрии со сценой и картой: `python3 scripts/check_hero_layout_map.py`
→ `HERO-LAYOUT-MAP: блоков 19, адресных строк карты 18, расхождений нет` (уровень
в `doc_gates.sh`).

## Границы вердикта

- Буквальная сверка с пикселями макета невозможна: носителя нет (расхождение 1).
- Значения элементов в этом кадре не проверяются — для них есть тикетные
  фикстуры (список выше).
- Открытые половины задач остаются тикетами: **T-242** (16 рамок куклы против
  12 слотов `Artifact.Slot`), **T-252** (плитка «?»), **T-253** (тон носителей),
  **T-260** (бейдж стака), **T-317** (прокрутка карточек отряда), **Q-M121**
  (строка уровня). Смена закрывается, хвосты живут в `docs/mvp/TICKETS.md`.
