## 3.4 Актёрная модель боевого слоя (состав, акт 12-й итерации)

**Единица актёра — единичный комбатант.** Стэков (численности) нет — A5-канон:
армия состоит из конкретных существ, каждое из которых может погибнуть.
Легаси-стэки city-арены (get_count, kills) — не канон (D-157: срез, архив).

**character_uid — мост «житель ↔ юнит».** Юнит-рекрут при создании получает
`character_uid` конкретного жителя (житель → рекрут; вакансия в производстве —
учёт T-116). Канон «погибший юнит = погибший поселенец» замкнут на уровне
боевого отчёта (milestone, вердикт владельца 14-й итерации §0): `battle_report`
обязателен к `{losses: [character_uid]}` и эмитится в хук населения **с дня
первого боя** (эмит даже пустой — фиксация формата раньше потребителя);
потребитель (убыль населения, вакансии в производстве) зреет до T-116.

**Состояния актёра (маска K-M7).** prone и высотный статус сосуществуют на
одном актёре; ситуативный перевес — по образцу ADVANTAGE_MARGIN; высотный
статус — верхний виртуальный ярус (+margin по наземному, −margin по носителю).

**Смерть и риск.** Смерть — только по death saves (mod ТЕЛ, 3/3,
детерминированно); стабилизированный — ранен, не потеря (Т17-№2: риск
остаётся, но не фатален автоматически). Дом правила — [[02-mechanics#3.2 Партия и персонажи — НОВОЕ]].

**Разрешение — без RNG (K2).** Инициатива «Удача + Ловкость» один раз на бой
(тай-брейки: Ловкость → ID); исход удара — лестница перевеса
([[02d-luck-professions#3.2 Лестница исходов]]); Долг судьбы — таблица Б.4
(Расплата = ступень ниже + сброс, без триггера накопления — резолюция R1).
Те же входы → тот же `battle_report` (I1). Лимит 20 раундов — ничья (D-128).
Хаб боевого ядра — [[02d-combat-core]].

**Статблоки — данные, не код (K-M15).** Три базовых бойца MVP (Пехотная
линия / Стрелок / Волшебник, 07-balance §3) + рейдеры — в
`game/data/config/balance/campaign.json → unit_statblocks` (provisional до
T-041); инвариант входа T-041: взаимная сбалансированность против босс-биома
(якорь ур. 5) + I1 (детерминизм не затрагивают).

**Реализация:** `game/scripts/campaign/campaign_battle.gd` (резолвер),
`game/scripts/main/main.gd` (проводник шва), тесты
`game/tests/campaign/test_campaign_battle.gd`.
