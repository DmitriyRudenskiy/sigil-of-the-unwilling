# GAP-LIST — GDD (docs/) ↔ код (game/)

> Создан 2026-10-15 — этап 1 цепочки «сведение свежего дизайна с кодом»
> (валидация доков → маппинг систем → reverse-документация → consistency-check →
> этот артефакт). **Живой документ**: обновляется на каждом следующем этапе
> (scope-check → эпик → вертикальный срез → истории → оценка → QA-план).
>
> **Метод.** Канон = `docs/` (GDD-серия 00–09 + `docs/mvp/`); код = `game/`
> (386 `.gd`, 49 JSON, 40 сцен, 19 autoload, ~35 систем). Каждая система
> получила корзину:
> - **A** — в доках, не в коде (MVP-разрыв: канон ждёт реализации);
> - **B** — в коде, не в доках (legacy/пре-пивот: канон его не описывает);
> - **C** — расхождение доки↔доки или доки↔код (одна из сторон протухла).
>
> **Источники статусов:** [[TICKETS]] (источник истины по тикетам, append-only D-139),
> [[MVP_SCOPE]] (scope), [[f-plan]] (таблица расхождений Д1/Д2), [[DECISIONS]] (K/D),
> [[QUESTIONS]] (Q-M). Конфиденс: **высокий** = проверено по файлам; **средний** =
> по статусам тикетов, файл-сверка при открытии тикета.
