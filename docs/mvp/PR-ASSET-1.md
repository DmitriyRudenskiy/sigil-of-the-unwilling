## 1. Мера различимости: одна реализация, две оправки

**Мера одна, и она не Python.** `game/tools/dhash_measure.gd`
(`class_name DhashMeasure`) — единственная реализация яркости, хэша 9×8 и
Хэмминга. Нею же считаются матрица в гарде, `game/tools/dhash_report.gd`
(матрицы «до/после» по каталогу, извлечение констант из атласа) и константы
`HOMM_DHASH_*`. Python-зеркало (`tools/dhash_matrix.py`) **удалено этим
коммитом**: PIL-ресайс 16×16→9×8 расходится с Godot на 2–12 бит на пару
(ore↔silver: Godot 11, PIL 13/16/23 в зависимости от фильтра), то есть цифры
зеркала — не цифры гейта. Все числа ниже пересняты мерой гейта; прежние
(«медиана 18», «121 пара из 190») аннулированы.

**Парная мера — по поле содержимого, а не по канвасу.** На канвасе она
вырождена 8 px прозрачных полей (медиана пары 8, при пороге 12 краснеют 191
пара из 210). Замер на этом HEAD (`DHASH_MATRIX=1`): **пар 210, красных 0**,
минимум 13 (`limonite↔stone`), медиана 26, максимум 40 при `PAIR_MIN` = 12.

**A-9 — двойная оправка.** Кража «ячейка один-в-один» невидима в чужой
оправке: чужой тайл, залитый в канвас, даёт 0 по канвасу и 31 по полю;
вписанный в поле — 0 по полю и 19 по канвасу. Гард мёрит обе оправки, у каждой
свой порог: `DHASH_MIN_CANVAS` = 8 (измеренный шум своих же иконок — 11) и
`DHASH_MIN` = 12 (шум 14). Пороги взяты из распределения, а не из цитаты §12.1.

**Честное «до/после».** Перерисовка силуэтов не чинила красную матрицу: по мере
гейта матрица пар была зелёной (минимум 15) уже до неё, перерисовка опустила
минимум до 13 (всё ещё зелёный). Ценность перерисовки — §7.1/читаемость
силуэта, а не пункт матрицы; раньше это подавалось как «чиним красные пары»
потому, что красноту считало зеркало.

## 2. Еда и железо: чем они являются на самом деле

`food` — файл с собственным рисунком (никакого «байт-в-байт дубля grain» в
репо нет: файла `icon_resource_grain.png` не было ни в одной ревизии ветки).
`ResourceAtlas.texture_for_id` грузит иконку по конвенции пути
`icon_resource_<id>.png`, поэтому `food` резолвится без регистрации в таблице.

Носитель еды — **шапка города**, а не полоса мира: `ResourceType.ID` не содержит
`FOOD`, полосу `resource_bar.gd` рисуют семь классических типов. `city_screen`
показывает чипы `food` / `wood` / `iron` (`city_screen.gd:220`). Резолв `food`,
`oak` и `iron` держит гард.

**Железо вошло в акт — прежнее «19 + food, iron вне ASSET-1» ошибалось.**
`iron` уже рисовался в шапке города, и рисовался ему чужой по смыслу рудой
(`city_screen.gd:155`: `texture_for_id(&"ore")`). Отсутствие файла было не
«невводом ресурса», а живым багом неверной иконки — ровно тот класс, который
ASSET-1 и закрывает. Фигура — подкова (единственное кольцо в наборе; руда —
купол, лимонит — низкая плита, серебро — штабика), 13 бит до ближайшего
dвойника по мере гейта. `city_screen.gd` больше не подменяет `iron` рудой.

## 3. Свип: id ресурса ↔ поверхность UI

Каждый id, который игра может попросить нарисовать, против комплекта иконок
(источники: `resource_registry.gd`, `ResourceType`, вызовы
`texture_for_id`/`texture_for_type`):

| id | где рисуется | иконка |
|---|---|---|
| 13 мировых узлов (`oak silver quartz saltpeter turquoise limonite coal gold_ore coal_swamp bog_iron cinnabar wood stone`) | панель ресурсов (`resources_panel.gd:10–19`) и карта (`resource_node.gd:74`) | есть ✓ |
| 7 типов `ResourceType.ID` | `world_spawner.gd:140` (карта спавнит только 0…6, `map_spawner.gd:81`) | есть ✓ |
| `food` `wood` `iron` | шапка города (`city_screen.gd:153–155`) | есть ✓ (`iron` — с этого акта) |
| `stone` как *тип* 7 | нигде: `TYPE_TO_ID` длиной 7, карта тип 7 не выдаёт | файл есть, рисуется по id |
| `grain flour bread tools scholar_points` | городские (`_add_city`), на карте не спавнятся, иконокой не рисуются | нет — fallback, если начнут |
| `crystals` (слой 1), `fabrics potions provisions weapons` (слой 2) | не-MVP-кампания, поверхности UI пока нет | нет — fallback |

Долг, который свип делает видимым: `crystals` — двойник `crystal` (в
`ResourceType` единственное число), и первая же полоса ресурсов кампании упрётся
в fallback. Чинится переименованием id или алиасом в `ResourceAtlas` — не здесь.
