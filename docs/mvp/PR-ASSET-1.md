## 1. Мера различимости: только гейт, зеркало удалено

Парная мера — dHash **по полю содержимого**, а не по канвасу: на канвасе мера
вырождена (медиана пары 10, при пороге краснели 121 пара из 190). Порог
`PAIR_MIN` = 12.

Замер авторитетной мерой на этом HEAD (`DHASH_MATRIX=1` вместе с прогоном
гарда): **пар 190, красных 0**, худшие пары — `limonite↔stone` 13,
`limonite↔silver` 14, `ore↔stone` / `quartz↔silver` 15.

Python-зеркало меры (`tools/dhash_matrix.py`) **удалено этим коммитом**:
PIL-ресайс 16×16→9×8 расходится с Godot на 2–12 бит на пару (ore↔silver: Godot
11, PIL 13/16/23 в зависимости от фильтра), то есть цифры зеркала — не цифры
гейта, и по зеркалу красная пара пряталась за мнимым запасом. Матрицу печатает
сам гард.

## 2. Еда: чем она является на самом деле

`food` — **двадцатый файл, у него собственный рисунок** (никакого
«байт-в-байт дубля grain» в репо нет: файла `icon_resource_grain.png` не было
ни в одной ревизии ветки). `ResourceAtlas.texture_for_id` грузит иконку по
конвенции пути `icon_resource_<id>.png`, поэтому `food` резолвится без
регистрации в таблице.

Носитель еды — **шапка города**, а не полоса мира: `ResourceType.ID` не содержит
`FOOD`, полосу `resource_bar.gd` рисуют семь классических типов. `city_screen`
показывает чипы `food` / `wood` / `iron` (`city_screen.gd:220`); у `iron` своей
иконки нет и в этом акте — она рисуется рудой (`city_screen.gd:155`, вне ASSET-1
намеренно). Резолв `food` и `oak` держит гард.
