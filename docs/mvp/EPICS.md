## 3. Вертикальный срез

### 3.1 Тонкий срез (ранняя верификация — «один полный ход», критерий фазы 1 из 08-tech)

```
NEW GAME → предыгра (есть: T-001/T-002) → меню (есть)
→ КАРТА (серый блок, E-1-минимум: 5 регионов S1, туман) ход 1 (бит «Знак» — каркас есть)
→ 1 шаг движения (E-1-минимум: стоимость входа в регион)
→ ПАРТИЯ (серый блок, E-2-минимум: ростер 2, вес)
→ SETTLEMENT (есть: settlement_processor) → THREATS (есть: threat_system, рейда в ход 1 по дизайну нет)
→ ХРОНИКА (есть: ядро chronicle.gd) → сейв/загрузка (есть: T-110)
```

Цель: первый сквозной проход «ход = сезон» в сером блоке — до полных E-1/E-2/E-3.
Верификация: GdUnit4 (логика) + MCP e2e (сквозной прогон); UI в сером блоке — playtest deferred.

### 3.2 Полный срез (приёмка MVP)

Полная кампания 21 ход по [[MVP_SCOPE]] §2 (NEW GAME → предыгра → цикл ×21 →
босс CR 6–8 → ПОБЕДА/ПОРАЖЕНИЕ → меню). Цепочка собирается ✓ (scope-check).
