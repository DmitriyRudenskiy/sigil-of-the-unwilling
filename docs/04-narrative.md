## Нарратив / Сеттинг / Тон

**Канон (без изменений):** восемь знаков как институт направления ([[02c-signs]]), Нежелающий (носитель, который не хочет светить), кампания = один знак и его носитель ([[02c-signs]]). Тон: давление среды, напряжение лидерства, без карикатурного добра/зла.

**Предыгра (Q18, 2026-10-02):** конструктор → знак (протагонист становится Носителем) → земной шар → города (сколько угодно; штраф оккупации после второго) → партия (5 попутчиков, тренировка). Нарративная рамка: знак приходит без спроса (бит хода 1). Детали: [[00-overview#Предыгровой поток (Q18) [КАНОН, автор 2026-10-02]]].

## Ключевые биты кампании (скрипт 21 хода)

| Ход | Бит | Хроника (пример, ≤3 строки) | Механика-носитель |
|---|---|---|---|
| 1 | «Знак выбрал тебя» | «Ты не просил. Знак всё равно пришёл. Город маленький — начни с него.» | обучение (07-ui-ux) |
| 3 | первый слух о рейде | «Говорят, караваны обходят нашу сторону. Говорят.» | слуховой движок (ниже) |
| ≈7 | первый рейд | «Пришли за зерном. Унесли треть. Записал.» | `pressure.floor(city, by_turn=7, tier=1)` (K-R3: директива, не календарь); рейд (02-mechanics §3.8) |
| 10 | смерть персонажа (если была) | «Знак помнит. Мы — нет. Не помним намеренно.» | death saves (02-mechanics §3.2) |
| 14 | район создан | «У города теперь есть имя. Его назвала пекарка.» | район (8.3) |
| ≈17 | сильный рейд | «Они знают, где твоя слабая сторона. Теперь знают и ты.» | `pressure.window(tier=2–3, by_turn=17)` (директива, K-R3); уязвимость (06-economy) |
| ≤21 | финальный рейд | «Нежелающий стоит. Не потому что хочет — потому что стоит.» | `pressure.floor(city, by_turn=21, tier=max)` + `wave.composition = босс` (K-R3); крупный рейд (12.1) |

Правило битов: бит = запись хроники + (опционально) 1-строчный диалог NPC; нет сценарных окон >5 строк (инвариант тона).

> [!note] K-R3 (2026-10-02): биты-угрозы (7/17/21) — только директивы темпа (floor/ceiling/window/composition), календарных триггеров не имеют; нарративный бит «район создан» (14) — календарный триггер сохраняется (нарративным битам разрешено). Механика рейда — функция давления (K-T5, [[02e4-military#13.2. Функция давления (K-T5, 2026-10-02) [КАНОН]]]).

## Доставка нарратива (MVP — один канал)

- **Хроника поселения** (из 10.12): лента событий «что случилось и почему» — главный канал; каждое ключевое событие (рейд, район, смерть персонажа, передача знака, биты таблицы выше) — запись с причиной.
- **Слухи** (10.12): фоновый канал, 2–3 слуха в неделю, влияют на настроение и дают разведданные (указывают на узлы карты).
- **БАНК:** именованные персонажи (5%, 10.7), обряды (10.9), культы (10.10) — со второй кампании/DLC.

**Слуховой движок (SM, псевдокод):**
```
SM: SEED → SPREAD → DISTORT → (BELIEF | REVEALED)
def tick_rumor(r):
    r.hops += 1                       # 1 прыжок/тик (10.12)
    if rng.chance(0.2): r.distort()   # 20%: деталь искажается
    if r.hops >= 3:
        if r.is_truth(): r.state = REVEALED   # истина: разведданные на карте
        else: r.state = BELIEF                # вымысел: эффект на настроение
```

**Правила:** нарратив читается по действиям, а не по окнам текста: один текстовый блок за событие ≤3 строки; весь лор мира доступен в хронике и энциклопедии знаков.

**EC:**
1. **Слух противоречит хронике** (игрок видит и то и другое) → доверие не ломается: слух всегда помечен «слух», хроника — «факт», в UI разные стили (07-ui-ux); смешивание в одной записи запрещено.
2. **Два события в один день** → хроника объединяет в одну запись с двумя строками (лента не превращается в спам; лимит 5 записей/день, дальше — сводка).
3. **Игрок никогда не читает нарратив** → никаких геймплейных штрафов: нарратив — опциональный слой; вся необходимая информация дублируется в UI-числах (столп 1).
4. **Слух-разведка указывает на узел, который уже исследован** → слух превращается в BELIEF (настроение), разведданные не начисляются дважды (узел one-time, 02-mechanics §3.1).

**Инварианты:** отклонённые идеи (12 Печатей, Разлом) — НЕ канон (2.6); происхождение знаков не раскрывается; нарратив не блокирует геймплей (нет обязательных к прочтению окон >5 строк).
