# Концепт: персонажная система (характеристики, навыки, способности)

Единый фэнтезный справочник для новой игры. Источники объединены из **D&D 3.x/5e**
и **Fallout-подобной** системы (в основном Fallout 2) в один список, близкие
навыки свернуты в общие дисциплины, но исходные названия сохранены в скобках.
Вся терминология переписана под единый фэнтезный стиль (радиация/карма/репутация
→ порча/скверна/слава); **ОД** — очки действий в бою.

> **Статус:** дизайн-справочник (без привязки к коду). В текущем коде есть
> частичные аналоги: статы героя (`attack/defense/spell_power/knowledge/luck/
> morale`) и `HeroSkills` (уровни 0–3) — см. `docs/hero_system.md`,
> `docs/inventory_system.md` (§2.2–2.3). Этот документ — общая модель, а не
> описание конкретной реализации.

## 4. Производные характеристики (формулы)

Производные статы вычисляются из базовых и пересчитываются при любом изменении
базы (перк, трейт, экипировка). Формулы — референс **Fallout 2**, адаптированы
под единые характеристики:

| Производный стат | Формула (Fallout 2) | Адаптация под единые статы |
| --- | --- | --- |
| ОЗ (HP) | `15 + Выносливость + Сила * 2` | `15 + Сойкость + Мощь * 2` |
| ОД (AP) | `5 + Ловкость / 2` (вниз) | `5 + Ловкость / 2` (вниз) |
| КЗ/КБ (AC) | `Ловкость` + бонусы брони | `Ловкость` + бонусы брони/щита |
| Инициатива (Sequence) | `2 * Восприятие + Ловкость` | `2 * Чутьё + Ловкость` |
| Грузоподъёмность | `25 + Сила * 25` | `25 + Мощь * 25` |
| Шанс крита | `Удача` | `Судьба` |

Производные **не пересчитываются каждый кадр** — только по сигналу
`recalculate_stats()` (при взятии/снятии перка/трейта, экипировке, изменении базы).

## 5. Модификаторы, генерация и архитекция эффектов

### 5.1 Модификаторы характеристики (D&D 5e)

- **Формула модификатора:** `floor((Base − 10) / 2)`. Например, мощь 16 → +3,
  мощь 9 → −1. Модификатор — величина, к которой применяется почти вся проверка
  навыков и атак (бросок d20 + модификатор ± бонусы).
- **Генерация статов:** 4к6, отбрасываем низший (4d6 drop lowest) по каждому стату;
  можно повторять/распределять по желанию. Средний результат ≈ 12.3.
- **Ключевое правило сортировки модификаторов:** `Override/FlatOverride → Multiply → Add`
  (изменение через перезапись, затем умножение, затем сложение), чтобы порядок
  наложений был предсказуемым.

### 5.2 Типы эффектов (модель Fallout 2)

- **StatModifier** — применяется к стату. Операции: `ADD`, `MULTIPLY`,
  `OVERRIDE`, `FLAT_OVERRIDE` (жёсткая установка, напр. «Камикадзе» обнуляет КЗ).
  Источник (`source_name`) нужен для отладки и снятия эффекта.
- **Модификация навыков** — проценты к конкретному навыку (торговля, скрытность и т.п.),
  аналог 5e-бонусов к навыкам и Fallout-перков типа Speaker/Salesman.
- **Игровые правила (game rules)** — флаги, меняющие саму механику, а не цифры:
  напр. `disable_aimed_shots` (запрет целиться), `fast_shot_ap_discount` (−1 ОД на
  стрельбу), `heavy_handed_crit_penalty` (×0.7 по таблице критов). Проверяются через
  `has_rule_flag()` / шину событий (EventBus), а не через модификаторы.
- **Контекстные статы** — один и тот же стат может отличаться в зависимости от контекста
  запроса: напр. «+3 к Мощи только для требований к оружию» (Weapon Handling),
  «+1 к Разуму только для диалогов» (Smooth Talker). Реализуется через `get_stat(stat, context)`.

### 5.3 Черты (Traits) vs Способности (Perks)

| Признак | Черты (Traits) | Способности (Perks) |
| --- | --- | --- |
| Момент получения | При создании персонажа | При повышении уровня |
| Лимит | Макс. 2 (каждая: бонус **+** штраф) | По требованиям, бывают множественные ранги |
| Состав | `positive_modifiers` + `negative_modifiers` + `game_rules` | `modifiers` + опц. `script_logic` (стратегия) |
| Требования | нет | уровень, статы, навыки, prereq-перк |
| Уникальность механики | обычно модификаторы | сложные механики — отдельный скрипт-стратегия |

**Разделение по сложности реализации (каталог Fallout 2):**

- 🟢 **Статические модификаторы** — только массивы `modifiers` (энергичность +ОД,
  образованный +очки навыков, крепость +DR и т.п.). Код не требуется.
- 🟡 **Модификаторы действий/правил** — влияют на константы систем движения/инвентаря
  (быстрые карманы, быстрый подъём, +движение, снижение штрафа от темноты, ×время пути).
- 🔴 **Уникальные боевые/системные механики** — требуют скрипта-стратегии: криты
  (Sniper/Slayer/Better Criticals/Silent Death), условный урон (Living Anatomy/
  Pyromaniac/Demolition Expert), подмена статов (Weapon Handling), экономика
  (Master Trader), UI-осмотр (Awareness), боевые триггеры (Adrenaline Rush/HtH Evade),
  мутации.

## Заметки по применению

- Модель **не привязана к коду** — это проектный справочник. В текущей реализации
  статы и навыки героя описаны в `docs/hero_system.md` (`HeroSkills`, уровни 0–3)
  и `docs/inventory_system.md` (§2.2 атака/оружие, §2.3 урон/DR).
- При проектировании новой игры можно взять этот справочник как эталон «полного
  списка» и мапить его на конкретные классы (`HeroStats`, `SkillRegistry`,
  `AbilityRegistry`), сохраняя исходные названия в скобках для прослеживаемости.
