# Концепция: Взаимосвязи построек (TerraScape-style скоринг)

> Источники: [TerraScape Fandom — Library](https://terrascape.fandom.com/wiki/Library),
> анализ колод (Decks) игры TerraScape.
> Цель: описать систему радиального скорнинга зданий и слияний (Merging)
> как образец для системы размещения построек на гексах проекта
> (связь с `data/BuildingDefs.gd`, `world/Borough`, `world/City`).

---

## 🏛️ Ключевые механизмы

### 1. Радиус влияния (Input Radius)
- Здание «сканирует» окружение в радиусе для начисления/штрафования очков.
- Библиотека = радиус **4**, здания Ремесла = **3**, базовые = **1**.

### 2. Бонус биома (Biome Bonus)
- Одно и то же здание выгодно/убично в зависимости от тайла под ним:
  - *Urban:* Библиотека +25, Рынок +25, Хирург +10.
  - *Rural:* Домики +20, Школа +10.
  - *Swamp:* Гончар +25, вся колода Wetlands.
  - *Thicket/Forest:* Лесоруб +15, Лесопилка +10.
  - *Stone:* Каменоломня/Рудник/Кузнец.

### 3. Синергия и Антагонизм (Adjacency)
- **Положительная (+бафф):** создание «кварталов»/«районов».
- **Отрицательная (−штраф):** запрет на спам одинаковыми зданиями
  (правило «один тип — один штраф»).

### 4. Прогрессия и слияние (Merging)
- Базовые здания объединяются в продвинутые (занимают 2–6 гексов),
  которые сами становятся хабами баффов.

## 🔍 Глобальные паттерны баланса
1. **Правило «один тип — один штраф»:** почти у всех зданий самоштраф
   (Библиотека −120, Кузнец −80, Лесопилка −55). Запрещает спам,
   вынуждает строить гетерогенные кластеры.
2. **Иерархия «Ресурс → Переработка → Город»:** 3 уровня, каждый бафает следующий.
3. **Биомная поляризация:** одно здание выгодно/убыточно по тайлу под ним.
4. **Радиус как инструмент баланса:** большие радиусы (Библиотека 4, Ремесло 3)
   требуют места, но их сложнее разместить без штрафующих соседей.
