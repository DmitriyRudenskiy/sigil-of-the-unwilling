# 4. Карта и пространство

## 4.1. Сетка [АННУЛИРОВАНО (K-T7, 2026-10-02)]

> **Аннулировано (K-T7, 2026-10-02):** карта = граф регионов 40–48 с планетарным замыканием, не сетка. См. [[DECISIONS#K-T7. Карта = граф регионов с планетарным замыканием (2026-10-02)|K-T7]]. Текст ниже — архив, валидного места не имеет.

MVP: квадратная сетка **24×24**. Позже: 32×32, 40×40, неправильные формы с естественными препятствиями.

## 4.2. Биомы [КАНОН]

**MVP:**

| Биом | Описание | Эффекты |
|---|---|---|
| Равнина | открытая земля | бонус фермам, дорогам, командным зданиям |
| Лес | деревья, чащи | бонус лесопилкам, стрельбищам, башням; штраф крупным зданиям |
| Горы | скалы, рудные жилы | бонус шахтам, кузницам; штраф фермам |

**Позже:** болото, река, руины, священная роща, выжженная земля.

## 4.3. Изменение местности [КАНОН]

Здания могут менять местность (военный лагерь вытаптывает траву, кузница коптит, лесопилка редекает лес). В MVP изменения минимальны: визуальные + бонусные теги.

## 4.4. Дороги [КАНОН]

| Тип | Стоимость | Эффект |
|---|---:|---|
| Тропа | низкая | базовая связь, низкая пропускная способность |
| Грунтовая дорога | средняя | лучше скорость снабжения |
| Мощёная дорога | высокая | высокая надёжность, меньше штраф расстояния |

Правило: **ресурсы и военная логистика идут по дорогам; бонусы соседства работают по радиусу/клеткам.**

## 4.5. Связность [КАНОН]

Для каждого военного узла считается:

```
connectivity_score =
    base_connection
  × road_quality        (0.5–1.2 по типу дороги)
  × distance_penalty    (снижается при длинном пути)
  × damage_penalty      (дорога разбита рейдом)
  × defense_bonus       (башни, стены, гарнизоны на маршруте)
```

Опорные значения: прямая мощёная — 1.0; длинная грунтовая — 0.75; разбитая — 0.5; под рейдом — 0.2; охраняемая — +0.1.

## 4.6. Карта = граф регионов (K-T7, 2026-10-02) [КАНОН]

- **Карта = граф G(V,E)** с планетарным замыканием (любой регион достижим из любого).
- **Базовая кампания: фиксированный граф 40–48 регионов** (MAP-1 — [[02e1-base-map-v1|базовая карта v1]], draft); 1 город на регион (регион может быть без города — TBD при базовой карте).
- **Вода = биом** (городов на открытой воде нет); **броды = контент** (именованные рёбра с cost/CR; контентные решения — Ф3).
- **Движение:** стоимость входа в регион (по биому, config) + шаги внутри региона; дороги — снижение cost рёбер (4.4, Post-MVP в MVP).
- **Туман войны:** неизведанные регионы не видны; радиус — TBD (Ф3).
- **8 стартов** по тематике знака (02c); MVP-старт = один из них (K-R4).
- **Процедурная генерация — не фундамент:** базовая кампания фиксирована; процедурность — только как редакторский инструмент (K-T7).
- **MVP (K-R4):** связное подмножество **5–8 регионов** базовой карты; единый источник данных — поле `mvp`-маски в конфиге региона; внешняя граница = отсутствующие рёбра (граница непроходима).
- **Фазы:** Ф3 = карта-граф v1 (40–48, броды, 8 стартов) — **draft v1 готов ([[02e1-base-map-v1]])**; Ф5а = узлы карты (узел = атрибут региона).
