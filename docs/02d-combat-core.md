## 1. Лестница исходов (K2, без кубиков)

Канонический носитель: [[02d-luck-professions#3.2 Лестница исходов]] — зоны
Триумф / Успех / Частичный / Провал / Критпровал; пороги +4 / 0 / −3 / — / −8,
сдвиг модификатором Удачи (Триумф — `max(1, 4 − модУДЧ)`, Частичный —
`−(3 + модУДЧ)`, Критпровал — `−(8 + модУДЧ)`). Свойства зон — там же.
Реализация: `game/scripts/core/battle_rules.gd` (`ladder_zone`), детерминизм I1.

## 2. Долг судьбы (таблица Б.4)

Канонический носитель: [[02d-luck-professions#4.2 Долг судьбы (антагонист Удачи)]]
— порог = бонус мастерства носителя (K-R1); Расплата = исход на ступень ниже
(Триумф → Успех → Частичный → Провал; на Провале — Критпровал) + сброс долга
в 0; лимит единовременного заёма (без накопительной Расплаты — резолюция R1);
штраф 1,25 при долге ≥ 1 («Судьба следит»; привязка к лестнице — Ф3).
Реализация K-канона: `game/scripts/campaign/campaign_battle.gd` (`_strike`).

## 3. Death saves (mod ТЕЛ, 3/3)

Канонический носитель: [[02-mechanics#3.2 Партия и персонажи — НОВОЕ]] —
`перевес = mod(эфф. ТЕЛ)` (без prof): ≥ 0 = успех, < 0 = провал; 3 провала =
смерть (перманентная), 3 успеха = WOUNDED. Стабилизированный — ранен, не
потеря (Т17-№2: риск остаётся, но не фатален автоматически).

## 4. Лимит боя — ничья (Q-M20, D-128)

Канонический носитель: [[02-mechanics#3.4 Бой по D&D — НОВОЕ (Q13 РЕШЁН: ручная тактика + авто-опция)]]
— 20 раундов; по истечении — ничья (победа не присуждается, потери
фиксируются); правило завершения, не состояние SM; детерминированная гарантия
конечности (I1, T17-инвариант №3).

## 5. Состав боевого слоя K-канона (акт 12-й итерации §3.4)

- **Единичные комбатанты** (стэков нет — A5-канон); юнит-рекрут несёт
  `character_uid` конкретного жителя (житель → рекрут; канон «погибший юнит =
  погибший поселенец» замкнут на уровне боевого отчёта, milestone 14-й итерации).
- **Инициатива «Удача + Ловкость»**, один раз на бой; тай-брейки: Ловкость → ID
  (лексикографика). AC-правка T-050: не «mod ЛОВ» — по §3.4 (иерархия М1).
- **Маска K-M7:** prone + высотный статус сосуществуют; ситуативный перевес —
  по образцу ADVANTAGE_MARGIN; высотный статус — верхний виртуальный ярус.
- **Бой без RNG** (T-050 AC, 02d 8.3 #14): те же входы → тот же `battle_report`.
- **Шов §2.2:** `battle_report` обязателен к `{losses: [character_uid]}` и
  эмитится в хук населения с дня первого боя (даже пустой); потребитель зреет
  до T-116. `battle_over` — флаг поллинга, не таймер (D-152-семья).
- **Статблоки** — баланс-конфиг (K-M15: «ни одна позиция не хардкодится в
  коде»): `game/data/config/balance/campaign.json → unit_statblocks`; числа —
  T-041. Актёрная модель — [[ACTOR-ARMY]].

Реализация: `game/scripts/campaign/campaign_battle.gd`; тесты
`game/tests/campaign/test_campaign_battle.gd` (+15, 14-я итерация).
