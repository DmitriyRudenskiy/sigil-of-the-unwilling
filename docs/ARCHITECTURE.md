# Архитектура проекта

Прототип гексовой стратегии в духе Heroes of Might and Magic III.
Движок: Godot 4.7.

## Основные принципы

1. Координаторы не содержат тяжёлую логику.
2. Данные отделены от визуала.
3. Логика принятия решений не работает с узлами сцены.
4. Визуал не изменяет игровое состояние.
5. UI показывает состояние и излучает намерения игрока.
6. Все данные — типизированные объекты, не `Dictionary`.

## Слои

### Ядро

- `HexUtils` — гекс-математика, соседи, дистанция, BFS.
- `UnitRegistry` — статические характеристики юнитов и фракций.
- `UnitStack` — runtime-стек юнитов с `duplicate_stack()`.
- `TerrainAtlasMap` — карта тайлов биомов.

### Бой

```text
BattleController — координатор
├── BattleState — данные, очередь, атака, конец боя
├── BattleAI — решения вражеских юнитов
├── BattleView — поле, спрайты, камера, подсветка
└── BattleUI — панель, кнопки, статус
```

Правила:
- `BattleState` не знает о спрайтах и узлах.
- `BattleAI` не использует `await`, узлы и анимации.
- `BattleView` не меняет `BattleState`.
- `BattleUI` не принимает боевых решений, только сигналы.
- `BattleController` связывает модули и управляет `await`.

### Мир

```text
WorldController — координатор
├── MapGenerator
│   ├── MapModel — данные карты, шум, биомы
│   ├── MapRenderer — покраска тайлмапа
│   └── MapSpawner — размещение деревень, ресурсов, врагов
├── HeroController
├── WorldCamera
├── WorldInput
├── WorldSpawner
└── BattleFlow
```

Правила:
- `WorldController` не двигает камеру вручную.
- `WorldController` не создаёт бой напрямую (делает `BattleFlow`).
- Прямой доступ к `_tile_map` только внутри `MapGenerator`.

### UI

```text
AdventureUI — координатор
├── MinimapPanel — мини-карта, прыжки камеры
├── ArmyPanel — слоты армии
├── ResourceBar — ресурсы
└── InfoPanel — дата, статус, списки, кнопки
```

Правила:
- Панели не меняют игровое состояние.
- Действия игрока передаются сигналами.
