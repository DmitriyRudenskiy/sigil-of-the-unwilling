# Binomials (Биномы)

## Общее описание
**Биномы** — это механизм ресурсов, состоящий из пар объектов: основного (base) и "редкого" (variant). Этот механизм используется для создания визуального разнообразия объектов в мире, где один и тот же тип объекта может иметь разные визуальные воплощения с определенной вероятностью появления.

## Техническая реализация

### 1. Данные (Data)
Определения ресурсов и их связей находятся в `data/ResourceDef.gd`. Здесь описываются типы ресурсов и то, как они соотносятся друг с другом в системе игры.

### 2. Обработка ассетов (Processing)
Инструмент для обработки сырых ассетов биномов: `tools/binom_cutter.gd`.

**Процесс обработки:**
1. **Сбор:** Скрипт сканирует директорию `res://assets/raw/binom/` на наличие изображений листов.
2. **Нарезка (Slicing):** Каждый лист нарезается на сетку 5x5 гексагональных тайлов (размер тайла 82x82).
3. **Классификация:**
    - Скрипт анализирует средний цвет каждого нарезного тайла.
    - На основе цветовых характеристик тайлу присваивается название биома (например, `grass`, `snow`, `sand`, `swamp`).
4. **Определение Базового варианта:**
    - Для каждого биома вычисляется "индекс пустоты" (разброс яркости).
    - Самый "пустой" тайл (с наименьшим разбросом яркости) помечается как **Base** (`{biome}_base.png`).
    - Остальные тайлы сохраняются как вариации (`{biome}_v01.png`, `{biome}_v02.png` и т.д.).

### 3. Хранение результатов
Обработанные тайлы сохраняются в:
- `res://tilesets/processed/{biome}/base/` — базовые фоновые тайлы.
- `res://tilesets/processed/{biome}/objects/` — декоративные объекты (с шансом появления 15%).

## Визуализация и превью
Для оценки визуального соответствия биномов были сгенерированы скриншоты в различных комбинациях.

**Путь к скриншотам:** `previews/`
**Набор скриншотов включает:**
- **Solo**: Одиночные примеры каждого биома.
- **Duo**: Все возможные пары комбинаций биомов.
- **Trio**: Три репрезентативные комбинации из трех биомов.
- **Matrix**: Смесь всех доступных биомов в одной сцене.

*Для генерации новых превью используйте `tools/biome_preview_tool.gd` с параметром `--mode all`.*
