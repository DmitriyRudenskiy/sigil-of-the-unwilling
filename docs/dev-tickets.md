# Dev Tickets (MVP)

Приоритет по графу зависимостей ([[gdd.canvas]]): P0 — фундамент (без него нет ничего), P1 — ядро loop, P2 — сборка. Ссылки — на секции GDD.

## P0 — фундамент

### T00. Бумажный прототип
- **Описание:** лист 24×24, карточки 5 зданий, жетоны ресурсов, карточки статов (бой — детерминированная лестница перевеса, без кубиков — K2; цель рейда — фиксированный график, 02 §3.8). Правила — только MVP-scope.md.
- **DoD:** 3 человека играют 1 полный ход за <15 мин без вопросов по правилам; зафиксированы правки правил (→ GDD).
- **GDD:** 01-core-loop (Критерий), MVP-scope.md.

### T01. Каркас проекта
- **Описание:** Godot 4, структура сцен, CI-запуск headless. Генератора случайных чисел нет (K2, 02d v1.2) — детерминизм на уровне правил.
- **DoD:** `godot --headless` запускает пустую сцену; 2 запуска с одинаковыми вводными → идентичная последовательность событий (тест).
- **GDD:** 08-tech.

### T02. TurnSystem
- **Описание:** `turn.advance() → PhaseEvents[]`; фазы SETTLEMENT → PLAYER → THREATS; блок ввода вне фазы игрока.
- **DoD:** цикл фаз крутится headless 21 раз; события фаз логгируются; ввод игнорируется в SETTLEMENT/THREATS.
- **GDD:** 01-core-loop (Структура хода), 08-tech.

### T03. MapSystem
- **Описание:** сетка 24×24, 3 биома (02e 4.2), туман r=3 (от героя и города), движение 6 точек/день (cost 1), 5 узлов (2 руины, 1 руда, 2 лагеря), SM героя (EXPLORE/ENGAGE/RETREAT).
- **DoD:** герой проходит путь город→узел→город; туман раскрывается/не раскрывается корректно (тест на раскладку); ENGAGE-детект в radius 1.
- **GDD:** 02 §3.1, MVP-scope (Карта).

### T04. EconomySystem
- **Описание:** 3 ресурса, `production/consumption/B(t)`, население = min(жильё, floor(прод_нед/0.7)), SM дефицита OK/WARN/DEFICIT, старт-запасы (R2).
- **DoD:** headless-симуляция 21 хода с 5 зданиями: кривая B(еда) сходится с якорем «≤50% после рейда» (±10%); DEFICIT включает производство 25%.
- **GDD:** 06-economy, MVP-scope (R2/R3).

### T05. BuildingSystem
- **Описание:** 5 зданий (ферма/лесопилка/шахта/барраки/жильё), SM GHOST→BUILDING→WORKING, жёсткий биом, 1 правило соседства (ферма у леса +15%), 1 клетка = 1 здание.
- **DoD:** постройка на несовместимом биоме невозможна; ферма у леса даёт +15% (тест); разрушение рейдом → RUINED → REPAIRING (0.5×t).
- **GDD:** 02 §3.5, MVP-scope (Город).

## P1 — ядро loop

### T06. PartySystem
- **Описание:** персонаж (статы 5e, HD, AC; 6 характеристик + гейт класса — [[02d-classes-skills]] [ждёт K1/K3]), SM READY/WOUNDED/UNSTABLE/DEAD, XP-пороги SRD 2700/6500/15000/38000 (02 §3.2), снабжение 10 еды (R7), герой = лидер партии (R1).
- **DoD:** death saves 3/3 работают (тест с фиксированными статами); REST 1 день лечит (2+CON) × hit dice (куб → среднее, 02d v1.2); голод (0 еды) → флаг для боя.
- **GDD:** 02 §3.2, MVP-scope (R1/R4/R7).

### T07. DnDBattleSystem
- **Описание:** детерминированный боевой движок (K2 РЕШЁН, 02d v1.2): инициатива, атака (лестница перевеса: Триумф/Успех/Частичный/Провал/Критпровал; Удача двигает пороги зон), урон, prone, death saves, greedy AI врага, отступление по команде, TIMEOUT 20 раундов. Одинаковые вводные → идентичный бой. + **Местность (3 типа MVP):** болото/шипы/высота — entry-триггеры, per-turn штрафы, порядок модификаторов (аддитив → множитель скорости → ±2). + **Бином «Фланг» (fighter+ranger):** после успешной атаки одного следующая атака другого по той же цели в раунде — +2 перевеса (1/раунд на пару; SM INACTIVE/ACTIVE/BROKEN).
- **DoD:** реплей: 2 боя с одинаковыми вводными → идентичные события; враг 1v1 против fighter ур.1 — исход в коридоре ROUND_CAP (05-content); TIMEOUT разрешает бой; шипы дают урон (1d4 → среднее 2) ровно один раз за вход (тест); скорость в болоте = `max(1, floor(move×0.5))` (тест); «Фланг»: fighter+ranger против якоря фазы — исход в коридоре ROUND_CAP, +2 от «Фланга» виден в логе проверки.
- **GDD:** 02 §3.4, 02b (A.4 «Фланг», B.2–B.4), 05-content (авто-тест, terrain.json/binom.json).

### T08. Бой: UI
- **Описание:** поле 8×8 с **местностью** (маркеры болото/шипы/высота, тултип клетки: какие штрафы), инициатива сверху, карточки статов (AC/HP/способность) — **врага тоже** (M1), **иконка бинама «Фланг»** (активна/сломана, у партии fighter+ranger), индикатор лестницы перевеса (зона исхода + цифры), кнопки Авто(заглушка)/Отступить/Пропустить, экран отчёта (кто/чем/почему).
- **DoD:** игрок без D&D после урока 0 («лестница за минуту») делает ход без подсказок и называет штраф клетки по тултипу; «Пропустить» доступен всегда; отчёт показывает каждую проверку (включая +2 от «Фланга»);
- **GDD:** 07-ui-ux (БОЙ/ОТЧЁТ), 02b (A.4, B.2), MVP-scope (M1).

### T09. Наём
- **Описание:** очередь (REQUESTED→TRAINING→READY), 2 юнита (ополченец 10 еды/0.3д, мечник 20 еды+10 железа/0.6д), пауза при сломанной сети, слоты партии.
- **DoD:** наём без барраков невозможен (tooltip с причиной); таймер паузы не сбрасывается; READY-юнит занимает слот автоматически.
- **GDD:** 02 §3.3, MVP-scope.

### T10. RaidSystem
- **Описание:** график 7/14/21, power 15/30/60 (R6), defense 0.2 с барраками, цель — по фиксированному графику (02 §3.8), предупреждение день-1, бой с рейдом при герое в городе (CR 1/2/6), кап 30%/день, условия победы/поражения кампании (R5).
- **DoD:** headless: рейд хода 7 при старт-запасах уносит 12 еды (±2); бой босса хода 21 vs партия 3 ур.3 — исход в коридоре ROUND_CAP (детерминирован, 05-content); wipe партии → экран поражения кампании.
- **GDD:** 02 §3.8, MVP-scope (R5/R6).

## P2 — сборка

### T11. SaveSystem
- **Описание:** 3 слота, формат v1 (08-tech), атомарный write (tmp+rename), бэкап предыдущей версии, точка сейва в бою = граница раунда.
- **DoD:** kill процесса во время записи → сейв не повреждается (тест); загрузка сейва воспроизводит состояние 1:1 (сравнение хэшей состояния).
- **GDD:** 08-tech (Сохранения), MVP-scope (M2).

### T12. SignSystem
- **Описание:** выбор из 3 знаков на старте (Время, Тень, Основа — S1 решено); Престиж — единое число: универсальные начисления + фракционные действия знака (≤12 за кампанию, счётчик в UI), ранги по порогам (0/500/1500/3500/7000/12000), понижение ниже порога (косметика гаснет), правила: проигрыш не списывает, отступление не штрафуется, стилевой штраф только за повтор. Престиж чисто косметический (S2): на геймплей не влияет.
- **DoD:** каждое начисление/списание Престижа в хронике с причиной (тест); 13-е фракционное действие не начисляется (тест); ранг 2 (500) → титул в UI партии (тест косметики); престиж ≤ 0 → SLEEPING.
- **GDD:** 02 §3.7, 02c-signs, MVP-scope (Знак).

### T13. Хроника
- **Описание:** лог событий 1 строка (рейд/постройка/смерть/уровень/биты 04), лимит 5/день, стиль «факт».
- **DoD:** все события MVP попадают в лог с причиной; биты ходов 1/7/21 отображаются текстами 04.
- **GDD:** 04-narrative, MVP-scope.

### T14. Экраны города и партии
- **Описание:** ГОРОД: сетка, постройка, тултип «Почему так?» (топ-3/топ-2), панель ресурсов + SM дефицита. ПАРТИЯ: карточки персонажей (AC/HD/XP), очередь наёма (красным — не хватает).
- **DoD:** любой модификатор — ≤2 клика до причины; очередь наёма показывает недостающую сеть.
- **GDD:** 07-ui-ux (ГОРОД/ПАРТИЯ).

### T15. Обучение + цели 3 дней
- **Описание:** урок 0 «лестница за минуту», панель целей: день 1 — ферма+барраки, день 2 — ополченец, день 3 — руины (M3); TTFD-логирование.
- **DoD:** 3 новых игрока: TTFD ≤ 30с; все 3 цели выполнены к утру дня 3 без подсказок.
- **GDD:** 07-ui-ux (Обучение), 01-core-loop (метрики), MVP-scope (M3).

### T16. Баланс-прогон
- **Описание:** детерминированные прогоны каждого юнита против CR-якорей фаз (один прогон = точный исход, без seed/win-rate — K2); коридор ROUND_CAP (05-content); матрица «бином × местность» (Фланг × 3 типа, 09-risks); прогон кампании ботом 10 раз (разные расстановки) — completion (ход 21) 25–60%.
- **DoD:** все юниты в коридоре ROUND_CAP; матрица бинам×местность в коридоре (местность не ломает «Фланг» в одну сторону >10 п.п.); бот-кампания не даёт 0% и 100%; таблица расхождений → правки цифр (не правил).
- **GDD:** 05-content (авто-тест), 06-economy (якоря), 03-progression (кривые).

**Порядок запуска:** T00 → T01–T05 (параллельно после T01) → T06–T10 → T11–T16. Критический путь: T01 → T02 → T03/T04 → T07 → T10.
