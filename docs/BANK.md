## 10.1. Житель и настроение [ЧЕРНОВИК]

Житель — карточка: раса/сословие/специализация, настроение, рассудок, лояльность, связи, черты, именованный персонаж (5%).

**Настроение** = базовое + жильё + еда + сервисы + связи + работа + психика + события (шкала 0–100, пересчёт каждый тик). Устойчивость 0–10 снижает штрафы кризисов.

| Настроение | Состояние | Эффект |
|---|---|---|
| 0–19 | Отчаяние | −25% к работе, риск бунта |
| 20–39 | Уныние | −10% к работе |
| 40–69 | Норма | 0% |
| 70–84 | Добрые | +10% к работе |
| 85–100 | Вдохновение | +15% к работе |

## 10.2. Сословия [ЧЕРНОВИК]

3 сословия, каждое с прогрессом (0–100, пороги 50/100):
- **Ремесленники** — еда и ремёсла, рационализация;
- **Учёные** — знания, просвещение, предсказание событий;
- **Стража** — оборона, дисциплина, набор в военные отряды.

## 10.3. Лояльность и эскалация [ЧЕРНОВИК]

Лояльность 0–100 на сословие, старт 50, дрейф 0.5/тик. 6 стадий эскалации:

```
Шёпот (<40) → Волнение (<30) → Петиция (<25)
→ Страйк (настроение <20 и доля сословия >30%)
→ Бунт (10 тиков) → Исход (30–50% сословия уходит)
```

Спец-события: старейшины, тихий переворот (при влиятельности лидера >70%).

## 10.4. Совет и политика [ЧЕРНОВИК]

Два источника указов: совет (бесплатно) и игрок (за влияние / поправка за авторитет −2). Авторитет лидера 0–10 = 3 + харизма. Две валюты: влияние и авторитет.

## 10.5. Дикие народы [ЧЕРНОВИК]

5 народов (бобры, гарпии, лисы, жабы, летучие мыши) + культурные углы. Матрица отношений v2: 40 пар, односторонние обиды, «старая кровь» (наследственная вражда), дикость −10.

## 10.6. Дикие земли [ЧЕРНОВИК]

3 слоя: подлесок / подстилка / перекрёстки. Лояльность земли 0–100, порча (запятнанность → заросли → паутина), звери с поведенческими моделями.

## 10.7. Связи, поколения, именованные [ЧЕРНОВИК]

Семья (15 тиков → ребёнок), дружба/вражда, ученичество (ученик → мастер → наставник), «родившиеся у очага», двойная кровь. Именованные персонажи (5% жителей): желание → свершение / демагогия.

## 10.8. Рассудок и безумие [ЧЕРНОВИК]

Рассудок 0–100, старт 80. Состояния: ясность / норма / туман / страх / безумие. Спасение Воли: `10 + мод(МДР) + ситуативное против DC 10 + глубина/10` — лестница перевеса (02d v1.2, без кубиков). Таблица безумий: паника, мегаломания, бегство в землю, «Святой Безумных». Сны — раз в сезон.

## 10.9. Память: смерть, обряды, наследование [ЧЕРНОВИК]

Похороны, обряды для 11 рас, «непогребённые» (проклятие), памятники, наследование достижений, старейшины (200+ тиков).

## 10.10. Вера и справедливость [ЧЕРНОВИК]

Культы: Очаг / Дикие земли / Круг мыслей; ересь («Пепельные»); синкретизм («Два Огня»). Справедливость: закон 0–100 (старт 30), прецеденты, присяжные, тюрьма.

## 10.11. Демография, календарь, еда [ЧЕРНОВИК]

Притяжение жителей, архетипы (беженец/мастер/изгнанник/дикий), исход, «перелом». Календарь: 6 тематических фестивалей, стража (vigil). Еда: расовые предпочтения, общий пир, «кухонная дипломатия».

## 10.12. Слухи и хроника [ЧЕРНОВИК]

Движок слухов: зерно → 1 прыжок/тик → 25% искажение на 3-м прыжке. Типы: клевета / хвала / паника / надежда. Гонец (разносчик). Хроника поселения, прозвища.

## 10.13. Интеграция с GDD [ЧЕРНОВИК]

- Настроение (10.1) — детальный аналог «морали» 005§11; расовая мораль = среднее(настроение)/10;
- Стража (10.2) = рекрутский пул военной сети ([[02e-city#12.1. Сеть и роли узлов [КАНОН]|02e 12.1]]);
- Потери в боях — это конкретные жители: похороны, память, наследование (10.9).
