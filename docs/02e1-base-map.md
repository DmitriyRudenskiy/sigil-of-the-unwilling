# Базовая карта v1 — граф регионов (MAP-1, Ф3)

> **Замещение (2026-10-03, D-125):** заменяет целиком [[02e1-base-map-v1]] (44 региона, кольцо 36 + сердце 8) — тот архивирован; «резонансные» флейвор-имена умирают вместе с носителем. Данные карты — `data/maps/` (создаёт T-022). Старты назначает решатель T-022 (§9), не вручную. Эскалация на 48 узлов — решение владельца по логу решателя.

## 1. Схема данных

Регион: `{id, кольцо, биом, вода/суша, узлы_layer1[], роскошь{тип, остаток}, шанс_данжа, шанс_аномалии, флаги{босс, mvp_маска}}`.

v1.1 (аддитивное поле, D-131): `россыпи: [{тип, объём}]` — динамический контент сценария; собираются героем, исчезают после сбора.

Лагеря-источники — **не данные карты**: динамические сущности функции давления (02e4 §13.2, D-130); отсутствие в схеме — по дизайну.

Два графа:
- **соседства** — все рёбра; давление, радиус аномалий, добыча с берега;
- **армейский** — суша + переправы весом 2; движение, сепарация стартов.

Вода не содержит городов, данжей и вершин армий.

## 2. Топология — 46 узлов

Кольца: экватор E1–E16, северное умеренное N1–N14, южное умеренное S1–S14, шапки CN, CS.

Рёбра:
- **внутрикольцевые:** i–i+1 с замыканием n–1 (восток смыкается с западом);
- **межкольцевые:** регион k кольца из n соединяется с j и j+1 (mod m) соседнего кольца из m, где `j = ceil(m·k/n)` (экватор↔север и экватор↔юг; умеренные кольца не смежны между собой);
- **шапки:** CN–{N1, N8}, CS–{S1, S8} — степень 2, минимальное замыкание полюсов (шапки — контент-регионы Пустоты, не транзитные хабы; низкая степень бережёт дистанции).

**«Краёв нет»:** замыкание восток–запад плюс полюса — чекер проверяет наличие рёбер E16–E1, N14–N1, S14–S1 и ≥2 соседей у каждого узла.

## 3. Гидрография

Внутренние моря: северное N7–N8, южное S7–S8 (4 региона воды; 42 суша). Переправы: N6–N9 и S6–S9, вес 2. Добыча роскоши из воды — контролёром соседнего берега (уточнение T7, фиксируется здесь).

## 5. Месторождения Layer-1

Правила: лес → узел дерева; равнина → пашни (еда); холмы/горы → узел железа.

Редкие узлы: ртуть — N10, S10 (болота); сера — N13, E4 (горы/разлом; добыча в босс-регионе — поздний контент, якорь ур.5); кристаллы — S13, N9.

## 7. Шансы (числа — баланс-конфиг карты)

- **Данжи:** равнина 0.10, лес 0.25, болото 0.30, холмы 0.15, горы 0.20, разлом 0.40, шапки 0.25, вода 0.
- **Аномалии:** базовый 0.04; CN, CS, E4 — 0.12. Радиус аномалии `k_a = 2` (взвешенные рёбра графа соседства).
- Базы движения по биомам — [[07-balance]] (T-112); карта несёт только поле биома.

## 8. Босс-регион

E4 «Разлом»: босс-биом — спецконтент вне регулярного счёта (K-M2); узлы Сложности уровня 5 (якорь «ход 21 = 5 × ур.5», Q-M13); соседство со стартом Искры — драматургия Пустоты у истока.

## 9. Старты

**Ограничение:** попарно ≥ 3 **взвешенных рёбер армейского графа** (переправа = 2; вода исключена). Обоснование числа: ≥ 4 доказуемо неосуществимо на 46 узлах — поясная структура: три экваториальных старта накрывают оба умеренных кольца радиусом 2, шапки лежат в 2 от умеренных; конструктивные попытки дают максимум ~6 стартов при ≥ 4. При ≥ 3 упаковка на границе: непересекающиеся шары радиуса 1 ≈ 40 узлов при 46 — осуществимо, но туго.

**Назначение — решателем T-022, не вручную** (вручную доходит до 6 и упирается; это задача машины).

- Вход решателя: предпочтения биома по Знакам — Искра равнина, Время горы/холмы, Равновесие равнина, Первозданность лес, Тень болото, Гармония равнина, Цикл лес, Основа холмы.
- Фиксированные позиции: **Искра E3, Время N6** (якорь MVP-сценария; взаимная дистанция 3 ✓; Время на равнине у переправы — «страж переправы», тема рассчитанного часа).
- Остальные шесть — решатель по предпочтениям + ограничение ≥ 3 + отчёт покрытия (доля Воронея ≥ 4 регионов на старт).
- **Эскалация:** при доказанной решателем неосуществимости (лог исчерпания) — карта v1.1 на 48 узлах (шапки по 2 региона, степень ≤ 3, якоря равномерно); решение за владельцем по логу, не автоматически. 48 — верхняя граница канона 40–48.

## 10. MVP-маска

`{E3, E4, N4, N5, N6}`: связность ✓ (E3–E4 кольцо; E3–N4 межкольцевое; N4–N5, N5–N6); регулярные биомы {равнина, лес} ✓; босс внутри ✓; вода/холмы/горы вне ✓ (K-M2).

Сценарная директива MVP (не данные карты): игрок — Искра, ИИ — Время; полный выбор знака — 1.0. Данных MVP не существует — маска есть поле базовой карты (K-R4).

## 11. Валидация (расширение T-022)

- матрица стартов ≥ 3 (взвешенные рёбра армейского графа);
- связность суши (42 региона достижимы без воды);
- замыкание (рёбра E16–E1, N14–N1, S14–S1; ≥2 соседей у каждого узла);
- один город — только суша;
- MVP-маска: связность, 2 старта, регулярные биомы, босс внутри;
- поле `E4.difficulty_anchor = 5`; `k_a = 2`;
- **диаметр армейского графа (взвешенный, дни) ∈ [8, 14]** — измерение при эталонном модуле скорости 1 (без Ловкости/веса); строка отчёта покрытия решателя; при выходе из окна коррекция — биом-множителями [[07-balance]], **не топологией** (топология — канон карты) (D-129).

Решатель стартов + отчёт покрытия (включая диаметр) — тем же тикетом (T-022).
