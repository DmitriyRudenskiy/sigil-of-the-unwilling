## Социальная система — поселение у Древнего Очага [ЧЕРНОВИК v1.2, БАНК — не в MVP (Q4/P2)]

Расширенный преемник соц-системы 10.x ([[BANK]]): три оси (настроение / лояльность / память), три сословия, семь рас, Совет, культы, слухи, герои, вера, демография + новые слои (Лес как антагонист-партнёр, архитектура, экономика-цепочки, психея, культура, дипломатия, большие ритмы времени, Регент, погода, Подземье, звук, тайные общества, образование, тело, логистика, режимы сложности, обучение, стартовые сценарии). Нумерация частей I–LII — собственная, внутри документа.

## Пост-пивотная рамка (Q16) [v2]

*Обновлено 2026-10-01. Детали таблицы — [ПРЕДЛОЖЕНИЕ], ждут подтверждения автора.*

Тело документа написано в пре-пивотной рамке (Буря / Корона / Тлеющий город / сезоны). Пост-пивотный канон ([[01-core-loop]], [[10-worldbuilding]], [[02c-signs]], [[03-progression]]) использует другие имена и единицы времени. Таблица ниже — **переводный слой**: механики документа не меняются, меняются только названия и тайминги.

| Имя в документе | Пост-пивотный канон | Примечание |
|---|---|---|
| Тик | ¼ дня (1 ход = 1 день, Q6) | Игроку виден ход, не тик; таймеры 15/20/50/500 тиков = ~4/5/12/125 ходов |
| Сезон | Фаза кампании (1–6 / 7–13 / 14–20 / 21) | «Раз в сезон» = раз в фазу |
| Год / десятилетие / столетие | Кампания / мета-цикл (кампания + хроника) | Столетие → Престиж знака (ранги 1–6, [[03-progression]]) |
| Буря (10 тиков, 3 волны) | Волна рейдов: серия рейдовых дней | Рейды по графику [[02-mechanics]] §3.8; «бурный» гекс = гекс под давлением рейдов; «стойкость» = прочность сети перед рейдом |
| Затишье перед Бурой | Предупреждение планщика угроз (≥1 цель/день) | [[01-core-loop]]: fail-state «нечего делать» |
| Корона | Знак (институт направления) | Требования Короны (дипломатия, XXXIII) → испытания знака ([[02-mechanics]] §3.7) + Престиж знака |
| Тлеющий город | Хроника (мета-архив) | «Перенос механизмов и артефактов» → мета-перенос Престижа и хроники ([[03-progression]], P-1) |
| Регент | Носитель знака (игрок, 3 варианта — [[10-worldbuilding]] §4) | «Обход Регента» = глагол «обход» 5-минутного цикла; «смерть Регента» = смерть носителя (знак передаётся смертью) |
| Репутация 18 = победа | Пережить крупный рейд хода 21 + состояние сети | [[03-progression]]: «Итог кампании: исход крупного рейда + состояние сети» |
| Лес (Подлесок / Чаща / Заречье) | Угрозы: рейды + давление среды + узлы карты | Чаща = зона спавна рейдов; Заречье = узлы карты с добычей; Лесная лояльность = «цена» мирных обрядов у источника угроз |
| Дипломатия (послы, посольства) | Последователи и семь других знаков | Часть XXXIII строится на институте 8 знаков ([[10-worldbuilding]] §1) |
| Гниль (Пятна, гниль-корни) | Давление среды / узлы-угрозы | [[02e-city#13.3. Оборона [КАНОН]|02e 13.3]] остаётся канон-базой обороны |
