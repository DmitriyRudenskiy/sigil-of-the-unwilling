# 9. Расы и культуры

## 9.1. Принцип [КАНОН]

Расы дают **альтернативный стиль**, а не жёсткие рамки. Каждая культура: несколько специализаций; особые выходы, а не только проценты; смешанные команды дают гибридные бонусы.

## 9.2. Первый эшелон — 7 рас [КАНОН]

**K-M5-правка (владелец, 2026-10-02):** первый эшелон = **7 рас, одна на группу** (пре-пивотное «3 культуры» аннулировано — пре-пивотные данные). Формула: первый эшелон = 7 (по одной на группу), горизонт = 54 (каталог), дубли аннулируются. Дубли (драконорождённые, полуэльфы) — миграционный горизонт каталога 54, не стартовый пул; вхождение — K-A6 (расовый флаг), контентный слой (Q-M18). ## 9.3. Смешанные команды [КАНОН]

Метод 1 — средняя эффективность:
```
team_modifier = (modifier_A + modifier_B) / 2
```
Метод 2 — гибридный бонус: люди + орки в казарме — +5% к дисциплине; эльфы + люди в башне — +5% к дальности. Гибридные бонусы — только 3–5 штук в MVP, чтобы не усложнять.

## 9.5. Волны доменов — каталог 54 (владелец, 2026-10-04, 7-я итерация) [КАНОН]

Гейт снят (дифф с 02e3 §9.4 пуст, Σ = 54). Волны строятся на применённой таблице.

### Правила

- **R-W1 (анти-календарь).** Волна — условие состояния; поле «ход» в конфиге волн запрещено (семья K-T5). Никаких «раса X на ходу Y».
- **R-W2 (два канала).** Канал М — миграция (контакт региона); Канал Д — освобождение пленных из данжей. Третьи каналы (покупка, награда, диалог) запрещены. GDD §3/§6 вербатим.
- **R-W3 (единица — домен).** Семь волн по доменам; внутридоменный порядок не вводится; первый эшелон — старт, волны только расширяют пул, никогда не заменяют.
- **R-W4 (биомы — производная канона).** Биом тяготения выводится из специализации домена (02e3 §9.4) — чтение канона, не новая таблица.

### Таблица биомов тяготения

|---|---|---|---|
| Инженеры и Строители | деревообработка, строительство | лес | N1, N2, N5, N12, S2, S14 … |

Двойное заселение биома (два домена на лес; два на равнину) — допустимо: условие ИЛИ по домену, биом не «занимается».

### Каналы

**Канал М (миграция):** контроль ≥ 1 региона биома тяготения → домен входит в миграционный пул. Прибытие — органическое: рейтинг миграции (Репутация, замкнутый цикл §1) × жильё × еда; волна задаёт пул, троттлинг остаётся за петлёй. Потеря региона закрывает пул (приток останавливается), живущих не высылает — зеркально добыче §4.

**Канал Д (освобождение):** зачистка данжа в регионе биома тяготения → пленники домена; «немедленная миграция в ближайший город» (§6 вербатим) — единственное исключение из троттлинга, источник драматургии экспедиций. Состав пленных — данные данжа (сценарий), не генератор; только каталожные расы (нежить-трио — мобы данжей, вне пула). Канал Д опережает канал М: экспедиция в глубину приносит расу до контроля региона.

### Инварианты и проверки

- Чекер waves.json: нет поля «ход»; биомы ∈ карты v1; пул ≤ 54; пленники ∈ домена биома данжа; нежить-трио вне.
- Летопись: каждое волновое прибытие — запись {раса, канал, регион-источник}.
- Автобалансировщик (срез-якорь, не триггер): медиана 1.0-кампании к середине — ≥ 3 домена с живущими вторыми расами.

### Слои

MVP — волны вне среза (первый эшелон 7); 1.0 — полные волны. Конфиг waves.json создаётся при запуске T-111-full (одним актом с транскрипцией A6-R-таблицы в Приложение А).
