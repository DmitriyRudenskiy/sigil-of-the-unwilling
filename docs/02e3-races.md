# 9. Расы и культуры

## 9.1. Принцип [КАНОН]

Расы дают **альтернативный стиль**, а не жёсткие рамки. Каждая культура: несколько специализаций; особые выходы, а не только проценты; смешанные команды дают гибридные бонусы.

## 9.2. Культуры MVP [КАНОН]

**Люди — «Универсалы и Логисты»**
- Роль: инфраструктура, снабжение, командование, универсальная пехота.
- Теги: `logistics`, `command`, `settlement`, `versatile`.
- Особые: склад +10% лимит снабжения; командный шатёр +1 лимит армии; таверна +5% скорость ремонта; воины (базовая пехота) дешевле (K-M15: «ополченцы» — аннулировано).
- Стиль: «Построй прочную сеть и управляй ресурсами».

**Орки — «Кузнецы и Воины»**
- Роль: железо, оружие, пехота, обучение.
- Теги: `heavy`, `forge`, `warrior`, `ramp`.
- Особые: кузница +10% скорость оружия; шахта +5% шанс рудной жилы; плац +10% обучение, +5% шанс боевого опыта; воины +5% атака (K-M15: «мечники» — аннулировано).
- Стиль: «Преврати ресурсы в военную мощь».

**Эльфы — «Лесные Стражи»**
- Роль: лес, разведка, стрелки (Следопыты), оборона.
- Теги: `forest`, `ranged`, `recon`, `defense`.
- Особые: лесопилка +10% дерево; башня +10% разведка; стрельбище +15% Следопыты (K-M15: «лучники» — аннулировано); следопыты.
- Стиль: «Создай сеть разведки и обороны».

## 9.3. Смешанные команды [КАНОН]

Метод 1 — средняя эффективность:
```
team_modifier = (modifier_A + modifier_B) / 2
```
Метод 2 — гибридный бонус: люди + орки в казарме — +5% к дисциплине; эльфы + люди в башне — +5% к дальности. Гибридные бонусы — только 3–5 штук в MVP, чтобы не усложнять.

Иерархия расового канона (решение автора): **конструктор MVP — первый эшелон = 7 рас (★, по одной на группу, K-M5/A6-R); расширение — 7 экономических групп (ниже); 54 расы `002` распределены по группам.**

**Принципы (A6-R):** (1) одна раса → одна группа; (2) первый эшелон = 7, по одной на группу (K-M5: «9 рас» заменено); (3) нежить-смежные линии выводятся из демографии живого города — возрастная модель (16–60, «60+Удача») к ним неприменима; их место — контент данжей/аномалий (Пустота: Тень/Цикл); (4) конструкты и водные — флаги origin, не механики (K-A6); (5) минимальная хирургия: правятся конфликты с каноном и целостность линий, не перетематизация каждого вхождения v0.1.

**Изменения к v0.1:** (1) + тифлинги → Алхимики (в v0.1 отсутствовали); (2) + полуорки → Охотники (имя — полуорки, не орки: раса базовой системы); (3) + полуэльфы → Торговцы (горизонт, K-M5); (4) люди: Земледельцы → Торговцы (GDD §3: посредничество; v0.1 противоречил канону); (5) «карлики» → **дворфы** (каноническое имя) + Инженеры → Металлурги (GDD §3: домны, кузни); (6) дуэргары: Инженеры → Металлурги (дварф-линия следует за дворфами; разрыв линии по группам запрещён); (7) − дампиры, − перерождённые, − одержимые гексом (принцип 3); сальдо −3/+3 — итог 54 сохранён; (8) флаги origin (ниже); (9) «MVP = 3 группы» аннулируется — первый эшелон 7.

**Флаги origin (A6-R, K-A6):** `aquatic` = {тритоны, локатахи, грингли, генази воды, ящеролюды} — критерий: наследственная амфибийность или скорость плавания; задержка дыхания (тортлы) не считается; водные расы не требуют водных регионов для жилья. `construct` = {кованые, автогномы} — вне рождений, старения и училищ; численность — производственная (строительство), не демографическая; срок службы — [[07-balance#6. Экономика и население|07-balance]]. Остальные 47 — полная возрастная модель §3. «Водные расы» — **не группа**, а атрибут расы (K-A6, 2026-10-02).

**Первый эшелон (конструктор MVP):** 7 рас — ★ в таблице (гномы, полурослики, тифлинги, эльфы, люди, полуорки, дворфы); данные — `mvp_catalog.json` (SRD-модификаторы; half_orcs; luck: 0 — гномы +2 в [[07-balance]]/`races.json`, D-135/D-136). «MVP = 3 группы» (Земледельцы — люди, Металлурги — орки-кузнецы, Ткачи — эльфы) — **аннулировано** (A6-R); культуры 9.2 сохраняются как нарративный старт, не как расовый cut.
