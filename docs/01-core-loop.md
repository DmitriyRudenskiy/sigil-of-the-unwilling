## Core Loop

**Единица времени: 1 ход = 1 сезон = 20 дней** (`DAYS_PER_SEASON`, Q-M26, владелец 2026-10-05; прежняя формулировка «1 ход = 1 день» **аннулирована** grill v3 pass 4 — она противоречила коду и строке «День-единица» в [[07-balance]]). Кампания MVP = 21 ход = 420 дней. **Тик** — деление дня внутри города (1 день = 4 тика [ПРЕДЛОЖЕНИЕ Q6] ⇒ 80 тиков/ход): производство, слухи и таймеры тренировки идут по тикам. Игроку тики не видны — для него единица = ход; тик это шаг движка, не единица ввода.

## Цикл 30 секунд (одно действие)

`увидел → решил → сделал → увидел результат`

Одно атомарное действие игрока: сдвинуть героя на клетку, поставить здание, назначить рабочих, нанять юнита, сделать ход в бою. Результат всегда виден сразу: число, стрелка, подсветка (столп 1: «машина, но читаемая»).

## Цикл 5 минут (глаголы)

`увидел → двинул → решил (бой/обход/возврат) → построил → снабдил`

Пять глаголов — весь геймплей; всё остальное в UI — сервис этих глаголов. За 5 минут игрок проходит один микроразворот: заметил проблему (дефицит/угрозу), принял решение, исполнил, проверил сеть.

Глагол «решил» в бою расширяется подсистемой [[02b-binoms-terrain]]: **биномы** (синергии пар персонажей — «кем из пары бью») и **местность поля** (штрафы/укрытия — «где бью»). На карту кампании и фазы хода система не влияет.

## Цикл сессии (35–50 минут, метрики — [[09-risks]])

```
увидеть угрозу/дефицит → перепланировать поселение → усилить узкие места
→ сформировать/усилить партию → поход (бой/ресурс) → вернуться
→ применить добычу → пережить рейд
```

## Структура хода

1. **Фаза поселения** (автомат): производство, настроение города (02g; отдельной шкалы морали нет — K-M14), слухи, обслуживание районов.
2. **Фаза игрока**: движение героя по карте, исследование, бой, постройка, назначение рабочих, тренировка (Q18).
3. **Фаза угроз** (автомат): рейды по функции давления (K-T5; «по графику» — аннулировано, K-T5/K-R3), давление среды. **События — 1.0** (Q-M77 → (а), D-197): единственный носитель каталога (`CrisisEventSystem` + `data/events/`) лежит в корзине **B-1** (T-128), из кампанийного цикла не вызывается и в [[MVP-scope]] не зарегистрирован — слово в MVP-фазе было носителем без носителя.

## Campaign loop (21 ход)

**До хода 1** — предыгровой поток: конструктор → знак (из 8, на всю игру) → земной шар → города (сколько угодно; штраф оккупации после второго) → партия (5 попутчиков) → тренировка ([[00-overview#Предыгровой поток (Q18) [КАНОН, автор 2026-10-02]]]).

1–6 выживание → 7–13 железо, первый рейд (ход 7) → 14–20 районы и **пережившие** (K-M10: пережившие бои бойцы с личным опытом — вход эволюции A5/§5; «Ветеран» — **статус** пережившего бойца, а не юнит и не ярус (Q-M56 → (а), D-189)) → ход 21 крупный рейд-проверка.

## Метрики валидации core loop (как проверить, что цикл работает)

Референс (research, офлайн): индустриальные гейм-метрики стратегий — TTFD (time-to-first-decision), action rate, session length, D1/D7 ([[09-risks]] уже задаёт D1 35%+, D7 15%+, сессия 35–50 мин).

| Метрика | Измерение | Цель | Сигнал сбоя |
|---|---|---|---|
| TTFD: старт → первое осмысленное действие | event `action` после `game_start` | ≤ 30 с | > 60 с — игрок не понял, что делать (учёба не сработала) |
| Action rate: осмысленных действий / 5 мин | event `action{type}` | 8–15 | < 5 — скучно/застрял; > 20 — мельтешение без решений |
| Доля решений: действия с ≥2 осмысленными опциями | event `action{choice_count}` | ≥ 60% | < 40% — цикл принудительный, «жми дальше» |
| Закрытость цикла: сессии с ≥1 полным циклом (угроза→план→поход→рейд/итог) | event `loop_closed` | ≥ 70% | < 40% — игрок не доходит до кульминации сессии |
| Aha-момент: первая ПЕРЕПЛАНИРОВКА города после просмотра «Почему так?» | event `replan_after_tooltip` | ≤ 10 мин, ≥ 80% игроков | > 20 мин — столп 1 не работает |
| Длина сессии / D1 / D7 | стандарт | 35–50 мин / 35%+ / 15%+ | [[09-risks]] |

**Pseudocode логирования:**
```
on_action(player_action):
  log {t, type, choice_count, has_visible_result, in_loop_phase}
on_session_end:
  log {duration, actions, loops_closed, replan_after_tooltip_ts}
```

**Fail-states цикла (и защита от каждого):**
1. **«Нечего делать»** (нет угроз, нет целей): планировщик угроз гарантирует ≥1 цели на каждый день (рейд/узел карты/испытание знака, 02-mechanics §3.8).
2. **«Принуждают»** (только одна осмысленная опция): инвариант UI — в любой фазе игрока ≥2 доступных глаголов (двинул/построил/тренировал).
3. **«Не награждает»** (нет видимого результата): инвариант — каждое действие даёт визуальный фидбек (число/стрелка/подсветка), иначе действие не считается «осмысленным» в метриках.

**Edge cases:**
- **Игрок AFK 5 дней подряд:** рейды разрешаются последовательно, но с **per-ресурсным** капом: еда ≤ 40%/день, железо/оружие ≤ 30%/день (02-mechanics §3.8; Q-M58 → (в), D-189; прежде — единое «≤ 30%/день»); снежный коллапс (всё на нуле за оффлайн) невозможен — при возвращении играем дальше. Именно поэтому «все запасы ≤ 0» **снято** как самостоятельное условие поражения (Q-M68 → (а), D-190): при таких капах оно не достигается.
- **Игрок игнорирует город, только ходит:** партия голодает (1 еда/персонаж/переход, 06-economy; ёмкость 10 еды → 5 переходов на старте и 2 перехода при полной партии, Q-M70 → (а), Q-M75 → (б)), голод → −2 к атакам и ступени спасбросков (P-4, MVP-scope R7; 02-mechanics §3.4) → цикл сам тянет обратно (fail-state партии, 02-mechanics §3.2; шкалы морали нет — K-M14). Длительный голод бьёт не «по запасам», а по людям: гибель всей партии = **единственный** конец кампании (Q-M68 → (а), D-190).
- **Игрок сидит на месте (не расширяется):** видимость не растёт, но и добыча узлов = 0 → к ходу 14 нет ресурсов для фазы 3; хроника подсвечивает: «знак требует движения» (испытание знака — **Post-MVP**, 02-mechanics §3.7; в MVP канал давления — рейды K-T5 и узлы карты).

## Критерий

Бумажный прототип (карта 5–8 регионов, карточки, жетоны, таблица лестницы исходов для боя — без кубиков, таблица давления) воспроизводит один полный ход за <15 минут. #done-if
