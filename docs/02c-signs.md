# Восьмь Знаков — контент-справочник

Финальная редакция системы знаков (решение автора, 2026-09-30). Система — [[02-mechanics#3.7. Знаки — ПЕРЕНОС (канон: Часть 11)|02 §3.7]]; контент — этот файл (финальная редакция 2026-09-30, Q3 РЕШЁН); пре-пивотная «Часть 11» GDD удалена как дубль (таблица — [[RESTRUCTURING_LOG]]).

**Что изменилось (финальная редакция):**
1. Карты удалены. Игровой мир = 4 сущности: **юниты, постройки, ресурсы, действия**.
2. Резонанс/Диссонанс удалены. Есть только **Престиж** — единое число, растёт и падает напрямую.
3. Добавлена **матрица знаков** (4.1–4.3 ниже).

**Маппинг на кампанию (single-player, 21 ход):** «матч» = кампания; «журнал матча» = хроника (04-narrative). PvP-строки (противник/эмодзи/выход из матча) **удалены** — мультиплеера в игре нет (S3 решено). MVP: 3 знака (Время, Тень, Основа — S1 решено), 1.0: все 8. Престиж — чисто косметический (S2 решено): награда ранга = титул/рамка носителя, геймплейных эффектов нет.

## 1. Четыре слоя знака

Каждый знак проявляется в четырёх слоях (карты/колоды больше не существуют):
- **Юниты** — существа, бойцы, работники на поле (1.0-контент; MVP — общие юниты 02 §3.3).
- **Постройки** — здания с постоянными/активируемыми эффектами (1.0-контент; MVP — 15 зданий 02 §3.5).
- **Ресурс знака** — внутренняя валюта, копится и тратится (1.0; MVP: ресурс знака не вводится — только Престиж).
- **Действия** — фирменные операции; за них начисляется Престиж (таблицы ниже; в MVP — кампанийные аналогии, S3).

## 2. Восемь знаков

### Универсальные начисления (кампания)

| Событие | Престиж |
|---|---|
| Победа в бою | **+100** |
| Достойное поражение (доиграл бой до конца, без отступления) | **+30** |
| Фракционное действие (таблицы знаков ниже) | **+5…+12** |
| Особая победа в духе знака | **+20…+30** |
| Испытание недели (1.0) | **+250** |

**Универсальные списания (PvP) удалены** (S3: мультиплеера нет): спам/насмешки/выход из матча/эксплойт — отсутствуют. Поведенческие списания — только в фракционных таблицах знаков ниже.

### ⚡ 1. Искра
**Девиз:** «Создавай быстрее, чем мир успеет понять, что произошло».
- **Юниты:** прототипы и конструкты — дешёвые, действуют сразу после появления, хрупкие.
- **Постройки:** мастерские и реакторы — возводятся за один ход, дают взрывной ресурс, недолговечны.
- **Ресурс:** *Заряд* — копится от активных действий, угасает при простое.
- **Действия:** *Импульс* (юнит действует в тот же ход), *Перегрузка* (жертва юнитом или ресурсом ради мгновенного эффекта), мгновенная сборка.

| Действие | Престиж |
|---|---|
| 3+ действия за один ход | +12 |
| Перегрузка (жертва ради мгновенного эффекта) | +10 |
| Первое действие кампании (инициатива с 1-го хода) | +8 |
| Сборка прототипа/временного юнита | +8 |
| Прямая атака узла врага (лагерь/поселение) | +6 |
| Победа до 10-го хода | +30 |
| Два хода подряд без активных действий | −15 |
| Преждевременное отступление из выигранного боя | −30 |
| Намеренное затягивание (20+ раундов в выигранном бою) | −50 |

**Ранги:** Первая Вспышка → Подмастерье Импульса → Инженер-Испытатель → Архитектор Скорости → Сердце Кузницы → Аватар Искры.

### ⏳ 2. Время
**Девиз:** «Победа приходит к тому, кто умеет ждать и отменять».
- **Юниты:** хрономанты, стражи мгновений, летающие наблюдатели — малочисленны, но решают исход.
- **Постройки:** обсерватории и часовни — дают информацию о планах врага, замедляют его действия.
- **Ресурс:** *Хроно-метки* — копятся за точные ответы, тратятся на отмены.
- **Действия:** отмена действия врага, возврат юнита в резерв, отключение способностей.

| Действие | Престиж |
|---|---|
| Отмена ключевого действия врага (перехват рейда в бою) | +12 |
| Возврат юнита в резерв (отход раненого без потери) | +10 |
| Отключение способности юнита (stunned/frightened на ключевого врага) | +10 |
| Предотвращение крупного урона (защита здания/района) | +10 |
| Атака поверх обороны (летуны, 02b C.1) | +6 |
| Победа после 15-го хода | +30 |
| Контрольное действие, потраченное впустую | −10 |
| Торопление (отказ от предупреждения рейда, бой на худших условиях) | −25 |
| Отступление из проигранного боя без попытки | −150 |

**Ранги:** Ученик Секунд → Хронометр → Хранитель Мгновений → Ткач Времени → Судья Потока → Вечный Наблюдатель.

### ⚖️ 3. Равновесие
**Девиз:** «Мера сильнее ярости».
- **Юниты:** стражи со щитами, лекари, паладины — сильны в связке атаки и защиты.
- **Постройки:** алтари и бастионы — ауры защиты и лечения.
- **Ресурс:** *Весы* — сдвигаются между **Напором** (атака) и **Устойчивостью** (защита); максимум силы — в центре.
- **Действия:** усиление, лечение, спасение юнитов, своевременный контрудар.

| Действие | Престиж |
|---|---|
| Предотвращение летального урона герою (спас из UNSTABLE, 02 §3.2) | +15 |
| Спасение юнита от гибели (3 success death saves) | +12 |
| Уцелевший «выносливый» юнит после атаки (HP ≤ 25%, выжил) | +8 |
| Лечение юнита/героя (REST, 02 §3.2) | +6 |
| Усиление юнита (уровень/снаряжение) | +6 |
| Победа с 3+ усиленными юнитами | +25 |
| Кампания целиком в одной чаше (только атака или только оборона) | −15 |
| Издевательски медленное добивание (5+ раундов против 0-HP-состава) | −50 |
| Игнорирование раненых (не REST после боя) | −50 |

**Ранги:** Ученик Весов → Длань Меры → Хранитель Чаш → Судья Поля Битвы → Свет Равновесия → Аватар Меры.

### 🌿 4. Первозданность
**Девиз:** «Расти, пока не станешь больше страха».
- **Юниты:** гиганты и стаи — медленный старт, чудовищная поздняя стадия.
- **Постройки:** рощи и гнездовья — ускоряют добычу ресурсов, выводят крупных существ.
- **Ресурс:** *Кольца Роста* — каждое здоровое действие усиливает всех следующих юнитов.
- **Действия:** рамп (ускорение ресурсов), мутация, эволюция.

| Действие | Престиж |
|---|---|
| Призыв крупного юнита (ветеран, 02 §3.3) | +12 |
| Дополнительный ресурс / ускорение (район создан) | +10 |
| Мутация или эволюция юнита (уровень 4+) | +10 |
| Атака юнитом с силой 8+ (уровень 4+) | +8 |
| Добор (дополнительный ресурс с узла карты) | +6 |
| Победа стаей (5+ юнитов в бою) | +25 |
| Бессмысленная гибель ветерана (бой 1v1 против CR ≤ 1) | −15 |
| Слив ресурсов (продажа здания с аурой, 02 §3.5 EC2) | −20 |
| Паническая сдача при живом плане (отступление при HP партии > 70%) | −30 |

**Ранги:** Росток → Дитя Чащи → Зов Стаи → Первозданный Страж → Сердце Дикого Мира → Аватар Первозданности.

### 🌑 5. Тень
**Девиз:** «То, что скрыто, уже правит».
- **Юниты:** вампиры, ассасины, нежить — сильны из невидимости и засад.
- **Постройки:** тайные гробницы — невидимы для врага, поднимают павших.
- **Ресурс:** *Шёпоты* — копятся в тишине, тратятся на засады.
- **Действия:** сброс ресурсов врага, кража, вампиризм, поднятие **павших юнитов противника** под свой контроль.

| Действие | Престиж |
|---|---|
| Поднятие павшего юнита врага (1.0; MVP: рейд поселения без атаки — союз, 02 §3.1) | +12 |
| Заставить врага потерять ресурс (рейд пережит с потерями у врага) | +10 |
| Вампиризм (лечение за счёт урона, 1.0) | +8 |
| Уничтожение из засады/невидимости (бой при численном превосходстве врага) | +8 |
| Победа-камбэк из проигрышной позиции (после DEFEAT-боя в кампании) | +25 |
| Шумное поведение (рейды по нейтральным поселениям без нужды) | −20 |
| Раскрытие планов (слишком высокая видимость, 02 §3.8) | −15 |
| Использование силы знака ради унижения (атака после победы) | −50 |

**Ранги:** Шепот → Тень-Странник → Жнец Тайн → Владыка Пустоты → Вечная Тень → Аватар Сокрытого.

### 🎶 6. Гармония
**Девиз:** «Ни один голос не должен звучать один».
- **Юниты:** разнотипные ансамбли — каждый усиливает остальных (см. биномы, [[02b-binoms-terrain]]).
- **Постройки:** резонансные кристаллы — общие щиты и ауры на всю армию.
- **Ресурс:** *Ноты* — копятся за разнообразие юнитов; полный набор складывается в *Аккорд*.
- **Действия:** синхронизация характеристик, массовое лечение, общие баффы.

| Действие | Престиж |
|---|---|
| 3+ разных классов в партии одновременно | +12 |
| Спасение союзного юнита (см. Равновесие, спас) | +12 |
| Активация бинама (аккорд, 02b A.2) | +10 |
| Массовое лечение (REST всей партии) | +8 |
| Общий бафф нескольких юнитов (здание с аурой, 02 §3.5) | +8 |
| Победа без потерь (0 смертей в кампании) | +20 |
| Однотипный состав всю партию | −10 |
| Бессмысленная гибель союзника | −15 |
| Игнорирование биномов (сбор несовместимых классов) | −50 |

**Ранги:** Искатель Созвучия → Ткач Нот → Голос Единства → Хранитель Хора → Аватар Гармонии → Вечный Аккорд.

### ♾️ 7. Цикл
**Девиз:** «Конец — это только дверь».
- **Юниты:** фениксы и сезонные существа — меняются по фазам, возвращаются после гибели.
- **Постройки:** круги возрождения, сезонные храмы — управляют фазами кампании (сезоны, 02 §3.8).
- **Ресурс:** *Фазы* — глобальные сезоны (**Рост → Цветение → Увядание → Покой**), влияют на обоих игроков.
- **Действия:** плановая жертва юнита ради эффекта, возврат своих павших, трансформация.

| Действие | Престиж |
|---|---|
| Возврат своего павшего юнита (замена того же класса, 02 §3.2) | +12 |
| Плановая жертва юнита ради эффекта (1.0) | +10 |
| Трансформация юнита / смена фазы (сезон, 02 §3.8) | +10 |
| Повторная активация способности (бином восстановлен заменой, 02b A.2) | +8 |
| Победа юнитом, который уже погибал (замена выиграла бой) | +30 |
| Судорожное спасение всего подряд (REST каждого раненого) | −10 |
| Негативные эмоции после гибели (отказ от замены) | −15 |
| Жалобы на «несправедливость» (отказ от кампании после DEFEAT) | −25 |

**Ранги:** Наблюдатель → Проводник Пустоты → Мастер Перерождения → Хранитель Колеса → Сердце Цикла → Воплощение Вечности.

### 🪨 8. Основа
**Девиз:** «То, что построено правильно, нельзя сломать».
- **Юниты:** каменные титаны и стены — медлительные, монументальные, их нельзя вытеснить или вернуть в резерв.
- **Постройки:** форты и монолиты — броня герою, запрет действий врага в зоне.
- **Ресурс:** *Опоры* — копятся за успешную оборону, дают пассивную защиту.
- **Действия:** блок атак, набор брони, нейтрализация вражеских эффектов.

| Действие | Престиж |
|---|---|
| Юнит пережил 10+ урона в бою | +12 |
| Срыв ключевого плана врага защитой (рейд отбит, 02 §3.8) | +12 |
| Нейтрализация вражеского эффекта (ремонт RUINED до следующего рейда) | +10 |
| Успешный блок атаки (бой с рейдом при герое в городе) | +8 |
| Увеличение брони/здоровости (стены/башни, 12.4) | +6 |
| Победа монументальным юнитом (10+ HP сохранено) | +25 |
| Жертва защитного юнита ради случайной атаки | −15 |
| Самоповреждение без цели (ремонт отложен, здание сгорело) | −10 |
| Преждевременное отступление (бой при HP > 70%) | −30 |

**Ранги:** Каменщик → Страж Порога → Несокрушимый Бастион → Живой Фундамент → Оплот Реальности → Аватар Основы.

## 5. Финальная идея системы

Престиж — **единственное зеркало**: каждая операция с юнитом, постройкой, ресурсом и каждый поступок либо добавляют очки, либо списывают их. Никаких скрытых шкал — только арифметика стиля.

- **Искра** зарабатывает скоростью и теряет её от застоя.
- **Время** зарабатывает точностью и теряет от спешки.
- **Равновесие** зарабатывает мерой и теряет от перекоса.
- **Первозданность** зарабатывает ростом и теряет от паники.
- **Тень** зарабатывает тишиной и теряет от шума.
- **Гармония** зарабатывает единством и теряет от раздора.
- **Цикл** зарабатывает принятием потерь и теряет от страха перед ними.
- **Основа** зарабатывает стойкостью и теряет от нетерпения.

Знаки различаются не силой, а **языком, которым они говорят с игрой**: один кричит, другой ждёт, третий шепчет, четвёртый молчит и стоит. Матрица показывает этот язык целиком — а престиж следит, чтобы вы говорили на нём без акцента.
