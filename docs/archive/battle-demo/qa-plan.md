## Что покрывают автоматические тесты (главные инварианты)

- **Бою не нужен дисплей** — бой прогоняется до конца без сцены; тест границ
  слоёв ловит `DisplayServer`/`Node2D` в `scripts/combat/`.
- **Шаг за шагом** — весь бой проходит только вызовами `next_round()`; ни один
  тест не поднимает таймер (`test_stepwise_only.gd`).
- **Детерминизм** — один seed и один набор дают одинаковую последовательность
  раундов; смена seed меняет ход боя.
- **Инварианты набора** — состав, суммы стоимости, отсутствие дублей; битый
  `.tres` — отказ загрузки с именем файла, а не молчаливый пропуск.
- **UI синхронен модели** — после каждого действия полоса порядка, панель
  персонажа и гекс-подсветка пересчитаны из `CombatState`, а не «догоняют»
  (регрессии 10.12/10.13/10.14 держатся тестами).
- **Клик по гексу = выбор цели** — попадание по спрайту, а не по рамке
  карточки (10.16).
- **Павший снят с игры во всех местах одновременно** — полоса пуста, крест
  стоит, спрайт обесцвечен тем же сигналом, карточка ушла из порядка (10.15,
  10.20, `test_dead_units_leave_the_order_strip`).
- **Команды не лезут за кадр и не перекрывают поле** — права кнопок ≤ ширины
  кадра, левый край за последним силуэтом поля, текст влезает в кнопку (10.17,
  10.19).
