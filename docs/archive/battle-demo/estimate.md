# Estimate — battle-demo

Оценка времени агента (активная работа). Серверное время генерации — отдельной
строкой, оно не суммируется с активной работой: очередь ComfyUI идёт фоном.

| Фаза | Работа | Оценка |
| --- | --- | --- |
| 0 | Контракт агента, `known-issues.md`, `agent-skills.md` | 1.0 ч |
| 1 | Каркас: `project.godot`, GdUnit4, `run_tests.sh` | 1.0 ч |
| 2 | ADR ×4, архитектура, глоссарий | 1.5 ч |
| 3 | Арт-библия, бриф, UI-спека, ассет-спека, три отчёта | 2.0 ч |
| 4 | Боевое ядро + тесты (очередь, урон, статусы, ИИ, детерминизм) | 4.0 ч |
| 5 | Данные девяти юнитов и двух наборов + тесты | 1.5 ч |
| 6 | Спека генерации, очередь, прогон, аудит, итерации | 2.5 ч |
| 7 | Keying, нарезка 180 кадров, нейминг, аудит, манифест | 2.5 ч |
| 8 | Анимации, синхронизация урона, разворот, тесты | 2.0 ч |
| 9 | UI трёх экранов, клавиатура, съёмка кадров, тесты | 4.0 ч |
| 10 | Дымовой прогон, балансировка, полный гейт, отчёты | 2.5 ч |
| 11 | `CHANGELOG.md`, коммит | 0.5 ч |
| **Итого** | | **≈ 25 ч** |

ТЗ оценивает 16–24 ч. Расхождение +1 ч объяснимо и принято до кода: в ТЗ не
было ни ИИ противника (найден на ревью, +тесты), ни входного `walk`
(+анимационный сценарий), ни отдельного аудита 180 кадров с отбраковкой.
Сокращать за счёт тестов или аудита нельзя — это единственная верификация.

## Стена (wall clock), отдельно от активной работы

| Операция | Время | Параллельно коду? |
| --- | --- | --- |
| 45 генераций `flux-3-t2i` (серия) | ≈ 1–1.5 ч | да |
| Повторные генерации отбракованных листов (бюджет ≤ 12) | ≈ 0.5–1 ч | да |
| `run_tests.sh` (GdUnit4, 0 → ~60 тестов) | 1–3 мин на прогон | нет |
| Съёмка 8 кадров UI (GUI-процессы по одному) | ≈ 5 мин | нет |

## Риск-премии (не заложены в сумму, а триггеры пересмотра)

- `turn`-листы не держат сетку чаще 30 % → упрощение до двух кадров + `flip_h`
  (экономит ~0.5 ч генерации, стоит 0.5 ч переделки).
- ComfyUI недоступен → фаза 6 блокируется целиком (см. `known-issues.md`);
  код фаз 4–5 и 9 пишется без ассетов, оценка не меняется.
