# Scope report — что вне объёма демо

Зафиксировано до кода, чтобы «а давай ещё» не входило через дверь полировки.

## Вне объёма (решение владельца, 2026-10-24)

| Позиция | Почему вне | Что пришлось бы добавить |
| --- | --- | --- |
| Аудио (музыка, удары, UI) | «Звук и playtest остаются отложенными — их нечем снять» (AGENTS.md) | микшер, 15–25 файлов, тест тишины; верифицировать нечем |
| Полировка (тряска, частицы, тайминги, замедление хода) | не входит в ТЗ; раздувает `battle_unit.gd` до нечитаемого | отдельный слой эффектов + регрессия синхронности |
| Сохранения | демо однократное, состояние живёт в экране | сериализация модели + миграция + тесты round-trip |
| Локализация | текст один экран подсказок; i18n-таблица ради 12 строк | `TranslationServer`, `.csv`, ключи везде |
| Мультиплеер | нет второго ввода и нет сети | команда-лог, разрешение конфликтов, транспорт |
| Девятый юнит игрока (`stormmage`) | занят ролью врага; иначе «наборы не идентичны» ломается | десятый персонаж и пересбор наборов |
| Движение по арене как действие | лома бы «одно действие за ход» и очередь | координаты, дистанции, зона поражения, новый UI |
| Анимация гибели | ADR-005 | +9 листов поз (+20 % GPU) ради кадров одного раза за бой |

## Граница, которую демо обязано соблюсти

Ни один пункт выше не появляется «случайно»: модель (`scripts/combat/`) не
полжна ссылаться на аудио, эффекты, сериализацию или сеть. Проверка — тест
«бой без сцены» (4.9) и grep по слоям.

## Что входит и выглядит как полировка, но является требованием

Синхронность состояния и отображения (9.8), недоступная способность с причиной
(9.6), читаемость по метрикам `ui-spec.md` (9.7) — это не украшение, а спека
`battle-demo-ui`.
