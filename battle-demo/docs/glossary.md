# Глоссарий — battle-demo

Один термин = одно определение. Спорное употребление правится здесь, а не в
коде.

| Термин | Определение |
| --- | --- |
| Персонаж | Один из девяти образов директории-источника. Единица арт-контракта. |
| Юнит | Персонаж в бою: экземпляр `UnitStats` с текущим HP и статусами. |
| Пул | Восемь юнитов, доступных игроку. Девятый персонаж в пул не входит. |
| Враг | Постоянный девятый персонаж, единственный юнит стороны противника. |
| Сторона | `player` (слева, идёт вправо) или `enemy` (справа, зеркало по `flip_h`). |
| Набор | Семь различных юнитов пула, выставляемых в бой: A = позиции 1–7, B = 2–8. |
| Инициатива | Число, определяющее место в общей очереди ходов (по убыванию). |
| Ход | Отрезок, в который активен ровно один юнит и выполняется ровно одно действие. |
| Действие | Атака, способность или пропуск. |
| Статус | Временный эффект с длительностью в ходах владельца. |
| Анимация | Одна из пяти: `idle`, `walk`, `attack`, `hit`, `turn`. |
| Лист поз | Один прогон генерации: сетка 2×2, из неё нарезаются 4 кадра анимации. |
| Кадр | PNG 512×512 с альфой, один из 4–8 кадров анимации. |
| Аудит | Машинная проверка файла (размер, альфа, сетка, имя, дубликат). |
| Приёмка | Визуальный вердикт read-агента по чек-листу, с сохранённым отчётом. |
| Read-агент | Свежая сессия `pi -p --no-tools --no-session`, получающая кадр и чек-лист. |
| Итерация | Пара «правка → повторная проверка» по одному файлу. Потолок — три. |
| Вердикт | `pass` / `fail` + отклонения + рекомендация. Без него файл не принят. |
