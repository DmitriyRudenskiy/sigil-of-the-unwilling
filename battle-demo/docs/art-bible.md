# Art bible — battle-demo

Канон основного проекта (`docs/13-art-bible.md`, семейства A/B2/B3/C/D) —
только чтение. Здесь — то, что меряется на девяти кадрах демо.

## Формат

| Параметр | Значение | Как меряется |
| --- | --- | --- |
| Кадр | 512×512, PNG, альфа | `audit_sprites.py` |
| Pivot | низ-центр | расчёт по альфа-маске, сценарий «разворот не меняет pivot» |
| Заполнение кадра | 78–92 % высоты, 60–90 % ширины | альфа-бокс |
| Отступ от края | ≥ 4 px со всех сторон | альфа-бокс не касается края |
| Контур | один тёмный, толщина 3–5 px в масштабе кадра | приёмка |
| Свет | один ключевой источник, сверху-слева, 45° | приёмка |
| Палитра | приглушённая, насыщенность ≤ 60 %, базовый тон тёмный | гистограмма + приёмка |
| Фон | чистый белый (снимается keying-ом) | доля белого в рамке 24 px ≥ 60 % |

## Стилевой контракт девяти

Общее: тёмное фэнтези, «уставшее» воинство, заметная рука (видимый штрих),
без глянца и без фотореализма. Персонажи различимы **силуэтом** на масштабе
арены: разная масса тела, разное оружие, разный головной убор.

Отклонения, которые приёмка не принимает: лишний персонаж в кадре, обрезанный
силуэт, белый фон съеден тенью, разный масштаб между персонажами, разворот
без смены направления корпуса (`turn` обязан показывать поворот, а не четыре
одинаковые позы).

## Что здесь своё, а не из канона

Канон описывает юнитов основного проекта в их масштабе и на их фоне. Демо
берёт из канона семейства палитры и правило «силуэт важнее детали», но
фиксирует числовые допуски кадра (таблица выше) под 512×512 — в каноне их нет,
потому что там нет спрайт-листов этого формата.
