## Промпт-шаблон (один на всех, меняется только `<POSE>` и `<CHAR>`)

```
dark fantasy game sprite, single character <CHAR>, full body, standing on
transparent-ready pure white background, no shadow on ground, no text, no
frame, side view facing right, <POSE>, consistent character sheet pose,
painterly line art, muted desaturated palette, single light from upper left
```

`<CHAR>` — письменный анализ источника (кто нарисован, оружие, одежда, масса),
пишется в `queue`-запись до генерации и не меняется между анимациями.

## Позы по анимациям (одинаковы для всех девяти)

| Анимация | 4 кадра листа поз |
| --- | --- |
| `idle` | стойка, выдох, стойка, выдох (малая амплитуда, цикл) |
| `walk` | шаг вправо: правая нога вперёд → пронос → левая нога вперёд → пронос (цикл) |
| `attack` | замах → максимально раскрытая поза удара → **контактный кадр** → возврат |
| `hit` | отклонение назад → наклон вперёд с защитой → стабилизация → стойка |
| `turn` | корпус вполоборота к зрителю → пол-оборота → три четверти → лицом к противнику |

`attack`: контактный кадр — **третий** по счёту; синхронизация урона проверяется
по номеру кадра (задача 8.4). `turn` — самый рискованный лист (ADR-004): после
двух отказов упрощается до двух кадров + `flip_h`.

## Выходные файлы

```
assets/sprites/<id>/char_<side>_<name>_<anim>_<NN>.png   # 01..04, 512×512 RGBA
```

Имя кадра — ровно схема из спеки `battle-demo-sprites` (нейминг), `<side>` =
`player` | `enemy`, `<name>` = `id` из реестра выше. Другой схемы имён нет.
