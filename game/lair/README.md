# lair/ — Логово

Каталог для контента фракции **«Логово»** (монстры и нейтральные здания логова).

## Размещение данных по слоям (см. `docs/ARCHITECTURE.md`)

Сам каталог `lair/` — только контейнер для ассетов/контента. Логику и данные
разкладываем по уже принятым слоям, не храня их здесь:

- **Определения/константы** (характеристики монстров, определения зданий) → `data/`
  (регистры/defs по аналогии с `UnitRegistry.gd`, `BuildingDefs.gd`).
- **Логика мира** (спавн монстров в логовах, правила нейтральных зданий) → `world/`
  (по аналогии с `Borough.gd`, `City.gd`, `BoroughRules.gd`).
- **Юниты/стеки** → `entities/`.
- **Ассеты** (спрайты, иконки, анимации) → `assets/units/` / `assets/raw/`
  с префиксом имени (`lair_*`).

## Конвенция

- Имена файлов/папок — `snake_case` (ASCII).
- Классы с `class_name` — `PascalCase`, имя файла = имени класса.
- Готовый контент добавляем через тесты (`tests/`) и прогоняем `./run_all_ci_checks.sh`.
