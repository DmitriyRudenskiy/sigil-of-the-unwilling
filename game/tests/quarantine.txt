# Карантин нестабильных GdUnit-сюит (реестр изолированных файлов)
#
# Формат строки: `<подстрока пути><TAB><ГГГГ-ММ-ДД><TAB><причина>`.
# Подстрока — путь к файлу (или каталогу) относительно `game/` **без** `res://`
# (`tests/functional/test_x` — она режет и `source_file` раннера, и дерево в
# читателе полноты). Дата — последний день карантина, наступление утра красит
# прогон. Причина — связка с тикетом, что чинится.
#
# Красные случаи (проверяются `scripts/check_test_tiers.py` до запуска тестов):
# строка без даты/причины, истёкший срок, подстрока, не режущая ни один файл
# (опечатка в карантине маскируется под работающий карантин: `-i` не исключает
# ничего, а сюжет выглядит изолированным).
#
# До 2026-11-02 GdUnit-сторона карантина не имела носителя и нестабильные сюиты
# «лечились» редрайвом прогона (раунд 13 §4). Записи сюда вносятся вместе с
# тикетом; молча пустеть реестр не обязан — пустой реестр и есть «стабильно».
