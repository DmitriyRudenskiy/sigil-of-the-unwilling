# Массовый прогон — история (2026-10-16)

Заказ владельца: 60 персонажей очереди без остановок, затем повтор действия
рекурсивным обходом /Users/user/sigil-of-the-unwilling-slop. На персонажа —
три круга по трём моделям = 9 кадров (уточнение владельца).

## Устройство

- Лестница: P8 (база: светотень плоская между формами тени) → P9 (фактура:
  мазок внутрь больших плоскостей) → P10 (линия: внутренние линии на лицо и
  одежду). Одна строка словаря за круг; P каждого юнита стартует с базового
  состояния (idempotent, self-check в прогоне).
- Судья STY — свежая `pi -p --no-tools --no-session` с эталоном и кадром: тот
  же прибор, что слепые якоря. Девятка обязана прийти с названным
  расхождением (иначе движок режет в восемь — правило 9 сохранено).
- Повтори-гард, круг, потолок, журнал — движок jobloop, без обходов.
- Пол диска 2 ГиБ: прогон останавливается до кадра и пишет «СТОП».
- Intake: шлюз «один персонаж на простом фоне» + подпись одним вызовом;
  вердикты (включая отказы) — в sweep-intake.json, повторный обход не
  переспрашивает. Категория `loose`, истина юнита — его собственный квадратный
  кроп, лист-заглушка не эталон.
