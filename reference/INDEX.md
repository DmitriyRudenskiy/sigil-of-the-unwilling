## Почему не в git

В git из `reference/` входит только эта карта. Пиксели (≈13 МБ) в истории репо не нужны:
агент и фазы работают с ними как с эталоном глазами и через замеры, а не как с бинарём,
который грузит движок. Чтобы канон, живущий вне git, не стал недоказуемым, **каждая строка
карты несёт md5 файла**:

- дрейф пикселя виден по изменению строки в `git diff`;
- удаление файла — по удалённой строке;
- «что тут лежало до замены» — по истории этого файла.

Проверка карты с диском — `python3 scripts/check_reference_index.py` (локально, рядом с
`check_docs_links.py`; в CI-2 не добавлялась намеренно: CI работает по git-индексу,
пикселей в нём нет → чекер был бы вечно зелёным).
